# 课件文档统一排版（lesson-typeset）

**一份规范、一支入口命令、一套命名规则。** 不再按文档类型分章节，也不再区分「四套骨架」。

| 唯一权威 | 路径 |
|---|---|
| 规范 | `references/unified-spec.md` |
| 入口命令 | `scripts/typeset.py` |
| 内部渲染模块 | `scripts/renderers/`（不直接调用） |
| 课件导出工具 | `scripts/ppt2png.py`（PPT → `assets/ppt/pNN.jpg`） |
| 历史归档 | `.archive/2026-11-06/统一化前/`（7 份旧规范＋8 支旧引擎，可回退不引用） |

## 1. 排版前先读什么

只读 `references/unified-spec.md` 一份。里面第 1 章是**唯一常量表**，第 3 章是**唯一差分表**，
第 2.4 节是**表格判据**，第 2.5 节是**逐字稿自动配图**，第 4 章是**命名与防副本**，
第 5 章是**校验清单**。任何版式数字都不要从别处找，也不要拿另一类文档的数字来套。

三条硬性约定：

1. **基础层只有一个**：页面、字族、色板、字号、间距、框线、页眉页脚四类共用；差异只在四行参数档里。
2. **构件按需启用**：田字格、作答线、星级自评、台词分层、四列活动表、板书图是构件，不是独立版式标准。
3. **只调格式，不改文字**：成品字符多重集必须与源稿一致（自动表头除外）。

改任何版式参数前，仍走 **「先出效果 → 用户确认 → 再写进技能」**，不得边改边写。

## 2. 唯一入口命令

```bash
T=~/.workbuddy/skills/lesson-typeset/scripts/typeset.py
ROOT="<课题目录绝对路径>"

# ① 预览：只写 /tmp/lesson-typeset-preview/，课题目录零改动
python3 "$T" --root "$ROOT" \
  --input ".workbuddy/牛和鹅-教学设计-源.md" \
  --header "20 牛和鹅" --mode preview

# ② 确认后落地：同名原子覆盖，旧成品移入系统废纸篓
python3 "$T" --root "$ROOT" \
  --input ".workbuddy/牛和鹅-教学设计-源.md" \
  --header "20 牛和鹅" --mode commit

python3 "$T" --root "$ROOT" --dry-run    # 命名推导与配图探测
```

参数说明：

| 参数 | 行为 |
|---|---|
| `--root` | 课题根目录，缺省为当前工作目录 |
| `--input` | 源稿路径（相对 `--root` 或绝对路径） |
| `--profile` | **可省略**，由源稿名自动推导（教学设计／逐字稿／学习清单／制作笔记） |
| `--header` | 页眉课题名，省略时取课文标题 |
| `--mode` | `preview`（默认，只写 `/tmp`）／`commit`（落地课题目录） |
| `--images` | 显式指定课件截图目录（跨课题样张时用） |
| `--no-images` | 明确跳过逐字稿配图 |

**不接受 `--output`**。成品名一律由源稿名推导，引擎自动校验文件名。

**必须先出预览**：默认 `--mode preview`，把 docx 与总览图给用户看，得到确认后才加 `--mode commit`。
`renderers/` 是内部实现，不要直接 `python3 renderers/xxx.py`。

## 3. 命名与防副本（引擎强制）

```
<课文标题>[-<课时段>]-<内容类型>.<扩展名>
```

- 课文标题**不带编号数字**：`牛和鹅-教学设计.docx`，不是 `20牛和鹅-教学设计.docx`
- 课时段保留中文数字：`牛和鹅-第一课时-学习清单.docx`、`牛和鹅-第二课时-课件.pptx`
- 内容类型词表见规范 4.1；禁止书名号、空格、下划线、竖线，以及 `终稿／草稿／预览／V2／备份` 等状态词
- 源稿唯一：`.workbuddy/牛和鹅-教学设计-源.md`，同类型只一份

防副本五条：

1. 成品名自动推导，不接受手填 `--output`
2. 同课题同类型只有一个成品，重排原子覆盖，不加任何后缀
3. 覆盖前旧成品移入**系统废纸篓**（可恢复），不建 `versions/`、不建日期目录
4. 预览与总览图只写 `/tmp/`
5. 改内容直接改源稿，不留 `-删减前`／`-备份`

## 4. 表格判据（最常被问到的部分）

**表格只解决「对齐」，不负责「装饰」。** 这条判据全文档统一，不因文档类型切换。

| 用表格（仅四类） | 用段落 |
|---|---|
| ① 二维数据列对齐（四列教学活动 4∶7∶5∶4、对照表、三星自评）<br>② 格子／横线本身是作答载体（作答横线、田字格）<br>③ 页眉 Logo 区＋课题名左右分区<br>④ **图版**：板书设计图，需与上方活动表同框同宽 | ① 单行「标签＋一行值」→ 制表位对齐，无外框无竖线<br>② 只加底纹／边框的 1×1 装饰表 → 段落底纹／`w:pBdr`<br>③ **插图**：课件截图、配图 → 专用居中版式，无框线无缩进<br>④ 主标题、章节标题、长段落 |

**图版 vs 插图**（用户 2026-11-06 定）：板书图是版式结构的一部分，用单行通栏表
（20 格网格／`tblInd=170`／0.5pt `9BA9A0`），与四列活动表左右齐平；课件截图是独立内容，
居中 12cm、上下各 5pt、图注 9.5pt，脱了表就**不再保留表格的间距与对齐**。

脱表后必须给短标题加 `keepNext`，否则标题会孤悬页底；长正文不加，避免大留白。

## 5. 逐字稿自动配图（不得静默漏图）

- 源稿按 `## 第 N 页 · 标题｜时间` 分节；截图 `p01.jpg`、`p02.jpg`… 与页号一一对应
- 目录按课时段自动探测：第二课时 `assets/ppt-第二课时/` → `assets/ppt2/` → `assets/ppt/`；
  `assets/ppt2/` 兼容《长城》等历史课题
- **探测不到必须打印告警**并在回复里说明，不能静默交无图稿；只有 `--no-images` 才允许明确跳过
- 校验：N 页源稿 → 成品内嵌 N 张图，且第 N 张图与「第 N 页」标题同页

本课题若还没有截图，先用 `scripts/ppt2png.py --pptx 课件.pptx --outdir assets/ppt` 导出。

## 6. 每次排版后的校验

1. 文字零增减（对比源稿，加粗标记 `**` 正常剥离）
2. 文件名通过命名校验；课题根目录无同类第二个成品
3. 版式常量与规范第 1 章一致，参数档与第 3 章一致
4. 表格逐张核对用途，必须符合第 4 节判据；`tblInd=170`；四列活动行 `gridSpan=4,7,5,4`
5. 分页：无空白页、无孤图、无标题落页底；板书图版与标题同页
6. LibreOffice 转 PDF 出总览图目视，再比对页数
7. 逐字稿额外核对内嵌图片数与图文同页率
8. 逐字稿额外查**同类段落样式是否唯一**：所有 `师…` 行字号／缩进一致，所有 `生…` 行一致
   （`生（部分）：` 曾因白名单漏判掉进正文，见规范 2.6）；有第二种样式即为引擎缺陷，改正则不改源稿

用 `present_files` 打开**这一次排的那一份**，回复只讲这一份：页数、版式、做过的判断、
文字核验结果。不要顺手排同课其他文档。

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| 「课时主题」这类字段被排成带框线的表格 | 判据漏了：单行标签＋值应走制表位段落。检查 `table_v32.py` 的 `needs_table()` |
| 板书图看着像独立插图，与上方表格不对齐 | 应标为「图版」回表格；标题去掉自身下边线，由表格上框线分隔，避免双线 |
| 表格比标题色块向左突出约 3mm | 表格少了 `w:tblInd w:w="170"`；段落色块在 x=65.2，表格边框应同为 ~64.9 |
| 逐字稿没有课件截图 | 检查 `assets/ppt*/p01.jpg` 是否存在；入口会告警，不能用「本来就没图」搪塞 |
| 逐字稿某一页的学生台词比别处小、不加粗 | `style_of()` 没认这种行首标记（如 `生（部分）：`）；改正则为任意括号标注，别加白名单 |
| `row.cells` 数出 20 格、误判四列比例 | python-docx 按 `tblGrid` 展开；要数实际 `w:tc` 的 `gridSpan` |
| 出现 `预览／终稿／V2／备份` 文件 | 违反防副本规则，清理副本并用 `--mode commit` 重排一次 |
| 想用旧的 V2.0／V3.0 骨架 | 已归档，不再是权威；现行只有统一标准。确需追溯去 `.archive/`，不要点名启用 |
