# 课件文档统一排版（lesson-typeset）

**一份规范、一支入口命令、一套命名规则。** 版式细节只写在规范里，本文件只保留路由与不可丢的口径。

| 唯一权威 | 路径 |
|---|---|
| 规范（唯一） | `references/unified-spec.md` |
| 入口命令（唯一） | `scripts/typeset.py` |
| 内部渲染模块 | `scripts/renderers/`（禁止直接调用） |
| 课件导出工具 | `scripts/ppt2png.py` |
| 历史版本 | git 提交历史（技能目录不保留旧版副本） |

---

## 1. 开工前

1. 读 `references/unified-spec.md`：第 1 章常量、第 2.4 节表格判据、第 2.5 节自动配图、第 3 章参数档、第 4 章命名、第 5 章校验。版式数字不从别处找，也不拿另一类文档的数字套用。
2. 三条硬约束：基础层四类共用；构件按需启用；只调格式不改文字（成品字符多重集与源稿一致，自动表头除外）。
3. 改**版式参数**仍走「先出效果 → 用户确认 → 再写进技能」。此条只约束参数；交付落地按第 2 节直接执行。

---

## 2. 唯一入口命令

```bash
T=~/.workbuddy/skills/lesson-typeset/scripts/typeset.py
ROOT="<课题目录绝对路径>"

python3 "$T" --root "$ROOT" \
  --input ".workbuddy/牛和鹅-教学设计-源.md" \
  --header "20 牛和鹅" --mode commit
```

| 参数 | 行为 |
|---|---|
| `--root` / `--input` | 课题根目录／源稿路径（相对 root 或绝对路径） |
| `--profile` / `--header` | 均可省略，分别由源稿名、课文标题推导 |
| `--mode` | `commit`＝交付（落课题根目录、原子覆盖、旧版进废纸篓）；`preview`＝引擎缺省，只写 `/tmp` 自校验，**不是交付状态** |
| `--images` / `--no-images` | 显式指定截图目录／明确跳过配图 |
| `--dry-run` | 只打印命名推导与配图探测 |

- **交付必须显式 `--mode commit`**：本轮结束前正式成品须已在课题根目录；不停在 `/tmp` 预览、不等「确认落地」再补一步。预览产物用完即删。
- **不接受 `--output`**，成品名由源稿名推导并自动校验。
- 要调整就地改 `.workbuddy/<课文>-<类型>-源.md` 再重排覆盖，不建副本、不建预览版、不来回征询；只有判断不了风险的覆盖／删除／大改才先问用户。

---

## 3. 不可丢的口径

1. **命名**：`<课文标题>[-<课时段>]-<内容类型>.<扩展名>`；标题不带课文编号数字，课时段用中文数字；禁止状态词、版本号、空格、下划线、竖线。完整词表与防副本规则见规范第 4 章。
2. **表格**：只解决对齐，不负责装饰。仅四类可建表（二维列对齐／作答格子／页眉分区／板书图版），其余一律段落；图版与插图的区分见规范 2.4。
3. **配图**：逐字稿按页自动配图，探测不到素材必须打印告警并在回复里说明，不得静默交无图稿；只有 `--no-images` 可跳过。
4. **防副本**：同课题同类型只有一个成品，覆盖前旧版进系统废纸篓；不建 `versions/`、日期目录、备份包。
5. **交付形态**：只交 Word，不转 PDF、不出总览图。

---

## 4. 排版后

按规范第 5 章逐项校验（文字零增减、命名、常量与参数档、表格用途、分页、逐字稿内嵌图片数与同类台词样式唯一）。直接打开 docx 目视版式再比对页数，用 `present_files` 打开**课题根目录里这一次排的正式成品**；回复只讲这一份：页数、版式、做过的判断、文字核验结果。不要顺手排同课其他文档。

---

## 5. 排障速查

| 现象 | 处理 |
|---|---|
| 单行字段被排成带框线表格 | 判据漏判，查 `table_v32.py::needs_table()` |
| 板书图像独立插图、与上方表格不对齐 | 标为图版回表格，标题去下边线避免双线 |
| 表格比标题色块左突约 3mm | 表缺 `tblInd=170` |
| 逐字稿缺图／某页台词样式不一致 | 缺图查 `assets/ppt*/p01.jpg` 并告警；样式不一致改 `style_of()` 正则，不加白名单，也不改源稿 |
| `row.cells` 误判四列比例 | python-docx 按 `tblGrid` 展开，要数实际 `w:tc` 的 `gridSpan` |
