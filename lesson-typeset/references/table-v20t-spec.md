# 教学设计统一排版标准
**V2.0-T｜全表格式排版专用规范｜Skill执行版**

## 一、排版模式

### 1.1 基本形式

采用表格作为文档的主要排版结构。

支持以下形式：

- 整页表格式排版
- 分区块表格式排版
- 单列表格式排版
- 双列表格式排版
- 三列表格式排版
- 多列表格式排版
- 合并单元格式排版
- 纵向与横向混合表格排版

### 1.2 统一要求

1. 不固定表格数量、列数及行数。
2. 不强制所有章节使用相同表格结构。
3. 不强制使用固定的模块名称。
4. 不同类型的表格执行统一的字体、边框、内边距和间距规范。
5. 表格应随文字内容自动调整高度。
6. 不通过压缩字体、行距或内边距减少页面数量。
7. 所有表格必须位于正文版心内。
8. 页眉Logo及页脚独立于正文表格，不得被表格覆盖。

## 七、表格列宽规范

### 7.1 常见列宽比例

| 表格形式 | 推荐比例 |
|---|---|
| 单列表 | 100% |
| 标签＋内容 | 25% / 75% |
| 双列对照 | 50% / 50% |
| 三列均衡 | 33% / 34% / 33% |
| 三列活动布局 | 34% / 34% / 32% |
| 四列布局 | 25% / 25% / 25% / 25% |

以上比例为默认排版方案，并非强制固定比例。

### 7.2 列宽分配要求

- 根据单元格内的实际文字长度调整比例。
- 标题较短的列可以适当缩窄。
- 长文本列优先获得更多宽度。
- 同一张表格内列边界保持纵向对齐。
- 同类型表格尽量保持统一列宽。
- 不为保持等宽而制造过度拥挤的文字。

### 7.3 多列限制

A4纵向页面使用三列及以上布局时，必须确认有效文字宽度。

当列宽不足以正常容纳文字时，依次采用：

1. 调整列宽比例。
2. 允许文字自动换行。
3. 拆分过长的单元格内容布局。
4. 调整为纵向分块表格。
5. 必要时使用横向页面。

不得优先缩小文字字号。

## 九、单元格内部排版

**本章为强制执行标准。**

### 9.1 单元格内边距

| 方向 | 标准 |
|---|---|
| 左 | 3 mm |
| 右 | 3 mm |
| 上 | 2.5 mm |
| 下 | 2.5 mm |

最低限制：

- 左右不得小于2.5 mm。
- 上下不得小于2 mm。
- 文字、符号及图片不得触碰边框。

### 9.2 对齐方式

| 内容类型 | 水平对齐 | 垂直对齐 |
|---|---|---|
| 全宽分区标题 | 左对齐 | 居中 |
| 表头 | 居中 | 居中 |
| 字段名称 | 左对齐 | 居中 |
| 短文本 | 左对齐 | 居中 |
| 长文本 | 左对齐 | 顶部对齐 |
| 编号列表 | 左对齐 | 顶部对齐 |
| 数字 | 居中或统一右对齐 | 居中 |
| 图片 | 居中 | 居中 |

### 9.3 单元格行高

| 单元格类型 | 最小高度 |
|---|---|
| 一级分区标题行 | 13 mm |
| 二级分区标题行 | 12 mm |
| 普通表头行 | 12 mm |
| 单行字段 | 12 mm |
| 双行正文 | 15 mm起 |
| 多行正文 | 内容自适应 |
| 图片单元格 | 图片高度＋上下内边距 |

计算原则：

**行高 ≥ 内容实际高度＋上内边距＋下内边距。**

同一表格行内所有单元格的实际高度一致。

### 9.4 行高设置方式

- 默认使用“最小行高”。
- 不为长文本单元格设置固定行高。
- 不允许固定行高截断内容。
- 内容增加时行高自动增长。
- 不通过减小内边距解决行高问题。

### 9.5 单元格文字行距

| 项目 | 标准 |
|---|---|
| 正文字号 | 10.5 pt |
| 正文行距 | 1.3倍 |
| 单元格内部段前 | 0 pt |
| 单元格内部段后 | 2 pt |
| 列表项段后 | 2 pt |
| 字符间距 | 标准 |

- 单元格内正文默认不设置首行缩进。
- 普通长段落可统一采用2个汉字首行缩进，但同类单元格必须一致。
- 多行文字自然换行。
- 不使用连续空格模拟段落间距。
- 不出现行间文字重叠。

## 十二、三列表格专项排版

| 第一列 | 第二列 | 第三列 |
|---|---|---|

可根据实际文字量调整，但同一组表格应尽量保持列宽一致。

- 水平、垂直居中。
- 浅绿色背景。

- 楷体10.5 pt。

### 12.4 列间对应

- 同一行保持统一的实际高度。
- 不允许某一列的文字超出该列边界。

### 12.5 长文本处理

- 长文字按段落自然换行。
- 不强制每列具有相同行数。
- 不通过插入空行让三列文字底部对齐。
- 不使用固定行高制造大面积空白。
- 必要时将长文本拆分为连续的表格行。

- 不允许段落内容超出单元格边界。

---

## 十四、合并单元格规范

### 14.1 横向合并

- 合并后保留完整外边框。
- 删除被合并区域内部的竖线。
- 文字按照对应内容类型对齐。
- 保留标准内边距。
- 不因合并改变表格总宽度。

### 14.2 纵向合并

- 合并区域内文字默认垂直居中。
- 多行说明文字可采用顶部对齐。
- 不得因跨行合并造成相邻单元格错位。
- 不使用跨多页的纵向合并单元格。
- 合并区域内文字必须完整显示。

### 14.3 禁止事项

- 禁止无规律的大量合并。
- 禁止合并后出现多余边框。
- 禁止合并区域内部文字贴边。
- 禁止跨页合并导致文字消失或位置异常。

---

## 十五、表格分页与长内容处理

### 15.1 短行分页

当表格行能够完整放入一页时：

- 默认禁止跨页拆分。
- 当前页空间不足时整体移动至下一页。
- 不允许出现半行内容被截断。

### 15.2 超长表格行

当单行内容高度超过一页有效正文高度时：

- 不得继续强制“整行同页”。
- 优先将内容拆分为多个连续表格行。
- 不适合拆分结构时，允许该行按段落边界跨页。
- 跨页部分不得丢失文字或重复文字。
- 不允许内容延伸到页脚区域。

### 15.3 表头跨页

- 多页表格自动重复列标题行。
- 不重复无关的装饰性标题行。
- 表格标题与首行内容保持合理的同页关系。
- 表头不得单独留在页末。

### 15.4 长表格分段

- 可以按结构拆分为多个连续表格。
- 分段后保持列宽、边框、字体一致。
- 不使用手动空行填充剩余页面。
- 分段处不得出现双重外边框或重复留白。

---

## 十六、复杂表格与多层结构

### 16.1 混合列数表格

可通过合并单元格形成不同列数的行。

要求：

- 保持整表总宽度不变。
- 列边界遵循统一的网格基准。
- 不出现错位的竖线。
- 不因局部合并产生多余窄列。

### 16.2 嵌套表格

- 优先采用同一表格的行列合并实现。
- 只有确有必要时使用嵌套表格。
- 内层表格不得超出外层单元格有效宽度。
- 内层表格与外层边框保留不少于2.5 mm间距。
- 避免内外边框重叠。
- 嵌套表格的文字仍执行统一字号及内边距标准。

### 16.3 表格与图片混排

- 图片在单元格内居中。
- 保持原始宽高比。
- 图片与单元格边框保持安全距离。
- 图片说明与图片保持固定间距。
- 图片不得覆盖其他单元格文字。

### 16.4 大型表格

对于宽度较大或内容密集的表格：

- 优先调整列宽与结构。
- 允许拆分为多个表格。
- 允许独立使用横向页面。
- 不直接压缩字号。
- 不牺牲表格可读性控制页面数量。

---

## 十七、图片、流程图与板书图排版

### 17.1 图片单元格

| 项目 | 标准 |
|---|---|
| 图片最大宽度 | 不超过单元格有效宽度 |
| 图片对齐 | 居中 |
| 图片与边框距离 | 不小于3 mm |
| 图片缩放 | 等比例 |
| 图片说明字号 | 9.5 pt |

### 17.2 独立图片表格

- 可使用单列表格承载图片。
- 表格宽度与正文版心一致。
- 根据图片比例调整行高。
- 图片不强制拉伸填满单元格。
- 不允许图片被单元格边框裁切。

### 17.3 流程图

- 图形内部文字不小于9.5 pt。
- 同类图形尺寸统一。
- 连接线粗细一致。
- 图形之间保持合理距离。
- 不出现连线与文字重叠。
- 超宽流程图允许采用横向页面。

---

## 十八、横向表格页面

### 18.1 使用规则

- 仅对需要横向空间的部分使用横向页面。
- 其他页面继续采用A4纵向。
- 横向页面使用独立分节。
- 横向页面结束后恢复原纵向设置。

### 18.2 统一要求

- 页眉Logo区域不变。
- 字体字号不变。
- 表格边框规范不变。
- 单元格内边距不变。
- 页码连续。
- 不出现额外空白页。

---

## 十九、页脚与页码

| 项目 | 标准 |
|---|---|
| 页码格式 | 阿拉伯数字 |
| 页码位置 | 页脚居中 |
| 字体 | 楷体 |
| 字号 | 9 pt |
| 颜色 | `#666666` |
| 页脚距底端 | 10 mm |

- 页码连续。
- 不因表格跨页而重新编号。
- 不允许页脚进入表格内容区域。
- 横向页面与纵向页面保持相同的页码规则。

## 二十、样式管理规范

### 20.1 统一样式

表格式教学设计应建立以下可复用样式：

| 样式名称 | 对应格式 |
|---|---|
| 表格文档标题 | 主标题 |
| 表格文档副标题 | 副标题 |
| 表格一级分区 | 全宽一级分区标题 |
| 表格二级分区 | 全宽二级分区标题 |
| 表格课时标题 | 课时标题 |
| 表格环节标题 | 环节标题 |

| 表格字段名称 | 字段名称 |
| 表格正文 | 单元格正文 |
| 表格编号列表 | 单元格列表 |
| 表格图片说明 | 图片说明 |
| 页眉Logo | Logo显示区域 |
| 页眉占位 | Logo占位框 |
| 页脚 | 页码及页脚文字 |

### 20.2 样式执行

- 相同类型单元格使用相同样式。
- 不逐个单元格手动重复设置格式。
- 不因章节变化改变表格基础参数。
- 新增模块复用已有样式。
- 表格新增行自动继承对应格式。
- 表格新增列应沿用已有边框、内边距与字号标准。

### 20.3 表格布局属性

- 表格总宽度采用固定值。
- 列宽采用明确比例或固定宽度。
- 表格行高采用最小值，不设置不必要的精确固定高度。
- 正文单元格启用自动换行。
- 不启用导致文字被裁切的固定高度设置。
- 不允许表格根据内容自动超过版心。

## 二十一、DOCX与PDF导出规范

### 21.1 DOCX

- 保留真实表格结构。
- 保留合并单元格。
- 保留统一的单元格内边距。
- 保留可自动增长的行高。
- 保留表头重复属性。
- 保留正确的分页控制。
- 保留可替换的Logo或占位框。
- 不使用空格字符模拟表格。

### 21.2 PDF

| 项目 | 标准 |
|---|---|
| 纸张尺寸 | A4 |
| 页面比例 | 100% |
| 表格边框 | 完整、连续 |
| 字体 | 正确嵌入或可靠保留 |
| 文字 | 不重叠、不截断 |
| 图片 | 清晰、不变形 |
| 页码 | 连续 |
| Logo | 显示正确 |
| 占位框 | 按对应文件版本显示 |

### 21.3 版式一致性

- DOCX与PDF保持相同的页面顺序。
- 表格列宽保持一致。
- 合并单元格位置保持一致。
- 不出现字体替换导致的溢出。
- 不出现导出后新增空白页。
- 不出现表格边框丢失。
- 不出现单元格文字错位。

## 二十三、格式冲突处理优先级

当排版条件发生冲突时，按照以下顺序处理：

1. **页面安全边距**：任何内容不得超出可用版心。
2. **Logo及页眉**：保持Logo预留区域和页眉位置不变。
3. **文字完整性**：所有文字必须完整显示。
4. **最小字号**：不得通过过度缩小文字解决布局问题。
5. **单元格内边距**：必须保留规定的文字安全距离。
6. **表格结构**：保持行列对应和边框完整。
7. **分页完整性**：避免单元格裁切、错误跨页和内容丢失。
8. **页面美观性**：在满足前述要求后调整留白与视觉平衡。

发生冲突时，优先采用增加行高、调整列宽、拆分表格或增加页面的方式解决。

## 二十四、最终执行要求

1. 采用A4页面，默认纵向。
2. 正文表格宽度统一为164 mm。
3. 页眉固定预留30 × 12 mm的Logo区域。
4. Logo缺失时使用统一占位框。
5. 标题采用思源黑体，正文采用楷体。
6. 整体表格采用统一边框及色彩规范。
7. 单元格左右内边距3 mm、上下2.5 mm。
8. 行高根据内容自动增长。
9. 长文本单元格顶部对齐。
10. 不强制固定列数、行数或模块数量。
11. 支持单列、双列、三列及多列组合布局。
12. 支持不同形式的单元格合并。
13. 跨页表格重复表头。
14. 超长表格行不得被裁切。
15. 宽表格可以使用独立A4横向页面。
16. 页码保持连续。
17. 不通过缩小字号或内边距强行控制页数。
18. DOCX和PDF均应保持表格结构完整、清晰和一致。

**统一原则：整表宽度固定、列宽合理、内边距准确、行高自适应、边框统一、文字完整、跨页规范、Logo位置固定。**
