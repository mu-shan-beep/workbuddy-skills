# 学生学习清单 排版规范（统一标准 V2.1）

本文档是学习清单**唯一**的版式来源。引擎 `scripts/xuexqingdan_typeset.py` 顶部常量与本文档一一对应；
本文档不引用教学设计、逐字稿的任何参数，反之亦然。

排一份新学习清单：内容全写在 Markdown 源稿里，跑一条命令，脚本不动。

```bash
python3 ~/.workbuddy/skills/lesson-typeset/scripts/xuexqingdan_typeset.py \
    --input 学习清单_第一课时.md \
    --header "23 王戎不取道旁李" \
    --output 23王戎不取道旁李-学习清单.docx
```

## 1. 页面

| 项 | 值 |
|---|---|
| 纸张 | A4 纵向（210 × 297mm），背景纯白，缩放 100% |
| 上 / 下边距 | 各 16mm |
| 左 / 右边距 | 各 18mm（单面，默认） |
| 版心宽 | **174mm** |
| 双面装订（`--mirror`） | 内侧 20 / 外侧 18mm，奇偶页镜像；版心 172mm |
| 页眉距 / 页脚距 | 9 / 8mm |

版心是硬边界：任何段落、表格、图片、田字格都不得越出。双面与单面**不混用**，一份文档只用一种版心。

## 2. 字体与字号

| 层级 | 字体 | 字号 | 字重 | 颜色 |
|---|---|---|---|---|
| 主标题 | 思源黑体 | 17 | 加粗 | `#315A4B` |
| 一级标题（标题栏内） | 思源黑体 | 12.5 | 加粗 | `#315A4B` |
| 二级标题 | 思源黑体 | 11.5 | 常规 | `#315A4B` |
| 正文 | 楷体 | 11 | 常规 | `#2B302C` |
| 表格表头 | 思源黑体 | 11 | 常规 | `#2B302C` |
| 表格正文 | 楷体 | 11 | 常规 | `#2B302C` |
| 辅助文字（提示、自评） | 楷体 | 10.5 | 常规 | `#596960` |
| 页眉 / 页脚 | 楷体 | 9 | 常规 | `#596960` |

全篇**只用两种字体**。同一层级字号、字重恒定。

**字体缺失时的统一替换**：引擎启动时读 `fc-list :lang=zh family`，按下列顺序取本机真实存在的字族，
取到哪一个就全篇统一用哪一个，不做局部混用：

- 标题：思源黑体 → 思源黑体 CN → Source Han Sans SC/CN → Noto Sans CJK SC → Noto Sans SC → PingFang SC → 微软雅黑 → Microsoft YaHei → Heiti SC → 黑体 → SimHei
- 正文：楷体 → KaiTi → Kaiti SC → STKaiti → 楷体_GB2312

引擎在生成后打印实际使用的两个字族。需要强制指定时用 `--font-head` / `--font-body`。

|---|---|

| 正文 | `#2B302C` |
| 辅助文字 | `#596960` |

不使用渐变、底色块装饰、艺术字；黑白打印时各级文字仍有明度差。

## 4. 标题

**主标题**（`--title` 或「课题｜课时 学生学习清单」）：居中，17pt 加粗，行距 1.2，最多两行，下方 6mm 间距。

**一级标题（标题栏）**：左对齐，12.5pt 加粗，浅绿底 `#EDF3EE`，**栏高 12mm**（规范区间 11—13），
左右内边距 4mm，文字垂直居中，同级等宽等高。模块之间 7mm。

标题栏用 1×1 表格实现（段落底纹在 LibreOffice 里会被行距压塌成一条细线）；
标题栏单元格段落 + 其后的间隔段都设「与下段同页」，保证标题栏不会孤悬页底。

**二级标题**：左对齐，11.5pt 常规，与正文间距固定，无装饰线、无图标。

**页眉页脚**：9pt `#596960`；页眉为四类统一的 Logo 区（左 30×12mm `木老师原创课件` 虚线占位框 ＋ 右文档标题，思源黑体 ＋ 0.5pt `#CBD5CD` 分隔线），全页生效；
页码居中，首页也排，全文一致。

## 5. 段落与间距

| 项 | 值 |
|---|---|
| 正文行距 | 1.4 倍 |
| 标题与正文 | 4mm |
| 段落之间 | 3.5mm |
| 同级项目之间 | 4.5mm |
| 模块之间 | 7mm |
| 首行缩进 | 不缩进 |
| 对齐 | 左对齐，同级左边界一致 |

不用空格模拟缩进；中文标点不出现在行首；不出现文字裁切、遮挡、溢出。

## 6. 表格

| 项 | 值 |
|---|---|
| 宽度 | 与版心等宽（单面 174mm / 双面 172mm），居中 |
| 边框 | 外框 0.75pt、内框 0.5pt，实线，`#9BA9A0` |
| 表头底色 | `#EDF3EE`；其余单元格白色 |
| 单元格内边距 | 左/右 3mm，上/下 2.5mm |
| 行高 | 单行 12mm（`atLeast`，内容多则自动增高） |
| 表头 | 思源黑体、水平垂直居中、跨页重复 |
| 数据文字 | 楷体、左对齐、垂直居中、行距 1.3 |

**列宽比例**：两列 30/70；四列 28/24/24/24；三列均分。同表同用途列等宽。

**跨页**：表头行重复（`tblHeader`）+ 行内段落设「与下段同页」，表头不单独留页底；
数据行 `cantSplit`，不拆行；表格前后的间隔段都设「与下段同页」。

**实现要点（改引擎时别踩）**：`tblW`、`tblGrid/gridCol`、每个 `tcW` 三者必须逐列一致，
只写其中一个时 Word 会把列拉平。`trHeight` 必须带 `hRule="atLeast"`，只给 `val` 会被忽略。

## 7. 填写横线

真实线段，不是下划线字符；0.75pt 实线 `#9BA9A0`；同组等长；三四年级行距 **10mm**（规范区间 9—11）。

两种形态：
- 「标签 + 横线」：标签格无边框、右对齐紧贴线段起点；作答格只有下边框，线段从标签右侧起，不穿字。
- 纯空行：整行到底边框。

多行横线用**一张无边框表**逐行给下边框——相邻段落画同样的底边框时，Word 和 LibreOffice 会把它们
合并成一条线，表格不会。

## 8. 复选框与符号

`□` 用 12pt 楷体渲染（约 4.2mm 见方，规范要求 4—5mm）；符号与文字间距 2mm 左右，相邻选项间隔两个全角空格（≥5mm）；
同类符号大小一致、同组基线一致。

## 9. 田字格

| 项 | 值 |
|---|---|
| 单格 | 18mm 正方形（规范区间 18—20） |
| 相邻格间距 | 3.5mm（规范区间 3—4） |
| 外框 | 0.75pt 实线 `#9BA9A0` |
| 中心横竖 | 0.5pt 虚线 `#B5C7B9` |
| 对角辅助线 | 0.45pt 虚线 `#B5C7B9` |
| 范字 | 楷体，`#2B302C`，格内水平垂直居中，不触碰外框 |
| 每字格数 | 1 个范字 + 3 个练习格（`:::grid 戎 竞 4` 可改） |

每字一行：左列字头（11.5pt 深绿，垂直居中），右列格子图（300dpi 位图，宽度按格数换算）。
整块用一张无边框表组织，行不跨页。

## 10. 学习评价

统一三星：`☆☆☆` 能独立完成 / `☆☆` 借助提示完成 / `☆` 还需继续练习。
项目 3—5 项，与课堂任务一一对应。评价表为四列：评价内容 46%、三个等级各 18%，符号居中。

## 11. 分页

- 标题栏不孤悬页底；表头不与数据行分离；表格数据行不拆；一题不跨页。
- 不压缩字号、行距、内边距来强行减页。
- 不出现意外空白页；末页不留大片空白（内容自然结束即可，不为凑页删内容）。

## 12. 交付与打印

PDF 或 docx 均可；A4、100%、字体正确嵌入、边框完整、黑白打印可辨、双面打印边距正确。

## 13. Markdown 源稿语法

| 写法 | 渲染 |
|---|---|
| `# 课题` | 只作页眉 / 标题素材，不进正文 |
| `## 第一课时　学生学习清单` | 含「清单」二字 → 主标题素材，与 `#` 拼成「课题｜课时 学生学习清单」 |
| `## 任务一　读准字音` | 一级标题栏（浅绿底块） |
| `### 1. 给下面的字注音。` | 二级标题（11.5pt 深绿，不加粗） |
| `#### xxx` | 三级标题（11pt 深绿） |
| 普通段落 | 正文 11pt 楷体，支持行内 `**加粗**` |
| `- xxx` | 正文行（与段落同级） |
| `> 课文原句` | 引文（楷体，`#315A4B`） |
| `:::tip 提示语` | 辅助文字 10.5pt `#596960` |
| `:::blank 标签A：\|标签B：` | 一行多组「标签 + 填写横线」 |
| `:::lines 3` | 3 条纯填写横线（间距 10mm） |
| `:::check 能复述\|能背诵` | `□` 勾选项 |
| `:::grid 戎 竞 诸 唯 4` | 田字格；末位数字为每字格数，省略则 4 |
| `:::stars 能读准字音\|能说清依据` | 四列三星评价表；不带参数时降级为一行文字提示 |
| `:::pagebreak` | 硬分页 |
| `\| a \| b \|` 连续行 + 分隔行 | 数据表格，首行作表头 |

源稿里**不要**写页码、页眉、班级姓名行——标题区（主标题 + 班级/姓名/日期）由引擎统一生成。
