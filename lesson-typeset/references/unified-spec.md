> `references/*.md` 已全部归档到 `.archive/2026-11-06/统一化前/references/`，

## 0. 适用范围与五条原则

适用：教学设计、逐字稿、学习清单、制作笔记，以及后续同类课件文档的 docx 排版。

1. **基础层只有一个**：页面、字族、色板、字号、间距、框线、页眉页脚，四类文档共用第 1 章这一张表；任何地方不得再写第二份数字。
2. **差异只剩参数档**：页边距、主标题字号、独有构件的启用与否，全部收进第 3 章的四行差分表；表外不允许出现「某类文档另有一套颜色／字号」。
3. **构件按需启用**：田字格、作答线、星级自评、台词分层、四列活动表、板书图等属于构件库（第 2、4 章），不是独立的版式标准；哪个文档用哪个，由参数档决定。
4. **表格按功能判断，不按文档类型、也不按「原来有没有框线」死套**：技能只固化判据（第 2.4 节）和可复用构件，具体某块用表还是用段落由判据推出。规则是提效工具，不是让引擎照抄的清单。
5. **改动流程不变**：任何版式参数变更仍须「先出效果 → 用户确认 → 再写进本文件与 `typeset.py`」，不得边改边写进技能。

只调格式，不改文字。版式参数全部固化为常量，不每次重新设计。

## 2. 统一构件库与源稿语法

源稿是 Markdown；块级构件一律用 `:::xxx` 起头，行内用 `**加粗**`。

### 2.1 文字块

| 语法 | 渲染 |
|---|---|
| `# 标题` | 文档主标题，字号取参数档 `fs[0]` |
| `## / ### / ####` | 一级／二级／三级标题，一级字号取参数档 `fs[1]` |
| 普通段落 | 11pt、1.45、首行缩进 2 字（表格内不缩进） |
| `- xxx` / `- [ ] xxx` | 一律转阿拉伯数字序号，与相邻项连续编号 |
| `:::subtitle` | 副标题 10.5pt |
| `:::label` / `:::caption` | 模块标签 / 图注表题 |
| `:::tip` / `:::check` / `:::blank` | 提示块 / 勾选框 / 留白 |
| `:::pagebreak` | 强制分页 |
| `**标签：** 值` | 制作笔记的字段行：制表位对齐（值列 3.3cm），换行与值左缘齐平，标签加粗 |

### 2.2 表格块

| 语法 | 渲染 |
|---|---|
| Markdown 标准表格 | 全框线数据表：外 0.75／内 0.5pt，浅绿表头居中 |
| 表头行全空的 Markdown 表格 | **无表头的作答网格**（如「线索／疑问／补记」三行填空），不画浅绿表头行 |
| `:::act` | 四列教学活动行（`T:` 教师 / `S:` 学生 / `D:` 设计意图），比例 4∶7∶5∶4 |
| `:::lines N` | N 行填写横线，行距 10 mm；横线本身是作答载体，属第 2.4 节第 ② 类 |
| `:::grid` / `:::stars` | 田字格 / 四列三星自评表，属第 2.4 节第 ② 类 |
| `:::row` / `:::row2` | **字段行**：单行「标签＋值」，按第 2.4 节判据走**段落制表位**（5/10/15 格），不建表；仅当确有多组字段需要二维对齐时才成表 |
| `:::colw 50 50` | 覆盖下一张表的列宽比例；本次不成表时不生效 |

用不用表格一律按第 2.4 节判据，不按「有没有框线」判断。确需用表的表格整体写
`w:tblInd w:w="170"`（3mm），使表格边框与段落底纹、文字左边缘齐平。

### 2.3 特殊构件

| 语法 | 渲染 |
|---|---|
| `![](path)` | 图片，按原始比例缩放到版心内居中，上限 11 cm；可配 `:::caption`。归属「图版」还是「插图」按第 2.4 节判据自动判定 |
| `:::grid 字=栽,耸 格=4` | 田字格：18 mm 方格、内部十字虚线 `B5C7B9`、每字 1 范字＋3 练习格 |
| `:::stars 项目1,项目2` | 四列三星自评表 |
| 板书设计章节下的 `![](path)` | 板书图版：单行通栏表格，与上方教学活动表同框同宽 |

特殊构件只在声明了它的 profile 里可用；未声明时按普通段落处理，不报错。

### 2.4 表格使用判据（优先级高于任何 profile）

> 2026-11-06 用户反馈：「课时主题这些内容不应该使用表格吧，skill 只是辅助我们
> 提效，你也应该思考哪些使用表格合适，哪些不用合适」。
> 表格的价值是**让二维信息横向对齐**或**让格子本身成为作答载体**；只为装饰而建的表
> 让文档难编辑、也让「看教学活动」这件事变模糊。

**用表格（且只在这四种情况）**

| 情形 | 例子 |
|---|---|
| ① 二维数据需要列与列横向对齐 | 四列教学活动表 4∶7∶5∶4、对象/前后态度对照表、生字练写表、三星自评表 |
| ② 格子或横线本身是作答载体 | `:::lines` 作答横线、班级/姓名/日期填写线、田字格（格线是功能，不是装饰） |
| ③ 页眉左右分区 | 30×12mm Logo 预留区 ＋ 右侧课题名，共用 `build_header()` |
| ④ **图版**：需要与上方表格同框同宽、作为版式一部分的教学图 | 板书设计图。用单行通栏表格（20 格网格 / `tblInd=170` / 0.5pt `9BA9A0`），左右边缘与四列活动表齐平；标题仍用段落底纹，标题下边线省略，由表格上框线充当分隔 |

**用普通段落（一律不建表）**

| 情形 | 视觉替代 |
|---|---|
| 单行「标签＋一行值」（课题、作者、年级、课型、课时主题…） | 制表位对齐（5/10/15 格处），标签绿色、内容墨色，**无外框、无竖线** |
| 只给一块文字加底纹或边框（章节标题栏、note 强调块、辅助对照容器） | 段落底纹 `EDF3EE`；需要框时用 `w:pBdr` 段落边框，整块仍是一个段落组 |
| **插图**：课件截图、配图等独立图片 | **专用插图版式**：居中、上下各 5pt、图注 9.5pt `596960` 居中、无缩进无边框；不套用表格的内边距、行距、段前段后，也不与表格左右边缘强行对齐 |
| 主标题、章节标题、环节分区标题、长段落 | 底纹段落；分区标题加上下边线、`keepNext` 绑定下一段 |

> 关键区分：**图版是版式结构的一部分，要「和上面一致」；插图是独立内容，
> 要么完整进表、要么彻底用另一套版式，不能脱了表还留着表格的间距与对齐。**
> 2026-11-06 用户原话：「这个板书设计，应该和上面的一致，放进表格里，
> 不放表格就不要和表格使用一致的排版结构，设计一个合适的排版」。

**实现口径**：`scripts/renderers/table_v32.py` 里只保留一个 `needs_table(cells, opts)`
判据——四列表头／活动行、或显式标记 `figure_panel` 的板书图返回 True，其余行一律走
段落渲染器；段落渲染器提供 `shade_paragraph()` / `para_border()` / 制表位 /
`render_inset_figure()` 四种替代构件。**判据是全文档统一的，不因文档类型切换**；
只有「板书设计」章节下的图会被标成图版。

**脱表后必须补的分页约束**：标题与正文变成两个独立段落后，章节标题、小标题、
字段行都要 `keepNext`，否则标题会孤悬页底；只对短标题加，长正文段落不加，
避免整块被绑走产生大留白。

**《牛和鹅》实测**（2026-11-06 二次试排，文字零增减）：

| 文档 | 表格数 改前 → 改后 | 说明 |
|---|---|---|
| 教学设计 | 5 → 20 | 18 张环节四列表 ＋ 2 张板书图版；脱表的是基本信息／课时主题字段行、环节分区标题、辅助对照容器 |
| 第一课时学习清单 | 11 → 7 | 4 个 1×1 标题栏改段落底纹 |
| 第二课时学习清单 | 14 → 8 | 6 个 1×1 标题栏改段落底纹 |
| 制作笔记 | 2 → 0 | 2 个 note 强调块改段落底纹 |
| 逐字稿（长城样张） | 0 → 0 | 台词分层、逐页标题本来就是段落；16 张课件截图走插图版式（见 2.5） |

教学设计表格数变多，是因为原来把多个环节塞进 2 张大表；现在每个环节
一张自带表头的四列表，教学活动对齐不变、结构更好编辑。两张板书图回到
表格结构，与这些活动表共用同一套网格和框线。

### 2.5 逐字稿课件截图（自动配图，不得静默漏图）

> 2026-11-06 用户反馈：「逐字稿怎么没放图片」。根因不是引擎不支持，而是源稿
> 没有写 `![](path)`、派单时又漏传截图目录；引擎本来就有按页自动配图能力。
> 结论：**逐字稿没有配图属于缺陷，不是可选项；找不到素材必须显式告警。**

1. **对应关系**：源稿按 `## 第 N 页 · 标题｜时间` 分节，课件截图按
   `p01.jpg`、`p02.jpg` … 顺序命名，与页号一一对应；也接受 `png`／`jpeg`。
2. **目录约定**（统一入口 `resolve_images_dir()` 按课时段自动探测，优先级从高到低）
   - 第一课时：`assets/ppt-第一课时/` → `assets/ppt/`
   - 第二课时：`assets/ppt-第二课时/` → `assets/ppt2/` → `assets/ppt/`
   - `assets/ppt2/` 是《长城》等历史课题已有的第二课时目录，保持兼容不改名。
3. **不得静默**：探测不到截图目录时打印 `⚠️ 未找到课件截图目录`，仍出文字版但
   必须在回复里说明；跨课题样张可用 `--images` 显式指定，只有 `--no-images`
   才允许明确跳过配图。源稿里写了 `![](path)` 时优先用源稿路径。
4. **版式**：截图属于 2.4 节的「插图」——居中、上下各 5pt、图注 9.5pt
   `596960`、无边框无缩进，**不套表格**；默认宽 12cm（第 3 章参数档差分，
   版心 16.2cm 内），按原始比例缩放且不超过版心。
5. **校验**：N 页源稿 → 成品内嵌 N 张图，且第 N 张图与「第 N 页」标题同页；
   文字零增减，图不压页脚。

《长城·第二课时》样张实测：16 张截图全插入，7 页 → 12 页，16 组图文同页率
100%，统一入口与试排入口产物逐部件一致（35 个 zip 部件零差异）。

### 2.6 逐字稿行首标记（分层只认这几种，括号标注不限）

> 2026-11-07 事故：源稿写了 `生（部分）：不能。`，`style_of()` 只白名单了 `生（齐）`，
> 该行被判成正文，11pt／不加粗／首行缩进，成品同一页出现两种学生台词样式。

判定规则（`zjg_typeset.py::style_of`）：

| 行首 | 段落类型 |
|---|---|
| `师：`、`师（指名）：`、`师(板书)：` | 教师台词（同档字号与悬挂缩进） |
| `生（齐）：`、`生（部分）：`、`生（全体）：`、`生：` | 学生台词 |
| `〔操作〕`、`〔板书〕`、`〔学生可能说〕`、`〔停顿〕` | 提示类，灰阶弱化 |

- 括号内**任意短标注**（≤8 字、中英文括号皆可）都归为对应角色，不再逐个白名单。
- 标记与台词之间**必须有冒号**（`：` 或 `:`）。`生（部分）不能。` 无冒号仍会落进正文，
  由 `lesson-transcript` 的 `[标记]` 规则先拦。
- 新增角色或标注形式时改 `style_of()` 的正则，不要在白名单里添词。

## 4. 命名与输出规范（防副本）

### 4.1 文件名骨架

```
<课文标题>[-<课时段>]-<内容类型>.<扩展名>
```

- **课文标题不带课文编号数字**，写 `牛和鹅-教学设计.docx`，不写 `20牛和鹅-教学设计.docx`
- 课时段仅在分课时的类型里出现：`第一课时` / `第二课时`（中文数字，不是阿拉伯数字）
- 内容类型词表：教学设计、课件、逐字稿、学习清单、作业设计、评价量表、资料卡、
  微课、互动课件、板书设计、说课稿、教学反思、单元教学设计、制作笔记
- 禁止：阿拉伯数字、书名号、引号、空格、下划线、竖线；以及 `终稿／草稿／预览／
  待确认／自用版／设计版／标准版／优化版／修复版／_V2／备份／副本` 等状态与版本词

### 4.2 各类文件的固定落位

| 类别 | 位置与命名 |
|---|---|
| 交付成品 | 课题根目录，`牛和鹅-教学设计.docx` 等 |
| 源稿 | `.workbuddy/牛和鹅-教学设计-源.md`（同类型只一份） |
| 制作笔记 | `.workbuddy/牛和鹅-制作笔记.docx`（规范标注不交付） |
| 素材 | `assets/牛和鹅-图片-01.jpg`、`牛和鹅-音频-范读.mp3` |
| 教材原文 | `教材-牛和鹅.pdf` |
| 工作日志 | `.workbuddy/memory/YYYY-MM-DD.md` |
| 历史版本 | 技能目录 `.archive/`；课题目录**不建** `versions/`、不建日期目录 |

### 4.3 防副本六条（引擎强制）

1. **成品名由源稿名自动推导**，引擎不接受手填 `--output`；推导结果必须通过 4.1 的校验。
2. 同课题同类型**只有一个成品**，重排直接原子覆盖，不产生任何后缀文件。
3. 覆盖前把旧成品移入**系统废纸篓**（可恢复），课题目录内不留备份。
4. 预览与总览图只写 `/tmp/`，确认后才覆盖正式成品，不落盘到课题目录。
5. 源稿唯一：改内容直接改源稿，不留 `-删减前` / `-备份` 副本。
6. **不建备份（2026-11-06 用户裁定）**：课题目录与 `.workbuddy/` 内都**不建** `备份-<内容>-<日期>/`、`旧版/`、`草稿/`，也不打 `*.zip` 备份包。改内容直接改源稿、改二进制直接改原件；要回退靠系统废纸篓与技能仓库 git 历史。`/tmp` 的预览产物在任务收口时清掉，不留过夜。**拿不准风险时先问用户：「这次拉一份副本再改，还是直接在源文件上改？」** 等回答再动手；用户说"看着办"则按就地改。

### 4.4 唯一入口命令

```bash
# 预览（只写 /tmp，不动课题目录）
python3 ~/.workbuddy/skills/lesson-typeset/scripts/typeset.py \
    --root "<课题目录>" \
    --input ".workbuddy/牛和鹅-教学设计-源.md" \
    --header "20 牛和鹅" --mode preview

# 确认后落地（同名原子覆盖，旧成品进废纸篓）
python3 ~/.workbuddy/skills/lesson-typeset/scripts/typeset.py \
    --root "<课题目录>" \
    --input ".workbuddy/牛和鹅-教学设计-源.md" \
    --header "20 牛和鹅" --mode commit

python3 .../typeset.py --dry-run     # 只打印命名推导与配图探测结果
```

- `--profile` 可省略，由源稿名自动推导；`--header` 省略时取课文标题。
- 逐字稿自动探测课件截图目录；`--images` 显式指定，`--no-images` 明确跳过。
- `renderers/` 是内部实现，不直接调用；`ppt2png.py` 是把课件导出成 `pNN.jpg` 的独立工具。

## 5. 校验清单（每次排版后）

1. 文字零增减：成品字符多重集与源稿（含自动表头）一致，加粗标记 `**` 正常剥离。
2. 文件名通过 4.1 校验，课题根目录无同类第二个文件。
3. 基础层：色板、字号阶梯、内边距、框线宽度与第 1 章一致；参数档与第 3 章一致。
4. 结构：表格边框与段落底纹左右边缘齐平（各表都有 `tblInd=170`）；四列活动行
   `gridSpan=4,7,5,4`；`:::row2` 为 `5,5,5,5`（不算比例异常）。
5. **表格判据**：逐张核对表格用途，必须属于第 2.4 节四类之一；出现 1×1 装饰表、
   单行字段表即为漏判。**例外**：板书设计下的 1×1「图版」表是第 ④ 类，必须有
   `tblInd=170`、0.5pt 同色框线、与上方活动表左右齐平。
6. 分页：无空白页、无孤图、无标题落页底（标题段落有 `keepNext`）；板书图版与标题同页。
7. LibreOffice 转 PDF 目视总览，再与上一版比对页数与文字。
8. **逐字稿档已纳入**：`--profile 逐字稿` 可排，成品名按第 4 章推导；本课题暂无
   逐字稿源稿时不出成品，用别课现成源稿出样张验证引擎，不伪造内容。
9. **逐字稿配图**：按 2.5 节核对 `word/media/` 内嵌图片数 = 源稿页数，逐张图与
   对应「第 N 页」标题同页；无图时必须已经告警并说明原因，禁止静默交付。
