# 教学设计 / 逐字稿 / 学习清单 / 制作笔记排版（自用版）

本技能排四类文档，**每一类的排版规则完全独立**：页面网格、字族字号、骨架、表格与分页规则，只写在本类那一节和它对应的 `references/*.md` 里，任何一条规则都不跨类型复用。

| 文档 | 引擎 | 规范（该类唯一权威） |
|---|---|---|
| 教学设计·开放式（V2.0） | `scripts/jxsj_typeset.py` | `references/jxsj-spec.md` |
| 教学设计·表格式 | `scripts/table_layout.py` | `references/table-spec.md` |
| 逐字稿 | `scripts/zjg_typeset.py` | `references/zjg-spec.md` |
| 学习清单 | `scripts/xuexqingdan_typeset.py` | `references/xuexqingdan-spec.md` |
| 制作笔记 | `scripts/zhizuobiji_typeset.py` | `references/zhizuobiji-spec.md` |

四类文档的**页眉 Logo 区完全统一**：都是左 30×12mm 预留区（默认虚线占位框内写「木老师原创课件」9pt `#999999`、可换实图、可隐藏）＋ 右课题（思源黑体 9pt `#596960`）＋ 底边 0.5pt `#CBD5CD` 分隔线。`build_header` 只实现**一份**，在 `xuexqingdan_typeset.py`，其余引擎 `import` 复用——不要在各引擎里再各抄一份（那是之前漂移打架的根源）。

- 参数一律以该类的规范文件为准；本节**不汇总数值**——同一个数字写两处，改一处就打架。

## 防「规则打架」铁律（改版式前先读）

1. **每类文档只认自己的 `references/*.md`**：四类文档（含教学设计的两种骨架）的页面、字体、颜色、表格、分页**互不复用、互不引用**，换类型就换整份规范，绝不拿另一类的数字来套。
2. **spec 与脚本是同一套数字的两面**：`references/*.md` 是权威描述，`scripts/*.py` 顶部的常量（`M_*`/`FS_*`/`CONTENT_W`/`BORDER_*`/`RGBColor`）是代码化落地，两者必须同步改；以 `references` 为准，禁止只改脚本不改 spec、或反过来。
3. **底层 OOXML 构件只有一份**：schema 顺序、框线、行高、列宽等通用构件集中在 `xuexqingdan_typeset.py`，其余引擎 `import` 复用（`table_layout.py` 复用 `jxsj_legacy.py`）。要改这些通用逻辑，只改源头那一个文件，不要在各引擎里各抄一份——抄多份必漂移。
4. **技能根目录只放生效文件**（`SKILL.md` / `references/` / `scripts/` / `assets/`）；历史版本全部收进 `.archive/`，不要散落在根目录，避免把旧规范误当成权威。
- 教学设计的两种骨架也互不套用（边距、表格宽度都不同），换骨架就同时换规范。
- 排哪一份就只看哪一节，**不要拿另一类文档的版式做参照**。
- 制作笔记、逐字稿、教学设计（开放式）与学习清单共用同一套 OOXML 底层构件（都 import 学习清单引擎的 `_put / _tbl_borders / _set_row_h / set_col_widths` 等），但**版式常量各写各的**，不要互相套用。

## 一次只排指定的那一份

用户说排哪一份，就只动那一份：

- 只读该文档自己的源稿；不顺手检查、重排、重新生成同课的其他文件（教学设计／逐字稿／学习清单／制作笔记、第一课时／第二课时）。
- 不顺手为其他文档备料（渲染课件图、裁板书图、转格式）；这轮点不到的那份，一个字都不碰。
- 结论也只报这一份：页数、版式自检、改动点。不附其他文件的现状，不替用户安排下一份。
- 需要用户拍板的事（如逐字稿用哪种排列）只在排到那一份时才问。

版式参数全部固化为常量，不要每次重新设计。**只调格式，不改文字。**

教学设计默认用 **V2.0 开放式版式**（`jxsj_typeset.py`）；另有**表格式骨架**（整篇一张 4 列表，见过
《出塞教学设计》模板或用户要求「整体排版用一个表格」时用），不是默认方案，参数自成一套，见下文「表格式版式」。

## 何时使用

- 教学设计：给出教案内容（文本、Markdown、docx，或只给课题＋教材＋课时），要求排版／生成 docx
- 逐字稿：给出讲稿 + 对应课件 pptx，要求排成「上课能照着念」的稿子（页眉带 Logo 区）
- 学习清单：给出清单内容或课题＋课时，要求排成课堂配套练习纸
- 制作笔记：给出课件制作／使用笔记，要求排成说明性 docx
- 已有文档需要重新套版式

不适用：党政机关公文（用内置 `workbuddy-docx`）、内容从零创作（由写作类能力产出内容，本技能只负责版式）。

# 一、教学设计

## 规范来源

**全部版式参数只看 `references/jxsj-spec.md`（统一标准 V2.0）**。本节不复述数值——
同一个数字写在两处，改一处就打架。

V2.0 是纯排版规范（不固定章节、课时、模块结构），与旧自用版的关键差别：

| 项 | V2.0 口径 |
|---|---|
| 字体 | 标题思源黑体 + 正文楷体两种（旧版全文宋体） |
| 字号 | 18 / 14 / 13 / 12 / 11.5 / 11 / 10.5 / 9.5 / 9 |
| 边距 | 上 28、下 20、左右 23mm（版心 **164mm**）；`--mirror` 内侧 26 / 外侧 20，版心不变 |
| 页眉 | 左侧固定 30×12mm Logo 区（实图／虚线占位／隐藏留位）+ 右侧课题 + 0.5pt 分隔线 |
| 正文 | 楷体 11pt、**1.45 倍**、首行 2 字、左对齐、段后 3pt |
| 表格 | 六边全框线，外 0.75pt 内 0.5pt `#9BA9A0`，表头 `#EDF3EE`，内边距 3/3/2.5/2.5mm，行高 ≥12mm |
| 配色 | 主标题 `#222222`、一二三级标题用 `#315A4B`、正文 `#2B302C`、辅助 `#596960` |

## 第一步：取得内容并规范化

把源内容整理成**规范 Markdown**，写入临时 `.md` 文件。完整映射见
`references/jxsj-spec.md` §9，核心对应：

| Markdown | 含义 |
|---|---|
| `# 课题 教学设计` | 文档主标题 18pt 加粗居中 |
| `:::subtitle xxx` | 副标题 10.5pt 居中 |
| `## 一、xxx` | 一级标题 14pt |
| `### （一）xxx` | 二级标题 12pt |
| `### 第一课时：xxx` | 课时标题 13pt 居中（按「第X课时」自动识别） |
| `#### 环节一：xxx` | 三级标题 11pt；以「环节」开头自动升级为环节标题 11.5pt |
| `##### xxx` | 四级标题 11pt 楷体加粗 |
| `:::label 模块名` / 整行 `**模块名**` | 模块标签 10.5pt，缩进 4mm |
| 普通段落 | 正文 11pt 楷体，首行缩进 2 字符 |
| `1. xxx` | 有序条目，编号顶格、悬挂缩进 |
| `- xxx` / `- [ ] xxx` | **一律转阿拉伯数字序号**，与相邻项连续编号，不输出圆点或方框 |
| `\| 表 \| 格 \|` + 分隔行 | 网格表，首行作表头（浅绿底、六边框线） |
| `:::caption 表 1 xxx` | 表题 |
| `![图注](绝对路径)` | 图片 + 9.5pt 居中图注（alt 为空则不插图注） |
| `:::pagebreak` | 硬分页 |

**整理内容时的硬性要求：**

1. **一字不改**。不增删、不改写、不润色、不调整语序，只补结构标记。
2. 单元格内用 `<br>`、或按「；2.」的序号书写条目均可，脚本会自动拆成独立行。
3. **板书设计一律用图片**：用户提供实拍／截图照片，用 `![板书](绝对路径)` 插入，
   按版心宽 16.4cm 居中，不要手敲字符画重绘（引擎遇到 ```` ``` ```` 块会按纯文本
   降级并打 warn）。用户只给文字板书时先提示提供照片；明确要「先按文字排」才降级。
4. 缺失的章节（如「设计者」「日期」）留空占位，不编造。

## 第二步：一条命令

```bash
python3 ~/.workbuddy/skills/lesson-typeset/scripts/jxsj_typeset.py \
    --input draft.md \
    --output 17长城-教学设计.docx \
    --header "17 长城"
```

| 参数 | 说明 |
|---|---|
| `--header` | 页眉右侧文字，写课题名；页脚自动居中页码，从 1 连续 |
| `--title` / `--subtitle` | 覆盖主标题 / 副标题 |
| `--logo` | 品牌 Logo，等比缩进 30×12mm 区（高 ≤10mm，同时给宽高） |
| `--logo-mode` | 无 Logo 时：`placeholder`（默认虚线框 + 「木老师原创课件」）/ `hidden`（隐藏留位） |
| `--mirror` | 双面装订：内侧 26 / 外侧 20mm，版心仍 164mm |
| `--font-head` / `--font-body` | 强制字族（默认自动检测本机思源黑体 / 楷体） |
| `--img-width` | 图片宽度 cm，上限 16.4 |
| `--no-page-number` | 不排页码 |
| `--accent` | 仅为兼容旧命令保留，传什么值都不产生效果（V2.0 配色固定） |

用户没提 Logo 就默认占位框；**不要自己画一个 Logo**，也不要用随机图标代替。

## 表格式版式（整篇一张表）

**这是另一套骨架，页面与字体参数按 `references/table-spec.md` 执行，不套用上面的 V2.0**
（V2.0 的边距、字号、配色、框线全部不适用；只有「排哪一份就只动哪一份」等通用约定仍然适用）。

整份文档装进**一张 4 列网格表**，对齐已交付的《出塞教学设计》模板。
四种行型——分组行、标题行、标签·值行、内容行（正文段落、嵌套表、板书照片）；
教学过程**必须用满四列**（活动名称 / 教师活动 / 学生活动 / 设计意图），四列的 `tcW` 要与
`tblGrid` 逐列一致，否则 Word 会把四列拉平、看着像少了一列。

用它的信号：用户说「整体排版使用一个表格」「参照《出塞》那种版式」，或要求标题分层次带底纹。
否则用上方 `jxsj_typeset.py` 的 V2.0 版式。

```bash
python3 ~/.workbuddy/skills/lesson-typeset/scripts/table_layout.py \
    --input draft.md --output 课题-教学设计.docx --title "《牛和鹅》教学设计"
```

| 参数 | 说明 |
|---|---|
| `--title` | 表格上方的文档标题；源稿里的 `#` 行会被丢弃，不会落成空行 |
| `--subtitle` | 标题下副标题。**默认不要给**：用户明确不要「最终定稿版｜两课时」这类字样 |

### 源稿语法

| 写法 | 渲染 |
|---|---|
| `# 标题` | 文档标题，表格上方居中 |
| `## 一、教学基本信息` | **大节分组行**：整行合并、居中、深灰 `C8C8C8` |
| `## 第一课时教学设计` | 同上；同时把解析器切到「课时内」上下文 |
| `### 一、本课时教学目标`（课时内） | 独立整行、左对齐、浅灰 `F0F0F0`、不跨页 |
| `### 教学重点`（课时外） | 正文流里的加粗小标题，与下面条目**同格**，不单独占行 |
| `#### 环节一：谈话导入（3分钟）` | 独立整行、白底、与下方四列表同页 |
| `:::row 课　题 \| 第20课《牛和鹅》` | 标签行：标签 1 格 + 值 3 格 |
| `:::row2 作　者 \| 任大霖 \| 年　级 \| 四年级` | 四格均分 |
| `:::act 活动名` + `T:` / `S:` / `D:` | 教学过程四列行，块尾 `:::` |
| `\| a \| b \|` | 嵌套表（全框线 0.5pt，宽 14.26cm；三列按 36/20/44 分宽，其余自适应） |
| `![](...)` | 图片，14.06cm 居中（板书用实拍照片，不用字符画） |
| 普通段落 / `1. xxx` | 整行内容行 |

`T:` `S:` `D:` 一行一段，同列多段就多写几行：

```text
:::act 活动一　谈话导入，激发兴趣
T: 出示课文插图，提问：看到这只鹅你有什么感觉？
T: 板书课题，全班齐读。
S: 观察插图，说出自己的感受。
D: 用熟悉的画面唤起阅读期待，为体会「我」怕鹅做铺垫。
:::
```

### 版式常量

A4，页边距**上下 2.54、左右 3.17**，表格宽 **14.66cm**（正好铺满版心，左右不再缩进）、居中，
四列 **2.10 / 5.60 / 3.70 / 3.26 cm**（合计 14.66cm）；
文档标题 18pt；表内正文四号 14pt、行距 **1.45**；教学过程四列小四 12pt、行距 **1.18**；
嵌套表五号 10.5pt（≥4 列 9.5pt）。**全文宋体，标题前不加竖线、无强调色。**
底纹三档：`C8C8C8` 大节分组行 > `F0F0F0` 课时内章节标题 ≈ 四列表头 > 白底环节标题。
四列表头**每个课时只出一次**（由含「课时」的 `##` 行触发），不是每个环节重出。

**框线（硬性）**：所有表格六条边全画、一律 0.5pt（`sz=4`）、纯黑；
外框**不加粗**，不用 1.5pt 顶/底线，整份文档不出现三线表外观；不写单元格级 `tcBorders`。
主表与嵌套表同一套框线。用户 2026-11-04 明确「表格的所有框线都需要显示，不能加粗」。

### 分页约定（2026-11-05 定稿：表格允许跨页断行）

**总则：整篇就是一张长表，允许跨页；行也允许跨页断行。不为「把一行凑整」把内容推到下一页而留白。**
分页完全交给排版器，不用阈值、不预估高度。

| 元素 | 约束 | 原因 |
|---|---|---|
| 主表 | 无 | 表格式必然跨页，不做整表保护 |
| 大节分组行（`##`） | `cantSplit` ＋ `keepNext` | 只有一行高，拆开只剩半行字；带住下一行 |
| 课时内章节标题（`###`） | `cantSplit` ＋ `keepNext` | 同上 |
| 环节标题（`####`） | `cantSplit` ＋ `keepNext` | 同上 |
| 四列表头 | `cantSplit` ＋ 段落 `keepNext` | 单行高；keep 保证至少带着活动首行同页 |
| **活动行（四列）** | **无**，可跨页断行 | 高行强推会在上一页尾部留 3–5cm 空白（实测 27→31 页） |
| **含嵌套表 / 图片的内容行** | **无**，可跨页断行 | 同上；嵌套表自身跨页是正常的 |
| 标签行（课题、作者、教材依据等字段） | `cantSplit` | 字段不可拆：标签与值被分到两页，比整行下移更难读 |

只有「单行高」的行才加 `cantSplit`（拆了也只是一行字搬家，代价 ≤1.5cm）；
**凡是会很高的行一律不加**，否则就是大片留白的来源。

- 表头后首个活动行**不再传** `force_keep`：表头靠段落 `keepNext` 与活动首行同页，活动行自己可以断。
- 活动名称格内的段落加 `keepLines`（`keep_together`），尽量让活动名整段换页，不出现「一、回顾与字词复｜查（4分钟）」这种半截名。
- 嵌套表首行保留 `tblHeader`：表跨页时续排页重复表头。
- 正文段落不设 `keep`，全局加会从 27 页涨到 31 页。
- 渲染差异：LibreOffice 转 PDF 时跨表格行的 `keepNext`、单元格内 `keepLines`、嵌套表 `tblHeader` 可能都不生效（Word / WPS / 腾讯文档正常）。用 LibreOffice 预览看到「标题留页底」「活动名断成两截」「续表没表头」，先按渲染差异处理，**不要为它加约束**。

语法细节与校验命令见 `references/table-spec.md`。

## 页眉 Logo 的三种形态（用户没提就默认占位框）

| 场景 | 用法 | 结果 |
|---|---|---|
| 待补 Logo 的预览稿／可编辑模板 | 默认 | 30×12mm 虚线框＋「木老师原创课件」8pt |
| 有品牌 Logo | `--logo 路径` | 只显示 Logo，无虚线框、无占位文字 |
| 正式无 Logo 版 | `--logo-mode hidden` | 框与文字都隐藏，30×12mm 空间保留 |

无论哪种，**正文起始位置完全一致**。用户给的是 Logo 文件就直接用，**不要自己画一个**。

## 引擎实现约定（改引擎时必守）

1. 页眉是 **1×2 表格**（左 30mm / 右 132mm，行高 12mm）：只有表格能同时锁死宽、高、左对齐、垂直居中。
2. 占位框画成**单元格虚线边框**，不画自选图形——边框随行高走，换字号不跑位。
3. 页眉部件结尾必须留一个段落（Word 结构要求），用 1pt 行高收尾，否则多一行把正文顶下去。
4. 页眉区 12mm ＋ 距顶 9mm ＝ 21mm，正文上边距 26mm，正好留 5mm。**页眉里不能再加分隔线段落**。
5. Logo 图片必须**同时给宽高**（按原图比例算，高 ≤10mm、宽 ≤30mm）；只给宽度会按原始 dpi 撑爆页眉。
6. 逐页标题的时间用**右制表位**（`WD_TAB_ALIGNMENT.RIGHT` 设在 16.2cm），不用空格、不用表格。
7. `pPr/tblPr/tcPr/trPr` 子元素按 schema 顺序插入（复用学习清单引擎的 `_put`），
   直接 `append` 时 LibreOffice 预览正常、Word 会静默丢格式。

5. **防孤悬**：标题栏单元格段落、表头行段落、以及所有间隔段都设「与下段同页」，

# 常见问题（按文档类型分开查）

## 教学设计（两种骨架共同）

| 现象 | 原因与处理 |
|---|---|
| 板书设计 | **一律插图片**：用户提供实拍／截图照片直接 `![说明](路径)` 插入；不要用字符画重绘——手敲的 `│ ├ └` 线框一换字体就散架、且占篇幅、可读性差，已成禁用做法 |
| 多出空白页 | 文末空段落所致，脚本会自动清理 |
| 边框整段失效 | `tblBorders` / `tcBorders` 的子元素必须按 top→left→bottom→right→insideH→insideV 排，用 `_put()` 按 schema 顺序插入 |

## 教学设计·开放式（V2.0）

完整清单见 `references/jxsj-spec.md` §13，这里只列最常踩的：

| 现象 | 原因与处理 |
|---|---|
| **表格列被拉平、看着少一列** | `tcW` 与 `tblGrid` 不一致，Word 按 `tcW` 重排。用 `set_col_widths()` 一次写全 `tblW/tblGrid/tcW` |
| **表格外框缺一边、看着没封口** | 写了单元格级 `tcBorders` 且某边 `val="none"`，把外框挖掉。只保留表格级 `tblBorders` 六边 |
| **某页尾部空出 10cm+** | 数据行被 `cantSplit` 强推整行下移。数据行一律不加 `cantSplit`，允许跨页断行（实测 5 页→4 页） |
| **标题孤悬页末、表头单独留页底** | 标题/表头段落缺 `keepNext`；表格前的 4mm 空段也要 `keepNext` |
| **一级标题看着像正文** | run 层没写 `bold=True`，`python-docx` 的 `run.font.bold` 默认写 False，把样式加粗冲掉了 |
| **主标题、副标题、表题、图注全变左对齐** | `style.paragraph_format.alignment` 对自定义样式**不落盘**（`pPr/jc` 静默丢失）。必须用 `_set_style_align()` 自己往 `pPr` 里插 `w:jc` |
| **页眉占位框变形、被裁** | Logo 只给了宽度没给高度，按原始 dpi 撑爆 30×12mm。必须按原图比例同时给宽高（高 ≤10mm） |
| **正文被页眉顶下去** | 页眉里多加了分隔线段落（页眉区 12mm＋距顶 8mm 只剩 8mm 余量）。分隔线只做页眉表格的下边框 |
| **表格后正文紧贴底线** | 表格没有段后属性，用 `gap(doc, 5)` 撑出 5mm；表格前用 `gap(doc, 4, keep_next=True)` |
| 表格右边界溢出 | V2.0 表格与版心等宽（16.4cm）、**左对齐**，不居中也不缩进；写成 14.4 反而窄出一截 |
| **PDF 里楷体看着像黑体** | 本机 LibreOffice 对 CJK 一律回落 Hiragino Sans GB，字族以 docx 写入为准，别按 PDF 判断 |
| **预览里行高比 12mm 大** | LO 在 `trHeight=atLeast` 外另算上下单元格边距，Word 是 12mm 整。**不要据此调小规范值** |

## 教学设计·表格式

| 现象 | 原因与处理 |
|---|---|
| 表格右边界溢出 | 表格宽 14.66cm，铺满版心，本来就不缩进；写成 14.4 反而窄出一截 |
| **表格框线缺一边、看着没封口** | 单元格级 `tcBorders` 的优先级高于表格级 `tblBorders`：在某个边写了 `val="none"` 就把外框那条线挖掉了。**`tcBorders` 一律不写**，只保留表格级 `tblBorders` 六边 |
| **“只剩三列”、活动名称与教师活动连成一段** | 每格 `tcW` 与 `tblGrid` 不一致，Word 按 `tcW` 重排把四列拉平。用 `finish_table()` 从每格起始列求和，四列写 1191/3175/2098/1848 |
| **框线粗细不一、外框明显加粗** | 嵌套表还在走三线表（`sz=12` 顶底 + `sz=6` 表头线）或残留 `tcBorders`。统一调 `grid_borders()`，六边 `sz=4` |

## 逐字稿

| 现象 | 原因与处理 |
|---|---|
| **页眉 Logo 区跑到正文位置、或正文被顶下去** | 页眉里多加了一个分隔线段落（页眉区 12mm＋距顶 9mm 只剩 5mm 余量）。分隔线要么不要，要么画成页眉表格的下边框 |
| **页眉占位框变形、被裁** | Logo 只给了宽度没给高度，按原始 dpi 撑爆 30×12mm。必须按原图比例同时给宽高（高 ≤10mm） |
| **换了 Logo 后仍看到虚线框和「木老师原创课件」** | 占位框是单元格边框，插图时应跳过 `_cell_borders`，两者不能同时画 |
| **Word 打开后正文位置比预览高一点** | 页眉末尾的空段没设 1pt 精确行高，多出一行。检查 `build_header()` 的收尾段 |
| 时间没贴右边 | 制表位没设在版心右边界（16.2cm），或用了连续空格 |
| **续行没有和台词首字对齐** | 只设了左缩进没设悬挂：`left = 标识宽度`、`first = -标识宽度`，标识宽度按实际字号算 |
| 文档 60MB | 截图用了 PNG，改 JPG 质量 88 |
| **LibreOffice 预览里行高比 12mm 松** | LO 在 `trHeight="atLeast"` 外另加上下单元格边距（实测 12mm 排成 17.2mm），Word 是 12mm 整。**不要据此调小规范值** |
| **PDF 预览看不出楷体与黑体差别** | 本机 LibreOffice 对 CJK 一律回落 Hiragino Sans GB。字族以 docx 写入的名为准，别按 PDF 判断字体对不对 |

## 学习清单

| 现象 | 原因与处理 |
|---|---|
| 填空横线打印不出来 | 用了段末下划线空格或制表位引导符，LibreOffice 不渲染；改用下划线字符 `_` |
| 连续「标签：____」没合成填字表 | 只识别连续 2 行以上；单行按普通段落排，属预期 |

## 制作笔记

| 现象 | 原因与处理 |
|---|---|
| **Word 里一级标题的上分隔线不见了** | `h2_rule()` 用了 `_put(pPr, bdr, ["pBdr"])`，`pBdr` 落到 `pPr` 末尾，Word 静默丢弃。必须传完整的 `_PPR_ORDER` |
| **某页尾部空出 6cm** | 一级标题被 `keepNext` 整组推走，且原先用「独立分隔线段落」多占了一行高度。分隔线改为标题段落上边框后即可排满（实测 5 页全部排到 266—275mm） |
| 末页只有两三行 | 收紧 `:::note` 块间距与表格上下间距（都还在 4—6mm 规范区间内），**不要动字号和行距** |
| 两列表格内容列太窄 | 默认 30/70 是「项目＋说明」口径；对比表用 `:::colw 50 50` 显式指定 |
| 一级标题编号重复 | 引擎不自加编号，源稿里写一次就够；不要既写「（一）」又写「1.」 |
