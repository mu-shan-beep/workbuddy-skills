# 教学设计排版方案（自用版）· 完整规范

目标：打开就舒服、打印也体面。核心思路——字号克制、行距舒展、留白多一点、全黑白不施色。

单位换算备忘：小三 15pt / 四号 14pt / 小四 12pt / 五号 10.5pt / 小五 9pt。
1 倍行距 = 240 twips，1.75 倍 = 420 twips。

## 1. 页面网格

| 项目 | 参数 |
|---|---|
| 纸张 | A4 纵向（21 × 29.7cm） |
| 页边距 | 上 2.5 / 下 2.5 / 左 2.8 / 右 2.8 cm |
| 页眉 / 页脚距边界 | 1.5 cm / 1.75 cm |
| 正文行距 | **1.75 倍**（比 1.5 更透气，长文不累） |
| 段前段后 | 0 / 0，靠行距拉开 |
| 首行缩进 | 2 字符 |
| 对齐 | 两端对齐，开启「允许标点溢出边界」 |
| 孤行控制 | 开 |

版面可用宽度 = 21 − 2.8 × 2 = **15.4cm**。左右边距给到 2.8 比常规 2.5 略宽，是让整页「显贵」的最省力办法。

## 2. 字体层级

**全文字族统一宋体**（含标题、表头、数字与英文）。层级只靠**加粗 + 字号 + 段距**拉开，不换字体、不换颜色。

| 层级 | 字号字重 | 格式 |
|---|---|---|
| 文档标题 | 小三 15pt 加粗 | 居中，段后 18pt |
| 一级标题（一、二、） | 四号 14pt 加粗 | 左对齐，段前 16pt 段后 6pt，编号「一、」 |
| 二级标题（（一）） | 小四 12pt 加粗 | 左对齐，段前 12pt 段后 3pt |
| 分课时标题（第一课时：） | 13pt 加粗 | **居中**，段前 20pt 段后 8pt |
| 三级标题（1.） | 小四 12pt 加粗 | 左对齐，段前 12pt 段后 2pt |
| 标签行（任务／课时目标） | 小四 12pt 加粗 | 首行缩进 2 字符，段前 3pt |
| 正文 | 小四 12pt 常规 | 首行缩进 2 字符，1.75 倍行距 |
| 表题 / 图题 | 五号 10.5pt 加粗 | 居中 |
| 表格正文 | 五号 10.5pt 常规 | 单倍行距，不缩进，垂直居中 |
| 表头 | 五号 10.5pt 加粗 | 居中 |
| 页眉 / 页码 | 五号 10.5pt | 居中 |

字号差一档（12 / 13 / 14 / 15pt）视觉上很弱，靠的是加粗与段距配合，不要为了「看着层次不够」而换字体或加颜色。

**分课时标题取 13pt 而非 12pt**：它要与二级标题（12pt 加粗）拉开，又不能盖过一级标题（14pt）。

## 3. 颜色（全黑白）

- 全文**纯黑** `#000000`，不用深灰，打印才实
- **不使用任何强调色**。标题、表头、结论一律黑白；一级标题**不加左侧竖条、不加色块**（用户 2026-11-04 明确不要）
- 层级只靠加粗与字号拉开，不靠颜色。黑白打印一遍，层级必须仍然清楚
- **表头不加任何底纹**——不铺灰、不铺彩色。表头靠加粗、居中、下方 0.75pt 细线区分，复印时不会压成灰块
- **段落也不加底纹**，装饰只允许表格线本身

实现方式：`--accent` 参数保留以兼容旧命令，但本版式没有任何着色点，不产生可见效果。

## 4. 表格规范

**统一三线表**：顶线 1.5pt、表头下线 0.75pt、底线 1.5pt，中间竖线全部去掉。**表头不加底纹**，仅用加粗＋居中区分（与正文同为宋体）。

> 例外：用户明确要求「表格的所有框线都需要显示，不能加粗」时，本文档所有表格改为
> **六条边全画、一律 0.5pt（`sz=4`）、纯黑**，外框不加粗。

- 表格宽固定 **14.4cm**（版心 15.4 左右各缩 0.5），居中放置；这个数字只属于本版式，别处见到的宽度不要搬过来
- 跨页必须重复表头（表头行 `tblHeader`）
- **表格允许跨页断行**：数据行不设 `cantSplit`，也不加 `keepNext`——全表绑死会把整张长表推到下一页，上一页留十几厘米空白（实测 30 行表首页空白 21cm）；`keepNext` 只给表头段落，`cantSplit` 只给表头行（单行高）
- 单元格上下留白 4.25pt，左右 5.4pt

教学过程表推荐列宽（表头含「环节」或「活动名称」时自动套用）：

| 环节/时间 | 教师活动 | 学生活动 | 设计意图 |
|---|---|---|---|
| 10% | 32% | 30% | 28% |

无「环节」列时按三列 40 / 30 / 30。两列键值表用 22 / 78。
表体统一五号，环节名可用 `**加粗**` 强调，不额外缩小字号。

## 5. 文档结构（无封面无目录）

1. 文档标题（课题名称 + 教学设计）
2. 一、基本信息（表格：课题／学科／年级／教材／课时／设计者／日期）
3. 二、教材分析
4. 三、学情分析
5. 四、教学目标
6. 五、教学重难点
7. 六、教学准备
8. 七、教学过程（核心表格）
9. 八、板书设计
10. 九、作业设计
11. 十、教学反思

基本信息用两列四行的三线表，比一行行文字好看得多。章节可按实际内容增删，编号连续即可。

## 6. Word 样式参数速查

在 Word「样式」里新建以下样式，之后全文只用样式、不手动改格式：

- **正文**：宋体 小四 12pt，行距 1.75 倍，首行缩进 2 字符，两端对齐，孤行控制开
- **标题 1**：宋体 四号 14pt 加粗，段前 16pt 段后 6pt，与下段同页
- **标题 2**：宋体 小四 12pt 加粗，段前 12pt 段后 3pt，与下段同页
- **课时标题**：宋体 13pt 加粗，居中，段前 20pt 段后 8pt，与下段同页
- **标题 3**：宋体 小四 12pt 加粗，段前 12pt 段后 2pt，与下段同页
- **表题**：宋体 五号 10.5pt 加粗，居中，段前 6pt 段后 3pt，与下段同页
- **图题**：宋体 五号 10.5pt 加粗，居中，段前 3pt 段后 6pt
- **表格文字**：宋体 五号 10.5pt，单倍行距，无缩进

以上样式名与 `scripts/jxsj_typeset.py` 的 `build_styles()` 一一对应，改版式只改那里的常量。

关键两条：所有标题样式勾选**「与下段同页」**，防止标题落单页末；正文样式勾选**「孤行控制」**。

## 7. 检查清单

- [ ] 页边距 2.5/2.5/2.8/2.8，行距 1.75 倍
- [ ] 标题只用样式改，没有手动加粗调字号
- [ ] 全文只有阿拉伯数字序号，**没有圆点 `·`、短横线式的无序列表**（例外：学生自检栏刻意保留的 `□` 勾选框属填写栏，不算列表符号）
- [ ] 表格默认是三线表、**表头无底纹**、跨页重复表头；用户要求全框线时改六边 0.5pt（见 §4 例外）
- [ ] 表题在上、图题在下，编号连续
- [ ] 全文**无彩色、无竖条、无段落底纹**；全文字族只有宋体一种（提示性文字可用楷体时另行说明）
- [ ] 黑白打印一遍，层级仍然清楚
- [ ] 页眉写课题名，页码从第 1 页连续

## 8. 本技能在规范之外的三处约定

规范只定义了三级标题，教案实际的层级比这更深，因此补充三条约定，样式表仍然只有**一种字族（宋体）**：

1. **环节标题**用「标题 3」——小四宋体加粗、顶格、段前 12pt。
2. **分课时标题**用「课时标题」——13pt 宋体加粗、居中。它挂在「七、教学过程」下，却要统领整段，视觉层级必须压过环节标题，否则读者看到「环节」比「课时」还显眼。
3. **任务／课时目标**用「标签行」——小四宋体加粗、首行缩进 2 字符、段前 3pt。靠缩进和段前距离与环节区分，不额外加字体或颜色。

板书设计一律用图片呈现（用户提供实拍／截图照片），不用字符画重绘。源稿里直接写 `![说明](绝对路径)`，开放式版式按**表格宽 14.4cm** 居中插入（版心 15.4 左右各缩 0.5，与表格同宽，不是版心 15.4），整幅不跨页。若用户只给了文字板书、没给照片，先提示其提供照片；用户明确要「先按文字排」时，板书文字按普通段落输出（引擎遇到 ```` ``` ```` 块按纯文本降级并打警告，**不生成字符画框**），拿到照片后再换成 `![]()`。详情见 `markdown-mapping.md` 的「板书设计：用图片」一节。
