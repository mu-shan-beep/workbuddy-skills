# 教学设计排版方案（自用版）· 完整规范

目标：打开就舒服、打印也体面。核心思路——字号克制、行距舒展、留白多一点、全文只用一个强调色。

单位换算备忘：小三 15pt / 四号 14pt / 小四 12pt / 五号 10.5pt / 小五 9pt。
1 倍行距 = 240 twips，1.75 倍 = 420 twips。

## 1. 页面网格

| 项目 | 参数 |
|---|---|
| 纸张 | A4 纵向（21 × 29.7cm） |
| 页边距 | 上 2.5 / 下 2.5 / 左 2.8 / 右 2.8 cm |
| 页眉 / 页脚距边界 | 1.5 cm / 1.75 cm |
| 正文行距 | **1.75 倍**（比 1.5 更透气，长文不累） |
| 段前段后 | 0 / 0，靠行距拉开 |
| 首行缩进 | 2 字符 |
| 对齐 | 两端对齐，开启「允许标点溢出边界」 |
| 孤行控制 | 开 |

版面可用宽度 = 21 − 2.8 × 2 = **15.4cm**。左右边距给到 2.8 比常规 2.5 略宽，是让整页「显贵」的最省力办法。

## 2. 字体层级

| 层级 | 字体字号 | 格式 |
|---|---|---|
| 文档标题 | 小三 黑体 加粗 | 居中，段后 18pt |
| 一级标题（一、二、） | 四号 黑体 | 左对齐，段前 16pt 段后 6pt，编号「一、」 |
| 二级标题（（一）） | 小四 黑体 | 左对齐，段前 12pt 段后 3pt |
| 分课时标题（第一课时：） | 小四 黑体 加粗 | **居中**，段前 20pt 段后 8pt |
| 三级标题（1.） | 小四 宋体 加粗 | 左对齐，段前 12pt 段后 2pt |
| 正文 | 小四 宋体 | 首行缩进 2 字符，1.75 倍行距 |
| 西文数字 | Times New Roman | 与中文同字号 |
| 表题 | 五号 黑体 | 表上方，居中，段前 6pt 段后 3pt |
| 图题 | 五号 黑体 | 图下方，居中，段前 3pt 段后 6pt |
| 表格正文 | 五号 宋体 | 单倍行距，不缩进，垂直居中 |
| 页眉 / 页码 | 五号 宋体 / TNR | 居中 |

字体替换规则：没有黑体就用思源黑体 / 微软雅黑，没有宋体就用思源宋体。**别混搭超过两种字体。**

## 3. 颜色（克制原则）

- 正文：**纯黑** `#000000`，不用深灰，打印才实
- 标题：黑即可；区分层级靠字号字重，不靠颜色
- 强调色：**只选一个**，推荐藏青 `#2C3E50` 或墨绿 `#2F5D50`，只用于两处：
  1. 一级标题前的色块
  2. 关键结论加粗
- **表头不加任何底纹**——不铺灰、不铺彩色。表头靠黑体加粗、居中、下方 0.75pt 细线区分，黑白打印零损耗，也不会在复印时压成灰块
- 全文彩色不超过两处色系，黑白打印后信息不能丢

实现方式：一级标题用左侧 3pt 竖条（悬挂在页边距内，不挤压文字）。表格不参与着色。

## 4. 表格规范

**统一三线表**：顶线 1.5pt、表头下线 0.75pt、底线 1.5pt，中间竖线全部去掉。**表头不加底纹**，仅用黑体加粗＋居中区分。

- 表格整体不要撑满版心，左右各缩进 0.5cm（表格宽 14.4cm，居中放置）
- 跨页必须重复表头
- 行不跨页拆分（`cantSplit`）
- 单元格上下留白 4.25pt，左右 5.4pt

教学过程表推荐列宽：

| 环节/时间 | 教师活动 | 学生活动 | 设计意图 |
|---|---|---|---|
| 10% | 32% | 30% | 28% |

无「环节」列时按三列 40 / 30 / 30。两列键值表用 22 / 78。
环节名可加粗，时间换行小一号。

## 5. 文档结构（无封面无目录）

1. 文档标题（课题名称 + 教学设计）
2. 一、基本信息（表格：课题／学科／年级／教材／课时／设计者／日期）
3. 二、教材分析
4. 三、学情分析
5. 四、教学目标
6. 五、教学重难点
7. 六、教学准备
8. 七、教学过程（核心表格）
9. 八、板书设计
10. 九、作业设计
11. 十、教学反思

基本信息用两列四行的三线表，比一行行文字好看得多。章节可按实际内容增删，编号连续即可。

## 6. Word 样式参数速查

在 Word「样式」里新建以下样式，之后全文只用样式、不手动改格式：

- **正文**：宋体 小四，行距 1.75 倍，首行缩进 2 字符，两端对齐，孤行控制开
- **标题 1**：黑体 四号，段前 16pt 段后 6pt，与下段同页
- **标题 2**：黑体 小四，段前 12pt 段后 3pt，与下段同页
- **课时标题**：黑体 小四 加粗，居中，段前 20pt 段后 8pt，与下段同页
- **标题 3**：宋体 小四 加粗，段前 12pt 段后 2pt，与下段同页
- **表题**：黑体 五号，居中，段前 6pt 段后 3pt，与下段同页
- **图题**：黑体 五号，居中，段前 3pt 段后 6pt
- **表格文字**：宋体 五号，单倍行距，无缩进

关键两条：所有标题样式勾选**「与下段同页」**，防止标题落单页末；正文样式勾选**「孤行控制」**。

## 7. 检查清单

- [ ] 页边距 2.5/2.5/2.8/2.8，行距 1.75 倍
- [ ] 标题只用样式改，没有手动加粗调字号
- [ ] 全文只有阿拉伯数字序号，**没有圆点 `·`、方框、短横线式的无序列表**
- [ ] 表格全是三线表，**表头无底纹**，跨页重复表头
- [ ] 表题在上、图题在下，编号连续
- [ ] 全文强调色只用一种，且只用在标题色块与结论加粗
- [ ] 黑白打印一遍，层级仍然清楚
- [ ] 页眉写课题名，页码从第 1 页连续

## 8. 本技能在规范之外的两处约定

规范只定义了三级标题，教案实际的层级比这更深，因此补充两条约定，保持样式表仍然只有两种字体：

1. **环节标题**用「标题 3」——小四宋体加粗、顶格、段前 12pt。
2. **分课时标题**用「课时标题」——小四黑体加粗、居中。它挂在「七、教学过程」下，却要统领整段，视觉层级必须压过环节标题，否则读者看到「环节」比「课时」还显眼。
3. **任务／课时目标**用「标签行」——小四宋体加粗、首行缩进 2 字符、段前 3pt。靠缩进和段前距离与环节区分，不额外加字体或颜色。

板书设计一律用图片呈现（用户提供实拍／截图照片），不用字符画重绘。源稿里直接写 `![说明](绝对路径)`，开放式版式按版心宽（14.4cm）居中插入，整幅不跨页。若用户只给了文字板书、没给照片，先提示其提供照片、确认后再排版——**不要自行用字符画替代**。详情见 `markdown-mapping.md` 的「板书设计：用图片」一节。
