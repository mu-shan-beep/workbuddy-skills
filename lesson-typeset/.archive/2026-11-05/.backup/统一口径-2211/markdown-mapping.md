# 输入 Markdown 与样式的映射

排版引擎只认这一套精简 Markdown 子集。把任意来源（粘贴文本、docx、PDF、旧版教案）的内容整理成这个格式，其余交给脚本。

## 块级元素

| 写法 | 渲染结果 |
|---|---|
| `# 《17 长城》教学设计` | 文档标题：小三黑体加粗、居中、段后 18pt |
| `## 一、基本信息` | 一级标题：四号黑体、顶格、段前 18pt／段后 6pt，左侧藏青色块，与下段同页 |
| `### （一）课标分析` | 二级标题：小四黑体、顶格、段前 12pt／段后 3pt，与下段同页 |
| `### 第一课时：xxx` | 分课时标题：小四黑体加粗、**居中**、段前 20pt／段后 8pt（见下文「分课时标题」） |
| `#### 环节一：情境导入（3分钟）` | 三级标题：小四宋体加粗、顶格、段前 12pt／段后 2pt，与下段同页 |
| `##### 任务一：我会认` | 标签行：小四宋体加粗、缩进 2 字符、段前 3pt |
| `**课时目标**`（整行只有加粗） | 同上，标签行 |
| 普通文字 | 正文：小四宋体、1.75 倍行距、首行缩进 2 字符、两端对齐 |
| `1. 内容` | 有序条目：正文样式，左缩进 1.2cm、悬挂 0.6cm |
| `- 内容` | **一律转成阿拉伯数字序号**，与上一项连续编号；不输出圆点 |
| `- [ ] 内容` | 同上，转成序号；不输出方框 |
| `![板书](路径)` | 板书设计（实拍／截图照片）：按版心宽居中，整幅不跨页 |
| `:::caption 表 1 教学过程` | 表题：五号黑体居中 |

行内只支持 `**加粗**`，其余符号原样输出。

## 表格

标准 GFM 表格，首行为表头：

```markdown
| 教师活动 | 学生活动 | 设计意图 |
|---|---|---|
| 1. 出示图片；2. 提问；3. 板书课题 | 1. 观察；2. 表达感受 | 激活已有经验 |
```

渲染为三线表：顶线 1.5pt、表头下线 0.75pt、底线 1.5pt，无竖线，**表头不加任何底纹**（黑体加粗＋居中＋下方细线即可区分），跨页重复表头，行不跨页拆分。

## 列表：只用阿拉伯数字

全文只允许一种列表形态——`1.` `2.` `3.`。不出现圆点 `·`、方框 `□`、短横线式的悬挂符号。

源 Markdown 里写 `- 内容` 或 `- [ ] 内容` 也能跑，引擎会按出现顺序自动补上序号（连续的列表项共用一段编号，遇到正文／表格／标题就从 1 重计）。但**整理草稿时建议直接写成 `1.` `2.`**，可读，也避免跨块编号对不上。

例外：如果原文是给学生**打勾填写的自检栏**（如资料卡旁的「□ 名称准确」），方框是填写栏而不是列表符号，保留原样。

**列宽自动判定：**

| 条件 | 列宽比 |
|---|---|
| 4 列且含「环节」 | 10 / 32 / 30 / 28 |
| 3 列且含「教师活动」 | 40 / 30 / 30 |
| 2 列且含「项目」或「内容」 | 22 / 78 |
| 1 列 | 100 |
| 其他 | 按各列内容长度（75 分位）自适应，单列不低于 14% |

「设计意图」这类列字数少、句子长，纯按字数压缩会挤成七行，所以熟悉的表头一律走经验值，只有不认识的表才自适应。

**单元格内分条：** 内容以 `1.` 起头时，脚本会在 `；` `;` `。` 之后紧跟 `2.` `3.` 的位置自动换行，每条独立成段。也可直接写 `<br>` 强制换行。

## 板书设计：用图片，不用字符画

板书设计一律以**图片**呈现——用户提供实拍或截图照片，直接用 Markdown 图片语法插入：

```markdown
![第一课时板书](/绝对路径/17长城-图片-板书-第一课时.jpg)
![第二课时板书](/绝对路径/17长城-图片-板书-第二课时.jpg)
```

- 两个引擎都支持：开放式版式按版心宽（14.4cm）居中插入，表格式版式 14.4cm 居中。
- 照片完整、未变形、未横向截断即可，**无需对齐坐标**。
- **不要用字符画重绘板书**：手敲的 `│ ├ └` 线框一换字体就散架、占篇幅、可读性差，已成禁用做法。
- 若用户只给了文字版板书、没给照片：先提示其提供板书照片、确认后再排版，**不要自行用字符画替代**。
- 图片建议存到该课 `assets/`，命名沿用交付规范（如 `17长城-图片-板书-第一课时.jpg`）。

## 分课时标题

`### 第一课时：初识长城，识字写字，了解构造` 会被自动识别为**分课时标题**（正则 `^第[一二三四五六七八九十\d]+课时`），渲染为小四黑体加粗**居中**、段前 20pt／段后 8pt。

它挂在「七、教学过程」下面，但在视觉层级上要压过 `#### 环节一`，否则「环节」比「课时」还显眼，读者会找不到结构。

## 整理内容时的常见判断

1. **章节编号**：源文若缺编号（如只有「基本信息」「教材分析」），补 `一、` `二、` 是结构标记，允许；但章节标题文字本身不改。
2. **列表合并**：源文一段里并列了多个编号条目，可直接写成多行 `1.` `2.`，文字不增删。
3. **占位**：缺「设计者」「日期」等字段写 `________` 占位，不编造人名和日期。
4. **表格拆分**：一张表里塞了两类信息（如「评价标准」和「分层反馈」）时，可拆成两张表并各加表题，但要保持原文顺序与文字。
5. **页码引用**：正文里出现「见第 74 页」这类教材页码，是原文内容，照抄不动。
