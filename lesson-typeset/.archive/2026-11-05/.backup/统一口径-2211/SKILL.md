# 教学设计 / 逐字稿排版（自用版）

三类文档，一套底座：同样的页面网格、同样的字体体系、同样的黑白克制。
区别只在骨架——教学设计是连续阅读的档案，逐字稿是逐页对照的工作稿，学习清单是课堂配套的练习纸。
区别只在骨架——教学设计是连续阅读的档案，逐字稿是逐页对照的工作稿。

|  | 教学设计 | 逐字稿 |
|---|---|---|
| 骨架 | 标题层级 + 三线表 | 整表连续，每页课件一段对照 |
| 排列 | — | 左右（左图右文）／上下（图在上、文字满宽在下），**每次问用户** |
| 页码 | 有，页脚居中 | **无**，位置靠课件截图 |
| 正文字号 | 小四 12pt | 五号 10.5pt |
| 行距 | 1.75 倍 | 1.38 倍 |
| 完整规范 | `references/spec.md` | `references/zjg-spec.md` |

版式参数全部固化为常量，不要每次重新设计。**只调格式，不改文字。**

教学设计另有**表格式骨架**（整篇一张 4 列表，见过《出塞教学设计》模板或用户要求「整体排版用一个表格」时用），
不是默认方案，见下文「表格式版式」。

## 何时使用

- 教学设计：给出教案内容（文本、Markdown、docx，或只给课题＋教材＋课时），要求排版／生成 docx
- 逐字稿：给出讲稿 + 对应课件 pptx，要求排成「图文对照、上课能照着念」的稿子
- 已有文档需要重新套版式

不适用：党政机关公文（用 `gongwenformat-pro`）、内容从零创作（由写作类技能产出内容，本技能只负责版式）。

# 一、教学设计

## 第一步：取得内容并规范化

把源内容整理成**规范 Markdown**，写入临时 `.md` 文件。完整映射见
`references/markdown-mapping.md`，核心对应关系：

| Markdown | 含义 | 对应样式 |
|---|---|---|
| `# 标题` | 文档标题（课题＋教学设计） | 小三黑体加粗居中 |
| `## 一、xxx` | 一级标题 | 四号黑体，左侧强调色块 |
| `### （一）xxx` | 二级标题 | 小四黑体 |
| `#### 1. xxx` | 三级标题（环节） | 小四宋体加粗，顶格 |
| `### 第一课时：xxx` | 分课时标题（脚本按「第X课时」自动识别） | 小四黑体加粗居中 |
| `##### xxx` 或整行 `**xxx**` | 标签行（任务／课时目标） | 小四宋体加粗，缩进 2 字符 |
| 普通段落 | 正文 | 小四宋体，1.75 倍行距，首行缩进 2 字符 |
| `1. 内容` | 有序条目 | 左缩进，悬挂对齐 |
| `- 内容` / `- [ ] 内容` | **一律转成阿拉伯数字序号** | 与相邻项连续编号，不输出圆点或方框 |
| `\| 表 \| 格 \|` | 数据表 | 三线表，表头黑体加粗居中、**无底纹** |
| `![板书](路径)` | 板书设计（用户提供实拍／截图照片） | 按版心宽居中插入，整幅不跨页；**不用字符画重绘** |
| `:::caption 表 1 xxx` | 表题 | 五号黑体居中 |

**整理内容时的硬性要求：**

1. **一字不改**。不增删、不改写、不润色、不调整语序，只补结构标记。
2. 单元格内用 `<br>` 或按 `；2.` 的序号书写条目均可，脚本会自动拆成独立行。
3. **板书设计一律用图片**：用户提供实拍／截图照片，用 `![说明](绝对路径)` 直接插入，
   不要手敲字符画重绘（两种引擎都已支持图片：开放式版式按版心宽居中，表格式版式 14.4cm 居中）。
   若用户只给了文字板书、没给照片，先提示其提供照片、确认后再排版——**不要自行用字符画替代**。
4. 缺失的章节（如「设计者」「日期」）留空占位，不编造。

## 第二步：运行排版引擎

```bash
python3 ~/.workbuddy/skills/lesson-typeset/scripts/jxsj_typeset.py \
    --input draft.md \
    --output 课题-教学设计.docx \
    --header "17 长城" \
    --accent navy
```

| 参数 | 说明 |
|---|---|
| `--header` | 页眉文字，写课题名（如「17 长城」）；页脚自动居中页码，从 1 连续 |
| `--accent` | `navy`（默认，藏青 #2C3E50）／`green`（墨绿 #2F5D50）／`#RRGGBB` |
| `--title` | 覆盖文档标题（源 Markdown 的 `#` 行优先） |

强调色只作用一处：**结论强调**。一级标题**不再加左侧竖条**（用户 2026-11-04 明确不要）；
全文字族统一**宋体**（含标题、表头、数字与英文），层级靠加粗与字号拉开。

## 表格式版式（整篇一张表）

教学设计的另一种骨架：整份文档装进**一张 4 列网格表**，对齐已交付的《出塞教学设计》模板。
四种行型——分组行、标题行、标签·值行、内容行（正文段落、嵌套三线表、板书照片）；
教学过程再用满四列（活动名称 / 教师活动 / 学生活动 / 设计意图）。

用它的信号：用户说「整体排版使用一个表格」「参照《出塞》那种版式」，或要求标题分层次带底纹。
否则用上方 `jxsj_typeset.py` 的开放式版式。

```bash
python3 ~/.workbuddy/skills/lesson-typeset/scripts/table_layout.py \
    --input draft.md --output 课题-教学设计.docx --title "《牛和鹅》教学设计"
```

| 参数 | 说明 |
|---|---|
| `--title` | 表格上方的文档标题；源稿里的 `#` 行会被丢弃，不会落成空行 |
| `--subtitle` | 标题下副标题。**默认不要给**：用户明确不要「最终定稿版｜两课时」这类字样 |

### 源稿语法

| 写法 | 渲染 |
|---|---|
| `# 标题` | 文档标题，表格上方居中 |
| `## 一、教学基本信息` | **大节分组行**：整行合并、居中、深灰 `C8C8C8` |
| `## 第一课时教学设计` | 同上；同时把解析器切到「课时内」上下文 |
| `### 一、本课时教学目标`（课时内） | 独立整行、左对齐、浅灰 `F0F0F0`、不跨页 |
| `### 教学重点`（课时外） | 正文流里的加粗小标题，与下面条目**同格**，不单独占行 |
| `#### 环节一：谈话导入（3分钟）` | 独立整行、白底、与下方四列表同页 |
| `:::row 课　题 \| 第20课《牛和鹅》` | 标签行：标签 1 格 + 值 3 格 |
| `:::row2 作　者 \| 任大霖 \| 年　级 \| 四年级` | 四格均分 |
| `:::act 活动名` + `T:` / `S:` / `D:` | 教学过程四列行，块尾 `:::` |
| `\| a \| b \|` | 嵌套三线表 |
| `![](...)` | 图片，14.4cm 居中（板书用实拍照片，不用字符画） |
| 普通段落 / `1. xxx` | 整行内容行 |

`T:` `S:` `D:` 一行一段，同列多段就多写几行：

```text
:::act 活动一　谈话导入，激发兴趣
T: 出示课文插图，提问：看到这只鹅你有什么感觉？
T: 板书课题，全班齐读。
S: 观察插图，说出自己的感受。
D: 用熟悉的画面唤起阅读期待，为体会「我」怕鹅做铺垫。
:::
```

### 版式常量

A4，边距 2.54 / 3.17，表格宽 14.4cm，四列 **2.10 / 5.60 / 3.70 / 3.26 cm**；
正文四号 14pt、教学过程小四 12pt、行距 1.18、全框线 0.5pt；嵌套表五号（≥4 列 9.5pt）。
底纹三档：`C8C8C8` 大节分组行 > `F0F0F0` 课时内章节标题 ≈ 四列表头 > 白底环节标题。
四列表头**每个课时只出一次**（由含「课时」的 `##` 行触发），不是每个环节重出。

### 分页约定（踩过的坑，别改回去）

- 活动行**不加** `cantSplit`：整行强推会在上一页尾部留下大片空白（实测 27→31 页）。
- 表头后紧跟的第一个活动行传 `force_keep=True`，避免表头孤悬页底、活动被切在页缝。
- 标题行（`subhead_row`）带 `cantSplit + keepNext`；正文段落**不加** `keep`，全局加会暴涨页数。
- LibreOffice 渲染时跨表格行的 `keepNext` 不生效，`四、教学过程` 可能留在页底；Word 里正常，属渲染差异，别为此改约束。

语法细节与校验命令见 `references/table-spec.md`。

# 二、逐字稿

## 第零步：问用户要哪种排列（每次必做，不要替用户默认）

引擎有两种排列，结构完全不同，**开工前必须用 `AskUserQuestion` 问一次**，
除非用户在这轮对话里已经明确指定过。

| | 左右（`--layout side`） | 上下（`--layout stack`） |
|---|---|---|
| 结构 | 左列截图 5.4cm，右列稿子 8cm | 截图独占一行 11cm 居中，稿子满宽在下 |
| 每块行数 | 2 行（表头 + 图文） | 3 行（表头 + 图 + 文） |
| 15 页课件实测 | 9 页 A4 | 11 页 A4 |
| 适合 | 站着念、翻页快，一页看到更多；页数省 | 需要对照画面细节（板书、表格、字词）时图更大；稿子满宽行短，眼睛不易串行 |
| 代价 | 图小，画面细节要看投屏 | 页数多，一页放不下两块时页尾留白 |

提问模板：

```
问题：逐字稿用哪种排列？
1. 左右排列（推荐）：左图右文，15 页课件约 9 页 A4，紧凑省纸
2. 上下排列：图放大居中、稿子满宽在下，15 页课件约 11 页 A4，画面细节更清楚
```

用户选定后，把对应参数写进第三步的命令，回复里说明选的是哪种、因此页数是多少。

## 第一步：把课件渲染成图

```bash
python3 ~/.workbuddy/skills/lesson-typeset/scripts/ppt2png.py \
    --pptx "《19 秦兵马俑》第二课时.pptx" --outdir assets/ppt
```

输出 `p01.jpg … p15.jpg`，110dpi、约 10MB。**用 JPG 不用 PNG**——课件多是照片背景，
PNG 无损会把 15 页撑到 60MB+，Word 打开就卡。同一份课件渲染一次即可复用。

## 第二步：把稿子整理成规范 Markdown

```markdown
# 19 秦兵马俑 · 第二课时 逐字稿

小学语文 · 四年级 · 对应第二课时课件（第 1—15 页）· 40 分钟

## 使用说明

一、本稿按课件播放顺序逐页编写……

### 第二课时　编撰展陈手册下篇——品悟千人千面（40 分钟）

## 第 1 页 · 封面“红领巾解说团·下篇”｜0:00—1:00

〔操作〕翻到第 1 页封面。板书课题。

师：上课！同学们好，请坐。

生（齐）：老师好！
```

| Markdown | 含义 |
|---|---|
| `# 标题` | 文档标题，小三黑体居中 |
| 紧跟标题的第一段 | 副标题（年级·课时·时长），自动居中、小五灰字 |
| `## 使用说明` | 二级标题，小四黑体 |
| `### 第二课时：xxx` | 含「课时」→ 小四黑体加粗居中 |
| `## 第 3 页 · 环节名｜3:30—4:00` | **开始一个课件块**。页号和环节名进表格左格，时间进右格 |
| `![](p03.jpg)` | 指定该块截图；不写则按页号自动找 `pNN.jpg` |
| 普通行 | 块内一段稿子，按行首标记自动配字体（师／生／〔操作〕／〔学生可能说〕） |

**硬性要求：**

1. **一字不改**，不润色、不合并、不调整语序。
2. 页号必须与 pptx 实际页序一致——稿子说「翻到第 5 页」，截图就得是第 5 张。
3. `〔〕` 提示符原样保留，它不是列表符号，不转序号。
4. 某页确实没有课件（如纯口头过渡），仍要保留该块，写清「无对应课件页」，不要删。

## 第三步：运行排版引擎

```bash
python3 ~/.workbuddy/skills/lesson-typeset/scripts/zjg_typeset.py \
    --input draft.md \
    --output 19秦兵马俑-第二课时-逐字稿.docx \
    --header "19 秦兵马俑 · 第二课时 逐字稿" \
    --images assets/ppt \
    --layout side \
    --accent navy
```

| 参数 | 说明 |
|---|---|
| `--header` | 页眉文字；页脚**不排页码**（引擎固定关闭） |
| `--images` | 课件图目录，按 `p01.jpg` 命名自动匹配 |
| `--layout` | **必填**。`side`＝左右（默认值，紧凑）／`stack`＝上下（图放大） |
| `--img-width` | 截图宽度 cm，一般不用给：side 默认 5.4、stack 默认 11.0。stack 调到 12 会多排一页 |
| `--accent` | 同教学设计 |

## 第四步：校验

```bash
python3 -c "
import zipfile
z = zipfile.ZipFile('out.docx')
x = z.read('word/document.xml').decode()
# 页码字段在 footer 部件里，不在 document.xml，别查错地方
f = sum(z.read(n).decode().count('PAGE') for n in z.namelist() if 'footer' in n)
print('表格数', x.count('<w:tbl>'), '| 行数', x.count('<w:tr>'),
      '| 图', x.count('<pic:pic>'), '| 页码字段', f,
      '| 底纹', x.count('<w:shd'))
"
```

- [ ] **表格数 = 1**，行数 = 课件页数 × 2（side）或 × 3（stack）
- [ ] 块与块之间只有一条分隔线，左右边框贯通到底
- [ ] 页码字段为 **0**，页脚空白
- [ ] 表头时间贴右边界（不是浮在中间——那是制表位失效的特征）
- [ ] 表格无任何底纹
- [ ] stack 版式的截图水平居中、左右留白相等
- [ ] 稿子段落零丢失（逐段比对源文）

# 三、学习清单

## 何时使用

- 用户给出学习清单 / 作业清单内容（文本、docx，或只给课题＋课时），要求排版成课堂配套练习纸
- 已有学习清单需要重新套版式

不适用：内容从零创作（由写作类技能产出内容，本技能只负责版式）。

## 设计口径（已与用户逐项确认，不要重新设计）

| 项 | 值 |
|---|---|
| 纸张 / 边距 | A4；上 2.2 / 下 2.4 / 左 2.8 / 右 2.5 cm |
| 字体 | 宋体（全文字族统一） |
| 字号 | 正文 / 标题 / 表格 **统一五号 10.5pt**；主标题 16pt |
| 行距 | 全文 **1.5 倍** |
| 表格 | **全部边框网格**（外框四边 + 内部横竖线，浅灰 `BFBFBF` 细线） |
| 表格文字 | **一律不加粗**（表头、数据、田字格示范字、勾选框 `□` 均正常粗细） |
| 单元格内边距 | **所有填字表统一 0.3cm**（表格级 `tblCellMar`，Word 标准语义，跨软件渲染一致） |

# 常见问题

| 现象 | 原因与处理 |
|---|---|
| 表格列宽不对 | 有语义的表头（教师活动／环节／项目）走固定比例，其余按内容长度自适应；`tblPr` 子元素顺序错会静默丢属性，靠末尾 `normalize_xml` 修正 |
| 表格右边界溢出 | 表格用居中＋固定宽 14.4cm 实现左右各缩进 0.5cm，不要改成左对齐＋缩进 |
| 板书设计 | **一律插图片**：用户提供实拍／截图照片直接 `![说明](路径)` 插入；不要用字符画重绘——手敲的 `│ ├ └` 线框一换字体就散架、且占篇幅、可读性差，已成禁用做法 |
| 标题孤悬页末 | 标题样式已开「与下段同页」；表格紧跟标题时个别渲染器仍会拆，属渲染差异，可接受 |
| 多出空白页 | 文末空段落所致，脚本会自动清理 |
| 逐字稿表头与内容被分页拆开 | 表头段落漏了 `keepNext` |
| 逐字稿时间没贴右边 | 用了制表位，改用 6.4/4.0/4.0 三列网格 |
| 逐字稿文档 60MB | 截图用了 PNG，改 JPG 质量 88 |
| **表格框线缺一边、看着没封口** | 单元格 `tcBorders` 的优先级高于 `tblBorders`：在某个边写了 `val="none"` 就把外框那条线挖掉了。**只写要显示的边，其余一律不写**，用 `_set_cell_borders()`，别手搓 `none` |
| **块与块之间像断成两个表** | 一块建一个表时，Word 强制在两表间插段落，于是有空隙＋两条并排线。改成整表连续、每块追加两行，块间只留 `insideH` 一条分隔线 |
| 边框整段失效 | `tblBorders` / `tcBorders` 的子元素必须按 top→left→bottom→right→insideH→insideV 排，`_ORDER` 已收录，末尾 `normalize_xml` 会重排 |
