# 学习清单规范（自用版）

学习清单是「课堂配套练习纸」，版式只服从练习纸的读填需求，本文档是它唯一的规范来源。
排新课文时**直接喂 Markdown 源稿**：`xuexqingdan_typeset.py --input 学习清单_第X课时.md --header "课题"`，
内容全在 md 里改，脚本不动（2026-11-05 起不再需要「复制脚本改 lesson1/lesson2」）。

## 1. 页面与版式常量

| 项 | 值 |
|---|---|
| 纸张 | A4（21 × 29.7cm） |
| 页边距 | 上 2.2 / 下 2.4 / 左 2.8 / 右 2.5 cm |
| 版心宽 | 15.7 cm（21 − 左右边距 2.8 − 2.5） |
| 字体 | 宋体（含标题、表头、数字、英文） |
| 强调色 | navy `#2C3E50`（仅副标题用） |
| 字号 | 正文 / 章节标题 / 表格 **统一五号 10.5pt**；文档主标题 16pt |
| 行距 | 全文 **1.5 倍** |
| 页眉 | 课题名（如「17 长城」），9pt 灰字、居中 |
| 页脚 | 居中页码域（PAGE），9pt 灰字；Word/WPS 打开自动更新 |

## 2. 表格规则（核心，已逐条与用户确认）

1. **全部边框**：所有填字表都是完整网格——外框四边 + 内部横竖线统一浅灰细线（`BFBFBF`，sz=6）。
   不再只有上下线，也不再缺失左右框。
2. **表格内文字一律不加粗**：表头、数据文字、田字格里的示范字、勾选框 `□` 均为正常粗细。
   （章节标题、信息行「班级/姓名/日期」标签允许加粗，那是表格外的段落。）
3. **统一单元格内边距 0.3cm**：用**表格级 `tblCellMar`**（Word 标准语义，跨软件渲染一致、预览可见），
   所有填字表走同一值，不区分厚薄。文字不再贴边、四边留白一致。`_set_tbl_cell_margin()` 统一调用。
4. **文字垂直居中**：每个单元格 `vAlign=center`，用 `_set_vcenter()`。

## 2.5 Markdown 源稿语法（`--input`）

| 写法 | 渲染 |
|---|---|
| `# 课题` | 只作页眉／标题素材，不进正文 |
| `## 第一课时学习清单` | 文档标题：`页眉｜该行文字`（`--title` 可覆盖） |
| `### 一、…` | 小节标题（五号加粗、不缩进） |
| 含「姓名」且带 `_` 的行 | 信息行：自动换成「班级／姓名／日期」三格 |
| 普通段落 | 正文，支持行内 `**加粗**` |
| `- xxx` | 转为「1. 2. 3.」阿拉伯数字序号（连续列表共用一个计数器） |
| `\| a \| b \|` 连续行 | 填字网格表；第二行是 `\|---\|` 时首行作表头。两列＝4.2+11.5cm（合计 15.7＝版心宽），三列以上首列 3.6cm、其余均分 |
| 连续 2 行以上「标签：____」 | 合成一张左标签／右空白的填字表（批注区、记录区），行高 1.15cm；只出现 1 行时仍作正文 |
| `:::write 演 练 撤` | 田字格练写（大字框＋3 条练写线） |
| `:::check A \| B \| C` | `□` 勾选项（≥3 项三列，否则两列） |
| `:::pagebreak` | 硬分页 |
| 单独一行 `____` | 视作上一条「标签：」的续写横线，表格模式下忽略 |

单元格里保留 `____` 会把横线一起排出来；需要留白就直接留空单元格。
源稿里**不要**写页码、页眉——由引擎统一生成。

## 3. 通用构件（引擎已内置，直接调用）

| 函数 | 作用 |
|---|---|
| `setup_page(doc, header)` | 页面网格 + 页眉页脚 |
| `add_title(doc, title, subtitle)` | 16pt 居中主标题 + navy 居中副标题 |
| `add_info(doc)` | 班级／姓名／日期 三处填空（下划线字符） |
| `add_section(doc, title)` | 小节标题（五号、加粗、不缩进） |
| `add_tip(doc, text)` | 提示语（五号、正常粗细） |
| `grid_table(doc, widths_cm, header, rows, pad, rh_d, rh_h, exact)` | 填字网格表（默认就带全边框 + 0.3cm 边距 + 垂直居中 + 不加粗） |
| `char_practice(doc, chars)` | 「我会写」田字格：大字框 + 3 条练写线（示范字不加粗） |
| `checkboxes(doc, items, cols)` | `□` 勾选项（多列，□ 不加粗） |
| `writeline(doc, label)` | 带下划线填空的整行（如「我认为……因为：」） |

## 4. 填空横线：用下划线字符

填空线一律用 `_` 字符（`blank(p, n)`），**不要用**段末下划线空格、也不要用制表位引导符——
LibreOffice 导出对这两种都不渲染（实测丢失），下划线字符在任何软件都稳定显示。
信息行（班级/姓名/日期）与 `writeline()` 都已采用此写法。

## 5. 分页

- 不限制页数，但**排版必须美观**：避免末页大片空白。
- 内容密（如第一课时含字框 + 4 表 + 自评）时，标准 0.3cm 内边距会自然成 2 页，属正常；
  不要为了塞进 1 页而把内边距调小（用户明确"所有表统一标准内边距"优先于紧凑）。
- 资料卡这类标签型表格可用 `exact=True` 固定行高，让垂直居中在预览器里更稳；
  学生要填多行字的表用默认 `atLeast`，避免填长内容被裁切。

## 6. 校验清单

```bash
soffice --headless --convert-to pdf --outdir /tmp/out 课题-第一课时-学习清单.docx  # 看版面

python3 - <<'PY'
import zipfile, re
x = zipfile.ZipFile("课题-学习清单.docx").read("word/document.xml").decode()
bold = 0
for m in re.finditer(r"<w:tbl>.*?</w:tbl>", x, re.S):
    for r in re.findall(r"<w:r[ >].*?</w:r>", m.group(0), re.S):
        t = "".join(re.findall(r"<w:t[^>]*>([^<]*)</w:t>", r))
        bv = re.search(r'<w:b\b[^>]*?w:val="([^"]*)"', r)
        if ("<w:b " in r or "<w:b/>" in r) and (bv is None or bv.group(1)!="0") and t.strip():
            bold += 1
print("表格内加粗文字=", bold, "| 表格级边距tblCellMar=", x.count("tblCellMar"))
PY
```

- [ ] 所有填字表是完整边框网格（外框 + 内部横竖线均可见）
- [ ] **表格内加粗文字 = 0**（XML 复核通过）
- [ ] 所有填字表含 `tblCellMar`（统一 0.3cm 单元格内边距），文字不贴边、四边一致
- [ ] 单元格文字垂直居中
- [ ] 填空横线用 `_` 字符，三处信息行（班级/姓名/日期）都有横线、无残缺
- [ ] 田字格示范字清晰、不加粗；勾选框 `□` 清晰、不加粗
- [ ] 全文五号字、1.5 倍行距；末页无大片空白（内容自然分页即可）
- [ ] 页脚页码是真域：`document.xml` 无关，查 `footer*.xml` 里应有 `w:fldCharType="begin"`；
      若 PDF 底部显示字面「PAGE」，是 `fldChar` 属性名误写成 `w:val` 所致
