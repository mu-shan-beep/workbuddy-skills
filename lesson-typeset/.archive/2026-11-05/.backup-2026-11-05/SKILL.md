# 教学设计 / 逐字稿 / 学习清单排版（自用版）

本技能排三类文档，**每一类的排版规则完全独立**：页面网格、字族字号、骨架、表格与分页规则，只写在本类那一节和它对应的 `references/*.md` 里，任何一条规则都不跨类型复用。

| 文档 | 引擎 | 规范（该类唯一权威） |
|---|---|---|
| 教学设计·开放式 | `scripts/jxsj_typeset.py` | `references/spec.md` |
| 教学设计·表格式 | `scripts/table_layout.py` | `references/table-spec.md` |
| 逐字稿 | `scripts/zjg_typeset.py` | `references/zjg-spec.md` |
| 学习清单 | `scripts/xuexqingdan_typeset.py` | `references/xuexqingdan-spec.md` |

- 参数一律以该类的规范文件为准；本节**不汇总数值**——同一个数字写两处，改一处就打架。
- 教学设计的两种骨架也互不套用（边距、表格宽度都不同），换骨架就同时换规范。
- 排哪一份就只看哪一节，**不要拿另一类文档的版式做参照**。

## 一次只排指定的那一份

用户说排哪一份，就只动那一份：

- 只读该文档自己的源稿；不顺手检查、重排、重新生成同课的其他文件（教学设计／逐字稿／学习清单、第一课时／第二课时）。
- 不顺手为其他文档备料（渲染课件图、裁板书图、转格式）；这轮点不到的那份，一个字都不碰。
- 结论也只报这一份：页数、版式自检、改动点。不附其他文件的现状，不替用户安排下一份。
- 需要用户拍板的事（如逐字稿用哪种排列）只在排到那一份时才问。

版式参数全部固化为常量，不要每次重新设计。**只调格式，不改文字。**

教学设计另有**表格式骨架**（整篇一张 4 列表，见过《出塞教学设计》模板或用户要求「整体排版用一个表格」时用），
不是默认方案，见下文「表格式版式」。

## 何时使用

- 教学设计：给出教案内容（文本、Markdown、docx，或只给课题＋教材＋课时），要求排版／生成 docx
- 逐字稿：给出讲稿 + 对应课件 pptx，要求排成「图文对照、上课能照着念」的稿子
- 已有文档需要重新套版式

不适用：党政机关公文（用内置 `workbuddy-docx`）、内容从零创作（由写作类能力产出内容，本技能只负责版式）。

# 一、教学设计

## 第一步：取得内容并规范化

把源内容整理成**规范 Markdown**，写入临时 `.md` 文件。完整映射见
`references/markdown-mapping.md`，核心对应关系：

| Markdown | 含义 | 对应样式 |
|---|---|---|
| `# 标题` | 文档标题（课题＋教学设计） | 小三 15pt 宋体加粗，居中 |
| `## 一、xxx` | 一级标题 | 四号 14pt 宋体加粗，顶格 |
| `### （一）xxx` | 二级标题 | 小四 12pt 宋体加粗 |
| `#### 1. xxx` | 三级标题（环节） | 小四 12pt 宋体加粗，顶格 |
| `### 第一课时：xxx` | 分课时标题（脚本按「第X课时」自动识别） | 13pt 宋体加粗，居中 |
| `##### xxx` 或整行 `**xxx**` | 标签行（任务／课时目标） | 小四 12pt 宋体加粗，缩进 2 字符 |
| 普通段落 | 正文 | 小四 12pt 宋体，1.75 倍行距，首行缩进 2 字符 |
| `1. 内容` | 有序条目 | 左缩进，悬挂对齐 |
| `- 内容` / `- [ ] 内容` | **一律转成阿拉伯数字序号** | 与相邻项连续编号，不输出圆点或方框 |
| `\| 表 \| 格 \|` | 数据表 | 三线表，表头宋体加粗居中、**无底纹**；用户若要求「框线全显示、不加粗」则整份改为 0.5pt 全框线 |
| `![板书](路径)` | 板书设计（用户提供实拍／截图照片） | 按表格宽 14.4cm 居中插入，整幅不跨页；**不用字符画重绘** |
| `:::caption 表 1 xxx` | 表题 | 五号 10.5pt 宋体加粗居中 |

**整理内容时的硬性要求：**

1. **一字不改**。不增删、不改写、不润色、不调整语序，只补结构标记。
2. 单元格内用 `<br>` 或按 `；2.` 的序号书写条目均可，脚本会自动拆成独立行。
3. **板书设计一律用图片**：用户提供实拍／截图照片，用 `![说明](绝对路径)` 直接插入，
   不要手敲字符画重绘（两种引擎都已支持图片：开放式版式按**表格宽 14.4cm** 居中——版心 15.4 左右各缩 0.5，表格式版式 14.06cm 居中）。
   若用户只给了文字板书、没给照片，先提示其提供照片；用户明确要「先按文字排」时，
   把板书文字按普通段落输出（开放式引擎遇到 ```` ``` ```` 块会按纯文本降级并打警告，
   **不再生成字符画框**），拿到照片后再换成 `![]()`。
4. 缺失的章节（如「设计者」「日期」）留空占位，不编造。

## 第二步：运行排版引擎

```bash
python3 ~/.workbuddy/skills/lesson-typeset/scripts/jxsj_typeset.py \
    --input draft.md \
    --output 课题-教学设计.docx \
    --header "17 长城"
```

| 参数 | 说明 |
|---|---|
| `--header` | 页眉文字，写课题名（如「17 长城」）；页脚自动居中页码，从 1 连续 |
| `--accent` | 仅为兼容旧命令保留：本版式**没有任何着色点**，传什么值都不产生可见效果 |
| `--title` | 覆盖文档标题（源 Markdown 的 `#` 行优先） |

**全文字族统一宋体**（含标题、表头、数字与英文），层级靠加粗与字号拉开；
**不使用强调色**，一级标题**不加左侧竖条、不加色块**（用户 2026-11-04 明确不要）。
教学设计的两种骨架全程纯黑，没有任何着色点。

## 表格式版式（整篇一张表）

教学设计的另一种骨架：整份文档装进**一张 4 列网格表**，对齐已交付的《出塞教学设计》模板。
四种行型——分组行、标题行、标签·值行、内容行（正文段落、嵌套表、板书照片）；
教学过程**必须用满四列**（活动名称 / 教师活动 / 学生活动 / 设计意图），四列的 `tcW` 要与
`tblGrid` 逐列一致，否则 Word 会把四列拉平、看着像少了一列。

用它的信号：用户说「整体排版使用一个表格」「参照《出塞》那种版式」，或要求标题分层次带底纹。
否则用上方 `jxsj_typeset.py` 的开放式版式。

```bash
python3 ~/.workbuddy/skills/lesson-typeset/scripts/table_layout.py \
    --input draft.md --output 课题-教学设计.docx --title "《牛和鹅》教学设计"
```

| 参数 | 说明 |
|---|---|
| `--title` | 表格上方的文档标题；源稿里的 `#` 行会被丢弃，不会落成空行 |
| `--subtitle` | 标题下副标题。**默认不要给**：用户明确不要「最终定稿版｜两课时」这类字样 |

### 源稿语法

| 写法 | 渲染 |
|---|---|
| `# 标题` | 文档标题，表格上方居中 |
| `## 一、教学基本信息` | **大节分组行**：整行合并、居中、深灰 `C8C8C8` |
| `## 第一课时教学设计` | 同上；同时把解析器切到「课时内」上下文 |
| `### 一、本课时教学目标`（课时内） | 独立整行、左对齐、浅灰 `F0F0F0`、不跨页 |
| `### 教学重点`（课时外） | 正文流里的加粗小标题，与下面条目**同格**，不单独占行 |
| `#### 环节一：谈话导入（3分钟）` | 独立整行、白底、与下方四列表同页 |
| `:::row 课　题 \| 第20课《牛和鹅》` | 标签行：标签 1 格 + 值 3 格 |
| `:::row2 作　者 \| 任大霖 \| 年　级 \| 四年级` | 四格均分 |
| `:::act 活动名` + `T:` / `S:` / `D:` | 教学过程四列行，块尾 `:::` |
| `\| a \| b \|` | 嵌套表（全框线 0.5pt，宽 14.26cm；三列按 36/20/44 分宽，其余自适应） |
| `![](...)` | 图片，14.06cm 居中（板书用实拍照片，不用字符画） |
| 普通段落 / `1. xxx` | 整行内容行 |

`T:` `S:` `D:` 一行一段，同列多段就多写几行：

```text
:::act 活动一　谈话导入，激发兴趣
T: 出示课文插图，提问：看到这只鹅你有什么感觉？
T: 板书课题，全班齐读。
S: 观察插图，说出自己的感受。
D: 用熟悉的画面唤起阅读期待，为体会「我」怕鹅做铺垫。
:::
```

### 版式常量

A4，页边距**上下 2.54、左右 3.17**，表格宽 **14.66cm**（正好铺满版心，左右不再缩进）、居中，
四列 **2.10 / 5.60 / 3.70 / 3.26 cm**（合计 14.66cm）；
文档标题 18pt；表内正文四号 14pt、行距 **1.45**；教学过程四列小四 12pt、行距 **1.18**；
嵌套表五号 10.5pt（≥4 列 9.5pt）。**全文宋体，标题前不加竖线、无强调色。**
底纹三档：`C8C8C8` 大节分组行 > `F0F0F0` 课时内章节标题 ≈ 四列表头 > 白底环节标题。
四列表头**每个课时只出一次**（由含「课时」的 `##` 行触发），不是每个环节重出。

**框线（硬性）**：所有表格六条边全画、一律 0.5pt（`sz=4`）、纯黑；
外框**不加粗**，不用 1.5pt 顶/底线，整份文档不出现三线表外观；不写单元格级 `tcBorders`。
主表与嵌套表同一套框线。用户 2026-11-04 明确「表格的所有框线都需要显示，不能加粗」。

### 分页约定（2026-11-05 定稿：表格允许跨页断行）

**总则：整篇就是一张长表，允许跨页；行也允许跨页断行。不为「把一行凑整」把内容推到下一页而留白。**
分页完全交给排版器，不用阈值、不预估高度。

| 元素 | 约束 | 原因 |
|---|---|---|
| 主表 | 无 | 表格式必然跨页，不做整表保护 |
| 大节分组行（`##`） | `cantSplit` ＋ `keepNext` | 只有一行高，拆开只剩半行字；带住下一行 |
| 课时内章节标题（`###`） | `cantSplit` ＋ `keepNext` | 同上 |
| 环节标题（`####`） | `cantSplit` ＋ `keepNext` | 同上 |
| 四列表头 | `cantSplit` ＋ 段落 `keepNext` | 单行高；keep 保证至少带着活动首行同页 |
| **活动行（四列）** | **无**，可跨页断行 | 高行强推会在上一页尾部留 3–5cm 空白（实测 27→31 页） |
| **含嵌套表 / 图片的内容行** | **无**，可跨页断行 | 同上；嵌套表自身跨页是正常的 |
| 标签行（课题、作者、教材依据等字段） | `cantSplit` | 字段不可拆：标签与值被分到两页，比整行下移更难读 |

只有「单行高」的行才加 `cantSplit`（拆了也只是一行字搬家，代价 ≤1.5cm）；
**凡是会很高的行一律不加**，否则就是大片留白的来源。

- 表头后首个活动行**不再传** `force_keep`：表头靠段落 `keepNext` 与活动首行同页，活动行自己可以断。
- 活动名称格内的段落加 `keepLines`（`keep_together`），尽量让活动名整段换页，不出现「一、回顾与字词复｜查（4分钟）」这种半截名。
- 嵌套表首行保留 `tblHeader`：表跨页时续排页重复表头。
- 正文段落不设 `keep`，全局加会从 27 页涨到 31 页。
- 渲染差异：LibreOffice 转 PDF 时跨表格行的 `keepNext`、单元格内 `keepLines`、嵌套表 `tblHeader` 可能都不生效（Word / WPS / 腾讯文档正常）。用 LibreOffice 预览看到「标题留页底」「活动名断成两截」「续表没表头」，先按渲染差异处理，**不要为它加约束**。

语法细节与校验命令见 `references/table-spec.md`。

# 二、逐字稿

## 第零步：问用户要哪种排列（每次必做，不要替用户默认）

引擎有两种排列，结构完全不同，**开工前必须用 `AskUserQuestion` 问一次**，
除非用户在这轮对话里已经明确指定过。

| | 左右（`--layout side`） | 上下（`--layout stack`） |
|---|---|---|
| 结构 | 左列截图 5.4cm，右列稿子 8cm | 截图独占一行 11cm 居中，稿子满宽在下 |
| 每块行数 | 2 行（表头 + 图文） | 3 行（表头 + 图 + 文） |
| 15 页课件实测 | 9 页 A4 | 11 页 A4 |
| 适合 | 站着念、翻页快，一页看到更多；页数省 | 需要对照画面细节（板书、表格、字词）时图更大；稿子满宽行短，眼睛不易串行 |
| 代价 | 图小，画面细节要看投屏 | 页数多，一页放不下两块时页尾留白 |

提问模板：

```
问题：逐字稿用哪种排列？
1. 左右排列（推荐）：左图右文，15 页课件约 9 页 A4，紧凑省纸
2. 上下排列：图放大居中、稿子满宽在下，15 页课件约 11 页 A4，画面细节更清楚
```

用户选定后，把对应参数写进第三步的命令，回复里说明选的是哪种、因此页数是多少。

## 第一步：把课件渲染成图

```bash
python3 ~/.workbuddy/skills/lesson-typeset/scripts/ppt2png.py \
    --pptx "《19 秦兵马俑》第二课时.pptx" --outdir assets/ppt
```

输出 `p01.jpg … p15.jpg`，110dpi、约 10MB。**用 JPG 不用 PNG**——课件多是照片背景，
PNG 无损会把 15 页撑到 60MB+，Word 打开就卡。同一份课件渲染一次即可复用。
截图存该课 `assets/ppt/`，不进 `output/`。

## 第二步：把稿子整理成规范 Markdown

```markdown

小学语文 · 四年级 · 对应第二课时课件（第 1—15 页）· 40 分钟

## 使用说明

一、本稿按课件播放顺序逐页编写……

### 第二课时　编撰展陈手册下篇——品悟千人千面（40 分钟）

## 第 1 页 · 封面“红领巾解说团·下篇”｜0:00—1:00
```

| Markdown | 含义 |
|---|---|
| `# 标题` | 文档标题，小三 15pt 宋体加粗居中 |
| 紧跟标题的第一段 | 副标题（年级·课时·时长），自动居中、小五灰字 |
| `## 使用说明` | 二级标题，小四 12pt 宋体加粗 |

**硬性要求：**

1. **一字不改**，不润色、不合并、不调整语序。
2. 页号必须与 pptx 实际页序一致——稿子说「翻到第 5 页」，截图就得是第 5 张。
3. `〔〕` 提示符原样保留，它不是列表符号，不转序号。
4. 某页确实没有课件（如纯口头过渡），仍要保留该块，写清「无对应课件页」，不要删。

# 三、学习清单

## 何时使用

- 用户给出学习清单 / 作业清单内容（文本、docx，或只给课题＋课时），要求排版成课堂配套练习纸
- 已有学习清单需要重新套版式

不适用：内容从零创作（由写作类技能产出内容，本技能只负责版式）。

## 设计口径（已与用户逐项确认，不要重新设计）

| 项 | 值 |
|---|---|
| 纸张 / 边距 | A4；上 2.2 / 下 2.4 / 左 2.8 / 右 2.5 cm |
| 字体 | 宋体（全文字族统一） |
| 字号 | 正文 / 标题 / 表格 **统一五号 10.5pt**；主标题 16pt |
| 行距 | 全文 **1.5 倍** |
| 表格 | **全部边框网格**（外框四边 + 内部横竖线，浅灰 `BFBFBF` 细线） |
| 表格文字 | **一律不加粗**（表头、数据、田字格示范字、勾选框 `□` 均正常粗细）；表格外的小节标题与信息行标签可以加粗 |
| 单元格内边距 | **所有填字表统一 0.3cm**（表格级 `tblCellMar`，Word 标准语义，跨软件渲染一致） |
| 单元格对齐 | 文字垂直居中（`vAlign=center`） |
| 填空横线 | 用下划线字符 `_`（不用段末下划线空格、不用制表位引导符——LibreOffice 不渲染） |

分页：不限制页数，但**排版必须美观**（避免末页大片空白）；内容密时标准内边距自然成 2 页属正常，不要为塞 1 页而缩小内边距（「所有表统一标准内边距」优先于紧凑）。

版面元素：`char_practice()` 田字格（大字框 + 3 条练写线）、`grid_table()` 填字网格、`checkboxes()` `□` 勾选、`writeline()` 带横线填空、`add_info()` 班级/姓名/日期。

完整规范与构件说明见 `references/xuexqingdan-spec.md`。

## 运行排版引擎（Markdown 驱动，推荐）

```bash

```

| 参数 | 说明 |
|---|---|
| `--input` | 学习清单 Markdown 源稿；给了它就按 md 排，**不再手改脚本** |
| `--header` | 页眉文字，写课题名（如「21 一只窝囊的大老虎」） |
| `--title` | 文档标题；不给则用「页眉｜源稿第一个 `##`」 |
| `--subtitle` | 副标题（navy 居中，可不给） |
| `--lesson` | 旧接口（无 `--input` 时走脚本内置内容函数），新课文不要用 |
| `--output` | 输出 docx 完整路径 |

源稿语法（完整见 `references/xuexqingdan-spec.md` §3）：

| 写法 | 渲染 |
|---|---|
| `# 课题` | 只作页眉／标题素材，不进正文 |
| `## 第一课时学习清单` | 文档标题（配 `--header` 拼成「课题｜课时 学习清单」） |
| `### 一、…` | 小节标题（五号加粗） |
| `姓名：____ 日期：____` | 识别为信息行，自动换成「班级／姓名／日期」三格 |
| 普通段落 | 正文（支持 `**加粗**`） |
| `- xxx` | 自动转「1. 2. 3.」阿拉伯数字序号 |
| `\| a \| b \|` | 填字网格表；首行＋分隔行＝表头 |

| `:::write 演 练 撤` | 田字格练写（大字框＋3 条练写线） |
| `:::check A \| B \| C` | `□` 勾选项 |
| `:::pagebreak` | 分页 |

**不要再复制脚本改 `lesson1()/lesson2()`**——那是 2026-11-05 之前的做法，改内容一律改 md。

## 校验

```bash
soffice --headless --convert-to pdf --outdir /tmp/out 课题-学习清单.docx   # 看版面

python3 - <<'PY'
import zipfile, re
x = zipfile.ZipFile("课题-学习清单.docx").read("word/document.xml").decode()
bold = 0
for m in re.finditer(r"<w:tbl>.*?</w:tbl>", x, re.S):
    for r in re.findall(r"<w:r[ >].*?</w:r>", m.group(0), re.S):
        t = "".join(re.findall(r"<w:t[^>]*>([^<]*)</w:t>", r))
        bv = re.search(r'<w:b\b[^>]*?w:val="([^"]*)"', r)
        if ("<w:b " in r or "<w:b/>" in r) and (bv is None or bv.group(1)!="0") and t.strip():
            bold += 1
print("表格内加粗文字=", bold, "| 表格级边距tblCellMar=", x.count("tblCellMar"))
PY
```

- [ ] 所有填字表是完整边框网格（外框 + 内部横竖线均可见）
- [ ] **表格内加粗文字 = 0**
- [ ] 所有填字表含 `tblCellMar`（统一 0.3cm 单元格内边距），文字不贴边、四边一致
- [ ] 单元格文字垂直居中
- [ ] 填空横线用 `_` 字符，信息行（班级/姓名/日期）横线无残缺
- [ ] 田字格示范字 / 勾选框 `□` 清晰、不加粗
- [ ] 全文五号字、1.5 倍行距；末页无大片空白
- [ ] 页脚页码是真域：查 `footer*.xml` 应有 `w:fldCharType="begin"`；PDF 底部若显示字面「PAGE」，是属性名误写成 `w:val`

# 常见问题（按文档类型分开查）

## 教学设计（两种骨架共同）

| 现象 | 原因与处理 |
|---|---|
| 表格列宽不对 | 开放式：有语义的表头（教师活动／环节／项目）走固定比例，其余按内容长度自适应。表格式：固定 GRID 四列，不改比例。`tblPr` 子元素顺序错会静默丢属性，靠末尾 `normalize_xml` 修正 |
| 板书设计 | **一律插图片**：用户提供实拍／截图照片直接 `![说明](路径)` 插入；不要用字符画重绘——手敲的 `│ ├ └` 线框一换字体就散架、且占篇幅、可读性差，已成禁用做法 |
| 多出空白页 | 文末空段落所致，脚本会自动清理 |
| 边框整段失效 | `tblBorders` / `tcBorders` 的子元素必须按 top→left→bottom→right→insideH→insideV 排，`_ORDER` 已收录，末尾 `normalize_xml` 会重排 |
| **长表把首页留成半空** | 数据行被 `keepNext` 绑成一块，整表被推到下一页（实测 30 行表首页空白 21cm）。只让表头段落 `keepNext`；数据行**既不加 `keepNext` 也不加 `cantSplit`**，允许跨页断行 |
| **某页尾部空出 3–5cm** | 有一行被 `cantSplit` 强推整行下移。规则：只有单行高的行（分组行、标题、表头、标签行）可加 `cantSplit`，高行一律不加 |

## 教学设计·开放式

| 现象 | 原因与处理 |
|---|---|
| 表格右边界溢出 | 表格居中＋固定宽 14.4cm，等于左右各缩进 0.5cm，不要改成左对齐＋缩进 |
| 标题孤悬页末 | 标题样式已开「与下段同页」；表格紧跟标题时个别渲染器仍会拆，属渲染差异，可接受 |

## 教学设计·表格式

| 现象 | 原因与处理 |
|---|---|
| 表格右边界溢出 | 表格宽 14.66cm，铺满版心，本来就不缩进；写成 14.4 反而窄出一截 |
| **表格框线缺一边、看着没封口** | 单元格级 `tcBorders` 的优先级高于表格级 `tblBorders`：在某个边写了 `val="none"` 就把外框那条线挖掉了。**`tcBorders` 一律不写**，只保留表格级 `tblBorders` 六边 |
| **“只剩三列”、活动名称与教师活动连成一段** | 每格 `tcW` 与 `tblGrid` 不一致，Word 按 `tcW` 重排把四列拉平。用 `finish_table()` 从每格起始列求和，四列写 1191/3175/2098/1848 |
| **框线粗细不一、外框明显加粗** | 嵌套表还在走三线表（`sz=12` 顶底 + `sz=6` 表头线）或残留 `tcBorders`。统一调 `grid_borders()`，六边 `sz=4` |

## 逐字稿

| 现象 | 原因与处理 |
|---|---|
| 表头与内容被分页拆开 | 表头段落漏了 `keepNext` |
| 时间没贴右边 | 用了制表位，改用 6.4/4.0/4.0 三列网格 |
| 文档 60MB | 截图用了 PNG，改 JPG 质量 88 |
| **块与块之间像断成两个表** | 一块建一个表时，Word 强制在两表间插段落，于是有空隙＋两条并排线。改成整表连续、每块追加两行，块间只留 `insideH` 一条分隔线 |
| **跨页后图片整格空白** | side 主体行漏了 `cantSplit`：行跨页时图片格被渲染器丢空。代码已对 side 主体行加 `cantSplit`（行高仅约 3cm，代价仅多 1 页），详见 `references/zjg-spec.md` §5 |

## 学习清单

| 现象 | 原因与处理 |
|---|---|
| 填空横线打印不出来 | 用了段末下划线空格或制表位引导符，LibreOffice 不渲染；改用下划线字符 `_` |
| 连续「标签：____」没合成填字表 | 只识别连续 2 行以上；单行按普通段落排，属预期 |
