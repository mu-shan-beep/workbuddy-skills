## 一、来源与定位

用户 2026-11-06 确认预览效果后追加一条对齐修正（截图「课时主题」表格比上下色块宽出一截），修复后确认「没什么问题了，保存下来吧」，随后固化。

**流程**：先出效果 → 用户确认 → 再固化，两步确认均已完成。固化前备份见 `.archive/2026-11-06/`。

## 三、核心结构：有框线才成表

以行的边框档位 `bd` 为唯一判据，不按内容语义猜：

| 行型 | `bd` | V3.1 处理 |
|---|---|---|
| 主标题 `title` | `none` | 普通段落（居中） |
| 一级章节标题 `band` | `none` | 普通段落（段落底纹） |
| 通栏正文 `group`（小标题／编号／正文／辅助对照文字） | `none` | 普通段落组 |
| 环节分区 `band2` | `thick` 0.75pt | **表格行** |
| 四列表头 `head` | `thin` 0.5pt | **表格行** |
| 字段行 `field`（`:::row`／`:::row2`） | `thin` | **表格行** |
| 活动行 `act` | `thin` | **表格行** |
| 辅助对照块（Markdown 表并格） | `thin` | **表格行** |
| 板书图片 `image` | `thin` | **表格行** |

**分块规则**：连续同判据的行合并为一个块；段落块与表格块交替输出，段落块天然充当表间分隔，不插入空段落、不手工加间距。《牛和鹅》实测得到 **10 块 / 5 张表 / 57 个表格外段落**。

**一句话**：表格数量不再是 1，也不固定，取决于源稿里画框线的块有几段。

## 四、左右对齐口径（V3.1 新增，必做）

Word／LibreOffice 会把表格按 `tblCellMar.left` 向左顶出，导致**表格边框落在版心外 3mm**，与段落底纹色块左右错开（用户截图反馈的问题）。

三条同时成立才算对齐：

1. 每张表写 `w:tblInd w:w="170" w:type="dxa"`（= `tblCellMar.left` 3mm），把边框拉回版心左边界；
2. 标题／小标题段落：`left_indent = 0` 让底纹铺满版心宽，`first_line_indent = 3mm` 让文字首行与表格内文字齐平；
3. 正文／编号／对照段落：`left_indent = 3mm`、`right_indent = 3mm`（编号段落叠加悬挂缩进）。

实测验收坐标（A4、版心 164mm、LibreOffice 转 PDF）：

| 元素 | 修复前 x0→x1 | 修复后 x0→x1 |
|---|---|---|
| 段落色块 | 65.2 → 530.0 | 65.2 → 530.0 |
| 表格边框 | 56.5 → 522.0 | **64.9 → 530.5** |
| 色块文字 / 表格内文字 | 73.8 / 65.3 | **73.8 / 73.8** |

## 五、段落渲染口径

`render_free()` 只处理三类无框线行，参数一律取 `V.*`，不写新常量：

- `title`：18pt 主标题居中，段前 2pt／段后 4pt／行距 1.2；
- `band`：一级章节标题，段落底纹 `BAND`，段前 6mm／段后 3mm，左对齐，`keepNext` 沿用 V3.0 定向约束；
- `group`：按 `sub`／`item`／`tab`／`text` 逐条成段，小标题带底纹，编号段落悬挂缩进，正文首行缩进 2 字。

**只调格式，不改文字。** 段落化不得增删任何字符。

## 七、命令

须在课题根目录执行（源稿里的图片按课题根目录解析，找不到时回退源稿上一级）：

```bash
cd "<课题目录>"
python3 ~/.workbuddy/skills/lesson-typeset/scripts/table_v31.py \
  --input ".workbuddy/<课文>-教学设计-表格式源.md" \
  --output "<课文>-教学设计.docx" \
  --header "<页眉课题>"        # 可省略，省略时用源稿主标题
```

**源稿**：吃的是**表格式源稿**（不是开放式 V2.0 的源稿），语法与 V3.0 完全相同：
`# ` 主标题 → `## ` 一级章节 → `### ` 小标题 → `#### ` 环节标题（自动接四列表头）
→ `:::row `／`:::row2 ` 字段行 → `:::act ` + `T:/S:/D:` 活动
→ Markdown 数据表 → `![](assets/xxx.jpg)` 板书图。
四列表头由引擎生成，源稿里不要再写一遍。

## 八、校验清单（出稿必查）

1. **文字零增减**：成品全文（表格外段落 + 所有单元格，按 `tc` 去重）与源稿非空白字符多重集一致；差异只允许是被正常剥离的 `**` 加粗标记；无 `:::`／`T:`／`---` 残留。
2. **结构**：`<w:tbl>` 数量 = 画框线的连续块数（《牛和鹅》为 5）；每张表 20 个 `<w:gridCol w:w="465"/>`；表格外有正文段落；表格之间不需要空段落。
3. **对齐**：每张表都有 `w:tblInd w:w="170"`；LibreOffice 转 PDF 后表格横线 x0 与段落色块 x0 差 ≤ 1pt，表格内文字与标题文字 x0 一致。
4. **版式**：活动行 `gridSpan` 全为 `4,7,5,4`（《牛和鹅》54 行）；`:::row2` 四字段行是 `5,5,5,5`（1 行），**属预期、不要当比例异常**；`val="nil"` 只出现在（已脱表的）无框线行——若仍有留在表内的 `nil` 行，说明分块判据漏了；底纹仅 `EDF3EE`、框线仅 `9BA9A0`、字号仅 10.5／11／11.5／13／18pt。
5. **分页**：无空白页、无孤立标题、页首无「钟）」类孤字、两张板书图与各自标题同页、页数不比 V3.0 多（《牛和鹅》两版同为 18 页）。
6. **页眉页脚**：占位表 + 居中 PAGE 域，与 V3.0 一致。
