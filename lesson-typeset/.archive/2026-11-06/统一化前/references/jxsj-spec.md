# 教学设计统一排版标准 V2.0 · 完整规范

本文件是**教学设计（开放式／正文流骨架）的唯一权威**。页面、字体、颜色、表格、
图片、页眉 Logo、分页、校验，全部只认这里；`SKILL.md` 不复述数值。

表格式骨架（整篇一张 4 列表）是另一套模板复刻，规范在 `table-spec.md`，参数自成一套，
**不与本文件互相引用**。

适用于各学段、各学科、不同课时数量与章节结构的教学设计。不固定章节数量与名称，
按实际结构匹配样式；同一层级同一类型必须同格式；不增删内容；不靠缩字号、压间距控页数。

单位：毫米（mm）／磅（pt）。1mm = 2.8346pt。

## 四、页眉与 Logo

页眉固定为**左侧 30 × 12mm Logo 预留区 + 右侧品牌文字**，底边一条分隔线。

| 项目 | 标准 |
|---|---|
| Logo 预留区 | 30 × 12mm，左对齐正文左边界 |
| Logo 最大显示高度 | 10mm，等比缩放，不拉伸不裁切 |
| 页眉右侧文字 | 思源黑体 9pt，`#596960`，右对齐、垂直居中 |
| 分隔线 | 0.5pt 实线 `#CBD5CD`，宽度等于版心 |
| 页眉背景 | 白色/透明 |

Logo 缺失时给标准占位框：30 × 12mm、`#B8B8B8` 0.5pt 虚线、透明底、
居中「木老师原创课件」8pt `#999999` 思源黑体。禁止用随机图标或虚构 Logo 代替，
禁止因缺 Logo 取消预留空间或移动正文。

三种形态（`--logo` / 默认 / `--logo-mode hidden`）：

| 场景 | 表现 |
|---|---|
| 待补 Logo 的预览稿、可编辑模板 | 可见虚线占位框 |
| 有品牌 Logo | 只显示 Logo，无虚线框、无占位文字 |
| 正式无 Logo 版 | 框与文字都隐藏，30 × 12mm 空间保留 |

替换 Logo 只在原区域换图，不改预留区尺寸、页眉高度、正文边距与分页；所有页同步。
无论哪种形态，**正文起始位置完全一致**。

### 3.1 分隔线的实现口径

分隔线画成**页眉表格的下边框**（0.5pt `#CBD5CD`），不做独立线段落。页眉表格行高 12mm、
距顶 8mm，线落在距顶约 **20mm** 处，正文上边距 28mm，留出 8mm 间距，不会压到正文。

理由：页眉区 12mm 之后只剩 8mm 余量，再加一个分隔线段落会把正文顶下去（逐字稿
实测过这个坑）。验收清单只查「页眉与正文不重叠」，20mm 完全满足。

## 七、表格

| 项目 | 参数 |
|---|---|
| 宽度 | 与版心等宽 **164mm** |
| 对齐 | 与正文左边界对齐（不居中、不缩进） |
| 外边框 | 0.75pt 实线 |
| 内边框 | 0.5pt 实线 |
| 边框色 | `#9BA9A0` |
| 表头背景 | `#EDF3EE` |
| 正文背景 | `#FFFFFF` |
| 单元格内边距 | 左 3 / 右 3 / 上 2.5 / 下 2.5mm |
| 行高 | 最小 12mm，内容多时自适应 |
| 表格段前 / 段后 | 4mm / 5mm |

**网格表**：六条边全画、横竖完整、交点准确、不出现双线、不缺线断线；
同一张表线宽与颜色统一。不使用单元格级 `tcBorders` 逐边覆盖（会把外框挖断）。

**三线表**（需要时）：顶线 0.75—1pt、表头下线 0.5—0.75pt、底线 0.75—1pt，无内部竖线。

**单元格**：

- 表头 10.5pt 思源黑体加粗，水平垂直居中，长表头允许自动换行，同行等高。
- 正文 10.5pt 楷体，行距 1.25—1.35，内部段后 1—2pt，自动换行、不裁切、不压字距。
- 单行正文左对齐 + 垂直居中；**多行正文左对齐 + 顶端对齐**。
- 数字居中或统一右对齐；图片、符号居中。
- 实际行高 ≥ 内容高 + 上下内边距；同一行各格等高。
- 合并单元格继续执行统一内边距，文字完整、无多余边框、无错位。

**列宽**（`column_ratios()` 的经验值）：

| 表型 | 比例 |
|---|---|
| 教学过程四列（表头含「环节」或「活动名称」） | 15 / 30 / 28 / 27 |
| 三列且含「教师活动」 | 40 / 30 / 30 |
| 两列「项目 + 内容」 | 28 / 72 |
| 其他 | 按内容长度 90 分位自适应，单列不低于 14% |

**分页**：

- 跨页重复表头（表头行 `tblHeader`），表头行 `cantSplit`。
- 表头不得单独留页末：表头段落 `keepNext`，保证带着首行同页。
- 数据行**不加 `cantSplit`**——规范 §14.7 的「原则上不拆分」按「行高超过半页才允许拆」
  落地：教学过程四列的行常达 10cm 以上，强推整行会在上一页留十几厘米空白
  （实测 5 页→4 页，且上一页空白 20cm）。长段落自然跨页续排是预期行为。
- 嵌套表宽度不得超过外层单元格有效宽度，与外框保留 ≥2.5mm 间距，不因嵌套缩字号。

## 十一、引擎实现约定（改引擎时必守）

1. **页眉是 1×2 表格**（左 30mm / 右 134mm，行高 12mm、`hRule=atLeast`），
   只有表格能同时锁死宽、高、左对齐与垂直居中。分隔线=表格下边框。
2. **占位框画成单元格虚线边框**，不画自选图形；`--logo` 时跳过边框，否则预览里会
   同时看到虚线框和 Logo。
3. **Logo 图片必须同时给宽高**（按原图比例，高 ≤10mm、宽 ≤30mm），只给宽度会按
   原始 dpi 撑爆页眉。
4. **页眉部件结尾留一个 1pt 精确行高的空段**，否则多一行把正文顶下去。
5. **属性节点按 schema 顺序插入**（`_put()` + `_PPR_ORDER/_TBLPR_ORDER/_TCPR_ORDER/_TRPR_ORDER`）。
   直接 `append` 时 LibreOffice 预览正常、Word 静默丢格式。
6. **行高必须带 `hRule="atLeast"`**（`_set_row_h()`）；`tblW / tblGrid / tcW` 三者逐列一致
   （`set_col_widths()`），否则 Word 把列拉平。
7. **表格前后用精确行高的空段**（`gap()`）撑出 4mm / 5mm，表格本身没有段距属性；
   表格前的空段加 `keepNext`，避免标题孤悬页尾。
8. **run 层显式写字体/字号/颜色/加粗**，不依赖样式继承——`python-docx` 的
   `run.font.bold` 默认会写 False，把样式里的加粗冲掉。
9. **样式对齐也必须自己写 `w:jc`**（`_set_style_align()`）：`style.paragraph_format.alignment`
   对自定义样式不落盘，实测主标题/副标题/表题/图注全部退化成左对齐。
10. **图注间距由图片段落的段后给**（2.5mm），图注自身段前归零——图片是 inline，
    行高自带 surplus，靠图注段前撑不出间距（实测只剩 0.7mm，字贴在图边上）。
11. 双面装订用 `w:mirrorMargins` + 左右边距（内侧写在 `left_margin`），不是逐节反转。

编号悬挂对齐；无空格空行凑版；无溢出重叠裁切；无孤立标题。

**表格**：宽度=版心；六边框线完整，外 0.75pt 内 0.5pt `#9BA9A0`；

跨页重复表头；每页尾部留白 ≤3cm。

**图片**：比例正确、不超版心、图注 9.5pt 居中、图文间距 5mm。

## 十三、常见问题

| 现象 | 原因与处理 |
|---|---|
| 表格列被拉平、看着少一列 | `tcW` 与 `tblGrid` 不一致。用 `set_col_widths()` 一次写全三者 |
| 表格外框缺一边 | 写了单元格级 `tcBorders` 且某边 `val=none`，把外框挖掉。只保留表格级 `tblBorders` |
| 某页尾部空出 10cm+ | 数据行被 `cantSplit` 强推。数据行一律不加 `cantSplit` |
| 标题孤悬页末、表头单独留页底 | 标题/表头段落缺 `keepNext`；表格前空段也要 `keepNext` |
| 一级标题看起来像正文 | run 层没写 `bold=True`，`run.font.bold=False` 冲掉了样式加粗 |
| 页眉占位框变形 | Logo 只给了宽度，按原 dpi 撑爆；必须同时给宽高 |
| 正文被页眉顶下去 | 页眉里多加了分隔线段落。分隔线只做表格下边框 |
| 表格后正文紧贴底线 | 表格没有段后属性，需 `gap(doc, 5)` 撑出 5mm |
| PDF 里楷体看着像黑体 | 本机 LibreOffice 对 CJK 一律回落 Hiragino Sans GB，字族以 docx 写入为准 |
| 表格行高在预览里偏大 | LO 在 `trHeight=atLeast` 外另算上下边距，Word 是 12mm 整，**不要据此调小规范值** |
