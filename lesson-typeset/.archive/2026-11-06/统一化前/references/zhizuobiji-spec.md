# 课件制作笔记 · 统一排版标准 V1.0

> 本文件是「制作笔记」这一类文档的**唯一权威**。页面、字号、颜色、间距、表格、图片、
> 分页、交付校验全部在这里；本文件不引用、不参照其他文档类型的任何数值或规则。
> 引擎：`scripts/zhizuobiji_typeset.py`（常量在文件开头，改版式只改常量）。

制作笔记是**说明性文档**（讲这套课件为什么这样做、每一页怎么想的），不是课堂用纸，
也不是教案。判定依据：内容里出现「设计理念／页面组织思路／视觉表达／使用建议」这类
复盘性章节，而不是「教学目标／教学过程／板书设计」。

---

## 1. 页面规格

| 项目 | 值 |
|---|---|
| 纸张 / 方向 | A4 210 × 297 mm，纵向 |
| 上 / 下边距 | 18 / 18 mm |
| 左 / 右边距 | 20 / 20 mm |
| 版心 | **170.0 mm** |
| 双面装订（`--mirror`） | 内侧 22 / 外侧 18 mm，奇偶页镜像，**版心仍 170.0 mm** |
| 页眉距上边 | 10 mm（`header_distance = 1.0cm`） |
| 页脚距下边 | 10 mm（`footer_distance = 1.0cm`） |
| 页面缩放 / 背景 | 100% / 纯白 |

单面与双面**只换左右边距，不换版心**——两种模式下列宽、表格宽度、图片宽度全部不变。

不通过缩字号、压行距、改页面比例来控制页数。

## 2. 字体与字号

标题思源黑体，正文楷体，全篇只有这两种。本机缺字体时按候选表整篇回落，不局部混用。

| 层级 | 字体 | 字号 | 字重 |
|---|---|---|---|
| 文档主标题 | 思源黑体 | 20 pt | 加粗 |
| 文档副标题 | 思源黑体 | 13 pt | 常规 |
| 一级标题 | 思源黑体 | 14 pt | 加粗 |
| 二级标题 | 思源黑体 | 12 pt | 加粗 |
| 三级标题 | 思源黑体 | 11 pt | 加粗（"中等"，docx 无 500 字重，用加粗＋同色实现层次） |
| 正文 | 楷体 | 11 pt | 常规 |
| 表格表头 | 思源黑体 | 10.5 pt | 常规（靠浅绿底纹区分，不加粗） |
| 表格正文 | 楷体 | 10.5 pt | 常规 |
| 图片说明 | 楷体 | 9.5 pt | 常规 |
| 页眉 / 页脚 | 楷体 | 9 pt | 常规 |

回落候选（引擎内置，按序取本机第一个真实存在的字族）：

- 标题：思源黑体 → 思源黑体 CN → Source Han Sans SC/CN → Noto Sans CJK SC → Noto Sans SC → PingFang SC → 微软雅黑 → 黑体
- 正文：楷体 → KaiTi → Kaiti SC → STKaiti → 楷体_GB2312

正文不得低于 10.5 pt。

## 3. 颜色

| 元素 | 色值 |
|---|---|
| 主标题 / 一级标题 / 二级标题 | `#315A4B` |
| 三级标题 / 正文 | `#2B302C` |
| 辅助文字 / 图注 / 页眉页脚 | `#596960` |
| 表头 / 强调区域底 | `#EDF3EE` |
| 表格边框 | `#9BA9A0` |
| 章节分隔线 | `#CBD5CD` |
| 页面背景 | `#FFFFFF` |

标题颜色不随章节变化；不使用大面积深色底、渐变、装饰底纹。黑白打印时文字与分隔线要分得清。

## 4. 标题区（首页，不单独做封面页）

| 元素 | 规则 |
|---|---|
| 主标题 | 20 pt 加粗居中，行距 1.2，段前 6 mm（"标题上方留白"），不超版心，最多两行 |
| 副标题 | 13 pt 居中，与主标题间距 6 mm（规范 5—7 mm） |
| 副标题 → 首章 | 14 mm（规范 12—16 mm） |

默认不单独设封面页；首页标题区之后直接进入正文，"一、"之前不额外留白。

## 5. 标题层级与间距

| 层级 | 段前 | 段后 | 行距 | 颜色 | 分隔线 |
|---|---|---|---|---|---|
| 一级 | 10 mm | 4 mm | 1.2 | `#315A4B` | 上边框 0.5 pt `#CBD5CD` |
| 二级 | 7 mm | 3 mm | 1.2 | `#315A4B` | 无 |
| 三级 | 5 mm | 2 mm | 1.2 | `#2B302C` | 无 |

- 一级标题的章节分隔线**画成段落上边框**（`h2_rule()`），不另起一个分隔线段落：
  独立线段在标题被推到下页时会孤零零留在上一页页脚，而且多占一行高度（实测多出 61 mm 空白）。
- 首个一级标题**不画**分隔线（紧接标题区）。
- 三个层级的标题都开 `keepNext`：标题不得单独留在页末，其后至少跟住一段正文。
- 编号由源稿书写，引擎**不自加编号**（作者原文可能是「第一阶段」「1. 第04页」，直接沿用）。

## 6. 正文

| 项目 | 值 |
|---|---|
| 字号 / 字体 | 11 pt 楷体 |
| 对齐 / 行距 | 左对齐 / **1.5 倍** |
| 首行缩进 | 2 个汉字（`Pt(22)`） |
| 段前 / 段后 | 0 / 3 mm |
| 孤行控制 | 开（`w:widowControl`） |

引文（`>`）左缩进 0.6 cm、同倍行距、`#596960`；有序列表（`- xxx`）悬挂缩进 0.78 cm、
`1. 2. 3.` 自动编号、项间 2 mm。

## 7. 编号与列表

| 层级 | 样式 |
|---|---|
| 一级 | 一、二、三、 |
| 二级 | （一）（二）（三） |
| 三级 | 1. 2. 3. |
| 四级 | （1）（2）（3） |

编号是**内容**不是版式：源稿里写什么就排什么，引擎不改写、不重排编号。
无序列表统一转阿拉伯数字序号，不出现 `·`、`□` 等符号。

## 8. 表格

| 项目 | 值 |
|---|---|
| 宽度 | 与版心等宽 **17.0 cm**，居中，左右与正文对齐 |
| 外框 / 内框 | 0.75 pt / 0.5 pt 实线，`#9BA9A0` |
| 表头 | `#EDF3EE` 底、10.5 pt 思源黑体（回落黑体）、水平＋垂直居中、行高 ≥12 mm |
| 数据行 | 白底、10.5 pt 楷体、左对齐＋垂直居中、行高 ≥12 mm（`hRule=atLeast`） |
| 单元格内边距 | 左 3 / 右 3 / 上 2.5 / 下 2.5 mm（`tblCellMar`，全表统一） |
| 多行文字行距 | 1.3 倍 |
| 表格外间距 | 上 4.5 mm / 下 5 mm（规范 4—6 / 5—7） |
| 跨页 | 表头行 `tblHeader`（重复表头）、`cantSplit`；数据行 `cantSplit` 不拆行 |

**列宽比例**（按内容类型，不无条件平均分）：

| 结构 | 比例 |
|---|---|
| 两列（项目＋说明，默认） | 30% / 70% |
| 两列对比 | 50% / 50%（用 `:::colw 50 50` 显式指定） |
| 三列 | 25% / 35% / 40% |
| 四列 | 28% / 24% / 24% / 24% |

源稿写 `:::colw 25 35 40` 可覆盖为任意比例（按权重归一化到版心宽）。

## 9. 图片与图注

| 项目 | 值 |
|---|---|
| 宽度 | 不超过版心 17.0 cm，按原始比例缩放，单张居中 |
| 与上方文字 | 5 mm |
| 与图注 | 2.5 mm |
| 图注 → 下方文字 | 3 mm |
| 图注 | 楷体 9.5 pt `#596960` 居中，行距 1.2 |
| 清晰度 | 位图按排版尺寸 ≥300 dpi |

图片不得拉伸变形、不得与文字重叠。多图并排时等宽、间距 4—6 mm、顶部对齐。

## 10. 分隔线与强调区域

**分隔线**：0.5 pt 实线 `#CBD5CD`，不超版心。两种来源——
章节分隔（一级标题上边框，默认自动）、源稿 `:::divider`（段落下边框，需显式写）。

**强调区域**（`:::note`）：1×1 无框表 + `#EDF3EE` 底 + **四边 4.0 mm** 内边距
（规范 4—5 mm）。文字沿用正文 11 pt，可按原文加粗。块上下各 4.5 / 5 mm。
整篇不超过 2—3 处——用在「核心结论」这类全篇落点上，不要每章都来一块。

用表格实现的原因：段落底纹会被行距压塌成一条细线（LibreOffice / Word 都不把段距算进底纹）。

## 11. 页眉与页脚

| 项目 | 值 |
|---|---|
| 页眉 | 9 pt `#596960`，距上边 10 mm；左 30×12mm `木老师原创课件` 虚线占位框 ＋ 右课题（思源黑体），底边 0.5pt `#CBD5CD` 分隔线（四类统一） |
| 页脚 | 9 pt 楷体 `#596960`，距下边 10 mm，"第 N 页" 居中 |
| 页码 | 阿拉伯数字真域（`fldSimple PAGE`），正文第一页即第 1 页，连续 |
| 首页 | 与正文页同样式（`different_first_page_header_footer = False`） |

## 12. 分页

- 一级／二级／三级标题都 `keepNext`，标题不与正文分离。
- 段落开 `widowControl`，不出现段首孤行／段末孤行。
- 表格表头 `tblHeader` 重复，数据行 `cantSplit`。
- 不通过缩字号、压行距解决分页。
- 不出现只有两三行的尾页：收紧 `note` 块间距或表格上下间距（都在 4—6 mm 区间内）即可，不动字号。

## 13. 源稿语法

Markdown，一条命令生成 docx。

| 写法 | 渲染 |
|---|---|
| `# 课题` | 文档主标题（20 pt 居中加粗） |
| `:::subtitle 课件制作与使用笔记` | 文档副标题（13 pt 居中） |
| `## 一、xxx` | 一级标题（14 pt 深绿 + 章节分隔线） |
| `### （一）xxx` | 二级标题（12 pt 深绿） |
| `#### 1. xxx` | 三级标题（11 pt 深灰加粗） |
| 普通段落 | 正文（11 pt 楷体，1.5 倍，首行缩进 2 字，支持 `**加粗**`） |
| `- xxx` | 自动转 `1. 2. 3.` 悬挂缩进序号 |
| `> xxx` | 引文（左缩进、辅助色） |
| `\| a \| b \|` + 分隔行 | 表格，首行作表头；两列默认 30/70 |
| `:::colw 50 50` | 紧接下一张表的列宽权重 |
| `:::note 文字` | 浅绿强调区（单块，可 `**加粗**`） |
| `:::divider` | 独立细分隔线（一般不用，章节已自动） |
| `![图注](绝对路径)` | 图片 + 居中图注 |
| `:::caption 表 1 xxx` | 独立图表题（9.5 pt 居中，与下表同页） |
| `:::pagebreak` | 硬分页 |

标题区（主标题＋副标题）由源稿给，页眉与页码由引擎生成。

## 14. 校验

```bash
python3 ~/.workbuddy/skills/lesson-typeset/scripts/zhizuobiji_typeset.py \
    --input 制作笔记.md --header "23 王戎不取道旁李" --output 课题-制作笔记.docx

/Applications/LibreOffice.app/Contents/MacOS/soffice --headless \
    --convert-to pdf --outdir /tmp/o 课题-制作笔记.docx     # 逐页目视
```

```python
import zipfile, re
from docx import Document
f = "课题-制作笔记.docx"
d = Document(f); sec = d.sections[0]
cm = lambda v: round(v / 360000, 2)
print("版心 %.1fcm" % (cm(sec.page_width) - cm(sec.left_margin) - cm(sec.right_margin)))
x = zipfile.ZipFile(f).read("word/document.xml").decode()
print("字号", sorted({int(v)/2 for v in re.findall(r'<w:sz w:val="(\d+)"/>', x)}))
print("字族", sorted(set(re.findall(r'w:eastAsia="([^"]+)"', x))))
print("底纹", sorted(set(re.findall(r'w:fill="([^"]+)"', x))))
print("分隔线 pBdr", x.count("<w:pBdr>"), "| 表头重复", x.count("<w:tblHeader"))
```
