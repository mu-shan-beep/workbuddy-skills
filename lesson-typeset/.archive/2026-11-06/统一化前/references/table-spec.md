# 表格式教学设计 · 完整规范

整份教学设计装进**一张 4 列网格表**。骨架来自已交付的《出塞教学设计》，用《牛和鹅》两课时打磨定稿。
引擎：`scripts/table_layout.py`，底层构件来自 `scripts/jxsj_legacy.py`（两者必须放在一起）。

> **与 `jxsj-spec.md`（V2.0 开放式版式）互不套用**：页面边距、版心、字族、字号、配色、
> 框线粗细全部各写各的。V2.0 的 164mm 版心、思源黑体＋楷体、`#9BA9A0` 边框、页眉 Logo 区
> 都**不适用**于本骨架；本骨架的 14.66cm 表格、全宋体、纯黑 0.5pt 框线也不适用于 V2.0。
> 换骨架就同时换规范，不要混用参数。

## 一、页面与网格

| 项 | 值 |
|---|---|
| 纸张 | A4，21.0 × 29.7 cm |
| 页边距 | 上下 2.54、左右 3.17 cm |
| 表格 | 宽 **14.66cm**（＝版心宽，左右不缩进，正好卡在两条页边距之间）、居中、**全框线 0.5pt**（六条边全画、粗细一致） |
| 单元格内边距 | 左右 0.15cm（85 twips）、上下 0.07cm（40 twips） |
| 四列宽 | **2.10 / 5.60 / 3.70 / 3.26 cm**（合计 14.66cm） |

> **表格宽就是 14.66cm**——它等于 A4 扣掉左右各 3.17cm 的版心宽度，所以铺满、不缩进。
> 换成别的数字会让表格比正文宽出或窄出一截，右边界直接出框。

四列不是「四栏并排」，而是**一套可合并的网格**。不同行按需要占几格：

| 行型 | 占格 |
|---|---|
| 大节分组行、环节标题行、整行内容行 | 4 格合并为 1 |
| 标签行 `:::row` | 第 1 格标签 + 第 2—4 格合并放值 |
| 四格行 `:::row2` | 1 + 1 + 1 + 1 |
| 教学过程活动行 `:::act` | 1 + 1 + 1 + 1，正好对应活动名称 / 教师活动 / 学生活动 / 设计意图 |

改列宽只改文件头 `GRID`，不要在各行里写死宽度——`finish_table()` 按每格在该行的**实际起始列**求和回写 `tcW`（跨列格 `sum(GRID[start:start+span])`）。
宽度必须与 `tblGrid` 一致：LibreOffice 认网格、Word 认 `tcW`，两者不一致时 Word 会把四列拉平，看着就像少了一列。

## 二、字号与底纹

| 元素 | 字体 | 字号 | 底纹 |
|---|---|---|---|
| 文档标题 | 宋体加粗 | 18pt（小二）居中 | 表格外，白底 |
| 副标题 | 宋体 | 10.5pt 居中 | 表格外，白底 |
| 大节分组行（`##`） | 宋体加粗 | 14pt 居中 | **C8C8C8** |
| 课时内章节（`###`，在「第X课时教学设计」之内） | 宋体加粗 | 14pt 左对齐、缩进 2 字符 | **F0F0F0** |
| 课时外小标题（`###`，如教学重点） | 宋体加粗 | 14pt | 无，与下方条目同格 |
| 环节标题（`####`，如环节一） | 宋体加粗 | 14pt | 无（白底） |
| 标签行（`:::row`／`:::row2`）的标签 | 宋体加粗 | **12pt** 居中（标签列仅 2.10cm，14pt 会折行） | 无 |
| 标签行的值 | 宋体 | 14pt 左对齐 | 无 |
| 正文 / 条目 | 宋体 | 14pt（四号） | 无 |
| 四列表头 | 宋体加粗 | 12pt 居中 | F0F0F0 |
| 教学过程四列内容 | 宋体 | 12pt（小四） | 无 |
| 嵌套表表头 | 宋体加粗 | 10.5pt；≥4 列用 9.5pt | **无底纹** |
| 板书照片 | — | 宽 14.06cm（表格宽减 0.6cm）居中 | 无 |

全文统一**宋体**（含标题、表头、数字），层级只靠加粗、字号、底纹拉开。标题前**不要竖线**。

底纹只有三档，顺序不能乱：`C8C8C8` 表示「换大节了」，`F0F0F0` 表示「课时内换小节 / 这里是表头」，白底表示「这里还是同一段内容的延续」。

行距：正文 `LINE = 1.45`（参考模板 1.5，压到 1.45 是为了把全文压进整页）；教学过程 `LINE_ACT = 1.18`。

### 2.1 框线（硬性规则）

用户 2026-11-04 明确：**表格的所有框线都要显示，且不能加粗**。

| 规则 | 做法 |
|---|---|
| 六条边全画 | `tblBorders` 的 top / left / bottom / right / insideH / insideV 一律 `val="single"` |
| 粗细统一 | `sz=4`（0.5pt），**外框不加粗**，不用 1.5pt 顶/底线，整份文档不出现三线表外观 |
| 颜色 | `auto`（纯黑），不用灰线 |
| 单元格级 | 不写 `tcBorders`；`grid_borders()` 会清掉嵌套表遗留的表头下线，避免与网格线叠成粗线 |

主表与嵌套表同一套框线：一页里不允许出现「一张全框线表 + 一张三线表」。

## 三、源稿语法

### 3.1 标题层级

```markdown
# 第20课《牛和鹅》教学设计          ← 文档标题（给 --title 时丢弃此行）

## 一、教学基本信息                  ← 大节分组行（C8C8C8，居中）
### 教学重点                         ← 课时外：正文流加粗小标题，与条目同格
#### 环节一：谈话导入，质疑激趣（3分钟）  ← 独立整行，白底

## 第一课时教学设计                   ← 大节分组行 + 切到「课时内」上下文
### 一、本课时教学目标                ← 课时内：独立整行，F0F0F0
```

判断「课时内 / 课时外」的唯一依据：`##` 行里是否含「课时」二字。含 → 之后所有 `###` 独占一行；
不含 → 之后所有 `###` 都退回正文流。

### 3.2 标签行

```text
:::row 课　题 | 第20课《牛和鹅》
:::row2 作　者 | 任大霖 | 年　级 | 四年级
```

- `:::row` 的值写在竖线右边，可以含 `；` 分隔的多条内容，引擎会拆成多段。
- `:::row2` 必须是 4 段（标签/值/标签/值），多退少补。
- 标签用全角空格撑齐（`课　题`、`作　者`），不要用半角空格加空格凑宽度。

### 3.3 教学过程四列

```text
:::act 活动一　谈话导入，激发兴趣
T: 出示课文插图，提问：看到这只鹅，你有什么感觉？
T: 板书课题，全班齐读。
S: 观察插图，说出自己的感受。
D: 用熟悉的画面唤起阅读期待，为体会「我」怕鹅做铺垫。
:::
```

| 前缀 | 列 | 说明 |
|---|---|---|
| 活动名（`:::act` 后的文字） | 第 1 列 | 加粗 12pt |
| `T:` | 第 2 列 教师活动 | 一行一段 |
| `S:` | 第 3 列 学生活动 | 一行一段 |
| `D:` | 第 4 列 设计意图 | 一行一段 |
| `:::` | 块结束 | 必须写，否则后续段落会被吞进本块 |

同一列要多段，就重复写多行 `T:`。列内不写序号时引擎原样输出；写 `1.` 就照 `1.` 输出。

### 3.4 其他块

```markdown
| 项目 | 内容 |           ← 嵌套表（全框线 0.5pt，宽 14.26cm，表头无底纹、宋体加粗）
![](assets/20牛和鹅-图片-板书第一课时.jpg)   ← 图片，14.06cm 居中
1. 正确认读「谓、拳、捶」等 12 个生字。      ← 整行内容行，保留原序号
```

嵌套表宽 **14.26cm**（表格宽减 0.40cm），列宽规则：三列固定 36 / 20 / 44（中列放「受挫、觉得为难」这类六字条目），
由 `nested_widths()` 按表宽换算成 `gridCol` 与 `tcW`；四列及以上沿用内容自适应。

无序列表（`-` / `- [ ]`）会被统一改成阿拉伯数字序号，与普通版式一致。

## 四、四列表头的出现规则

**每个课时只在第一个活动行之前放一次表头**，不是每个环节都重出。

- `head_pending` 在遇到含「课时」的 `##` 行时置 True；
- 读到第一个 `:::act` 时输出表头行，随即置 False；
- 表头行 `cantSplit` ＋ 段落 `keepNext`，保证表头与活动**首行**同页；活动行本身允许跨页断行（不再有 `force_keep`）。

如果某课时的教学过程被中间的小节（如作业设计）打断，表头不会重出——这符合用户要求「不要每段都来一个小表头」。

## 五、分页策略（2026-11-05 定稿：允许跨页断行）

**整篇是一张长表，必然跨页；行也允许跨页断行。原则是「不为凑整行留白」。**

| 元素 | 属性 | 原因 |
|---|---|---|
| 主表 | 无约束 | 表格式必然跨页，不做整表保护 |
| 大节分组行 | `cantSplit` ＋ 段落 `keepNext` | 单行高，拆开只剩半行字；要带住下一行 |
| 章节标题 / 环节标题 | `cantSplit + keepNext`（行级） | 同上 |
| 四列表头 | `cantSplit` ＋ 段落 `keepNext` | 单行高；keep 保证与活动首行同页 |
| 活动行（四列） | **无**，可跨页断行 | 高行强推会在上一页尾部留 3–5cm 空白（实测 27→31 页） |
| 含嵌套表的内容行 | **无**，可跨页断行 | 同上；嵌套表首行 `tblHeader`，续排页重复表头 |
| 标签行（课题 / 作者 / 教材依据） | `cantSplit` | 字段不可拆：标签与值分到两页比整行下移更难读 |
| 正文段落 | 无 | 全局 `keep` 会让页数从 27 涨到 31 |

**判定口径**：只有「单行高」的行加 `cantSplit`——它被推下去最多损失一行（≤1.5cm）；
**凡是会很高的行（活动行、含嵌套表或图片的内容行）一律不加**，否则就是页尾大片留白的来源。

**实测**：把活动行全部设为 `cantSplit` 时 27 → 31 页、多页下半部空白；
取消后 27 页、零孤立标题。2026-11-05 本课实测：去掉表头后首个活动行的 `force_keep` 后，
第 5 页尾部留白 4.56cm → 0.31cm，第 7 页 2.90cm → 0.32cm，总页数不变（10 页）。

断行的代价要认：活动名可能被切到下一页顶部。`活动名称` 格段落已加 `keepLines`，
尽量整段换页；Word / WPS / 腾讯文档会整段下移，LibreOffice 预览会切半截——属渲染差异。

LibreOffice 转 PDF 时，跨表格行的 `keepNext`、单元格内 `keepLines`、嵌套表 `tblHeader` 都可能不生效，
`四、教学过程` 这类标题会留在页底、续表没有表头。**这是渲染差异，不要为它改约束。**

## 六、校验清单

```bash
# 1) 顶层表格（w:body/w:tbl）必须是 1 张；嵌套表也写成 <w:tbl>，所以总数会大于 1，别数错
python3 -c "
import zipfile
from lxml import etree
ns = {'w': 'http://schemas.openxmlformats.org/wordprocessingml/2006/main'}
root = etree.fromstring(zipfile.ZipFile('out.docx').read('word/document.xml'))
top = root.findall('w:body/w:tbl', ns)
print('顶层表格', len(top), '| 含嵌套共', len(root.findall('.//w:tbl', ns)),
      '| 主表行数', len(top[0].findall('w:tr', ns)) if top else 0)
txt = ''.join(root.itertext())
print('表头', txt.count('活动名称'), txt.count('教师活动'), txt.count('设计意图'))
"

# 2) 转 PDF 看总页数、每页末行、找孤立标题
/Applications/LibreOffice.app/Contents/MacOS/soffice --headless --convert-to pdf --outdir /tmp/out out.docx
python3 -c "
import pymupdf as fitz
d = fitz.open('/tmp/out/out.pdf')
print('页数', d.page_count)
for i, p in enumerate(d):
    t = [x for x in p.get_text().split(chr(10)) if x.strip()]
    print(i+1, '尾:', t[-1][:26] if t else '(空)')
"
```

- [ ] **顶层表格只有一张**（`w:body/w:tbl` 计数 = 1；`<w:tbl>` 总数会因为嵌套表大于 1，属正常），宽 14.66cm、不溢出右边界
- [ ] 四列表头每个课时恰好一次，且与活动**首行**同页
- [ ] 每页尾部留白 ≤1.5cm（末页除外）；出现 3cm 以上空白，说明某行被 `cantSplit` 强推，或该加 `cantSplit` 的行意外掉了
- [ ] 表格允许跨页断行：活动行、含嵌套表的行**没有** `cantSplit`（`grep -c cantSplit` 应等于单行高行的数量）
- [ ] 每个四列行的 `tcW` 与 `tblGrid` 逐列一致（不一致时 Word 会把四列拉平、活动名称列「消失」）
- [ ] 所有表格六条边都是 0.5pt（`sz=4`），文档内无 `1.5pt` 粗线、无三线表外观、无 `tcBorders`
- [ ] 底纹三档清晰可辨（C8C8C8 / F0F0F0 / 白）
- [ ] 环节标题是白底整行，不是灰底小表头（用户明确不要灰底）
- [ ] 课时外的小标题（教学重点、教师准备）与条目同格，没有单独占行
- [ ] 整篇字符数与源稿零增减（只允许表头文字多出）

字符零增减的对账脚本：

```python
import pymupdf
from collections import Counter

def chars(pdf):
    t = "".join(p.get_text() for p in pymupdf.open(pdf))
    return Counter(t.replace(" ", "").replace("\n", ""))

a, b = chars("新版.pdf"), chars("旧版.pdf")
print("新版多", sum((a - b).values()), "旧版多", sum((b - a).values()))
```

## 七、常见问题

| 现象 | 原因与处理 |
|---|---|
| **看起来只有三列**，活动名称与教师活动连成一段 | 每格 `tcW` 与 `tblGrid` 不一致（旧版按「前 span 列求和」算，四格全取第一列 2.10cm）。Word 认 `tcW`，会把四列拉平。用 `finish_table()` 按起始列重算 |
| 框线粗细不一、外框特别粗 | 嵌套表仍走三线表（`sz=12` + `sz=6`）或残留 `tcBorders`。统一调 `grid_borders()` |
| 表头每环节都出现一次 | `head_pending` 被 h3 分支误置；只有含「课时」的 `##` 行才能置 True |
| 所有「活动一」重号、分不清环节 | 环节标题被合并进第一列导致；环节名必须留作 `####` 独立行 |
| 页尾大片空白 | 某高行被 `cantSplit` 强推整行。判定：只有单行高的行才可加 `cantSplit`，活动行 / 含嵌套表行一律不加 |
| 活动名被切成两截（页 5 底「复查」，页 6 顶「查（4分钟）」） | 行跨页时单元格在段间断开。`活动名称` 格段落已加 `keepLines`；Word / WPS 会整段下移，LibreOffice 预览切半截属渲染差异 |
| 续表没有表头 | 嵌套表首行需带 `tblHeader`；Word / WPS 会重复，LibreOffice 不重复嵌套表头（渲染差异） |
| 标题孤悬页底 | 标题行缺 `keepNext`，或渲染器不支持跨表行 keep（LibreOffice 的已知差异） |
| 表格第一行是空的 | 源稿给了 `# 标题` 又传了 `--title`，旧版会把标题当空段落落表；现版本丢弃 `#` 行 |
| 嵌套表上方多一条空行 | `render_nested_table()` 已删首空段，若复现检查 `was_first` 分支 |
| 单元格文字被吃掉首行缩进 | `_ind()` 未显式清零 `firstLineChars`，单元格会继承正文的 2 字符缩进 |
| 图片超宽 | `render_image()` 固定 14.06cm，源图过宽时先裁，不要改宽度常量 |
