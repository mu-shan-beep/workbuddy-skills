# 逐字稿版式规范（统一标准 V1.1）

本文件是逐字稿**唯一权威**。参数改了只改这里和 `scripts/zjg_typeset.py` 顶部常量，
不要拿学习清单、制作笔记的数值来套。

逐字稿是站着讲课、对着投屏念的工作稿。版式只服务一个目的：
**抬眼就能确认「现在讲的是第几页、这一句该怎么说」。**

---

## 1. 页面

| 项 | 值 |
|---|---|
| 纸张 | A4 纵向，210 × 297mm |
| 边距 | 上 26 / 下 20 / 左 24 / 右 24mm |
| 正文版心 | **162mm**（引擎 `CONTENT_W`） |
| 双面装订 | `--mirror`：内侧 26 / 外侧 22mm，**版心仍 162mm** |
| 页眉距顶端 | 9mm |
| 页脚距底端 | 10mm |
| 排版方式 | 单栏、连续排版，自然分页 |

**不强制一页课件对应一张纸。** 这是与旧「课件对照表」版式最根本的区别：
现在按文章流排，讲到哪排到哪，页数由内容决定。

页面网格是逐字稿自己的数值（`M_TOP/M_BOTTOM/M_LEFT/M_RIGHT` 显式写入 section），
改别的文档不会连带改这里。

---

## 2. 页眉与 Logo（本类独有）

页眉是一个 **1×2 表格**，行高 12mm，总宽 162mm：

```
┌──────────── 30mm ────────────┬──────────── 132mm ────────────┐
│  [ Logo 或 虚线占位框 ]        │                  课题 · 课时（9pt 右对齐）│
└──────────────────────────────┴───────────────────────────────┘
```

| 项 | 值 |
|---|---|
| 预留区 | **宽 30 × 高 12mm**，与正文版心左边界对齐 |
| Logo 最大显示高度 | **10mm**，等比缩放进预留区 |
| 占位框 | 0.5pt 虚线 `#B8B8B8`，文字「木老师原创课件」8pt `#999999` 居中 |
| 右侧品牌文字 | 思源黑体 9pt `#596960`，右对齐、垂直居中 |
| 分隔线 | 页眉表格下边框 0.5pt 实线 `#CBD5CD`，不另起分隔线段落 |
| 页眉背景 | 纯白 |

**硬性要求**

1. 没有 Logo 时**必须保留占位框**，不得取消这块位置、不得改用图标／首字母／几何图形代替。
2. 无论有没有 Logo，**正文起始位置完全一致**——页眉高度不能变，页边距不能动。
3. 预留区 12mm + 页眉距顶 9mm = 21mm，正文上边距 26mm，正好留出 5mm 间距。
   所以页眉里**不能再加分隔线段落**（多一行就吃掉这 5mm），要用线就画成页眉表格的下边框。
4. 页眉部件结尾必须有一个段落（Word 要求），引擎用 1pt 行高的空段收尾，不占位。
5. 首页与后续页页眉完全相同（`different_first_page_header_footer = False`）。

三种输出形态（`--logo` / `--logo-mode`）：

| 场景 | 参数 | 效果 |
|---|---|---|
| 有品牌 Logo | `--logo 路径` | 只显示 Logo，无虚线框、无占位文字 |
| 待补 Logo 的预览稿／可编辑模板 | 默认 | 显示虚线占位框 |
| 正式无 Logo 版 | `--logo-mode hidden` | 隐藏框与文字，**保留 30×12mm 空间** |

## 3. 字体与字号

| 层级 | 字体 | 字号 | 字重 | 颜色 |
|---|---|---|---|---|
| 文档主标题 | 思源黑体 | 20 | 加粗 | `#222222` |
| 文档副标题 | 思源黑体 | 10.5 | 常规 | `#222222` |
| 一级章节标题 | 思源黑体 | 15 | 加粗 | `#222222` |
| 逐页标题 | 思源黑体 | 11.5 | 加粗 | `#315A4B` |
| 教师台词 | 楷体 | 12 | 常规 | `#222222` |
| 学生齐答／学生发言 | 楷体 | 11.5 | 常规 | `#222222` |
| 学生预设回答 | 楷体 | 10.5 | 常规 | `#596960` |
| 操作提示 | 楷体 | 10.5 | 常规 | `#596960` |
| 板书提示 | 楷体 | 10.5 | 常规 | `#315A4B` |
| 说明性正文 | 楷体 | 11 | 常规 | `#222222` |
| 时间标记 | 思源黑体 | 10 | 常规 | `#596960` |
| 表格表头／正文 | 思源黑体／楷体 | 10.5 | 常规 | `#222222` |
| 图片说明 | 楷体 | 9.5 | 常规 | `#666666` |
| 页脚页码 | 楷体／思源黑体 | 9 | 常规 | `#666666` |

- 全篇**只两种字族**：思源黑体（标题类）＋ 楷体（台词类）。不用宋体、不用艺术字。
- 教师台词不低于 11.5pt（本规范取 12pt）。
- 不使用中文斜体强调；不用拉伸／压缩字宽。

**本机没有思源黑体**时引擎按 `HEAD_CANDIDATES` 回落到 PingFang SC；要严格用思源黑体，
装上字体后重跑即可，或用 `--font-head 思源黑体` 强制。

## 4. 颜色

| 元素 | 值 |
|---|---|
| 主标题／章节标题／台词 | `#222222` |
| 逐页标题／板书提示 | `#315A4B` |
| 预设回答／操作提示／时间 | `#596960` |
| 页脚页码／图注 | `#666666` |
| 表格边框 | `#9BA9A0` |
| 表头底色 | `#F2F5F2` |
| 分隔线 | `#CBD5CD` |
| Logo 占位框／文字 | `#B8B8B8`／`#999999` |

全文配色统一，黑白打印后层级仍要分得开——所以层级差异主要靠**字号＋字重＋灰度**，不靠彩色块。

---

## 5. 首页

| 元素 | 规则 |
|---|---|
| 主标题 | 20pt 加粗居中，行距 1.2，段前 8mm、段后 5mm，最多两行 |
| 副标题 | 10.5pt 居中，行距 1.2，段后 10mm |
| 首页章节标题 | 与正文一级章节标题同规格（15pt 加粗居中，段前 8、段后 5mm） |

首页沿用统一页眉与 Logo 区，不单独改页眉高度，也不单独做封面页（默认无独立封面）。

---

## 6. 标题层级

| | 一级章节标题 | 逐页标题 |
|---|---|---|
| 字号字重 | 15pt 加粗 | 11.5pt 加粗 |
| 对齐 | 居中 | 左对齐，时间右对齐 |
| 行距 | 1.25 | 1.2 |
| 段前／段后 | 8mm／5mm | 6mm／2.5mm |
| 左缩进 | 0 | 0 |

逐页标题结构：`第 N 页 · 环节名`（左）＋ `3:30—4:00`（右）。

**时间用右制表位定位，不用连续空格推。** 制表位设在版心右边界（16.2cm），
时间 10pt `#596960`，与标题至少留 3mm；标题过长时先让标题换行，不压字距。

标题一律 `keep_next`：标题后至少跟两行正文，不单独留在页末。

---

## 7. 台词与提示（核心）

所有标识型段落（`师：`／`生（齐）：`／`〔操作〕`…）都**标识加粗＋悬挂缩进**，
换行后与正文首字对齐，不用空格对齐。

| 类型 | 字号 | 行距 | 左缩进 | 段前／段后 | 悬挂 |
|---|---|---|---|---|---|
| 教师台词 `师：` | 12 | 1.45 | 标识宽度 | 1pt／2pt | 是 |
| 学生 `生：`／`生（齐）：` | 11.5 | 1.4 | 标识宽度 | 1pt／2pt | 是 |
| 预设回答 `〔学生可能说〕` | 10.5 | 1.35 | 4mm＋标识宽度 | 1pt／2pt | 是 |
| 操作提示 `〔操作〕` | 10.5 | 1.35 | 4mm＋标识宽度 | 2pt／2pt | 是 |
| 板书提示 `〔板书〕` | 10.5 | 1.35 | 4mm＋标识宽度 | 2pt／2pt | 是 |
| 说明性正文 | 11 | 1.5 | 首行缩进 2 字 | 0／3mm | 否 |

标识宽度 = 标识字符数 × 字号（全角算 1、半角算 0.5），引擎按实际字号算，不写死。

台词段落之间**不插空行**，间距全由段前段后控制。

---

## 8. 表格

| 项 | 值 |
|---|---|
| 宽度 | 与版心等宽 162mm，不超出 |
| 边框 | 外 0.75pt、内 0.5pt，`#9BA9A0` |
| 表头 | 底色 `#F2F5F2`，水平垂直居中 |
| 单元格内边距 | 左右 3mm、上下 2.5mm |
| 行高 | 单行最小 12mm，随内容增高 |
| 单元格文字 | 10.5pt，行距 1.3；单行垂直居中，多行顶部对齐 |

列宽按各列最长内容加权分配（不是无条件均分），保证文字完整显示。
表头行 `tblHeader` + `cantSplit`，数据行 `cantSplit`；跨页重复表头。

表格上下各留 4—6mm（引擎用 5mm 的透气段实现——表格前后不能用段距）。

---

## 9. 图片

| 项 | 值 |
|---|---|
| 最大宽度 | 版心 162mm，默认 12cm（`--img-width` 可调，上限 16.2cm） |
| 对齐 | 居中 |
| 与文字间距 | 上下各 4—6mm |
| 图注 | 楷体 9.5pt `#666666`，居中，与图 2.5mm |
| 缩放 | 严格等比，不拉伸、不裁切 |

课件截图由 `ppt2png.py` 渲染成 `p01.jpg …`，放该课 `assets/ppt/`；
源稿里不写 `![]()` 时引擎按页号自动匹配，写了就以源稿为准。
图与图注 `keep_next` 绑在一起，不跨页分离。

---

## 10. 页码与页脚

- 阿拉伯数字，**页脚居中**，9pt `#666666`，页脚距底 10mm。
- 页码是真域（`w:fldSimple` + `PAGE`），不是手打数字。
- 全文连续，首页即第 1 页（无独立封面时不分段编号）。
- 不需要页码时用 `--no-page-number`。

---

## 11. 分页控制

- 自然连续分页，不手动插分页符，不用空行凑版面。
- 标题不单独留页末（`keep_next`）。
- 避免台词段落首尾孤行（`widow_control` 开）。
- 图片与图注同页。
- 不靠缩字号、压行距来减页数。
- 不出现意外空白页。

---

## 12. 源稿语法（Markdown → 版式）

| 写法 | 渲染 |
|---|---|
| `# 课题 · 课时 逐字稿` | 文档主标题 20pt |
| 主标题后第一段 | 副标题 10.5pt（年级·课时·时长） |
| `## 一、课前准备` | 一级章节标题 15pt 居中 |
| `## 第 3 页 · 环节名｜3:30—4:00` | **逐页标题**（左标题＋右时间） |
| `### 第 3 页 · …` | 同上；不带页号时按 11.5pt 加粗小标题排 |
| `师：…` | 教师台词 12pt 楷体，标识加粗、悬挂 |
| `生（齐）：…` / `生：…` | 学生台词 11.5pt，标识加粗、悬挂 |
| `〔操作〕…` | 操作提示 10.5pt `#596960`，缩进 4mm |
| `〔学生可能说〕…` | 预设回答 10.5pt `#596960`，缩进 4mm |
| `〔板书〕…` | 板书提示 10.5pt `#315A4B`，缩进 4mm |
| `〔其他〕…` | 按灰色提示排（同操作提示） |
| `![图注](p03.jpg)` | 图片＋图注；在页块内则挂到该页 |
| `\| a \| b \|` 表格 | 全框线表格，首行＋分隔行＝表头 |
| 其他段落 | 说明性正文 11pt，首行缩进 2 字 |

**硬性要求**

1. 稿子**一字不改**：不润色、不合并、不调语序。
2. 页号必须与 pptx 实际页序一致。
3. `〔〕` 是标签不是列表符号，不转序号、不换成 `·`／`□`。
4. 某页确实没有课件（纯口头过渡）仍保留该页标题，写清「无对应课件页」，不要删。

## 13. 一条命令

```bash
python3 ~/.workbuddy/skills/lesson-typeset/scripts/zjg_typeset.py \
    --input draft.md \
    --output 23王戎不取道旁李-第一课时-逐字稿.docx \
    --header "23 王戎不取道旁李 · 第一课时 逐字稿" \
    --images assets/ppt \
    [--logo assets/brand/logo.png] [--logo-mode placeholder|hidden] \
    [--img-width 12] [--mirror] [--no-page-number]
```

| 参数 | 说明 |
|---|---|
| `--header` | 页眉右侧文字，写「课题 · 课时 逐字稿」 |
| `--images` | 课件图目录，按 `pNN.jpg` 自动匹配 |
| `--logo` | 品牌 Logo；给了就替代占位框 |
| `--logo-mode` | 无 Logo 时：`placeholder`（默认，虚线框）／`hidden`（隐藏留位） |
| `--img-width` | 截图宽度 cm，默认 12，上限 16.2 |
| `--mirror` | 双面装订镜像边距 |
| `--no-page-number` | 不排页码 |

## 14. 引擎实现约定（改引擎时必守）

1. **页眉用 1×2 表格**，不用「段落＋图片＋制表位」——只有表格能同时锁死
   30mm 宽、12mm 高、左对齐、垂直居中这四件事。
2. **占位框画成单元格虚线边框**，不画矩形自选图形：单元格边框随行高走，换字号不跑位。
3. **页眉部件结尾必须留一个段落**（Word 结构要求），用 1pt 行高收尾，否则页眉会多出一行把正文顶下去。
4. **右侧时间用右制表位**（`WD_TAB_ALIGNMENT.RIGHT` 设在 16.2cm），不用空格、不用表格。
5. **logo 图片必须同时给宽高**（按原图比例算出，高 ≤10mm、宽 ≤30mm），只给宽度会按原始 dpi 撑爆页眉。
6. **`pPr/tblPr/tcPr/trPr` 子元素按 schema 顺序插入**（复用学习清单引擎的 `_put`）；
   直接 `append` 时 LibreOffice 预览正常、Word 会静默丢格式。
7. **行高必须写 `hRule="atLeast"`**（`_set_row_h`），只给 `val` 会被忽略。
8. LibreOffice 渲染 `trHeight="atLeast"` 时会在行高外**另加**上下单元格边距（实测 12mm 排成 17.2mm），
   Word 里是 12mm 整。所以 LO 预览的行高看着偏松属正常，不要据此调小规范值。
9. 本机 LibreOffice 对 CJK 字体一律回落到 Hiragino Sans GB，**PDF 预览看不出楷体/黑体的差别**；
   字族以 docx 里写入的名为准（`PingFang SC` + `Kaiti SC`）。

## 15. 校验

```bash
/Applications/LibreOffice.app/Contents/MacOS/soffice --headless \
    --convert-to pdf --outdir /tmp/zjg 课题-逐字稿.docx

python3 - <<'PY'
import zipfile, re
from docx import Document
f = "课题-逐字稿.docx"
d = Document(f); s = d.sections[0]
cm = lambda v: round(v/360000, 2)
print("版心 %.1fcm | 边距 上%.2f 下%.2f 左%.2f 右%.2f | 页眉距上 %.2f"
      % (cm(s.page_width)-cm(s.left_margin)-cm(s.right_margin),
         cm(s.top_margin), cm(s.bottom_margin), cm(s.left_margin),
         cm(s.right_margin), cm(s.header_distance)))
z = zipfile.ZipFile(f)
x = z.read("word/document.xml").decode()
print("字号", sorted({int(v)/2 for v in re.findall(r'<w:sz w:val="(\d+)"/>', x)}))
print("颜色", sorted(set(re.findall(r'w:color w:val="([0-9A-Fa-f]{6})"', x))))
for n in z.namelist():
    if n.startswith("word/header"):
        t = z.read(n).decode()
        print("页眉 表格", t.count("<w:tbl>"), "| 虚线", t.count('w:val="dashed"'),
              "| 木老师原创课件", "木老师原创课件" in t, "| 图", t.count("<pic:pic>"))
PY
```

交付前逐项确认：

- [ ] 版心 162mm，边距 26/20/24/24，页眉距顶 9mm、页脚距底 10mm
- [ ] 每页页眉都有 30×12mm Logo 区（图或虚线占位框），右侧文字不与它重叠
- [ ] 占位框文字「木老师原创课件」8pt 居中；`--logo-mode hidden` 时框与文字都不出现但位置保留
- [ ] 有 Logo 时**没有**残留虚线框与占位文字，图不变形、高度 ≤10mm
- [ ] 主标题 20pt／章节 15pt／逐页标题 11.5pt，层级一眼可分
- [ ] 逐页标题右侧时间贴版心右边界（16.2cm），不是浮在中间
- [ ] `师：`／`生（齐）：` 等标识加粗，续行与正文首字对齐（悬挂缩进）
- [ ] 三种提示灰度与颜色正确：操作 `#596960`、板书 `#315A4B`
- [ ] 表格外框 0.75pt／内框 0.5pt、表头 `#F2F5F2`、文字不贴边
- [ ] 图片等比、居中、图注不跨页分离
- [ ] 页码是 PAGE 域、居中、连续；页眉页脚不压正文
- [ ] 无孤立标题、无意外空白页
- [ ] 稿子段落零丢失（与源文逐段比对）
