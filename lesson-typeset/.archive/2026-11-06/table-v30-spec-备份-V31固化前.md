# 教学设计统一表格式排版标准
**V3.0｜单一主表格结构｜Skill执行版**

## 一、核心排版约束

### 1.1 单表格原则

整份教学设计必须采用**一张连续的Word主表格**完成正文排版。

强制要求：

1. 正文中只能存在一张主表格。
2. 所有章节、标题、正文、活动、辅助表、图片、板书图均位于同一张主表格内部。
3. 不允许将不同章节拆成多张独立表格。
4. 不允许在单元格内部插入嵌套表格。
5. 不允许使用普通正文段落替代主表格中的章节行。
6. 不允许使用浮动文本框模拟表格。
7. 所有布局变化均通过主表格的行、列、合并单元格和单元格样式实现。
8. 主表格允许跨页连续延伸。
9. 页眉、页脚独立于正文主表格。
10. 新增或删除章节不得破坏主表格结构。

**单表格是不可变更的结构要求，表格总行数和章节数量不作限制。**

### 1.2 基础网格

沿用附件现有的20列基础网格结构。

| 参数 | 标准 |
|---|---|
| 主表格数量 | 1张 |
| 基础网格列数 | 20列 |
| 主表格总宽度 | 164 mm |
| 每个基础网格宽度 | 8.2 mm |
| 表格布局 | 固定列宽 |
| 行高 | 按内容自适应 |
| 单元格间距 | 0 mm |
| 布局变化方式 | 横向或纵向合并单元格 |

所有单元格必须对应统一的基础网格边界。

不得出现局部单元格宽度偏移、表格总宽度变化或不属于基础网格的任意列宽。

主表格宽度必须与正文版心一致。

### 2.2 双面装订

- 奇数页左26 mm、右20 mm。
- 偶数页左20 mm、右26 mm。
- 上下边距保持不变。
- 不额外叠加装订线宽度。

### 2.3 页面方向统一

由于正文必须保持为一张连续主表格，**同一文档内默认禁止混合纵向和横向页面**。

如整份教学设计需要横向排版，可将整个文档统一设置为A4横向：

| 项目 | 横向标准 |

| 纸张尺寸 | 297 × 210 mm |
| 上边距 | 28 mm |
| 下边距 | 20 mm |
| 单面左右边距 | 各23 mm |
| 主表格总宽度 | 251 mm |
| 20列网格单列宽度 | 12.55 mm |

不得为了局部宽表而拆分主表格。

所有行类型均属于同一张主表格。

## 七、主表格边框规则

### 7.1 按行类型设置边框

**主表格不得强制给所有单元格套用完全相同的四边框。**

| 行类型 | 边框设置 |
|---|---|
| 文档标题行 | 无边框 |
| 普通章节标题行 | 无边框或统一底部分隔线 |
| 普通长文本行 | 无边框 |
| 信息字段行 | 0.5 pt浅灰边框 |
| 环节分区行 | 0.75 pt分隔边框 |
| 活动表头行 | 0.5 pt内部边框 |
| 活动正文行 | 0.5 pt内部边框 |
| 辅助对照行 | 0.5 pt网格边框 |
| 图片行 | 按统一图片容器样式设置 |

### 7.2 边框参数

| 项目 | 标准 |
|---|---|
| 活动模块外边界 | 0.75 pt |
| 活动内部线条 | 0.5 pt |
| 章节分隔线 | 0.5—0.75 pt |
| 边框颜色 | `#9BA9A0`或`#B7C5BA` |
| 单元格间距 | 0 mm |

### 7.3 边框限制

- 不使用双重边框。
- 合并单元格后清除被覆盖的内部线条。
- 横线和竖线交点准确衔接。
- 不出现断线、重线。
- 通栏正文不强制添加可见网格线。
- 不因整篇是一张表格，就将整篇渲染成密集方格。

## 十、行高与自动换行

| 行类型 | 最小高度 |
|---|---|
| 主标题行 | 按标题实际高度确定 |

| 二级分区行 | 12 mm |

| 活动正文行 | 按内容自适应 |
| 图片行 | 图片高度＋内边距 |

### 10.2 行高规则

- 使用最小行高，不使用固定精确行高。
- 行高随文字内容自动增加。
- 同一行的所有单元格高度一致。
- 不允许文字被固定行高截断。
- 不通过增加大量空行改变行高。

### 10.3 换行规则

- 单元格内部自动换行。
- 中文标点执行正常换行规则。
- 不允许文字溢出边框。
- 不允许相邻单元格文字重叠。
- 不允许将括号中的时间拆成不合理的单字行。
- 不使用手动硬换行强制调整单个词组的位置。

## 十一、四列教学活动专项标准

**4∶7∶5∶4**

|---|---:|---:|---:|

| 第三列 | 5 | 41.0 mm | 25% |
| 第四列 | 4 | 32.8 mm | 20% |
| 合计 | 20 | 164.0 mm | 100% |

这一配置为默认四列结构。

若全文采用其他比例，必须统一调整所有四列教学活动行，不得局部采用不同列宽。

### 11.2 表头

| 行高 | 不小于12 mm |
| 底色 | `#EDF3EE` |

### 11.3 活动名称列

### 11.7 四列高度

同一活动行的四个单元格具有相同实际行高。

文字较短的列允许自然留白。

不得通过拉大文字行距、增加空段落等方式强行填满单元格。

### 12.3 编号段落

|---|---:|

### 13.2 双组字段

采用5＋5＋5＋5结构。

每组标签与内容形成固定的两格组合。

### 13.3 字段样式

- 不允许标签与内容错位。

## 十四、辅助表格的单表实现

### 14.1 核心要求

所有辅助信息表必须在主表格内部完成，不建立子表格。

通过主表格的新增行及合并单元格形成视觉上的辅助表格。

### 14.2 双列辅助区域

采用10＋10结构。

适用于两栏对照排版。

### 14.3 三列辅助区域

采用5＋7＋8结构。

各列宽度为41 mm、57.4 mm、65.6 mm。

### 14.4 辅助区域标题

使用20列合并通栏行。

- 字号10.5—11.5 pt。
- 思源黑体加粗。
- 左对齐或按该区域统一居中。
- 背景为`#EDF3EE`。
- 与辅助数据行保持同页。

### 14.5 辅助区域边框

- 与教学活动表使用相同线宽。
- 可采用浅灰色细边框。
- 不出现第二层表格外框。
- 不使用额外文本框模拟辅助表格。

### 14.6 辅助区域与活动表衔接

辅助区域结束后，直接在同一主表格内恢复4＋7＋5＋4的四列布局。

需要四列表头时，新增普通表头样式行。

不得拆分主表格。

## 十五、单表格跨页规则

### 15.1 基本原则

**允许一张主表格跨越多页，但不得因分页造成阅读顺序混乱或内容丢失。**

### 15.2 短行分页

对于能够完整放入一页的短行：

- 优先保持整行同页。
- 不允许在单行文字中间随意断开。
- 当前页空间不足时可整体移至下一页。

### 15.3 长行分页

对于内容较长的活动行：

1. 优先允许自然分页。
2. 必须保证所有列的文字完整显示。
3. 如果自动跨页造成阅读困难，可将一个逻辑活动拆为连续的多行。
4. 拆分后的所有行仍属于同一张主表格。
5. 不允许为了拆分活动而新建表格。
6. 不允许文字重复或遗漏。

### 15.4 超长行

如果某一活动行高度超过一页可用版心：

- 不得强制整行保持同页。
- 允许按段落边界在同一表格内拆成连续行。
- 不允许出现内容无法显示或超出页脚的问题。
- 不允许使用固定行高截断内容。

### 15.5 续表提示

在需要明确续接关系的页面，可在同一主表格中新增续接表头行。

续接表头沿用原活动表头格式。

注意：

- 续接表头是主表格中的普通行。
- 不得将其创建为第二张表格。
- 不依赖Word对非表格顶部行的自动重复表头功能。
- 不得让续接表头单独出现在页末。

### 15.6 表头重复限制

Word的自动重复表头通常适用于表格最顶部的连续表头行，不适用于巨型主表格中间任意位置的分区表头。

因此：

- 不对整张主表格启用不适用的全局重复表头。
- 教学活动模块开始时设置独立表头行。
- 对确需续接的部分，在同一表格内安排续表表头。
- 续表表头的位置应在最终分页检查时确认。

---

## 十六、分页优化

### 16.1 防止孤立标题

以下行不得单独留在页末：

- 一级章节标题。
- 课时标题。
- 环节标题。
- 活动表头。
- 辅助区域标题。

### 16.2 标题与表头组合

环节标题后方应尽量保留四列表头及至少一个活动行的起始部分。

不能仅将环节标题和表头放在页面底部，再把所有活动内容移至下一页。

### 16.3 分页优先级

按以下顺序选择分页位置：

1. 两个章节之间。
2. 两个教学环节之间。
3. 两个活动之间。
4. 同一活动的自然段落之间。
5. 不在单句中间强制分页。

### 16.4 页面留白

- 允许合理的页面底部留白。
- 不强制每页填满。
- 不使用空白行填充页面。
- 不通过过度压缩字体减少页数。
- 不允许出现由错误分页设置造成的大面积空白。

---

## 十七、板书图与图片排版

### 17.1 图片行结构

采用20列合并单元格。

图片不得放在嵌套表格中。

### 17.2 图片尺寸

| 项目 | 标准 |
|---|---|

| 图片下方间距 | 4—6 mm |
| 图片与容器边框最小距离 | 4 mm |
| 图片缩放 | 保持原始宽高比 |

### 17.3 板书图

- 优先完整显示。
- 不允许裁切。
- 不拉伸变形。
- 默认居中。
- 图片下方不插入多余空白段落。
- 不为填满页面而放大到模糊。
- 不允许图片跨页被拆分。

### 17.4 独立板书页面

如果板书图自然进入新页：

- 使用完整通栏图片行。
- 在版心范围内适当放大图片。
- 保持图像比例。
- 允许适度留白。
- 不通过插入额外表格改善布局。

- 图片按实际显示尺寸建议达到300 dpi。
- 不使用模糊或明显失真的图片。
- 图片中的文字必须清晰。
- 图片边缘与表格边框不重叠。

## 十九、合并单元格规则

### 19.1 横向合并

- 只能沿20列基础网格边界合并。
- 不改变主表格总宽度。
- 合并后清除多余内部线条。
- 合并区域的内边距按行类型执行。

### 19.2 纵向合并

- 原则上减少跨多行的纵向合并。
- 不允许纵向合并跨越不同教学环节。
- 不允许纵向合并跨越长距离分页。
- 避免因纵向合并导致部分文字无法显示。

### 19.3 合并后检查

- 不出现单元格宽度偏移。
- 不出现多余窄列。
- 不出现内部残留边框。
- 不出现文字位置异常。
- 不破坏其他行的20列网格对应关系。

## 二十、表格整体稳定性

### 20.1 固定宽度

- 主表格宽度始终为164 mm。
- 纵向页面每个基础网格宽度为8.2 mm。
- 不允许启用导致整表扩宽的自动适应内容功能。
- 不允许拖动局部边界造成基础网格宽度变化。

### 20.2 新增内容

新增章节、模块或活动时：

- 在主表格内部插入新行。
- 根据行类型合并基础网格。
- 继承对应样式。
- 不创建第二张表格。
- 不改变现有行列的网格基准。

### 20.3 删除内容

删除模块时：

- 删除对应的主表格行。
- 清理多余空白行。
- 保持相邻模块的边框连续。
- 不保留无意义的空单元格。

### 20.4 结构检查

最终文档正文必须满足：

- 只有一张Word表格。
- 基础网格列数固定为20。
- 总表格宽度符合标准。
- 不存在嵌套表格。
- 不存在游离于主表格外的正文模块。
- 页眉页脚不另建表格。

## 二十四、格式冲突处理优先级

当排版发生冲突时，严格按照以下顺序处理：

1. **唯一主表格结构**：不得拆表。
2. **20列基础网格**：不得破坏。
3. **页面安全边距**：不得越界。
4. **文字完整性**：不得截断或遗漏。
5. **最小字号与内边距**：不得随意压缩。
6. **表格列宽稳定性**：保持统一。
7. **分页完整性**：避免错误跨页。
8. **边框连续性**：不出现断线或重线。
9. **视觉平衡**：在满足以上条件后调整留白。

推荐的冲突解决顺序：

**调整换行 → 调整行高 → 调整主表格内行结构 → 合理分页 → 增加页面。**

不得以拆分主表格作为解决手段。

## 二十五、最终执行标准

1. 整份教学设计正文必须只有一张主表格。
2. 采用20列等宽基础网格。
3. 通过单元格合并实现所有版式变化。
4. 教学活动四列默认采用4∶7∶5∶4比例。
5. 不允许独立辅助表格和嵌套表格。
6. 页面默认A4纵向，正文版心宽164 mm。
7. 页眉固定预留30 × 12 mm Logo区域。
8. Logo缺失时使用统一占位。
9. 标题使用思源黑体，正文使用楷体。
10. 四列活动单元格全部顶部对齐。
11. 单元格左右内边距3 mm，上下2.5 mm。
12. 行高自动适应内容。
13. 单表格允许连续跨页。
14. 长活动允许在主表格内部拆分为连续行。
15. 续表表头仍属于同一张主表格。
16. 辅助对照内容通过基础网格合并实现。
17. 图片和板书图放入20列通栏合并单元格。
18. 不允许因分页或内容较多而拆表。
19. DOCX必须保留完整可编辑的单表格结构。
20. PDF必须保持文字、边框、图片及页码的完整性。

**最终原则：一张主表格、二十列基础网格、固定版心、灵活合并、统一列宽、自动行高、连续分页、完整可编辑。**
