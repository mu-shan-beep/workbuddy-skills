# 提示词模板

四个模板按阶段使用，**照抄结构，替换方括号内容**。不要临时自由发挥。

---

## 一、三件套（阶段 2—3）

### 1. 让模型先产出提示词

```
我给你一张教材截图，请不要写代码，先帮我产出一份制作提示词。

教材：[第 X 册 第 X 页《课题》]
我要解决的学生困难：[学生在哪个空间关系上想不明白]

请输出一份提示词，必须包含：
1. 主体对象与观察方式（学生从哪个角度看、能不能转、能不能缩放）
2. 需要分层显示的内容（逐条列，**精确到数量**：几支、几个、几条、多少度）
3. 每条内容的运动方向或数值依据（注明以教材原图为准）
4. 交互清单（图层开关、拖拽、滑块、点选、悬浮注释）
5. 配色与字体要求（适合投影、字号下限）
6. 硬约束（禁止杜撰教材之外的知识点、禁止装饰性动效）
7. 输出形态（可直接运行的 HTML 单文件，含注释）
```

### 2. 生成 v1 的三件套

```
【参照】教材原图见附件。所有方向、数值、专有名词以此为准，不得自行补充或改写。

【清单】这一课必须讲清的内容（逐条核对，缺一不可）：
- [对象 A]：[数量/角度/方向]
- [对象 B]：[数量/角度/方向]
- [对象 C]：[数量/角度/方向]
- [过程 D]：[起点、终点、中间是否连续]
- [易错点 E]：[必须明确排除的错误说法]

【要求】怎么实现：
- 可 360° 拖拽旋转、滚轮缩放
- 内容分 [N] 个图层，每个可独立开关、可叠加
- [季节/状态] 用一根可拖动的滑块连续控制，不允许跳帧
- 关键对象悬浮显示知识点卡片
- 讲解词预合成后内嵌，不联网合成
- 输出为单个 HTML 文件，所有资源内联，双击可开

【禁止】
- 禁止出现教材以外的名词、数值、结论
- 禁止装饰性粒子、光晕、背景动画
- 禁止依赖 CDN、外部字体、外部图片
```

## 二、五关任务模板（阶段 5）

关卡顺序**必须等于板书顺序**，先用一句话写出板书主线，再逐关对应。

```
【板书主线】（一句话）
[例：假设单圈 → 加自转低纬闭合 → 中高纬闭合 → 归纳 → 季节移动]

【关卡结构】
第 1 关｜[对应板书第 1 步]｜题型：[排序]
  任务：把 [N] 个环节按先后排好
  通过：顺序完全正确
  设计理由：[这一关是地基，错了后面全错]

第 2 关｜[对应板书第 2 步]｜题型：[图上点选]
  任务：在 [对象] 上点出 [位置]
  通过：点在容差范围内

第 3 关｜[对应板书第 3 步]｜题型：[单选/判断]
  任务：[因果或机理提问]
  干扰项：[必须编得合理，来自常见误解，不能明显凑数]

第 4 关｜[对应板书第 4 步]｜题型：[连线]
  任务：[左栏] 连到 [右栏]
  干扰项：[放一个不存在的项，考辨析]

第 5 关｜[对应板书第 5 步]｜题型：[滑块 + 判断]
  任务：拖动到 [状态] 后回答 [问题]

【两种模式】
困难模式：前一关通过才解锁下一关
简单模式：全部开放，未完成也可前进
两种模式都必须带提示。
```

### 题型选择原则

| 题型 | 什么时候用 | 效果 |
|---|---|---|
| 排序 | 有先后或因果链 | 逼学生想清顺序，不能蒙 |
| 图上点选 | 考位置 | 比选 ABCD 更能暴露空间误解 |
| 连线 | 考对应关系 | 可放不存在项做干扰 |
| 滑块 + 判断 | 考连续变化 | 只有拖过一遍才建立"连续"直觉 |
| 单选 | 考机理 | **只能作为补充，不能整课都是选择题** |

## 三、分层提示模板（三个阶段）

每一关都要写满三层，**不能只写答案**。

```
提示 1（思路，不指方向）：
[例：空气先动，还是先有气压差？]

提示 2（缩小范围，给一半）：
[例：先看赤道，那里受热之后空气往哪走？]

答案（连错两次后才出现）：
[把正确结果直接呈现在操作区，而不是用文字描述]
```

**关键**：答案以「结果」形式呈现——排序题把卡片排好，点选题把正确位置标出来，让学生对照着重读一遍；然后仍要再点一次「提交检测」才算通过。

## 四、返工对话模板（阶段 4—5）

教师的一句话反馈要翻译成可执行的结构改动，不要直接「优化一下」。

```
反馈原话：「[例：要那种四周上升的感觉，不要只有一个面在动]」

翻译：
- 现象：当前 [对象] 在 [视图] 下只剩 [表现]，因为用的是 [平面/贴图/单点] 结构
- 判定：不真。真实结构是 [绕整圈/三维分布]
- 改法：结构级替换，[旧结构] → [新结构]，参数 [数量/密度/张角]
- 附带：随结构变化需同步处理 [标签遮挡/层级/性能]
- 验收：转到 [侧面/背面/俯视] 仍然成立
```

**禁止**把反馈做成参数微调（调颜色、加位移、放大缩小）——反馈说的是结构，就改结构。

---

## 五、写进提示词的禁区清单

复制到每个提示词末尾：

```
禁止事项：
1. 不得出现教材之外的知识点、数值、结论、名词
2. 不得用二维示意冒充三维结构
3. 不得添加装饰性动效（粒子、光晕、背景渐变、漂浮物）
4. 不得依赖任何外部资源（CDN、字体链接、在线图片、在线语音合成）
5. 不得省略注释；关键坐标与参数需写明依据
6. 不得把多个知识点平铺，一屏只讲一个核心关系
```
