# 页面结构参考

仅在"新建并生成课件"时读取。它提供页面结构的**语汇与组织逻辑**，不是候选构图库，也不是可以机械轮换的版式模板。

## 定位与使用规则

- 每一页先确定**教学角色**（骨架 / 导入 / 讲解 / 互动 / 练习 / 总结 / 作业 / 学科专属），再按本指南选取该角色下的组织逻辑作为**起点**；坐标、背景、配色、装饰、留白和细节一律由 AI 按当前课题自主设计，本指南不提供任何像素坐标。
- 一页只用一个主组织逻辑，不在同一页堆叠多个结构（如"双栏里再套时间轴"）。结构是内容关系的产物，不是装饰花样。
- 相邻两页不得使用同一组织逻辑；练习、检测等成组页面允许同构，但各页的轮廓、视觉重心和排版必须明显不同，仍受 `visual_planning.md` 相邻页相似度（< 82%）与全册至少 4 种版面轮廓的校验约束。
- 组织逻辑只约束普通教学页。课堂活动页规则以 `subject_tool_guide.md` 的「课堂活动页规则」为唯一权威定义；古诗词 `poem` 页省略背景；`mindmap`、`table`、`plot`、`hanzi`、`pinyin`、`wordcard`、`ruled` 等原生工具页围绕组件安全区组织前景，遵守 `subject_tool_guide.md` 的页面契约。
- 文字垫底与 `fill`/`shape`/`scrim` 的使用规则**唯一权威定义在 `visual_planning.md`**（「核心原则」与「逐页契约」）：标题与普通文本默认直接排布、禁止用 `shape` 色块做任何文字底板、`fill` 容器仅用于特定重要内容或重要布局、scrim 仅作对比度兜底。本文件不再复述，各角色描述中提及"容器"时一律按该规则执行。
- 配图决策遵循 `visual_planning.md` 的「页面配图」：本指南标注的配图倾向只是提示，最终按"去掉配图后教学内容是否完整"逐页判断；纯文字梳理页、文本阅读页、课堂活动页保持无配图。
- 本指南不引入新的内容字段、元素种类或渲染参数。所有结构都只用 `text`（含文字 `fill` 容器 / `scrim`）、`shape`（`rect` / `rounded` / `oval` / `line` / `arrow` / `triangle` / `callout`，契约见 `visual_planning.md`「图层」节）、`image`（配图 + 图注）三类元素实现。

## 角色速查

| 教学角色 | 常见组织逻辑 | 配图倾向 |
|---|---|---|
| 骨架 | 封面 / 目录 / 章节分隔 / 结束页 | 背景图承载，不叠前景配图 |
| 导入 | 情境导入 / 复习导入 / 问题设问 | 情境大图；设问页留白 |
| 讲解 | 单栏要点 / 双栏并列 / 图文混排 / 概念定义 / 步骤推导 / 例题解析 / 对比同构 / 时间轴流程 / 数据图表 / 金句引用 / 大图全幅 | 按逻辑选：图文页、对比页、数据页必配；推导页不配 |
| 互动 | 选择问答 / 判断辨析 / 配对分类（活动组件）/ 小组讨论 | 活动页不配（组件独占）；讨论页一般不配 |
| 练习 | 课堂练习 / 分层练习 / 随堂检测 / 答案解析 | 题目需图示才配 |
| 总结 | 课堂总结 / 思维导图 / 易错对照 / 板书设计 | 思维导图页背景必配；其余一般不配 |
| 作业 | 课后作业 / 拓展阅读 / 下节预告 | 拓展阅读典型配图页 |
| 学科专属 | 诗词意境 / 人物介绍 / 文言翻译 / 几何图形 / 单词卡 / 听力朗读 / 实验步骤 / 地图标注 / 案例研讨 | 见各条目 |

## 布局骨架（几何排布参考）

结构类型决定**教学组织**，布局骨架决定**几何排布**——两者配套使用：先匹配结构类型，再从下方骨架中选择一种作为该页的排布起点。骨架是几何参考不是模板，具体坐标、比例、分区与装饰由 AI 按当前课题自主决定。

| 布局骨架 | 几何特征 | 典型配套结构 | 适用内容 |
|---|---|---|---|
| 左右分栏 | 左文右图 / 左图右文 / 左窄右宽，中线分隔 | 图文混排、人物介绍、对比同构、文言翻译 | 图文互证、并列内容、需要配图支撑的讲解 |
| 上下分层 | 标题 → 引导 → 正文 → 任务/结论 纵向层叠 | 单栏要点、概念定义框、例题解析、课后作业 | 顺序阅读、递进理解的内容 |
| 图文结合 | 大图承载氛围 + 浮字/图注呼应 | 情境导入、大图全幅、拓展阅读、金句引用 | 图为主文为辅、意境或证据页 |
| 中心聚焦 | 核心内容居中，四周留白或装饰收敛 | 问题设问、总结收束、封面、结束页 | 单点强调、制造认知聚焦 |
| 卡片流 | 2–5 个同构卡片横排或网格 | 课堂总结、分层练习、旧知复习、小组讨论 | 并列要点、分类信息 |
| 时间轴/流程 | 节点 + 连接线（shape）水平或垂直展开 | 时间轴流程、步骤推导、实验步骤、生长变化 | 顺序步骤、过程脉络 |
| 对比并置 | 两栏/三栏同构对比，底部一句差异结论 | 对比同构、易错对照、答案解析 | 差异对照、辨析内容 |
| 围合式 | 中心结论 + 四周支撑要点 | 思维导图、案例研讨 | 中心-分支结构 |

使用规则：

- 每页选择 1 种骨架作为几何组织逻辑；骨架用 `text` / `image` / `shape` 三类元素实现，不引入新字段。
- **相邻页优先更换骨架**；整册至少覆盖 4 种骨架，避免「标题 + 单栏文字」单调重复。成组练习页允许同骨架，但轮廓与排版必须明显不同。
- 形状（`shape`）是骨架落地的重要手段：分区色带、锚点竖条、序号圆点、流程箭头、卡片底，均可用 `shape` 实现（类型与红线见 `visual_planning.md`「图层」节）。
- 骨架之间不要嵌套堆叠（如"左右分栏里再套时间轴"）；一页只用一个主骨架。

## 骨架类

**封面**：课题、学段与制作人信息；标题层级靠字号与留白建立，直接排在背景留白区；细装饰线只作收尾点缀。背景图（本课视觉概念主场景）承担全部视觉，不叠加前景配图。

**目录**：3–5 条教学环节导航；编号与环节名用字号区分层级；内容多时可改为时间轴组织。一般不配图；结构页不计入页数区间。

**章节分隔**：单元课/多课时课件切分教学段落；一侧结构锚点（竖条，用 `shape`，不承载文字）+ 章节序号 + 大标题 + 一句重点；背景图承载意境。15 页以下通常不需要章节页。

**结束页**：收束语 + 课后提示 + 制作人信息；与封面使用同源背景形成首尾呼应，文字集中在中间带。

## 导入类

**情境导入**：真实情境大图（优先作整页背景）+ 1 个核心问题；文字总量控制在一问一题内；核心问题可用文字 `fill` 容器形成问题卡（页面唯一强调元素）。

**复习导入**：3 个旧知卡片横向同构排列（每卡 ≤3 条要点），下接一句承上启下的过渡引导；可配小图标帮助唤起记忆。

**问题设问**：一个开放大问题制造认知冲突；全页只放一个问题，留白充足，留白本身就是设计。

## 讲解类

**单栏要点**：最通用内容页——结构锚点（竖条）+ 标题 + 引导语、正文、要点列表垂直排布；要点 ≤5 条。

**双栏并列**：两组同构信息并列（左右栏内容同字段、同行数时最易读）；仅在栏内需要分组强调时才用浅色容器。

**图文混排**：图左文右或图右文左，配图承担说明、示例或证据；图注必填说明图中内容与教学作用。本逻辑必配 1 张前景配图。

**概念定义框**：定义（容器承载，本布局属重要布局需要）、关键词高亮、举例、辨析提示四要素；定义框是全页视觉焦点。

**步骤推导**：每步一行（序号 + 步骤 + 解释），关键变换步用强调色；底部结论容器承载最终结论。步骤 ≤5 步，过多时拆页或改用时间轴。

**例题解析**：题头（大字层级直接表达，不垫底）→ 题面 → 分步解析（容器承载）→ 答案（主色高亮）→ 变式思考。信息分层用 `question` + `answer` + `items`。

**对比同构**：两个对象按相同维度并置（两栏必须同构——同字段、同行数、同字号），底部一句话差异总结。典型双图页：两栏各配 1 张对比图形成视觉反差。

**时间轴/流程**：3–5 个等距节点（容器小卡承载），节点间用 `line` 连接；纵向流程自上而下。节点文案 ≤15 字。

**数据图表**：图表区承载 `data` 配图或 `table` 组件，配一句结论 + 1–3 条数据要点；结论是教学落点，不得只罗列数字。通常必配 1 张 `data` 图。

**金句引用**：一句诗词/名言大字居中，出处右下；留白占画布一半以上，背景图营造意境。

**大图全幅**：铺满全页的背景大图 + 少量浮字（≤3 行）置于留白区；多行文字用一块局部 scrim 服务整组；禁止再叠大配图。

## 互动类

**选择问答 / 判断辨析 / 配对分类**：一律使用希沃原生活动组件（`choice`/`judge`/`match`/`classify`），页面保持空白由组件独占（规则见 `subject_tool_guide.md`「课堂活动页规则」）；题干与选项写入组件数据；高年级活动数量受限（通常 ≤1–2 个）。

**小组讨论**：任务描述（明确可操作）+ 分组分工卡 + 讨论要求与时间；分工与时间两要素必须出现。

## 练习类

**课堂练习**：3–5 题竖排、难度递增；右下角固定位置放解题思路提示（页面唯一容器，不遮挡题目）；题目需图形时配 `diagram` 附图。

**分层练习**：基础/提高/拓展三层横向分区，同构容器承载，层名、星标与题量区分明显。

**随堂检测**：限时标注 + 3–5 题混排（题型 ≥2 种）+ 答案区后置便于讲评；聚焦做题动作，不配图。

**答案解析**：讲评课核心页——思路→易错→答案三段式纵向排布；易错提示用红色系容器、答案用主色高亮容器；错误红、正确绿（中国课堂惯例）。

## 总结类

**课堂总结**：3 个要点卡横向排列或 1 张知识框架；知识结构复杂时改用思维导图页。

**思维导图**：使用希沃 `mindmap` 原生组件（选型研判见 `subject_tool_guide.md`）；视觉契约按 `visual_planning.md` 的「思维导图工具页」执行：背景图必配且同源、组件安全区安静低细节、标题 + `lead` 任务引导 + 1–3 条 `items` 结构说明排在安全区外。顶部文字须**纵向排列**（标题→引导语→提示依次向下），不得把引导语并排放到标题右侧同一高度。

**易错对照**：一页聚焦 1–2 个高频易错点，错误/正确成对左右对照（红/绿容器），底部避坑一句话。

**板书设计**：用 `background.scrims` 声明一块深色圆角遮罩模拟黑板（不要用独立 `shape` 色块），白字直接排在 scrim 上；主板书（课题 + 概念/公式）与副板书（例题演示）分区。

## 作业类

**课后作业**：必做/选做/实践分层，列表直接排布（分层布局需要时才用容器）；标注预估时间与提交方式。

**拓展阅读**：配图 + 拓展主题/小故事 + 相关书目；拓展内容必须与课题直接相关。典型配图页。

**下节预告**：回顾 → 预告 → 预习任务三段式；可配 1 张新课意境图激发期待。

## 学科专属类

**诗词意境**：诗句大字 + 意象配图（每句重点诗句可配 1 张相关图，一页最多 2 张）+ 底部注释；整首诵读用 `poem` 原生组件（省略背景）。意象图与诗句情绪一致。

**人物介绍**：图左文右——画像/作品图必配（图注写清人物身份与作品名；无可靠画像时先与用户确认素材，不臆造）+ 生平、代表作、时代背景分层。

**文言文翻译**：原文句→译文句逐行对应（原文粗体/译文浅色），重点字词高亮旁注；单页 ≤6 句。

**几何图形**：图形区（`diagram` 配图或 `plot` 组件，标注角度/长度/名称）+ 性质要点；可操作图形用 `plot`，静态几何用配图。

**单词卡**：使用 `wordcard` 原生组件（每页 1–3 词）围绕安全区设计标题与任务引导；普通页形态则单词 + 音标 + 配图释义，对话按角色分行排布。

**听力朗读**：文字提示课堂播放节点（希沃无音频组件）+ 听力文本 + 跟读任务与简单自评；不配图。

**实验步骤**：器材清单 + 有序步骤 + 观察记录表（`table`）+ ⚠ 安全提示条（红色系容器）必标，四要素齐全。

**地图标注**：地图配图 + 图例 + 知识点。**合规强制**：涉及中国地图必须使用合规地图底图（标准审图号地图），不得自绘变形地图；出图后人工核对国界线与南海诸岛完整性；无合规底图时改文字描述。

**案例研讨**：案例背景（真实具体）+ 2–3 个开放问题 + 底部价值引导一句话（正向收束）；案例图按需配 1 张。

## 希沃能力限制与替代

| 模板中的能力 | 希沃落地替代 |
|---|---|
| 渐变装饰条 | 纯色块或同色系深浅两段色块（`shape:rect`），不用渐变参数 |
| 竖排诗句 | 横排大字 + 分行；一页多句时用多条 `text` |
| 音频播放按钮 | 文字提示播放节点（"播放录音"），标注课堂操作 |
| 投票二维码/举手表决 | 用 `choice` 活动组件或文字提示 |
| 超链接/下载链接 | 以文字列出书目/资源，提示课堂输入 |
| 动态动画（旋转/翻折） | 静态图 + 文字提示操作动作；可操作图形用 `plot` 组件 |
| 思维导图自动生成 | 希沃 `mindmap` 原生组件 |
| 数据图表绘制 | `role:"data"` 配图或希沃 `table` 组件 |
| 中国地图 | 必须使用合规底图，出图后核对国界线与南海诸岛；否则改文字描述 |

## 与既有约束的关系

- 结构的选择不豁免任何 `visual_planning.md` 校验：背景池分档复用上限（中间留白 6 页 / 侧边留白 2 页 / 底部留白 4 页）、相邻页相似度 < 82%、六页以上至少 4 种版面轮廓、字号下限（标题 42 / 正文 22）、对比度（≥ 3:1）、配图面积上限与图注字数，全部照常执行。内容页背景优先匹配**中间留白**池项（主体置边缘、中心安静），前景布局可结合配图自由组织，详见 `visual_planning.md` 的「背景图生成与复用」与「中间留白页的图文组合」。
- 结构不引入新字段；`visualPlan.elements` 仍只用 `text` / `image` / `shape`，`source` 仍绑定检查脚本列出的内容槽。
- 用户明确给出结构要求时，用户要求优先于本指南的角色匹配。
