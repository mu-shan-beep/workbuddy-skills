# 小红书「语文课件备课笔记」文案生成

## 一、核心定位

不是卖货话术，是**教师对教师的备课笔记**。可信度来自三样东西：

1. **痛点**——学生只能看到表面，却看不到文本里的门道；
2. **两课时具体流程**——一句一事的动作句；
3. **作者个人的教学取舍**——全文唯一表达「我怎么想」的地方。

语气是陈述式，零人称（不写「我」，也不称呼读者），不喊口号、不引导互动。

### 两种形态，别混

| 形态 | 立信靠什么 | 适合 |
|---|---|---|
| **备课笔记型**（主形态） | 痛点 + 流程动作句 + 取舍 | 有辨识度，攒粉，能被同行记住 |
| **商品说明型**（变体） | 完整 + 原创声明 + AI 配图声明 | 短、快、转化直接，但不记人 |

商品说明型不是「更好的写法」，是砍掉痛点与取舍换来的短。**默认写备课笔记型，只吸收说明型里有效的元素**（两行标题、原创声明、总述式脉络、板书设计入清单），不要整篇退化为商品描述。

---

## 二、何时使用

- 用户要写小红书发帖文案、课件推广帖、备课笔记
- 用户说「写小红书」「发帖子」「备课笔记文案」「帮我写个笔记」
- 用户提供一篇对标帖，要求「分析拆解」「照这个格式写」

不适用：正式教案 / 逐字稿 / 学习单等内容创作（由写作类技能产出内容，本技能只产出推广笔记文案）。

---

## 三、工作流程（5 步）

### 第 1 步：定体量、定分法

除非用户已给对标帖或已说明，否则先确认两件事：

1. **形态与分法，三选一：**
   - **整篇两课时合发**：一套骨架，脉络块里并列写课时 1、课时 2。
   - **分课时各发一篇**：每篇只写自己那课时，标题标「第一课时／第二课时」，但**产品清单仍写「2课时」**（整包产品，别让读者以为只卖一课）。
   - **总述式短帖**（商品说明型）：不分课时，脉络压成「总述＋顺序＋重点＋落点」四句，可带原创声明。约 235–260 字。
2. **目标字数：**
   - 跟对标帖走（约 380 字，保留「脉络 + 备课小想法」双块）；
   - 或压短到 150 字（只能留标题 + 清单 + 痛点 + 每课时两句，**删掉整个「备课小想法」块**，形态会和对标明显不同）；
   - 或走总述式短帖（约 235–260 字，见第五节的变体 A）。

### 第 2 步：拆解对标帖（用户提供时）

按下方「对标拆解六块法」逐块记录：原文要点、在文中的作用、可复用点，最后提炼出适用于本课题的**骨架公式**。
对标帖若缺块（如整段没有痛点、没有取舍、没有定调句），**必须把「缺哪块、代价是什么」写出来**，不能只记录有什么。

### 第 3 步：套骨架写本课题

把课题信息填进骨架公式。关键规则：

- 每课时写 **4 句动作句**，动词开头、一句一事；顺序用箭头「→」压缩，不写分钟数。
- 「备课小想法」写 **3 条**，全是减法 / 取舍 / 升到人文，用判断式短句（例：「过渡句不讲定义。」）。
- 引号只引**课文原词**或**单元要素词**（如「伟大的奇迹」「承上启下」）。
- 走总述式时，脉络四句的分工固定：**①一句总述（教案整理好了，按 2 课时教学思路设计）②顺序句（从…进入，依次安排…）③重点句（重点带学生…）④落点句（读懂…完成…）**。四句都不写动作细节，只给整体印象。

### 第 4 步：语言合规自检

过下方「语言规范（必须 / 禁止）」+「合规自检清单」。

### 第 5 步：交付

直接给可复制文本（标题三选一 + 正文 + 标签）。可选：存成 docx 放进课件包的「小红书封面海报 / 文案」类。

## 四、对标拆解六块法（＋1 个可选扩展块）

| # | 块 | 作用 | 可复用点 |
|---|---|---|---|
| 1 | **标题** | 前半=搜索词（年级+篇名+备课），后半=立意；用「｜」分开 | 前半照抄本课题格式，后半换本课文立意。**变体：只写「版本+年级+《篇名》+完整课件」，不挂立意**（见第五节变体 A） |
| 2 | **定调句** | 一句话给课文定性，10–13 字，带一个质感形容词 | 只用 10–13 字，不展开；说明型帖子可整块省掉 |
| 3 | **产品清单** | 小图标框出 5 项交付物，「2课时」前置，「可编辑动态」是卖点 | 交付物名称顺序照旧，不增不减。**变体：去星R框、纯文本、`+` 分隔、「完整」放教案前、板书设计单列** |
| 4 | **痛点段** | ①学生真实反应 ②课文核心概念加引号 ③把答案推回文本，为「深挖」立论 | 两句话：一句写学生只看到表面，一句写东西其实在文字里 |
| 5 | **课堂脉络** | 分块标记 📖，课时用 ▪️；每句动词开头，顺序用箭头压缩 | 每句只讲一件事，不写分钟数。**变体：总述式四句，不分课时、不写动作细节** |
| 6 | **备课小想法** | 💫 标记；三条全是减法与取舍，是全文唯一个人主张 | 一条讲「我不做什么」，一条讲「我放弃什么换来什么」，一条升到人文 |
| 7 | **原创与配图声明**（可选扩展块） | 建立信任，同时满足 AI 内容合规 | 固定放标签前一行：「课件教学设计、课堂框架、文字内容全部为本人原创，PPT 配图插图使用 AI 辅助绘画」。前提是事实成立，不得虚标 |

标签：固定 10 个，配比＝品类 + 学段 + 场景 + 商业 + 内容（见体量数据）。

## 五、版式骨架公式

### 整篇两课时合发

```
四年级《【篇名】》备课｜【一句立意】
【10–13字课文定性】

[星R][星R]（2课时 可编辑放映动态的ppt课件+教案+逐字演讲稿+学习单+课件笔记）[星R][星R]

【学生只会说的一句话】，
却很难真正【核心目标】。
【一句：真正的东西藏在文字里】。

📖两课时课堂脉络
▪️课时 1
【动词句 1】。【动词句 2：用箭头压缩顺序】。
【动词句 3】。【动词句 4：落到课后题】。
▪️课时 2
【一句：视角/重心转向哪里】。
【抓具体词句】。
【学生做什么】。
【拓到单元任务，由课内到课外】。

💫一点备课小想法
【一条减法】。
【一条取舍】。
【一条升到人文】。

#课件 #ppt #语文 #【篇名】 #ppt定制 #教案 #四年级语文 #教师备课 #公开课 #小学语文备课
```

### 变体 A：总述式短帖（商品说明型）

```
【版本+年级】《【篇名】》完整课件
2课时，可编辑放映动态ppt+完整教案文档+逐字演讲稿+学习单+板书设计
【主题 emoji】《【篇名】》教案整理好了，按 2 课时教学思路设计。
从【情境/导入方式】进入，依次安排识字写字、整体感知、精读品读、读写迁移。
重点带学生理清【结构】，沿【两条线/几个方面】走，品味【关键词语/写法】，读懂为什么是【课文结论词】，完成【表达训练】。
【可选：痛点两行，见主骨架】
【可选：备课想法两句，见主骨架】
课件教学设计、课堂框架、文字内容全部为本人原创，PPT 配图插图使用 AI 辅助绘画

#教师备课 #公开课 #语文课件 #课件ppt #小学语文备课 #课件 #ppt #语文教学设计 #教案 #笔记
```

**变体 A 的使用边界**

- 标题不带「｜立意」，纯搜索词 + 「完整课件」，靠版本缩写（三上／四上）吃搜索流量。
- 清单去装饰、`+` 分隔、末项接板书设计；**末项按实际产品增减，没有的别写**。
- 脉络四句只给整体印象，不剧透设计细节，被照抄的成本低。
- 痛点与想法「可选但推荐留」：全砍会退化成商品描述，与满屏同类帖同质。
- 原创声明必须属实（配图除 AI 绘画外无他人素材），发布时另在平台勾选 AI 声明。

### 分课时发（每篇只写自己那课时）

仅把「📖两课时课堂脉络」换成「📖第 X 课时课堂脉络」，下面只写本课时 4–5 句；「💫一点备课小想法」只写本课时相关的 2–3 条。**标题标「第一/二课时」，产品清单仍写「2课时」不动。**

## 六、语言规范（必须 / 禁止）

**必须**

- 全篇零人称：不写「我」，也不称呼读者（不用「姐妹」「家长们」）
- 段落以陈述句为主，动词开头；每句只讲一件事
- 引号只引课文原词或单元要素词
- 表达想法用判断式短句：「图片只用作情境引入。」
- 图标只用 5 类：星R 框清单、📖 脉络、▪️ 课时、💫 想法，另允许 **1 个主题 emoji 起一句**（如 🌲 小兴安岭、🗿 兵马俑），全文不超过 2 个，不叠用
- 正文提到 AI 配图时，须写一句配图声明；发布时勾选平台 AI 辅助创作声明

**禁止**

- 感叹号连用、引导互动（「需要的扣 1」）、表情堆叠
- 极限词：「最 / 第一 / 唯一 / 天花板」；夸张词：「震撼 / 封神 / 绝了」
- 课程方法论术语：「语文要素落地」「任务群」「大单元」（对标帖一个都没用，也别用）
- 技术参数：分钟数、页码数、动画个数
- 清单里写产品实际没有的交付项（虚标「板书设计」「微课」等）

## 七、体量数据

| 项 | 对标值 |
|---|---|
| 正文（含标题、不含标签） | 约 370–390 字 |
| 段落块数 | 6 块（标题／定调／清单／痛点／脉络／想法） |
| 课时 1 | 4 句，约 65 字 |
| 课时 2 | 4 句，约 90 字 |
| 备课想法 | 3 句，约 75 字 |
| 标签 | 10 个 |
| 分课时发单篇 | 约 400–430 字 |
| 整篇两课时合发实测 | 约 440 字，6 块（《秦兵马俑》） |
| 总述式短帖（商品说明型） | 约 235–260 字，4 块 |
| 总述式 + 痛点/想法融合版 | 约 340–360 字，7 块（《秦兵马俑》实测） |

体量差的可解释性：整篇合发比总述式多出的约 140 字，正好是「痛点 3 行 + 想法 3 句」的量。要短就得砍这两块，不能靠压缩动作句来省字。

## 八、合规自检清单

- [ ] 扫描风险词与站外导流词（微信号、二维码、「私我」等）= 0
- [ ] 无极限词、无效果承诺（「保提分」「必上优课」）
- [ ] 描述性表述（「路线写得极清楚」「可以停下来慢慢读」）不构成绝对化宣称
- [ ] 课文篇名、作者、数字（如「二百七十三间」）与教材一致，无杜撰
- [ ] 版本与年级对得上（如《秦兵马俑》属人教版四上，不可标「统编四上」）
- [ ] 零人称、无引导互动、表情不过量
- [ ] 清单每一项交付物都真实存在，无虚标
- [ ] 有 AI 配图时已写声明，发布端已勾选 AI 辅助创作

## 九、常见坑

| 现象 | 原因与处理 |
|---|---|
| 写成平台运营方案 / 销售话术 | 用户要的是「设计思路、上课思路」，不是卖货文案；回到「痛点 + 流程 + 取舍」三件套 |
| 出现「我」「姐妹们」 | 对标体是零人称陈述，删掉所有第一/二人称 |
| 堆极限词、感叹号 | 直接违规风险，按「禁止」清单逐句过 |
| 分课时发但清单写成「1课时」 | 整包产品，清单不动，只在标题标课时 |
| 写进分钟数 / 页码 / 动画数 | 教师读者不关心，且显营销感，全部删掉 |
| 引号乱用 | 只引课文原词 / 单元要素词，别给普通词加引号 |
| 照抄说明型对标，整篇只剩清单 + 三句总述 | 缺痛点与取舍，和同类帖同质、不记人；至少补回痛点两行或想法两句 |
| 清单照搬对标末项「板书设计」 | 产品没有独立板书文档就是虚标；先补齐文档，或删掉该项 |
| 标错教材版本 | 对标写「统编三上」不代表本课题也在统编；编号对不上时宁可不写版本 |

## 十一、持续迭代与融合机制（用户提供新对标帖 / 多篇文案时）

本技能不是一次性沉淀，而是**累积型**：用户会不断丢新的对标帖、爆款文案过来，目标是把它们拆解后融进本技能，越用越准、越用越贴合「我们自己的产品调性」。

### 触发

- 用户说「分析拆解这篇」「照这个格式写」「把这篇融进去」「后期还有文案你帮我拆解」等
- 用户直接贴一篇新文案（无论是否同课题、同体裁、同长度）

### 单个新对标的标准动作（4 步）

1. **拆解（必做，先出）**
   用「四、对标拆解六块法」逐块填表：原文要点 / 在文中的作用 / 可复用点。缺块也要写明缺口与代价。结尾给一句「本帖与现有骨架的差异点」，让用户一眼看到新东西在哪。

2. **出改良稿（先出效果，等确认）**
   把新对标里有效的结构、句式、节奏，套到用户当前课题上，产出一版可直接发的文案。
   ⚠️ 这一步只动「当前任务」，**不碰 skill 文件**。

3. **列「拟固化条目」（临时清单，不写文件）**
   明确告诉用户：准备把哪些新发现写进 skill，例如：
   - 骨架公式要不要加新块（如新增「避坑提醒」「互动钩子」「封面引导」）
   - 语言规范「禁止」要不要加新条目（如某类新出现的夸张话术）
   - 体量数据要不要调整（如对标普遍更短/更长）
   - examples.md 要不要新增一篇示例、归入哪类
   列出后**停一下，等用户确认**。

4. **确认后固化**
   用户说「可以 / 固化 / 写进去」后，才编辑 `SKILL.md` 与 `references/examples.md`。未确认前，所有新发现只停留在当前对话。

### 多篇对标融合

- **多篇同体裁**：取「结构并集」，在 `examples.md` 各存一篇并标注「类型 A / 类型 B」；骨架公式只保留最大公约数，差异点写进「常见坑」或单列「变体说明」。
- **多篇跨体裁**（如既有备课笔记、又有卖货种草、又有晒单反馈）：**分独立 few-shot 类别**，不混进同一骨架；跨体裁的只在示例区并列，绝不污染核心骨架与语言规范。
- **商品说明型对标**（清单 + 总述 + 原创声明）：作为**变体 A** 挂在主骨架之后，不替换主骨架；只吸收其标题格式、清单写法、总述四句、原创声明，痛点与取舍仍留在主骨架里。
- **同课题多版**：保留「定稿版」为基准示例，其余版本作为变体附录，避免主骨架被临时试错带偏。

### 红线（与全局技能迭代规则一致）
