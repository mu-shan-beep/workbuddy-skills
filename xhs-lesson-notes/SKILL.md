# 小红书「语文课件备课笔记」文案生成

## 一、核心定位

不是卖货话术，是**教师对教师的备课笔记**。可信度来自三样东西：

1. **痛点**——学生只能看到表面，却看不到文本里的门道；
2. **两课时具体流程**——一句一事；
3. **作者个人的教学取舍**——全文唯一表达「我怎么想」的地方。

语气是陈述式，零人称（不写「我」，也不称呼读者），不喊口号、不引导互动。

> **账号定位先分清（2026-11-10 定）**：本技能默认「教师对教师的备课笔记」，但账号实际可以是**个人售卖**。个人售卖笔记**保留成交意图**，处理方式是「正文降营销语气 + 成交只走笔记左下角官方个人售卖组件」，不是把文案改成纯分享、更不是删掉清单；正文与评论区都不写「私信／看主页／加V／链接」。账号层的虚拟资料类目准入、报备与发布节奏属平台运营规则，不写进本技能，交付时另行口头提示。

### 两种形态，别混

| 形态 | 立信靠什么 | 适合 |
|---|---|---|
| **备课笔记型**（主形态） | 痛点 + 流程动作句 + 取舍 | 有辨识度，攒粉，能被同行记住 |
| **商品说明型**（变体 A） | 完整 + 原创声明 + AI 配图声明 | 短、快、转化直接，但不记人 |
| **商品详情页型**（变体 E） | 痛点归因 + 可核对的落点 + 交易条款 | 详情页/商品介绍，一次说清买什么、怎么发货 |
| **发货文案型**（变体 F） | 渠道齐全 + 领取步骤 + 售后兜底 | 付款后自动发货/私信；不拉新，只交付 |

商品说明型不是「更好的写法」，是砍掉痛点与取舍换来的短。**默认写备课笔记型，只吸收说明型里有效的元素**（两行标题、原创声明、总述式脉络、板书设计入清单），不要整篇退化为商品描述。

### 两类体裁，别混

| 体裁 | 内容主要承载在 | 典型 | 用哪套 |
|---|---|---|---|
| **语文课件备课笔记**（主） | 正文 | 《颐和园》《秦兵马俑》类课件推广帖 | 主骨架：分课时／整篇合发／总述式／变体 B |
| **家长会课件型**（独立类别） | 配图（PPT 页面／实拍） | 家长会、期中家长会、开学家长会 PPT 笔记 | **变体 C**（见第五节末）：正文 3–5 行 + 页序模型 |

判据一句话：**正文读完就懂 → 主骨架；正文极短、要翻图才懂 → 变体 C。**

## 三、工作流程（5 步）

### 标题固定格式（2026-11-10 定，2026-11-10 末次修订，全局适用）

所有对外发布的小红书文案（备课笔记型、商品说明型、商品详情页型、分课时发）标题统一走下面这套格式：

> {版本缩写}《{篇名}》完整课件 · {课时数}

- **版本缩写**：统编版年级简称，如 四上 / 四下 / 三上 / 三下，紧贴《篇名》前，无空格。
- **《篇名》**：带书名号，照课文原题。
- **完整课件**：固定后缀，紧跟书名号之后。
- **·**：中间点（示例写作「 · 」，两侧半角空格环绕），分隔「完整课件」与课时数。
- **课时数**：2课时 / 第一课时 / 第二课时（分课时发标对应课时；整篇合发与商品介绍写「2课时」）。

示例：`四上《颐和园》完整课件 · 2课时`、`四上《颐和园》完整课件 · 第一课时`。

**资源类型组合（教学设计+课件+逐字稿+学习单+笔记）不进标题**——商品介绍型（变体 E）改写在标题下方【内容包含：……】一行（全角【】括号，各项以 ＋ 连接）；备课笔记型与商品说明型不列清单，资源类型交由图片与评论区承载。

**适用范围**：备课笔记型（主骨架）、变体 A（商品说明型）、变体 E（商品详情页型，标题仅此一行、零标签）、分课时发。
**不适用**：变体 F（发货文案，按定义无标题）；变体 B/C/D 标题各有专属规则，不套本格式。

> 立意（如「先带学生把路走明白」）不再进标题，移到封面叠字或正文首句承载。

### 第 1 步：定体量、定分法

除非用户已给对标帖或已说明，否则先确认两件事：

1. **形态与分法，三选一：**
   - **整篇两课时合发**：一套骨架，脉络块里并列写课时 1、课时 2；默认同样走思路级（见第 3 步），不是只有分课时单篇才压短。
   - **分课时各发一篇**：每篇只写自己那课时，标题走固定格式、课时数标「第一课时／第二课时」（如 `四上《颐和园》完整课件 · 第一课时`）；整包产品别让读者以为只卖一课，课时信息由标题或正文交代（C 式清单不强制前置「2课时」，见第四节第 3 块）。
   - **总述式短帖**（商品说明型）：不分课时，脉络压成「总述＋顺序＋重点＋落点」四句，可带原创声明。约 235–260 字。

   > 以上三选一都指**笔记**。若载体是**商品详情页**（带价格、立即购买、发货方式），不走三选一、不写标题与标签，按第五节**变体 E** 写，约 460–500 字。
2. **目标字数：**默认按第 3 步「唯一口径」走思路级（分课时单篇约 230–260 字，两课时合发约 260–300 字）；用户明确指定时才三选一：
   - 跟对标帖走（约 380 字，保留「脉络 + 备课小想法」双块）；
   - 或压短到 150 字（只能留标题 + 清单 + 痛点 + 每课时两句，**删掉整个「备课小想法」块**，形态会和对标明显不同）；
   - 或走总述式短帖（约 235–260 字，见第五节的变体 A）。

### 第 2 步：拆解对标帖（用户提供时）

按下方「对标拆解六块法」逐块记录：原文要点、在文中的作用、可复用点，最后提炼出适用于本课题的**骨架公式**。
对标帖若缺块（如整段没有痛点、没有取舍、没有定调句），**必须把「缺哪块、代价是什么」写出来**，不能只记录有什么。
拆解结果走**双落点**——飞书表对应子表（结构化字段）＋ IMA 知识库「小红书学习笔记」（同名 .md 全文副本，供以后全文检索）；**本地不另存文字稿与原图**（详见第十一节「归档位置」）。

### 第 3 步：套骨架写本课题

> **唯一口径（来源与详略）**：标题立意、痛点、📖脉络、💫想法**只从教学设计浓缩**，不得另起思路；课件与制作笔记仅用于核对页序、生字、范字等事实，不提供立意。**分课时单篇、整篇两课时合发一律适用**，总述式本就不写动作细节，按第五节变体 A 走。默认写**思路级**——只给环节走向，不写具体字词、正音、描写、巡视、范写等动作细节；想法一律 2 条：
> - **分课时单篇**：脉络 2–3 句方向句，约 230–260 字。
> - **整篇两课时合发**：保留「▪️课时 1／▪️课时 2」标记，每课时 1–2 句方向句（合计 3–4 句），约 260–300 字；两课时分工照教学设计浓缩，不因合发就铺开成动作清单。
>
> 用户明确要详细版时，才展开成动作句：分课时单篇 4–5 句、约 400–430 字；两课时合发按第五节公式、约 440 字。

把课题信息填进骨架公式。关键规则：

- 句子动词开头、一句一事；顺序用箭头「→」压缩，两档都不写分钟数。
- 「备课小想法」写 **2–3 条**，全是减法 / 取舍 / 升到人文，用判断式短句（例：「过渡句不讲定义。」）。
- 引号只引**课文原词**或**单元要素词**（如「伟大的奇迹」「承上启下」）。
- 走总述式时，脉络四句的分工固定：**①一句总述（教案整理好了，按 2 课时教学思路设计）②顺序句（从…进入，依次安排…）③重点句（重点带学生…）④落点句（读懂…完成…）**。四句都不写动作细节，只给整体印象。

### 第 4 步：语言合规自检（出稿必检）

> **强制规则｜每篇写完必检，不检不交付**：任何形态（分课时单篇／两课时合发／总述式／变体 B–D）出稿后，都按 `xhs-skincare-playbook/references/compliance-wordlist.md` 逐位扫一遍，并把结果写进交付回复；命中项没处理完，不给「可直接复制」的结论，也不给配图与发布建议。

扫 **4 个位置**，一个都不能省：

1. **标题**——三选一里的每一个备选都要扫；
2. **正文**——含产品清单、痛点、脉络、想法、封面叠字；
3. **标签**——逐个扫，重点看营销／接单类标签（`#ppt定制` 一类）；把课文名做成话题标签本身不等于违规，只作语境确认；
4. **配图**——封面画面 + 每张配图的**内页文字与画面**；用课件截图时要按页读内页文字，不能只看叠字。

检查重点按风险权重排：**①营销推广与交易链路（首要）**——正文里的商品详情页式清单（「可编辑 ppt＋教案＋学习清单」）、「定制／接单／打包／资料包」、强营销标签、**结尾的效果承诺与行动召唤**（「直接打印上课」「解放备课时间」「新手老师…👏」「来啦」「感兴趣的老师可以看看」）、正文里写「私信发你」「看主页」「加V」「链接」等引导。个人售卖笔记尤其要扫这一项；**②常规违禁词**——极限词／虚假承诺／站外导流／医疗功效／营销诱导；**③政治／时政表述**——人物称谓与职务、讲话原文、会见或时政叙述、以领导人语句做标题或标签，列为**需人工确认项**，不单独据此判定违规。

> **两套扫描并列，互不替代（2026-11-11 定）**：第 4 步扫的是「词面风险」；第八节「脱敏规则」扫的是「信息层残留」（姓名、学校、二维码、内部数据等，这些词本身不违规，却会泄露可识别信息）。用户说「注意脱敏」或涉及课堂实拍／课件内页截图时，**两套都要跑**，结果随稿一起给。

教材篇名、课题话题标签、课件内页的课文标题**不等于违规**（同课题纯教学分享笔记可过审），不要据此整页打码或「停发该题材」；只有与营销推广叠加时才从严。账号定位就是个人售卖时，命中①的处理是**改分享口吻 + 走官方个人售卖组件**，不硬删售卖意图；命中③则人工确认语境。

结果随稿一起给：命中 0 写「四位置 × 各类风险词 0」；有命中就列位置＋类别＋处理动作。「第一课时／第二课时」的序数是误报，不计入极限词。过完再走第 5 步交付。

> **判定逻辑（实证口径）**：平台先看「核心意图」——是分享教学还是卖资料，再看具体词面。**四样本差分结论（见 `examples.md` 示例八～十一对照表）**：课文措辞、课题名、教材篇名、政治／时政表述、商品清单、「可编辑／页数」、10 个营销标签、`#公开课 #教案` **都不是判据**（示例九、十反证）；真正稳定的是 ①结尾有无效果承诺与行动召唤 ②原创＋AI 配图声明 ③教学判断密度 ④`#ppt定制` 一类接单信号。**站内 AI 汇总笔记的分析口径逐篇漂移（售卖→意图→原创→清单），属结果倒推理由，只作样本不作规则**；其推测（教师资格认证、版权、类目准入）、自造量化与自相矛盾的改稿示范一律不作硬规则。只采信可追溯到实际案例、且能被对照样本交叉验证的归因。

### 第 5 步：交付

**在对话里用代码块给出，不落盘、不产生本地副本（2026-11-10 定，强制）**：成品文案只在回复中以代码块交付（一份文案一个代码块，便于整段复制）；**不写 .md / .docx / .txt 文件，不往课题目录存副本，不建「文案」类文件夹**。落点自检、链接同源核验等过程结论若需交代，直接写在回复正文里，同样不落盘。
⚠️ 这一步交付的是**本课题的成品文案**；**对标帖的拆解归档**是另一件事，走双落点（飞书表 + IMA 全文副本），本地不落文件（见第十一节「归档位置」）。两条口径合起来：**任何文案相关产物都不在本地产生副本**。

> **⚠️ 变体 F 唯一例外前置（2026-11-11 定，2026-11-11 修订，强制）**：写发货文案**出稿前必须先跑完**第五节变体 F 的「链接获取规程」——先做第 0 步开场预检（路径走底稿、能力可用性、两端登录态；指定 skill 缺装按规程自动安装并请用户授权），再按能力指定表调用 `quark-drive` 与 `baidu-netdisk` 取两端真实链接＋提取码、核对同源同版、回填 `.workbuddy/发货清单-底稿.csv`。**占位符（`【链接地址】`／`【网盘 B】`／`【四位提取码】`）一律不得出现在交付稿里**，也不把「请你自己填链接」当成交付结论。骨架模板里的占位符是**教学示意**，不等于可以照抄出稿。回填底稿属商品数据维护，不算文案副本，与上面「不落盘」不冲突。

**文案本体一律裸文本（全形态通用，2026-11-10 定）**：代码块**里面的**稿子不带任何 Markdown 标记——不加 `**` 加粗、不用 `#` 做层级、不用 `-`／`*` 项目符号、不加 `>` 引用、不夹 `---` 分隔线。小红书发布框、千牛／闲鱼私信框、自动发货输入框**都不渲染语法**，星号井号会原样露在买家眼前。
> **代码块 vs 裸文本不矛盾**：对话里的三反引号围栏是**复制容器**，只为把整段文案干净地交给用户，用户复制的是块内文字、围栏不进发布框；被禁止的是**文案内容里**出现 Markdown 标记。变体 F 第 0 条同此口径。

- **模块间空一行（强制，2026-11-10 定）**：标题、产品清单（【内容包含】／C 式星R清单）、痛点段、课堂脉络、备课小想法、原创声明、标签、注、发货方式等逻辑模块之间**各空一行**，提升手机端阅读体验。模块内同类型条目（■落点×6、▪️ 课时方向句、注 1／注 2 编号）紧凑排列，不必逐条空行；「注：」与其下编号不空行（编号本就换行）。变体 F 六段骨架段段空行，与此一致。不用 `---` 分隔线。
- 要列表：只用纯文本数字编号（`1.` `2.` `3.`），不用 `-`／`*` 起点。
- 要强调：靠短句、位置和 emoji 前置，不靠加粗。
- 方括号里的 `■`「📌」「💚」等本身就是纯文本符号，可以正常用。
- 技能文档内部为讲规则可以用加粗与表格，**但产出物里一个都不许带**。

### 变体 A：总述式短帖（商品说明型）

```
{版本缩写}《【篇名】》完整课件 · 2课时
2课时，可编辑放映动态ppt+完整教案文档+逐字演讲稿+学习单+板书设计
【主题 emoji】《【篇名】》教案整理好了，按 2 课时教学思路设计。
从【情境/导入方式】进入，依次安排识字写字、整体感知、精读品读、读写迁移。
重点带学生理清【结构】，沿【两条线/几个方面】走，品味【关键词语/写法】，读懂为什么是【课文结论词】，完成【表达训练】。
【可选：痛点两行，见主骨架】
【可选：备课想法两句，见主骨架】
课件教学设计、课堂框架、文字内容全部为本人原创，PPT 配图插图使用 AI 辅助绘画

#教师备课 #公开课 #语文课件 #课件ppt #小学语文备课 #课件 #ppt #语文教学设计 #教案 #笔记
```

**变体 A 的使用边界**

- 标题统一走「第三节 · 标题固定格式」（如 `四上《颐和园》完整课件 · 2课时`），资源类型组合不再进标题，改由【内容包含】或 C 式清单承载，也不再挂立意。
- 清单去装饰、`+` 分隔、末项接板书设计；**末项按实际产品增减，没有的别写**。此块（含 10 个营销标签）是**变体 A 专属的商品式写法**，仅用户明确要走变体 A 时启用；默认备课笔记型一律用第四节第 3 块的 C 式清单 + 泛标签。
- 脉络四句只给整体印象，不剧透设计细节，被照抄的成本低。
- 痛点与想法「可选但推荐留」：全砍会退化成商品描述，与满屏同类帖同质。
- 原创声明必须属实（配图除 AI 绘画外无他人素材），发布时另在平台勾选 AI 声明。

### 变体 B：第三方点评体（不替代主骨架，独立成类）

不看「创作者讲设计」，看「同行点评一套课件」。视角是第三人称（「这套课件」「这份课件」），不是「我做的」。

**两个子型，选错就废：**

| 子型 | 公式 | 立信靠什么 | 适用课文 |
|---|---|---|---|
| **B1 成果展示型** | 共识反转 + 证据密度（页码） | 页码＝东西真存在、结构真完整 | 常规阅读课、老教师想省事的课 |
| **B2 难点诊断型** | 共同恐惧 + 精准归因 + 可执行动作 | 诊断准确＝这人真懂这课难在哪 | 高难度课文（政治题材、文言、习作、革命文化） |

**B1 骨架（5 亮点必须落成一条动线，不许是 5 个平行优点）**

```
【课题】课件【三字立意】
【某类课】最容易上得很【正向词】，但【正向词】完孩子只记住【一句学生原话】。
这套课件比较好的地方，是它没有停在【表层做法】，而是一直把孩子往【方法】上带。📌

第一个亮点，是【三字判断】。第 X 页【动作】+【名词级细节】，不是【常见做法】。
第二个亮点，是【三字判断】。第 X–Y 页只重点讲【一个例子】，没有把几个故事堆在一起。
第三个亮点，是【三字判断】。第 X 页给出【可命名的几步】，可以直接迁移到【同单元其他篇目】。
第四个亮点，是【三字判断】。第 X 页的【工具/表格】很实用：【栏目 1】、【栏目 2】……
最后第 X 页落到【延伸任务】，把课堂接到【课外】。💡

所以这节课的重点不是【A 做得更多】，而是【B 做得更稳】。
```

**B2 骨架（四步：恐惧 → 归因 → 解法 → 动作）**

```
【课题】备课｜别把它讲成【读者最怕的那种课】

这课最怕上成【恐惧对象】——【把恐惧具体化：孩子的假动作】。

【学段】不是不懂【主题词】，是缺一个能听懂的【入口/例子/动作】。

所以全课没有一句直接【读者以为你会做的动作】。先让学生把【事实层】读清楚：
【追问 1】？【追问 2】？【追问 3】？

再落回学生身上：
【排比 1】、【排比 2】、【排比 3】、【排比 4：升一格】。

收束用一句【可执行动作】：【填空/填空式句子】。
【一句：说完就停，不往上拔】

📌 这节课的重点不是把【A】讲多深，而是让孩子找到一个能说出口的【B】。
```

**变体 B 的使用边界**

- **页码只在 B1 用**，且只用「第 X 页」「第 X–Y 页」；不写分钟数、动画数、总页数。B2 用课堂动作（追问句、填空句）代替页码立信。
- **第一人称克制**：变体 B 允许「我最怕」「我很喜欢」这类同盟口吻，但**全文不超过 3 处**，且必须紧跟判断句补充。主骨架（备课笔记型）仍零人称。
- **恐惧必须回收**：开场抛出的「怕」，中段必须有一句「所以全课没有一句……」。只抛不接，读者会落空。
- **结尾不许报货架**：「围绕…等环节展开」「整理了配套…思路」一律删，改成能接住开场的判断句。产品信息交给图片与评论区。
- **「我很喜欢」必换成判断句**：喜欢 ≠ 好用，写「这一页最实用，因为它把主题换成了学生能做的动作」。
- 标签同样 10 个，但不写生造词、不蹭其他篇目名句、产品没有的交付项不进标签。

### 变体 C：家长会课件型（跨体裁独立类别，不并入主骨架）

**先判体裁**：笔记**正文极短（3–5 行）、价值几乎全在配图里**，且配图是**课件页面／现场实拍**——这是家长会类 PPT 的典型打法，与主骨架「正文承载全部信息」正好相反。**套主骨架会写出一篇没人看的长文**，必须按本变体写。

**页序模型（N 可伸缩，6–14 页）**

```
封面（实拍场景照＋叠字：说清「用一场【场景】解决【矛盾】」）
→ 立场页（家校不是对立面，把两边的视角拼起来）
→ 家长焦虑页 × N（一页一议：座位／被批评／别人写完我还没写完／老师没及时回复…）
→ 学科能力页 × N（识字／朗读／列式／拼音／写字…）
→ 结尾页（一句立意，呼应封面，首尾闭环）
```

**三条固定写法（缺一条就掉档）**

1. **标题即矛盾**：前半写「用一节【场景】解释清楚」，后半抛具体阶段的矛盾。**不写「一年级家长会」这类平铺标题**——既无搜索词也无信息量。
2. **「会 X，不等于会 Y」贯穿全篇**：把教学结果翻译成能力差别（会读韵母 ≠ 会拼音节／会认词语 ≠ 能独立认读／会读儿歌 ≠ 读懂内容），替家长卸掉「孩子是不是不行」的焦虑。这是这类笔记的记忆点，全篇 ≥4 处。
3. **每页结尾落在动作**：不给空话，结论行给一句可执行动作（先看 → 再说 → 后写；摆一摆 → 问一问 → 说一说 → 再列式）。

**两个必备配角**

- **教师边界页**：主动说明老师的时间花在哪、消息会回，把沟通焦虑提前卸掉。
- **评论区承接**：这类笔记靠评论区承接转化。**正文不挂站外链接**，不写「私我／加V」。

**语言规范的品类差异（相对主骨架的例外）**

- 零人称规则**放宽**：允许第二人称「你／家长」（说话对象就是家长），但**不写「亲爱的家长朋友们」这类套话**。
- 页码／页数**仍不写**；允许写「一页只讲一件事」这类结构说明——它对家长是信息，不是技术参数。
- **不堆图标**：正文常为纯文本 3–5 行，排版信息交给图。

**版权红线（硬约束）**

- 对标配图若是**他人 PPT 实拍／截图**，**只能复用文字骨架，绝不可复用图片**；做成商品必须**原创排版重制**。
- 课件中的教材原文、儿歌文本按教材引用；**不整段搬运他人原创文案**。

### 变体 D：互动/游戏化课件型（工具型博主，与变体 C 并列的独立类别）

**先判体裁**：内容主体是**可交互/可玩的课件**（HTML 单文件、3D 模型、游戏化闯关），买家是「想要一件能直接用的工具」的老师。这类笔记的正文**不承载教学设计全文**（交付物在商品里），只负责**让人相信这东西值得买**。

**判据一句话**：正文在讲「这东西怎么做成的、用了什么新教法」→ 变体 D；正文在讲「这一课怎么上」→ 走主骨架。

**正文四段式（这是变体 D 的骨架，不是主骨架）**

```
① 痛点用课堂原话（不是"教学难点"这种空词）
   → ② 角色代入式开场（第二人称 + 身份 + 任务）
   → ③ 规模/参数量化（14章70个情境 / 30幕分镜 / 24个可交互章节 / 41道题）
   → ④ 交付形态与兼容性承诺（HTML离线可用 / 支持希沃手机电脑 / 可插入ppt）
```

**四条硬写法**

1. **痛点必须是学生/老师真实说过的话**——「学生永远在"看不出哪里有病"和"改完不知道对不对"之间反复横跳」「学生翻三页就困的一本书」。**不要写「教学难点」「知识点抽象」。**
2. **角色代入式开场**——「你是刚下乡的人类学学生」「你先"成为"江州司马白居易」「你是孔门守简的年轻弟子」。第二人称 + 身份 + 具体任务，一次性把静态课件讲成故事。
3. **规模用双数字量化**——「14章70个情境！！《乡土中国》沉浸式探索课件！」。**标题里的数字比形容词有力**。
4. **交付形态承诺必须写进主页简介和正文**——这是老师决策的最后一关，也是最容易被漏掉的一环。

**两条可选加分**

- **时间叙事**：「讲《琵琶行》第九年，今年终于把"学写文学短评"这节课做出了想要的样子」——用时间状语替代「精心制作」。
- **第三方证言反差钩**：「同事问我这是哪个游戏，我说是《琵琶行》课件，她不信」——天然转发理由。

**流量模型对照（选对标对象的关键）**

| 类型 | 赞藏关系 | 评论 | 流量来源 | 对标价值 |
|---|---|---|---|---|
| 互动/游戏课件型 | 1:1（工具型「留着用」） | 中（10+） | 推荐流 + 标签矩阵 + 日更 | **高**，文案骨架可学 |
| 3D/工具展示型 | 藏 > 赞 | **近零（<1）** | 精准长尾搜索 | 中，话术可学、模型不可复制 |
| 纯标签无正文型 | — | — | 封面扛流量 | ⚠️ **只可学标签矩阵，正文必须自写** |

**需规避**

- ⚠️ 「沉浸式」「游戏化」若无真实交互支撑＝标题党，自研必须确保交互真的能跑。
- ⚠️ 学对标时**不要连"纯标签无正文"一起抄**——那是它的漏斗上游写法，不是正文写法。

### 变体 E：商品详情页型（不是笔记，是详情页）

**先判载体**：带价格、立即购买、发货方式的**商品详情页**，不是笔记。只有一行标题（走固定格式）、没有标签、不排配图页序，全篇只承载四件事——买什么、懂不懂这一课、能改什么、怎么发货。

判据一句话：**用户说「商品介绍／详情页／照这个卖货的写」→ 变体 E；说「发笔记」→ 主骨架或变体 A。**

**七块公式（顺序固定，可整段照抄）**

```
【内容包含：分 N 课时，可编辑 PPT＋完整教案＋N 课时逐字演讲稿＋学习清单＋制作笔记】

很多老师上这一课，容易停在「【读者最可能的偏解】」上，忽略【真正的方法／落点】，【学生真实反应：圈了一页词句，却写不出一条】。

N 课时完整教学设计，把【落点】落到实处 👇

■【动作】，【可核对细节：生字数／正音字／范字】
■【动作】，【结构串：A→B→C→D】
■【动作】，【课文原句＋三层／几方面】
■【动作】，【方法名＋换到无支撑处再写一次】
■【动作】，【关键动作串＋并排看出的结论】
■【动作】，【阅读链接篇名＋撤掉支撑后的任务】

注：

1、课件、教学设计、课堂框架与文字内容全部为本人原创，均可自行编辑调整。

2、本商品为原创电子课件，属于虚拟数字化产品，发货形式为网盘链接＋提取码。资料一经发出即可获取全部文件，无质量问题不支持退款。

发货方式：网盘
```

**八条硬写法**

1. **有一行标题、零标签**：标题走「第三节 · 标题固定格式」（`{版本缩写}《{篇名}》完整课件 · {课时数}`），仅此一行；详情页不写 10 个标签（写标签即载体错位）。全篇只在承接句末留一个 👇，不叠 emoji。
2. **零人称零感叹号**：不写「我」、不称呼「老师们／姐妹们」，陈述句到底。竞品的说服力来自没有一句自我推销。
3. **每条落点必须可核对**：带生字个数、正音字、结构串、课文原句、动作串、阅读链接篇名。写「流程完整」「环节清晰」「设计科学」等于空话，与满屏同类商品无差别。
4. **落点 5–6 条，按教学推进顺序排、不分课时段**：识字→结构→品读→方法→对比→迁移，一条条读下来就是完整的教学推进，买家据此能判断「作者上过这一课」；**不要把落点切成「第一课时／第二课时」两块**——商品介绍是整包的整体介绍，课时只作整体表述（标题「· 2课时」、承接句「2 课时完整教学设计」），不在正文里分课时罗列。
5. **可编辑只写「可编辑 PPT」**：不写「文字可编辑／文本可编辑」（课件整体可改，加限定反而缩小卖点）；也**不写「配图不可编辑」「版式为固定版式」**——与「课件可编辑」自相矛盾（2026-11-10 用户裁定）。
6. **不写动态**：课件是静态的就只写「可编辑 PPT」，不写「放映动态」「动画」，否则属虚标。
7. **原创声明不写 AI**：用户不要 AI 声明时，注 1 只留「全部为本人原创，均可自行编辑调整」；**前提是插图确非 AI 生成**，否则仍属虚标。
8. **虚拟商品条款必写**：网盘链接＋提取码、发出即获取、无质量问题不支持退款，发货方式单列一行。这是详情页的交易要件；笔记里一律不写（笔记只走左下角组件，见第一节账号定位）。
9. **落点必须源于真实教学设计（零虚构硬约束）**：每条 ■ 背后的环节、数字、原句、写法，出稿前逐条回查本课教学设计，零杜撰；不得为凑卖点编造教案里没有的环节或说法。典型偏差：教材/教学设计原词是「人类作品与自然和谐相融」，写成「自然相融」即漏字失真，须照实。自检通过再交付（见第十一节红线与第八节合规自检清单）。

**与变体 A 的区别（别混）**

| 项目 | 变体 A 总述式短帖 | 变体 E 商品详情页 |
|---|---|---|
| 载体 | 笔记 | 商品详情页 |
| 标题／标签 | 有标题、10 个标签 | **只有标题、零标签** |
| 结构 | 清单＋总述四句＋声明 | 清单＋痛点归因＋■落点×5–6＋注 1／注 2＋发货方式 |
| 交易条款 | 不写 | 必写（网盘、退款、发货方式） |
| 篇幅 | 约 235–260 字（融合版约 350 字） | 约 460–500 字 |

### 变体 F：付款后自动发货文案（交易后话术，非笔记非详情页）

**先判载体**：买家**已经付完款**，这段文字的活儿只有三件——告诉他买到了什么、去哪里领、出问题找谁。它出现在自动发货、聊天私信、订单备注里，**不参与流量，不承担说服**。

判据一句话：**详情页讲「买什么、怎么发货」，发货文案讲「链接在哪、怎么领、找谁」；用户说「发货文案／领取说明／自动回复」→ 变体 F。**

**六段固定骨架（顺序不可调换，缺段即缺指引；整段纯文本，无任何 Markdown 标记）**

```
🎉 感谢您的支持！
您好！《【篇名】》教学资源包已为您备好，请根据自己的使用习惯，选择以下任意一种网盘方式领取。

📦 资源名称：《【篇名】》教学资源包

☁️ 方式一：【网盘 A】
🔗 下载链接：
【链接地址】
🔑 提取码：【四位提取码】

☁️ 方式二：【网盘 B】
🔗 下载链接：
【链接地址】

📌 领取说明
1. 【网盘 A】和【网盘 B】提供的是同一份教学资源，选择其中一个下载即可。
2. 复制链接到浏览器或对应网盘 APP 中打开，按提示领取。
3. 建议领取后及时转存到自己的网盘，并下载保存。
4. 这份资料为虚拟电子资源，采用网盘交付，无实体快递。

💚 售后服务
如遇链接失效、提取码错误、下载失败或文件异常等问题，请及时联系店铺客服，我们会协助处理。

🌷 感谢您的支持，祝您备课顺利、教学愉快！
```

**十条硬写法**

0. **零 Markdown，交纯文本**：文案**内容**不加 `**`、`#`、`-`、`>`、反引号、代码围栏。这段要粘进自动发货／私信／订单备注的输入框，**不渲染语法，星号和井号会原样显示成乱码符号**。上面代码块只用于在技能里展示；**交付时在对话里用一个代码块装整段文案**（复制容器，用户只复制块内文字，围栏不进输入框），块内保持裸文本、不写任何标记。要强调只能用「单独成行＋emoji 定位」，不能用加粗。
1. **六段结构固定**：致谢 → 资源名称 → 网盘渠道 ×N → 领取说明 ×4 → 售后 → 祝福。买家付款后第一次看这段，少一段就是少一条指引，不是「更简洁」。
2. **「任意一种」与「同一份」必须成对出现**：开头写「选择以下任意一种」，说明第 1 条写「同一份…选一个即可」。只说不成对，买家会以为两个网盘内容不同，重复下载、重复占空间。
3. **链接与提取码各占一行，不挤在一句里**：`🔗 下载链接：` 下一行放链接，`🔑 提取码：` 下一行放码。复制时要能整段选中，挤在一起是售后量的第一大来源；提取码靠独立成行＋🔑 定位，**不靠加粗**（加粗写 `**` 反而露星号）。
4. **领取说明四条固定**：同源说明／操作路径／转存提醒／虚拟商品无实体。第 3 条「及时转存」不能删，它是链接失效的兜底。
5. **售后只承诺「协助处理」**：写死「联系客服，我们会协助处理」，不预设补发、不预设退款。具体补偿口径由店铺临场决定，文案里写死会被截图当承诺用。
6. **祝福落在教学场景**：「备课顺利、教学愉快」。不写「记得好评／求五星／好评返现」——平台敏感，且这类话术会把前面攒的专业感一次清零。
7. **资源名三处一致**：`《【篇名】》教学资源包` 与商品标题、详情页清单一字不差；不写「全套／终极版／合集」（极限词），不加课时数与页数（与详情页「不写技术参数」同口径）。
8. **渠道只写真有货的网盘**：只有一个网盘时删掉「方式二」，开头改成「以下方式」；两个都写就必须两边同源同版，发前各下一次核对文件数与最新版——一边是旧版本比没写更糟。
9. **发货链接必须由网盘能力现生成、且永久有效（2026-11-11 定，强制）**：写发货文案时，先调用夸克与百度**各自的网盘能力**（技能／连接器，以当前可用为准）为本课目录生成分享链接，要求**永久有效**，核对返回的有效期信息后，再把链接与提取码填进文案。**不自己编链接、不复用别课的链接、不从旧文案里抄链接**；文案发出前按第 8 条各下一次核对两端文件数与版本，并在交付回复里一句话交代「两端均永久、同源同版」。**本技能不记录生成命令与参数**——具体命令、有效期取值、是否带提取码，一律以对应网盘能力的文档为准（专业的事交给专业的能力，参数变了不用来改本技能）。若本课已有有限期旧链接：重建永久链接 → 回填发货清单底稿 → 在回复里列出旧链接提示取消，并提醒替换自动发货／商品配置里的旧值。

**链接获取规程（2026-11-11 定，2026-11-11 修订，强制，写变体 F 必跑）**

写发货文案不允许靠记忆、不允许留空、不允许让用户自己填。**本技能只规定「指定谁、按什么顺序取、取完怎么验、验完怎么回填、缺能力怎么办」；具体生成命令、永久有效期的取值、是否带提取码、参数格式，一律以对应网盘能力自己的文档为准**（专业的事交给专业的能力，参数变了不用来改本技能，与硬写法第 9 条一致）。

**能力指定（2026-11-11 定，写文案时按此表调用，不自己实现）**

| 端 | 指定能力 | 本技能要它做的事 |
|---|---|---|
| 夸克 | skill `quark-drive` | 查「我的分享」、按 `first_fid` 认当课目录、创建永久分享、预览分享核对文件数 |
| 百度 | 官方 `baidu-netdisk` Connector（MCP）为主（**连接器形态，不在 `~/.workbuddy/skills/`**；是否可用按第 0 步预检），`baidu-pan-ops` skill 作兜底 | 核对目录与 fsid、创建永久分享、校验提取码、浏览分享内容 |
| 能力缺装／未授权 | `search_and_install_skills`（装技能）、`list_installed_plugins` + `reconnect_plugin`（连接器授权） | 开场补齐能力，不中途才发现 |

> 本技能**不写网盘 API 调用、不记录生成命令与参数、不代跑对应能力的登录初始化命令**。能力名可以指定，参数一律回去读对应文档。

**第 0 步：开场一次性预检（先做，别边做边发现）**

1. **路径解析走底稿，不猜不扫**：从年级根 `.workbuddy/发货清单-底稿.csv` 定位课题行，取网盘相对路径、fid／fsid、已有链接、交付文件数。课题目录迁移过就按底稿里的编号＋课题名向上反查，**禁止全盘 `find`、禁止按记忆里的旧绝对路径反复试**；反查不到才问一句，一次问清年级根在哪。
2. **能力可用性一次查完**：指定 skill 是否已安装、Connector 是否 bound／enabled、两端登录态是否有效（按各自文档的预检能力，如容量／用户信息查询）。**缺装与未授权在这里一次性暴露**，不要等生成链接时才发现。
3. **有缺口就一次处理**：按下方「缺装自动安装与授权」合并成一个问题问用户，不为同一缺口连问两次、不中途把「要不要先上传」抛给用户。

**短路顺序（能复用就不新建）**

底稿已有当课专属链接 → 先校验有效期／可打开／`first_fid`／两端文件数 → 全部通过就**直接复用**，跳过查分享与新建；校验不过才往下走：查当课已有分享 → 仍没有才创建永久分享。不要每次把「我的分享」全量列一遍碰运气。

**关键禁令（2026-11-11 实例教训）**

底稿里有 fid／fsid ＝ 文件**已经在两端网盘里**。此时**禁止**再去检查「这个技能能不能上传本地文件」、**禁止**据此得出「能力缺口、无法生成链接」的结论、**禁止**要求用户先上传。只有底稿根本没有该课题记录、且用户确认要新上传时，才走对应能力的上传流程。本轮曾因这条误判连问用户两次，绕了一大圈。

**缺装自动安装与授权（2026-11-11 定，用户授权边界）**

- **触发**：第 0 步发现指定 skill 未安装，或 Connector 未绑定／登录态失效。
- **自动安装 skill**：用 `search_and_install_skills` 先搜索、再安装，安装名称逐字复制本次搜索结果；只装用户明确要求或看到候选后同意的技能，候选要带上显示名与描述再让用户点头，按结果如实报 `installed`／`already_installed`／`refused`。
- **优先官方（2026-11-11 检索实例）**：搜索结果里出现标注「第三方非官方」的网盘工具时，**不擅自安装、不拿它做账号授权**；优先官方 Connector 与已装技能，确实需要时把风险说清再让用户决定。
- **授权 Connector**：`list_installed_plugins` 查状态 → 未启用请用户在左下角＋号菜单启用 → 已绑定但登录失效／需重连，用 `reconnect_plugin` 传 `pluginName`（不是显示名）走用户侧授权。CLI 类（如百度 `bdpan`）的安装与登录按对应技能文档执行，**本技能不代跑**。
- **授权边界**：用户说「写发货文案」＝授权「取／建本课分享链接」（红线已有）；用户说过「没装就自动安装」＝授权安装所需 skill，**不必再为安装单独问一次**。但**登录或授权第三方访问网盘账号仍须用户本人完成**（问一句／走授权流程，不静默代做）；同一缺口只问一次。
- **装完仍不可用**：如实说明缺口，给「用户自行上传后贴来现成永久链接」的备选；**仍不得用占位符出稿**。

**链路固定五步（第 0 步通过后）**

1. **查发货底稿**：课题行取夸克目录 fid、百度目录 fsid、已有链接／提取码、交付文件数。底稿是唯一可信的商品数据源；课题不在底稿里先问一句，不猜路径、不猜 fsid。
2. **夸克端走能力表指定的 `quark-drive`**：按该技能文档列出的「我的分享」能力查现有分享 → 用分享元数据里的 **`first_fid`** 核对是否指向底稿里的课题目录 fid（title 会重名／带旧名，**不可信**；指向整包根目录的链接也不能用于单课发货）→ 有当课专属且校验通过的有效分享就复用，没有才按该技能文档创建永久分享 → 再用该技能的「预览分享」能力核对目录与文件数。是否带提取码按该课既有惯例。
3. **百度端走能力表指定的 `baidu-netdisk` Connector**：按该连接器文档核对目录与 fsid → 用「创建分享链接」能力生成**永久**分享，取回链接与提取码 → 用「校验提取码」＋「浏览分享内容」能力实测可打开且文件数一致。百度侧没有「列出我的分享」，已有链接以底稿记录为准。
4. **同源同版核验**：两端文件数、文件名逐一对齐，并与本地 `交付文件/` 核对。对不上先修版本，不发稿（硬写法第 8 条）。
5. **回填底稿＋写进文案**：把两端链接、提取码、有效期「双端永久」、核验备注写回该课题行；文案里链接与提取码各占一行，带提取码的一端写码、免密的一端不写提取码行。交付回复一句话交代「两端均永久」与同源核验结论。

> **文案与链接解耦（2026-11-11 实例教训）**：取链接、核验、回填是独立一段，**先跑完再写文案文字**；商品介绍／笔记的字数打磨、示例核对不要和取链接在同一轮来回穿插。本轮两边混着做，往返次数被放大。

**红线**

- **禁止占位符出稿**：`【链接地址】`／`【网盘 B】`／`【四位提取码】`／`待补充` 出现在交付稿里＝未交付，等于把活儿甩给买家。
- **禁止编链接／抄链接**：不复用别课链接、不复用整包链接、不从旧文案里抄；复用仅限底稿已记录且 `first_fid`／可打开校验都通过的当课专属分享。
- **创建分享属外部发布动作**：用户要求写发货文案即视为授权「取／建本课分享链接」；删除、取消、覆盖他人分享，或课题／路径不确定时，先问一句。**授权范围只到链接本身**——安装技能、登录或授权第三方访问网盘账号另按「缺装自动安装与授权」处理，别拿这条当静默执行账号级动作的依据。
- **链接不写进技能文档**：具体链接会失效，只进底稿与当次对话文案，不固化进 SKILL.md、不写进课题目录（见下文「实例不落盘」）。
- **文案本体仍只在对话代码块交付**：回填底稿属商品数据维护，不算文案副本；其余口径同第 5 步。

**与笔记的边界（硬约束，别越线）**

- **这是全技能唯一允许出现站外链接的地方。** 笔记正文、评论区、商品详情页一律不写链接、不提网盘地址（见第一节账号定位、变体 E 第 8 条）。把这段当成笔记发出去，就是站外导流违规。
- **语言规范不通用**：允许客服口吻与图标（如「您好」与 🎉🌷☁️📦）；主骨架的零人称、零 emoji、不引导互动、不写效果承诺等条款不适用于此块。但「永久有效」「长期更新」「包过」一类承诺仍属禁止。**必须区分两件事（2026-11-11 定）**：链接「生成时设为永久」是技术配置（硬写法第 9 条，必须做）；文案里「写永久有效」是对买家的承诺（仍然禁止）。即便配置永久，链接仍可能因平台规则、账号状态或手动取消而失效，所以「及时转存」与售后兜底一条都不能删。
- **与变体 E 口径对齐**：详情页写「网盘链接＋提取码」「虚拟商品无质量问题不支持退款」，发货文案就必须落在这两句上，不能反过来写「不满意可退」。

**实例不落盘、不存技能（2026-11-10 定，2026-11-10 修订）**：具体链接属该课的商品数据，即使生成时设为永久也可能因平台规则／账号状态／手动取消而失效，写进通用技能等于埋旧链接；也不写进课题目录（旧口径的 `《篇名》-商品文案.md` 已废止）。成品两份文案一律在对话里用代码块给出，链接来源与同源核验结论在回复正文里一句话交代，不生成任何本地文件。发新课时照上面骨架重填，并按「链接获取规程」重新取链接、核验、回填底稿。

### 分课时发（每篇只写自己那课时）

仅把「📖两课时课堂脉络」换成「📖第 X 课时课堂脉络」，下面只写本课时的方向句（详略按第 3 步「唯一口径」：默认 2–3 句，详细版 4–5 句动作句）；「💫一点备课小想法」只写本课时相关的 2 条（详细版 3 条）。**标题标「第一/二课时」**；整包产品的课时信息由标题或正文交代，C 式清单不强制前置「2课时」（见第四节第 3 块）。

## 六、语言规范（必须 / 禁止）

**必须**

- 全篇零人称：不写「我」，也不称呼读者（不用「姐妹」「家长们」）。**例外**：变体 B 允许「我最怕」「我很喜欢」这类同盟口吻，全文 ≤3 处且必须紧跟判断句
- 段落以陈述句为主，动词开头；每句只讲一件事
- 引号只引课文原词或单元要素词
- 表达想法用判断式短句：「图片只用作情境引入。」
- 图标只用 5 类：星R 框清单、📖 脉络、▪️ 课时、💫 想法，另允许 **1 个主题 emoji 起一句**（如 🌲 小兴安岭、🗿 兵马俑），全文不超过 2 个，不叠用。**变体 E 例外**：不用星R／📖／▪️／💫，只用 `■` 起落点行、承接句末一个 👇
- 正文提到 AI 配图时，须写一句配图声明；发布时勾选平台 AI 辅助创作声明。**用户明确不要 AI 声明时不写**（前提：插图确非 AI 生成，见变体 E 第 7 条）
- 各逻辑模块之间空一行（标题／清单／痛点／脉络／想法／标签／注／发货方式），提升阅读体验（细则见第 5 步交付「模块间空一行」）

**禁止**

- 感叹号连用、引导互动（「需要的扣 1」）、表情堆叠
- 极限词：「最 / 第一 / 唯一 / 天花板」；夸张词：「震撼 / 封神 / 绝了」
- 课程方法论术语：「语文要素落地」「任务群」「大单元」（对标帖一个都没用，也别用）
- 技术参数：分钟数、页码数、动画个数（**唯一例外**：变体 B1 展示型允许「第 6–8 页」这类精确坐标，页码在该体裁里是信任资产；分钟数与动画数任何体裁都不写）
- 清单里写产品实际没有的交付项（虚标「板书设计」「微课」等）
- 结尾写效果承诺与行动召唤（「直接打印上课」「解放备课时间」「新手老师…👏」「拒绝熬夜备课！」「来啦」「感兴趣的老师可以看看」，以及「配套…全部配齐」式报货架）；成交只走左下角官方个人售卖组件，正文与评论区不引导。这是四样本里最稳的风险信号（示例十一被判灰色、示例十无此句且过审）

## 八、合规自检清单

### 脱敏规则（2026-11-11 定，强制，全形态适用）

> 用户说「注意脱敏」，或涉及课堂实拍／学生信息／课件内页截图时，本规则与第 4 步「出稿必检」**同时执行**，结果随稿给出。法规部分只作方向性判断，**以最新法规及平台规则为准，不作法律定论**。

**定义**：脱敏＝把可识别到具体个人、机构、账号、交易的信息，从文案与配图里移除或改成中性指代。按《个人信息保护法》口径，加密／打码属**去标识化**，处理后的信息仍是个人信息；只有**匿名化**（无法识别且不能复原）才不算个人信息。所以**打码不是免死金牌**——能删就删、能不拍就不拍，打码是最后一道。

**五层清单（逐层扫，缺一层不算做完）**

| 层 | 必删／必改 | 安全写法 |
|---|---|---|
| 1 未成年人 | 学生真实姓名、学校全称、班级号、校服校徽／班级牌、正面清晰人脸、成绩与评语、固定作息与上下学路线 | 只写「学生」「同桌」「班里」；配图只用课件方法页，不放课堂实拍 |
| 2 证件与标识 | 准考证／学生证／获奖证书上的条形码、二维码、编号；二维码、微信号、手机号、店铺水印 | 裁掉或打码；**含二维码的图一律不用**（平台按隐性导流处理） |
| 3 教师与机构 | 教师真实姓名、任教班级、学校名称、地区定位、发布时开启的地理位置 | 零人称本就天然规避；发布前关闭定位 |
| 4 交易与内部数据 | 网盘链接／提取码／fid／fsid、价格、销量、成交数、内部文件路径、文件大小与页数 | 只在变体 F 发货通道出现；笔记与详情页一律不写 |
| 5 时政与人物 | 人物姓名与职务、讲话原文长句、会见场合／国别／时间、以领导人语句做话题标签 | 用「课题这句话」「课文里的一个例子」「一项成就」等中性指代；**教材篇名作标题不等于违规，保留**（见第 4 步实证口径） |

**必做 / 人工确认分清**

- **必做**：1–4 层零残留；配图逐张读内页文字与画面（含叠字、页眉页脚、水印）；封面叠字不写课题整句；标签不拿课题整句做话题标签；正文不重复人物称谓与职务；不整段抄录课文原文。
- **人工确认（不据此停发题材）**：教材篇名、课题话题标签、课件内页的课文标题。技能实证记录过「同课题纯教学分享笔记可正常过审」，此前因误判政治敏感所做的整页打码**已撤销**；只有与营销推广叠加时才从严。用户明确要求「连标题一起脱敏」时另出一版，**不擅自改固定格式标题**。
- **不做**：为脱敏把教学落点改成含糊空话。**脱敏只换指代，不删方法**——换掉人名职务后，事件链、支架、追问这些可核对的细节必须原样留着，否则零虚构稿会退化成空话。

**依据（2026-11-11 检索，方向性引用）**：《个人信息保护法》第 4／6／25／28／29／31／51 条（去标识化与匿名化的区分、最小必要、不得公开、不满十四周岁未成年人信息属敏感个人信息、单独同意与监护人同意、去标识化措施）；《未成年人保护法》第 4 条；《民法典》第 1019 条肖像权；《可能影响未成年人身心健康的网络信息分类办法》（2026-03-01 施行）第 5／6 条；教育部主管中国教育新闻网「三不晒」实操口径（不晒身份定位信息、不晒带码证件、不晒规律轨迹，分享前打码、关定位）；国家网信办关于个人信息／敏感个人信息的答记者问；小红书未成年人保护治理中的隐私肖像保护机制。平台规则与法规持续更新，出稿时以最新规则为准。

- [ ] **涉及教案／设计思路的内容已对照真实教学设计逐条自检**：商品详情页（变体 E）每条 ■ 落点、备课笔记的脉络与想法、任何写到的环节／数字／课文原句／写法，都能在本课教学设计中找到依据，零虚构、零凭空想象；原词照实写（如「人类作品与自然和谐相融」不可漏成「自然相融」）。自检通过再交付，未自检不出稿
- [ ] 版本与年级对得上（如《秦兵马俑》属人教版四上，不可标「统编四上」）
- [ ] 零人称、无引导互动、表情不过量
- [ ] 清单每一项交付物都真实存在，无虚标
- [ ] 有 AI 配图时已写声明，发布端已勾选 AI 辅助创作（用户明确不写 AI 声明时，确认插图非 AI 生成再省）
- [ ] 若为商品详情页（变体 E）：只有一行标题（走固定格式）、零标签、可编辑只写「可编辑 PPT」（不写文本可编辑、不写配图不可编辑）、不写放映动态、注 2 与发货方式齐全
- [ ] 若为发货文案（变体 F）：**开场第 0 步预检已过**（路径走底稿未全盘扫描、两端能力已按能力指定表调用、缺装已自动安装并经用户授权、登录态有效）；站外链接只在发货通道出现（未进笔记正文／评论区／详情页）、**每条链接均由夸克／百度各自网盘能力现生成、已核对返回的有效期为永久**（非编造、非复用旧链接；有限期旧链接已重建、回填底稿并在回复中列出待取消）、两个网盘同源同版、「任意一种」与「同一份」成对、链接与提取码各自一行、售后只写「协助处理」不预设退款、无「永久有效／好评返现」一类**承诺**（配置永久≠可写承诺）、**整段零 Markdown 标记（无 `**` `#` `-` `>`、无反引号与围栏）**

## 九、常见坑

| 现象 | 原因与处理 |
|---|---|
| 写成平台运营方案 / 销售话术 | 用户要的是「设计思路、上课思路」，不是卖货文案；回到「痛点 + 流程 + 取舍」三件套 |
| 出现「我」「姐妹们」 | 对标体是零人称陈述，删掉所有第一/二人称 |
| 堆极限词、感叹号 | 直接违规风险，按「禁止」清单逐句过 |
| 分课时发但清单写成「1课时」 | 整包产品别写成单课时；课时信息按第 1 步由标题或正文交代，C 式清单不强制前置「2课时」 |
| 写进分钟数 / 页码 / 动画数 | 分钟数与动画数任何体裁都删；页码仅变体 B1 可留（那是点评体的信任资产），主骨架与 B2 一律不写 |
| 引号乱用 | 只引课文原词 / 单元要素词，别给普通词加引号 |
| 照抄说明型对标，整篇只剩清单 + 三句总述 | 缺痛点与取舍，和同类帖同质、不记人；至少补回痛点两行或想法两句 |
| 清单照搬对标末项「板书设计」 | 产品没有独立板书文档就是虚标；先补齐文档，或删掉该项 |
| 标错教材版本 | 对标写「统编三上」不代表本课题也在统编；编号对不上时宁可不写版本 |
| 正文结尾报货架（「围绕…等环节展开」「整理了配套…思路」） | 「等环节」是敷衍词，整句在报货架，把前面积累的专业感一次清零；改成接住开场的判断句 |
| 点评体写「我很喜欢这一页」 | 主观词不是判断，读者拿到的是情绪不是理由；换成「这一页最实用，因为它把 X 换成了学生能做的动作」 |
| 五个亮点写成五个平行优点 | 读者读完只记得「挺好」记不住「好在哪」；必须落在一条课堂动线上（入→讲→法→用→出），有权重差别 |
| 开场抛了「我最怕…」但中段不回收 | 恐惧开场只抛不接，读者被撩一下又落空；必须补一句「所以全课没有一句直接…」 |
| 家长会笔记套了主骨架 | 主骨架靠正文承载信息；家长会型价值在图，硬套会写成没人看的长文 → 改按变体 C：正文 3–5 行 + 页序模型 |
| 家长会笔记写成「老师 vs 家长」对立 | 立场页没先站队家长，家长读完只会更焦虑；先立「家校在同一边」再逐页拆焦虑 |
| 标题写成「一年级家长会」 | 既无搜索词也无矛盾；改成「用一节【场景】解释清楚，为什么【阶段】」 |
| 直接搬对标笔记的 PPT 实拍图 | 版权风险；只复用文字骨架，图片必须原创重制 |
| 评论区写「私我拿资料」 | 站外导流违规；改为在评论区给可复制的口播要点，正文不挂链接 |
| 只扫文案文字，漏了清单与标签 | 真正的命中常是正文商品清单 + 营销标签 + 交易引导，不在课文措辞 → 按第 4 步四位置全扫，风险权重以营销链路为先；别把课题名当主因，更别整页打码 |
| 把站内 AI 的推测当平台规则 | 「公开课／教案是敏感词」「需教师资格认证」等是汇总笔记生成的推断，已被实际反例证伪 → 只采信可追溯的归因，其余按第 4 步人工确认 |
| 个人售卖稿硬改成纯分享 | 账号要成交，删掉清单与售卖意图等于放弃转化 → 保留 C 式清单 + 官方组件，只降营销语气 |
| 误判成政治敏感就整课题停发 | 同课题纯教学分享笔记可正常过审 → 先查营销链路，题材只作人工确认（见示例九） |
| 拆解结果只存进本地目录 | 工作流中间产物不入库：归档走飞书表 + IMA 全文副本，本地不留（见第十一节） |
| 写完文案顺手存一份 md／docx 到课题目录 | 用户明确不要本地副本（2026-11-10 定）：成品只在对话代码块给，自检记录与链接核验结论写在回复正文，不落盘、不建「文案」文件夹 |
| 互动课件笔记写成教学设计全文 | 变体 D 的正文只负责「让人相信这东西值得买」，教学设计在商品里 → 按痛点原话→角色代入→规模量化→交付承诺四段写 |
| 互动课件笔记只写「本课件包含…」 | 干巴巴的清单没有说服力 → 换成学生真实痛点原话 + 「你是……」角色代入开场 |
| 抄了「纯标签无正文」的对标帖 | 那是封面扛流量的上游写法，不是正文写法 → 必须自己补「痛点＋解法＋交互亮点」三段文案 |
| 主页笔记列表抓不到互动数 | 主页 SSR 的 `userNotes` 为空，互动数必须逐篇抓：用移动端 UA + `/discovery/item/{id}` + `xsec_token`（见第十一节「数据采集」） |
| 另起思路 / 把脉络写成动作细节清单 | 讲解思路只从教学设计浓缩，详略按第 3 步「唯一口径」；课件与制作笔记不提供立意 |
| 结尾写「直接打印上课／解放备课时间／来啦」 | 效果承诺 + 行动召唤，四样本里最稳的风险信号 → 整句删，成交只走左下角官方组件，正文与评论区不引导 |
| 照抄对标的页数／✅／👇／✔️ 图标堆叠／「配套…全部配齐」 | 技术参数、引导互动、表情堆叠、报货架都属「禁止」清单；该学的是教学判断密度，不是版式符号 |
| 把站内 AI 逐篇漂移的分析当规则库 | 同一套样本它先后归因为售卖、意图、原创、清单，是结果倒推理由 → 只作样本，差分结论按第 4 步「判定逻辑」 |
| 照着官方 AI 给的「安全版」改稿 | 其示范自相矛盾（说删营销标签却留、说别引导却写「左下角链接」）且第一人称＋动作细节 → 只借「分享口吻」，写法仍按第 3 步唯一口径 |
| 详情页写「文本可编辑／文字可编辑」 | 课件整体可改，加限定反而把卖点写小 → 一律写「可编辑 PPT」（变体 E 第 5 条） |
| 详情页又写「可编辑」又写「配图不可编辑／版式固定」 | 前后自相矛盾，买家改不动就来纠纷 → 要么整份可编辑就都别限，要么如实只保留真实受限的那一项 |
| 商品详情页套笔记骨架，写了标题和 10 个标签 | 载体错位：详情页没有标题框，标签也无处挂 → 按变体 E，标题与标签一并去掉 |
| 详情页漏写注 2 与发货方式 | 虚拟商品必备条款，事后纠纷的直接来源 → 网盘链接＋提取码、发出即获取、不退款、发货方式缺一不可 |
| 详情页落点写成「流程完整／环节清晰」 | 空话无法核对，与同类商品无差别 → 每条落点带生字数、正音字、原句、动作串、篇名 |
| 商品介绍/笔记的设计思路凭记忆写、不回查教案 | 漏字漏环节、把教材原词写错（如「自然和谐相融」写成「自然相融」）、编造教案没有的环节 → 出稿前对照真实教学设计逐条自检，每条落点/数字/原句/写法都能在教案找到依据，零虚构再交付 |
| 发货文案给的是 Markdown 稿（带 `**` 加粗、`#` 标题、`-` 列表） | 买家看到的是满屏星号井号，像故障信息 → 变体 F **一律交裸文本**，强调靠独立成行＋emoji，不靠加粗 |
| 发货文案把链接与提取码挤在一行 | 买家复制时漏码或带上「提取码：」字样，售后量直接上升 → 链接、提取码各占一行 |
| 开头写「任意一种网盘」但说明里没说「同一份」 | 买家以为两个网盘内容不同，重复下载 → 成对出现，说明第 1 条固定写同源 |
| 两个网盘其中一个放的是旧版／空目录 | 比只挂一个网盘更伤——买家拿到缺文件又不敢确认 → 发前各下一次核对文件数与版本 |
| 发货文案写「永久有效／长期更新」 | 链接仍可能因平台规则／账号状态失效，写成承诺就是虚假宣传 → 只写「及时转存」，失效走售后兜底。**这与「生成时设永久」不冲突**：前者是文案承诺（禁），后者是技术配置（必做，见硬写法第 9 条） |
| 生成链接时用接口默认的 7 天／30 天有效期就交付（2026-11-11 实例） | 买家隔几天领取已失效；双网盘还会出现一端永久、一端过期的不一致 → 调用两端网盘能力生成永久链接并核对返回有效期；旧有限期链接重建后回填底稿、列出待取消，并替换自动发货配置里的旧值 |
| 不调用网盘能力，凭记忆编链接或复用别课／旧文案的链接 | 链接指向错目录、已失效或已被取消，买家领不到货 → 每个课题写发货文案前都现生成，生成后核对目录与文件数 |
| 发货文案里加「记得好评／好评返现」 | 平台敏感，且把专业感清零 → 祝福只落教学场景 |
| 售后写「不满意可退」 | 与详情页注 2「虚拟商品无质量问题不支持退款」冲突，纠纷时对自己不利 → 统一写「协助处理」 |
| 把发货文案当笔记正文发出去 | 带外链即站外导流违规 → 发货文案只走自动发货／私信通道（变体 F 边界） |
| 发货文案写「全套／终极版／合集」 | 极限词，且与商品标题、详情页名不一致 → 统一 `《【篇名】》教学资源包` |
| 文案各模块紧贴、不空行 | 标题／清单／痛点／脉络／想法／标签等模块挤在一起，手机端读着发闷、阅读体验差 → 模块之间各空一行（模块内同类条目如 ■落点、▪️ 方向句、注 1／2 可紧凑）；变体 F 六段骨架本就段段空行，保持 |
| 按记忆里的旧绝对路径找课题目录、反复 ls／全盘 find（2026-11-11 实例） | 课题目录会迁移，全盘扫描还容易超时，白耗十几轮 → 一律从年级根 `.workbuddy/发货清单-底稿.csv` 反查，反查不到才问一句，一次问清年级根 |
| 只看了规程的 grep 片段就开始查网盘能力 | 漏掉「先查发货底稿」这一步，误判文件不在网盘 → 出稿前把「链接获取规程」整节读完，按第 0 步顺序走 |
| 底稿已有 fid／fsid，却去检查「能不能上传本地文件」并得出「能力缺口」结论 | 文件本来就在两端网盘，这活儿是取链接不是传文件 → 见规程「关键禁令」；本轮因此连问用户两次，多绕 20+ 次工具调用 |
| 同一个能力缺口反复问用户、把文案打磨和取链接混在一轮 | 用户被打断、往返被放大（本轮 59 次工具调用才交付） → 缺口合并成一个问题一次问清；链接核验跑完再写文案文字 |
| 缺装的网盘 skill 不装就先说「做不了」 | 用户已明确要求「没装就自动安装并授权」 → 按规程先搜索再安装、连接器走用户侧授权；装完仍不可用才给备选，且不得用占位符出稿 |

## 十一、持续迭代与融合机制（用户提供新对标帖 / 多篇文案时）

本技能不是一次性沉淀，而是**累积型**：用户会不断丢新的对标帖、爆款文案过来，目标是把它们拆解后融进本技能，越用越准、越用越贴合「我们自己的产品调性」。

### 归档位置（硬规则）

**双落点：飞书表（结构化字段）＋ IMA 知识库（全文副本）；本地不留。**

| 落点 | 存什么 | 用途 |
|---|---|---|
| 飞书表「小红书爆款笔记与对标博主记录表」（子表：爆款笔记／对标博主） | 标题、链接、博主、数据快照、标题公式、封面形式、钩子、正文结构、标签、评论需求、爆点归因、可复用点、二次利用动作、复用状态、来源、合规自检 | 结构化、可比对、可统计，**唯一权威记录** |
| IMA 知识库「小红书学习笔记」 | 同名 .md 文字稿（正文原文＋逐页文字＋拆解要点） | 全文语义检索，以后可直接问 ima |
| 本地 | **不留** | 拆解中间产物不入库；**成品文案同样不落盘**，只在对话代码块交付（见第 5 步）。唯一例外是确需留存的配图原图，放该课题 `assets/` |

**三条注意**

1. **本地不留副本**：不在工作区建「文字稿 .md + assets 原图」目录（既删起来麻烦，又容易和对外交付的成品混淆）。确需留原图时，放该课题目录的 `assets/`，按素材命名规范走。
2. **IMA 只进不出**：官方 ima-mcp 工具集只有增/查，openapi 实测无任何 delete 端点（只有 move/rename）。存之前先确认这份内容值得长期留存；入错了只能「同名替换清内容」＋ 客户端手动删占位空壳。
3. **不重复拆解**：写新笔记前先查飞书表（结构化维度）与 IMA（全文检索维度），避免同一篇被拆解、入库两次。

**IMA 入库操作（3 步）**

1. `create_media`（同名 .md，`content_type=text/markdown`）→ 取 presigned_url
2. COS PUT 上传（`Content-Type` / `Content-Length` 必须与申请时完全一致）
3. `add_knowledge` 带 `duplicate_name_strategy: DUPLICATE_NAME_STRATEGY_REPLACE`（同名时**替换而非新增**，库内条目总数不变）

**回读校验**：`get_knowledge_list` 比对条目总数与 `file_size`；`search_knowledge` 确认正文可检索。

**批量入库**：一个文件放多个博主／多篇笔记时，**按主题合并成一份 md**（如「对标博主拆解-墨雨与化境可视化.md」），不要拆成几十个小文件——IMA 条目数越少越好检索。

新对标入双落点后，再决定要不要固化进本技能（按下面 4 步动作）。

### 数据采集：抓笔记互动数的可用通道（实测）

小红书笔记的点赞/收藏/评论/分享数**不在主页 SSR 里**，必须逐篇抓。按可用性排序：

| 通道 | 能否拿到互动数 | 说明 |
|---|---|---|
| **移动端 UA ＋ `/discovery/item/{id}` ＋ `xsec_token` ＋ `xsec_source=pc_user`** | ✅ **可用，首选** | 一次请求拿到 `likedCount` / `collectedCount` / `commentCount` / `shareCount` / `time` / `desc` / `tagList` / `type` |
| 移动端 UA ＋ `/explore/{id}` | ❌ | 返回的是搜索/发现页数据，无笔记详情 |
| 桌面端 UA ＋ 任意路径 | ❌ | 笔记详情一律不渲染（37KB 空壳） |
| 不带 token | ❌ | 返回 404/空 |
| 主页 SSR（`/user/profile/{userId}`） | ⚠️ 仅账号级 | 可拿 `fans` / `follows` / `likeAndCollect` / `redId` / `desc` / `tags` / `collectionList`（收藏夹＝产品矩阵）/ `tabs`（有 `buyer` 说明开了选品）；**笔记列表 `userNotes` 为空** |

**取 token 的路径**（按顺序）：
1. 短链 `xhslink.cn/o/xxx` → 302 到 `discovery/item/{id}?xsec_token=...`（分享 token，最稳）
2. 主页 SSR 里 `profile.userInfo.redId` 无用；**笔记 token 要从浏览器 DOM 拿**——`/user/profile/{userId}` 页面每个笔记卡片的 `<a href>` 里带 `?xsec_token=xxx&xsec_source=pc_user`
3. 用 `dom_cua_get_visible_dom` 读主页 DOM，一次能拿到 20–30 条笔记的 id＋token

**可复用抓取脚本模板**：
```bash
MUA="Mozilla/5.0 (iPhone; CPU iPhone OS 17_0 like Mac OS X) AppleWebKit/605.1.15 (KHTML, like Gecko) Version/17.0 Mobile/15E148 Safari/604.1"
curl -sL -A "$MUA" -H "Referer: https://www.xiaohongshu.com/" \
  "https://www.xiaohongshu.com/discovery/item/${nid}?xsec_token=${tok}&xsec_source=pc_user" -o out.html
```
- **串行 + 每次 sleep 0.8–1.2s**，并发会被限流返回空
- 失败重试 2–3 次（间隔 3s），限流是暂时的
- `desc` 字段里的 `\n` 是 JSON 转义，解析时先 `.replace('\\u002F','/')` 再 `unicode_escape` 解码
- `time` 是**毫秒时间戳**，除以 1000 再格式化
- `type` 区分图文（`topic`）/ 视频（`video`）
- 首页笔记数被折叠，DOM 里拿到的链接是**当前已渲染的部分**，不是全部

### 采集：账号级 vs 笔记级分工

| 想要 | 从哪拿 |
|---|---|
| 粉丝/关注/赞藏总数/简介/标签/收藏夹/是否有选品 | 主页 SSR 一次搞定 |
| 单篇互动数与发布时间 | 逐篇抓（上面的通道） |
| 平均点赞/收藏/评论 | 抓样本（20–30 篇足够）后自算，填进「对标博主」表的 I/J/K 列 |
| 商品成交数 | **取不到**（商品页是 APP 端），只能靠用户截图 |

### 归档：博主级 vs 笔记级的分工

- **单篇笔记** → 飞书「爆款笔记」子表（30 列结构化）＋ IMA 全文
- **博主主页** → 飞书「对标博主」子表（28 列档案：粉丝/笔记数/平均赞藏评/爆款数/更新频率/人设/内容主线/封面风格/标题套路/SEO/商业化形式/可借鉴/需规避/跟踪状态）
- **同一位博主的代表作** → 挑互动最高的 2–3 篇进「爆款笔记」，其余清单进 IMA 的 md
- 一个博主一份 md（**合并写，不拆多文件**）

### 触发

- 用户说「分析拆解这篇」「照这个格式写」「把这篇融进去」「后期还有文案你帮我拆解」等
- 用户直接贴一篇新文案（无论是否同课题、同体裁、同长度）

### 单个新对标的标准动作（4 步）

1. **拆解（必做，先出）**
   用「四、对标拆解六块法」逐块填表：原文要点 / 在文中的作用 / 可复用点。缺块也要写明缺口与代价。结尾给一句「本帖与现有骨架的差异点」，让用户一眼看到新东西在哪。

2. **出改良稿（先出效果，等确认）**
   把新对标里有效的结构、句式、节奏，套到用户当前课题上，产出一版可直接发的文案。
   ⚠️ 这一步只动「当前任务」，**不碰 skill 文件**。

3. **列「拟固化条目」（临时清单，不写文件）**
   明确告诉用户：准备把哪些新发现写进 skill，例如：
   - 骨架公式要不要加新块（如新增「避坑提醒」「互动钩子」「封面引导」）
   - 语言规范「禁止」要不要加新条目（如某类新出现的夸张话术）
   - 体量数据要不要调整（如对标普遍更短/更长）
   - examples.md 要不要新增一篇示例、归入哪类
   列出后**停一下，等用户确认**。

4. **确认后固化**
   用户说「可以 / 固化 / 写进去」后，才编辑 `SKILL.md` 与 `references/examples.md`。未确认前，所有新发现只停留在当前对话。

### 多篇对标融合

- **多篇同体裁**：取「结构并集」，在 `examples.md` 各存一篇并标注「类型 A / 类型 B」；骨架公式只保留最大公约数，差异点写进「常见坑」或单列「变体说明」。
- **多篇跨体裁**（如既有备课笔记、又有卖货种草、又有晒单反馈）：**分独立 few-shot 类别**，不混进同一骨架；跨体裁的只在示例区并列，绝不污染核心骨架与语言规范。
- **商品说明型对标**（清单 + 总述 + 原创声明）：作为**变体 A** 挂在主骨架之后，不替换主骨架；只吸收其标题格式、清单写法、总述四句、原创声明，痛点与取舍仍留在主骨架里。
- **商品详情页型对标**（方括号清单 + 痛点归因 + ■落点 + 双注 + 发货方式）：作为**变体 E** 独立成类，**不并入变体 A**——它无标题无标签、带交易条款，与笔记体量不可互换；只把它「每条落点带可核对细节」的写法反哺主骨架的痛点段密度。
- **同课题多版**：保留「定稿版」为基准示例，其余版本作为变体附录，避免主骨架被临时试错带偏。

### 红线（与全局技能迭代规则一致）

- 改 skill 一律「先出效果 → 等确认 → 再固化」，不得边改边写进技能。
- 未确认前，任何新发现的版式/语言偏好只停留在当前对话，不落盘。
- 用户已确认定稿的教案 / PPT / 学习单等教学内容，绝不因文案需要而改动。
- **涉及教案／设计思路的文案，出稿前必须对照真实教学设计自检、零虚构**：商品详情页（变体 E）每条 ■ 落点、备课笔记的脉络与想法、任何写到的环节／数字／课文原句／写法，都要能在本课教学设计中找到依据，不得凭空想象、不得为凑卖点编造教案里没有的环节或说法；原词照实写（如「人类作品与自然和谐相融」不可漏成「自然相融」）。自检通过再交付，未自检不出稿。
- **归档走双落点**：对标拆解进飞书表 + IMA 知识库全文副本，本地不留文件（见第十一节「归档位置」）。
