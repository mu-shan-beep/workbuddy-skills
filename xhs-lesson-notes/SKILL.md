# 小红书「语文课件备课笔记」文案生成

> 本文件是**执行手册**：一条规则只在这里定义一次，别处只给操作指令与出处。规则的完整登记（编号／级别／唯一位置／依据强度）见 [规则总账](references/rule-index.md)；历次改了什么见 [规则变更记录](references/rule-changelog.md)。**新增或修改规则前先查总账**，避免同一件事在两处各写一套。
> 规则审查与修订按[规则自检清单](references/rule-selfcheck.md)和[事实台账](references/fact-ledger.md)逐事实取证，核对方法用同机 `rule-review`。出稿继续使用本技能的出稿清单。

## 一、规则分级与五条铁律

### 1.1 规则分级：A 硬约束 / B 形态选择 / C 形态内自由

**规则不是一律必须遵守的。** 把「某个账号某篇的写法」当硬约束执行，就会写出篇篇一样、写不满就硬凑的死模板——这是本技能最容易犯的结构性错误。执行任何一条规则前先判它属哪一级：

| 级别 | 装什么 | 处理方式 |
|---|---|---|
| **A｜硬约束** | 平台合规（无引流、无虚假承诺、题材分级）、物理规格（标题 ≤20 字符、标题框与正文框分离、标签并入正文框一次可复制）、事实锚定（按教学、课堂、交付各自的证据核对） | 不可让、不讨论、不因风格或对标省略。违反即判失败 |
| **B｜形态选择** | 每篇从 M1—M6 选一个（第四节），**只看本课素材与读者需要，不受历史形态限制**；去重查开头首句／核心判断／收束三处是否与近 4 篇雷同。**首屏写什么包含在形态定义里**，不设全库统一硬规则 | 必选，但不指定用哪个。交付时写一句「本篇用 M?，因为……」 |
| **C｜形态内部自由** | 条数、字数、句式、符号组、段落微序、收束方式、封面形态、标题定位词、每个部位从手法池挑哪一种 | 在选定形态内部自由，由本课教案推导。跨形态套用同一句式＝同构，见 [去同构](references/anti-repetition.md) |

### 1.2 五条反过拟合铁律

1. **样本量决定规则强度**：同一账号 4 条一致，只能进 B 类。A 类只收平台规则与事实约束，任何「某账号怎么写」都不进 A 类。
2. **数字必须带来源与样本量**：字数、条数、标签数须标「来源 N 条样本」；N < 8 只作参考值，不作判定失败依据。
3. **规则实例由教案推导，不得由模板反推**：先数本课有几个真实教学点，再决定写几条。从「应该有 6 条」往回凑，凑出来的那条必然是编的，属事实造假。
4. **不存在默认形态**：没有「主骨架」这个概念。只要存在一个默认，九成笔记就会长成同一个样子——前几版反复回到原点都是这个原因。
5. **优秀点采并集，不采交集**：① 有一个真实样本在用 → 收录；② 有带数据的正面证据 → 推荐层，无数据 → 备选层（仍可调用）；③ 有平台合规风险 → 唯一一票否决。**「无法证明有效」不等于「已证明无效」**：风格类写法一律写成「X 适用于 Y 情况」，不写「不做 X」（平台红线与 0/21 的负面共性除外）。**用户一手观察权重最高**：本账号实际表现 > 跨账号不可比数据 > 单账号无数据样本。手法池见 [优秀点融合库](references/excellence-fusion.md)。

### 1.3 教学设计唯一锚定律（最高铁律，全变体通用）

文案中所有教学思路、环节动线、重难点预设、课堂支架、师生对话、板书设计，**必须 100% 来源于真实的《教学设计-源.md》**（及配套课件与逐字稿）。真实课堂经历另查实授记录，交付承诺另查采用成品与买家权限，见 4.5。

- **来源口径**：标题立意、痛点、`■` 落点、💫 想法只从教学设计浓缩；方法名、示范例句、学习单栏目名可从课件与学习清单核对（教案常只写动作名，具体内容在课件里，属正常情况）。
- **禁无中生有**：不得编造教案里没有的学生误区、课堂闹剧、活动环节。
- **禁改教学定位**：略读课文不得写成精读教法；定位为「自主批注」的环节不得写成「逐句精讲」。
- **全链条可核对**：每个避坑点、核心追问、板书逻辑，都要能在源稿里找到对应出处。

### 1.4 定位、账号与体裁分流

**定位**：不是卖货话术，是**教师对教师的资料说明**。可信度来自三样——学生看不到文本门道的痛点、按教学推进顺序排的可核对落点、作者的真实教学取舍。主语是**「这套资料」**，不是「这节课我怎么上」（21 条样本无一例外；形式归纳，不构成流量承诺）。语气陈述式、零人称（不写「我」，也不称呼读者），不喊口号。

**账号层**：个人售卖笔记在常规课题中保留成交意图，处理为「正文降营销语气 + 成交只走笔记左下角官方售卖组件」。交付说明的位置由所选形态决定（见第四节），正文与评论区都不写「私信／看主页／加V／链接」。账号层的类目准入、报备与发布节奏属平台运营规则，不写进本技能，交付时口头提示。

**题材优先级**：课题属「革命历史／党史地标」时，平台合规是一票否决项，优先级高于售卖转化，走 4.5 的四剥离纯教研形态。

| 体裁 | 说明 | 去哪 |
|---|---|---|
| **常规信息流笔记 M1—M6** | 主力，无主形态、轮换使用 | 第四节 |
| **总述式短帖（变体 A）** | 短平快，概括备课动线与教学重点 | 4.5 |
| **商品详情页（变体 E）** | 一行固定标题、零标签、含交易条款 | 4.5 |
| **付款后发货文案（变体 F）** | 六段纯文本，按核验后的约定渠道填链接，全技能唯一站外链接通道 | 4.5＋[履约规程](references/fulfillment.md) |
| **多账号矩阵（变体 G1—G4）** | 5 套隔离人设，账号级分流，不在同一账号按篇轮转 | 4.5＋[矩阵规范](references/account-matrix.md) |
| **特殊类（变体 B/C/D）** | 第三方点评体／家长会图集／互动游戏课件 | [特殊变体](references/special-variants.md) |
| **脱敏** | 不是独立变体，叠加在命中的任一形态上 | 第七条 |

## 二、何时使用与路由

### 2.1 加载与判据

**自动加载（强制）**：请求是「写文案」且对象是语文课件／教案商品，用户不 @ 也要作为第一步主动加载本技能；优先用 Skill 工具按名 `xhs-lesson-notes` 加载，不在自动发现列表里就直接读 `~/.workbuddy/skills/xhs-lesson-notes/SKILL.md`。用户已 @ 也照样跑完整规程，不跳过预检、自检或链接核验。

**一句话判据**：产出物是要发布／贴商品页／发给买家的文字 → 本技能；产出物是课堂用的文档（教案、逐字稿、学习单） → 别的技能。

### 2.2 路由

| 用户怎么说 | 走哪条 | 出稿前必做 |
|---|---|---|
| 「写文案」「写个笔记」「写小红书」「种草文案／帖」「推广帖」「备课笔记」「发帖」 | 先按 4.1 选 M1—M6 之一，再按 [去同构](references/anti-repetition.md) 换形态内槽位；点明「短一点／总述」→ 变体 A | 有对标先拆解（先看有无数据）；四位置合规扫描；有历史稿时查近篇开头、判断与收束 |
| 「带班号／避坑／课堂实录风／翻车现场／账号B」 | 变体 G1 | 回查学情预设与支架梯子，第一人称防翻车视角 |
| 「新手／救急／保姆级／40分钟怎么上／账号C」 | 变体 G2 | 回查环节耗时与 3 个核心设问 |
| 「公开课文案／名师视角／评课／眼位／账号D」 | 变体 G3 | 提炼核心教学思想与 3 个高阶眼位 |
| 「视觉／审美风／板书赏析／账号E」 | 变体 G4 | 提取课件视觉意象与板书动线 |
| 「商品介绍」「商品详情页」「详情文案」 | 变体 E（固定标题＋■落点＋交易条款，零标签） | 回查教学设计／产品清单核落点，零虚构 |
| 「发货文案」「自动发货」「领取说明」 | 变体 F（付款后纯文本指引） | 先核真实交付物与本课已可用链接；需建链、同步、回填按授权和 [履约规程](references/fulfillment.md) 处理。缺项不交带占位符的成稿 |
| 「注意脱敏」「隐去敏感信息」 | 叠加在命中的形态上，按 7.4 五层清单处理 | 词面风险扫描＋信息层残留扫描并列 |
| 「拆解这篇对标／爆款」「照这个格式写」「把这篇融进去」 | 第三节拆解流程 → 出改良稿 | 归档走飞书表与 IMA 知识库，本地不留副本 |
| 家长会／期中家长会 PPT 图集 | 变体 C | 正文极短、价值在配图，按页序模型 |

### 2.3 组合请求

**组合请求并列处理**：一次要「商品介绍文案和发货文案」时，文案与链接解耦。**无交付文件时**：变体 E 依教学设计正常产出；变体 F 坚决阻断，明确告知「尚无交付文件，为保障履约真实性已暂停生成发货文案，请提供文件或现成分享链接后再生」，绝不输出空链接或占位符。文件齐备则先出 E 再跑 F。

### 2.4 规则自我闭合（A 类）

**判据：任何一步走不通时，出口不能是「请用户去核实某条文案的具体成分」。** 如果规则在某处停下等你查资料，说明那条规则没写完。

三种缺口，三种自洽处理：

| 缺口 | 处理 | 例 |
|---|---|---|
| **内部决策**（选哪个形态／变体／要不要扫描） | 直接按规则判定执行 | 不指定用 M 几，按 4.1 三条理由自选 |
| **外部事实不明**（单元号、版次、真实页数、交付项） | **规则内降级**：换一种不依赖该事实的写法，或输出待核标记，**照常出完整稿** | 未拿到教材目录 → 本稿不用「第 N 单元」这类定位元素，换其余四类；页数未知 → 不写页数，不编 |
| **能力缺失**（封面撑不住、网盘取不到链、无交付文件） | 退回不依赖该能力的通道，具体退法按对应章节 | 封面只有课件截图 → 见 4.2；无交付文件 → 见 2.3 |

**唯一允许反问用户的三类**：课题／产品清单不明、账号级授权、非语文课件领域。同一缺口只问一次。

**为什么定成硬约束**：让用户去搜一个标签、翻一次教材，等于把规则的不完整转嫁给执行者；下一篇换一课，同样的坑还得再问一次。**规则通用性的标准就是——给任意一课，它自己能跑完。**

### 2.5 边界

正式教案／逐字稿／学习单等课堂内容创作不适用（走 `lesson-transcript`、`lesson-typeset`）；本技能只产出对外发布的文字，不改课件、不落盘成文件。站外链接只在变体 F 出现。**写文案是本技能的独立能力**，全程自给自足；唯一外部环节是变体 F 的网盘取链，属分工而非依赖，也不得因某外部能力不可用而停写本可独立完成的文案。

## 三、写作规程

### 3.1 标题（A 类，全文唯一权威定义）

**三条硬规**：

1. **≤20 字符**：汉字、字母、标点、空格、emoji 各算 1 字符。超限会被截断或报红，判定阻断，严禁流出。
2. **课题（篇名）必写**：凡对外标题（M1—M6／A／B／C／D／E／G1~G4／商品货架标题）必须出现课题，任何档位都不能只靠正文／标签交代。课题优先保全称，仅当全称已逼近 20 字时才用可辨识短称。**年级册次、立意、emoji、品类、课时数一律是辅助信息**，放不下依次退场，绝不允许反过来挤掉课题。变体 F 无标题，是唯一例外。
3. **容器分离**：标题框与正文框分开交付（见 8.1）。

**辅助信息让位四步**（不互斥，课题不动）：① 删立意／反差／网感 emoji → ② 压品类／课时字段（「完整课件」→「课件」、删「· 2课时」）→ ③ `四年级上册` 压成 `四上` → ④ 年级册次整个让出，只留课题，让出的信息移到正文首句与标签。四步都是常规压缩，不是例外。

**验收输出**：`标题字符数：N/20` ＋ `课题：✅` ＋ `年级册次：✅（全称／合法缩写／已让位）`。课题缺失直接判失败。

**双轨分流：笔记标题与货架标题不混用**

| 体裁 | 格式 | 示例 |
|---|---|---|
| 商品详情页（变体 E） | `{年级}{册次}《{篇名}》完整课件 · {课时数}` | `四年级上册《颐和园》完整课件 · 2课时`（20 字） |
| 信息流笔记（M1—M6）／矩阵号 | `{年级}{册次}《{篇名}》{一个定位元素}`，**默认平实写法** | `四上《陀螺》一课时课件`（11 字） |

信息流标题**严禁整串「完整课件·X课时」货架公式**（机器感重、劝退），也**不塞课时总数**（「2课时」属技术参数）。**「第一课时」「单课时」不是课时总数，是课型定位**，可进标题——分课时发两篇时靠它区分，否则两篇标题会撞。「搜索段｜钩子段」双段式（`四上《古诗三首》课件｜难的不是背诵`）**为可选、非默认**——同课题组内钩子型垫底（9／11 赞）vs 平实型（67／29／28 赞），全组最高三条皆平实场景型（345／316／586 赞）。方向可靠、量级不可靠；钩子里写教学技术细节比写场景更难被非本课老师读懂，默认不写技术细节。

**定位元素五类，每篇换一类**（C 类自由区）：① 交付定位（备课干货／完整备课／备课思路）② 课型定位（略读课文／第一课时／单课时／公开课）③ 内容抓手（批注只写关键词）④ 单元／教材位置（第 N 单元／新教材，**目录原文在手才用**；未拿到就本稿不出现该元素，换其余四类，按 2.4 降级、不询问用户）⑤ 平实直陈（只写课题＋学段）。**不指定具体词**：交付词在 21 条样本里 81% 出现，但同结构 4 条 0/4 用「课件」，N 不足不定硬词。

> `references/examples.md` 里的标题是真实定稿，只作语气与结构参考；换课文时按本节三条重写，不照抄字面。

### 3.2 拆解对标帖（用户提供时）

按六块法逐块记录，产出是**机制，不是模板**：

| # | 块 | 记录什么 |
|---|---|---|
| 1 | 标题 | 课题位置、定位元素类型、字符数 |
| 2 | 定调句 | 一句话给课文定性（10—13 字，带一个质感形容词）；若融入标题则正文可省 |
| 3 | 痛点段 | ① 同行误区＋后果 ② 学生表现＋推回文本。**位置随形态走**（见第四节） |
| 4 | 交付说明 | 交付物并成一句叙述，格式和可编辑范围以成品与权限为准 |
| 5 | 要点清单 | `■` 起行，按教案推进顺序，条数＝本课教学点数 |
| 6 | 备课小想法 | 💫 标记，可选；写成「这份资料里怎么做」 |
| — | 声明块 | **已整块废除**：正文收尾不放任何声明（不写配图来源、不写「仅供教学交流」、不写「原创整理」）。平台要求的 AI 标注按发布界面处理 |

**两个动作**：

1. **先标数据**：赞／藏／评／粉丝数，没给就写「未提供」。**没有数据的样本只能提供「写法可能性」，不能提供「写法优劣」**——可进选项池，不能进标准。跨账号、跨课题的数据不可直接比较（同课题内 3 行报货 345 赞 vs 六条清单 316 赞；跨课题白鹭组均值 415 vs 第一场雪组 37，差异主要来自课题本身）。
2. **只提炼机制，不提炼块序**：机制是有作用、可验证的东西（标题含课文名保搜索、零免责避营销号判定、首屏写人话保留存）；块序是外形，抄外形就抄出同一篇。**严禁把某条样本的块序写成「骨架公式」套到别的课题**。

对标缺块时指出信息是否由封面、正文其他位置或商品页承担。仅分析时交分析结论；有明确适用的归档授权时走 [持续迭代](references/iteration.md)，本地不另存文字稿。

### 3.3 `■` 要点写法（教学点密集的形态用）

**公式**：动词起句 ＋ 教什么 ＋ 具体方法或课文原词 ＋ 看出什么／落到哪。

- ✅`依托学习单梳理完整心情变化曲线，结合原文语句，读懂从懊恼、期待，到沮丧、惊喜、自豪的起伏`
- ✅`品读斗陀螺片段，抓住大小陀螺的攻防动词对比，体会「摇头晃脑」碰上「不动声色」的反转`
- 起句动词库（取自对标原文）：落实／夯实／教给／依托／借助／品读／梳理／对比赏析／深挖／联读／联系／搭建／读写迁移。
- **禁①只有观点没有内容**（`不靠老师讲`、`不讲道理`）——观点谁都能说，买家看不出资料里有什么。
- **禁②教师操作细节**（分钟数、巡视、范写、追问原话、评语）。
- **教学动作是允许的**（落实、品读、依托、联读、搭建、读写迁移），**教师琐碎操作不允许**，两者不是一回事，别一起删。
- **课文原词是硬证据**：对标 19/21 篇正文含课文原词，每条最好带 1 处原词、方法名或结构串。
- 每条 35—55 字；按教案环节顺序排，不按「字词→方法→品读→迁移」固定六类排（那只是常见顺序，不是要求）；不分课时段、不用 `▪️` 课时块。

**条数由本课决定，不由模板决定**：条数＝本课真实教学点数，通常 4—7 条（略读 1 课时多落 4—5 条，精读 2 课时常见 6—7 条）。

**四道凑数判据，命中任一即改**：① 两条讲同一件事 → 合并；② 一条换别的课文照样成立 → 删；③ 只有动作、没有「教什么／得到什么」 → 补内容或删；④ 把「字词」拆成读音、字形两条 → 合回一条。

**宁可少，不可编**：教学点不足时写 3—4 条，并在交付说明写「本课教学点集中，未凑条」。绝不为凑数补一条教案里没有的要点。

替换测试（用于要点与首屏）：把课文名换成别的课文仍成立 ＝ 通用空话，重写（反面：`五步脉络不靠老师讲`）。反过来，给一位没备过这一课的老师看能照着上 ＝ 信息够（正面：`依托学习单梳理完整心情变化曲线…`）。

### 3.4 句式与符号（C 类自由，但有边界）

- **判断句起头，一句一个取舍**（「不做什么」「只留什么」「先…再…」「留给口头」）；顺序需要压缩时用箭头「→」；两档都不写分钟数。**避免以操作动词（圈、填、读、出示、巡视）起句**。
- **💫 备课小想法可选 1 条**，全是减法／取舍，用判断式短句（「过渡句不讲定义。」）；须写成「这份资料里怎么做」，不停在纯主张。
- **引号只引课文原词或单元要素词**（「伟大的奇迹」「承上启下」）。
- **图标只用三类**：要点行 `■` 或 `▪`（**任选一套、全篇不混用**，对标四条用 `▪`）、`💫` 备课想法（可选，不强行）、1 个主题 emoji 起一句。
- **禁两类图标用法**：① 用 emoji 方框包住交付清单做清单行（`[星R][星R]（课件、教案…）[星R][星R]`）——0/21 出现；② `▪️` 做课时块。承接句本身要留，写「X 课时完整教学设计核心要点👇」，不加 📖 前缀。
- **可写课件配色**（非必选，零成本差异化）：一句写清主色与质感，须与实际课件一致，不编色名。
- **给一个明确去处**（非必选）：正文或末图点明「课件预览在图中／成交走左下角组件」；**只写平台内去处**。

## 四、形态库（六种平等形态，无主骨架）

### 4.1 选型规则（本节最高优先）

**选型只看这一篇：本课素材有什么、这一篇的读者需要什么。历史做什么形态，不参与选型。**

每篇动笔前写一句「本篇用 M?，因为……」，理由只许三条：本课教学点密度（密集 → M1／M2）、本课有没有一个反常识取舍（有 → M3）、这一篇想让第一屏承担什么（报规格 → M6；极简 → M4／M5，前提是封面首图是教学内容页）。

**不设「近 N 篇不得重复形态」这一条（2026-11-16 修）**。原规则要求近 4 篇不重复形态、每 5 篇至少 1 篇短形态，实际会卡死：近四篇用过 M1／M2／M3／M6，剩下的 M4／M5 都以「封面能独立说明教学内容」为前提，封面不满足就无稿可写——**一条规则把所有出口都堵上，它就不是规则，是死锁。**

**去同构在选型后做**：有同账号历史时比对近 4 篇的首句、核心判断和收束，用本课实际材料改掉重复。没有历史就按当前材料写，自检仅说明无法比对。查法见 [去同构](references/anti-repetition.md)。

> **一句话分清**：形态是「这篇用哪种信息结构」，去重是「这篇读起来像不像上一篇」。前者看素材，后者看文字。把去重压到形态上，就会出现「明明这一课最适合 M1，却因为上篇用过 M1 而被迫换一个不合适的」——那才是真的写不好。

### 4.2 六型对照

| 形态 | 第一屏写什么 | 中段 | 依据（各自有出处，不互相否决） |
|---|---|---|---|
| **M1 卡点型** | 同行误区／学生卡在哪 | 4—7 条内容要点 | 1-1~1-4 痛点段（无数据）、景之 316 赞 |
| **M2 骨架型** | 这一课怎么走，几步走完 | 每步一句，挂课后题／习作 | 景之 316 赞（四任务） |
| **M3 单点型** | 一个取舍的处境 | 只讲这一点、讲透、不分条 | 无对标，自创形态，待验证 |
| **M4 直给型** | 共几页＋怎么拿 | 无，3 行结束 | 张主任 345 赞（同课题最高） |
| **M5 极简型** | 一句最硬的取舍＋获取方式 | 无 | 小苏 67 赞（正文 0 字） |
| **M6 清单型** | 学段＋课号＋课题＋交付类型一句开头 | 痛点两行 → 承接句 → 4—7 条要点（**种草笔记一律不写【内容包含】报货块**，避免平台限流） | 1-1~1-4 同结构四条（同账号、无数据）；首句另有 4-3（29 赞）、2-2 |

**六种平等，没有主形态。** M6 是一个真实账号的成熟写法，与其余五型地位相同，只是它不能是默认。

**M4／M5 的前提：封面首图是教学内容页**（结构图、板书、核心问题、学习单页之一），不是纯课题页。短形态的全部信息都在图上，图撑不住就是空帖子。

已有课件截图要在实际手机预览大小看得清主要材料或学习任务。找不到符合条件的首图时，选能靠正文说清的形态。

### 4.3 首屏写法：由形态定义

1. **形态内一致**：选了 M1 却第一行报货 ＝ 自相矛盾，判失败；**种草笔记（M1—M6）一律不写【内容包含】报货块**（2026-11-16 用户定，避免平台限流），首屏与正文均不得出现，删掉不算形态缺失。首屏必须对得上声明的形态。
2. **替换测试（M1／M2／M3 适用）**：前 3 行换掉课文名仍成立 ＝ 空话，须重写（「这套资料老师必备」换哪课都对）。
3. **规格句带实数**：课件几页就写几页，正文、封面叠字、商品页三处必须一致；交付物按实际清单写全，不虚标不缩水。数字对不上比不写数字更伤信任。
4. **禁两类已被证否的写法**（0/21 出现）：正文里的 emoji 清单行、免责长声明。这是负面共性，不是风格偏好。
5. **M4／M5 不适用第 2 条**——它们首屏本就是规格性质，代价是封面必须独立呈现教学内容。M6 首屏为课题句、清单移至末尾，靠要点清单兜底，不强制封面。

> 首屏该写什么属**形态差异**，不是优劣差异：M1—M3 写处境，M4—M6 写规格，各有真实样本撑着。曾把「前 2 行必须人话」定为 A 类，结果把 345 赞的写法判成违规、逼出「豁免条款」——豁免本身就是在让优秀样本互相否决，已撤下。

```
这篇课文真正的门道，藏在【具体对比/关键语句/历史背景】里。

备课脉络
【落实哪部分字词与背景铺垫，攻克哪些读音或难句】。
→ 【核心思辨：抓住哪处对比／关键语句，读懂为什么】。
→ 【诵读或练笔收束：怎么把体会落回语文实践】。

💫一点教学心得
【一条减法：不讲成冗长历史课/不生硬拔高】。
【一条取舍：抓住核心意象与比喻，把时间留给学生思辨交流】。

#小学语文 #【年级】语文 #教学设计 #【篇名】 #语文老师 #公开课 #备课 #阅读教学
```

**变体 A 总述式短帖**（常规课文快速转化；红色题材禁用，须走上一节）：

```
【主题emoji】《【篇名】》教案整理好了，按【单课时／2课时】教学思路设计。
从【情境/导入方式】进入，依次安排识字写字、整体感知、精读品读、读写迁移。
重点带学生理清【结构】，沿【两条线/几个方面】走，品味【关键词语/写法】，读懂为什么是【课文结论词】，完成【表达训练】。

【可选：痛点两行，同 M1 写法】

含【按采用成品填写交付物与课件形态】。

【可选：💫一句备课想法，写成「这份资料里怎么做」】

#标签（第五节双层法）
```

四句分工固定：总述（教案整理好了，按课时思路设计）→ 内容句（教什么、怎么教）→ 重点句（重点读懂什么、靠什么带）→ 落点句（落到哪个语文实践）。四句都写内容要点，不写纯观点，也不写琐碎操作。

**变体 E 商品详情页**（不是笔记）：带价格、立即购买、发货方式的商品详情页。**七块顺序固定，可整段照抄**，正文零标签，全篇只承载四件事——买什么、懂不懂这一课、能改什么、怎么发货。**标题只填一次**：有独立商品标题字段时单列标题，详情直接进内容；只有一个输入框时把商品名放首行。见 8.1。

```
【商品标题字段】四年级上册《【篇名】》完整课件 · 【1课时／2课时】

【商品详情正文】
【内容包含：【单课时／分 2 课时】，【课件形态】＋完整教案＋【逐字稿／2 课时逐字演讲稿】＋学习清单＋制作笔记】

很多老师上这一课，容易停在「【读者最可能的偏解】」上，忽略【真正的方法／落点】，【学生最可能的卡点】。

【单课时／2 课时】完整教学设计核心要点 👇

■落实【哪部分】教学，重点攻克【读音词语／易错字】，认读【N 个生字】，【正音或辨析】
■教给【方法名】，【几个角度或几步】，落实【哪项课后任务】
■依托【学习单哪一栏】梳理【什么】，读懂【从…到…的变化／几层意思】
■品读【哪一片段】，抓住【什么对比或写法】，体会【哪一处反转／表达效果】
■联系【课文哪处】，读懂【课文结论句／古话】，引导联系生活谈感悟，不空洞说教
■读写迁移，借鉴【课文哪种写法】，练习写【什么片段】，对接【习作／阅读链接】

注：

1、【实际可编辑范围一句】

2、【实际领取方式与本商品已确认的售后条款】

发货方式：【实际发货通道】
```

> **详情页有两个事实源，不能混（A 类）**：
>
> | 写什么 | 只能从哪取 | 不能从哪取 |
> |---|---|---|
> | 教学卖点（痛点、要点、学情描述） | 教学设计定稿确认版 | 记忆、别的课、推测 |
> | **交付承诺（格式、页数、可编辑范围、领取方式、件数）** | **本课已确认的交付清单＋实物核对** | **教案、模板旧例、别课的交付物** |
>
> 这两个源一旦混用，就出现「文案说可编辑 pptx，实际发的是可画链接」这类纠纷。

**交付承诺逐项核（变体 E 必做，四项都不能套默认值）**

| 项目 | 怎么核 | 常见填法 |
|---|---|---|
| **课件形态** | 看这次实际交的是什么，不预设默认 | `可画设计链接`／`可编辑 pptx`／两者都有就都写；形态取自制作阶段已采用的成果 |
| **可编辑范围** | 用交付给买家的访问方式核权限，并实测能编辑的对象 | 分开写可查看、可另存或可编辑；文字、配图、底图或配色只写核实过的范围 |
| **页数** | 一律不写（2026-11-16 用户约定）；不因对标样本带页数而补写 | — |
| **领取方式** | 看这次实际怎么发 | `网盘（无码）`／`网盘（带码）`／`可画链接直接分享`／两者都有时写「网盘＋设计链接」 |

写法要点：① 承接句末留一个 👇，不叠 emoji；② 零人称零感叹号；③ 每条要点是教学内容不是空观点，可带生字数、正音字、原词等可核对信息；④ 条数＝本课教学点数，不切成课时、不强凑六类全齐；⑤ **课件形态按实际写**（可画链接／pptx），按核实结果说明可编辑对象；缺证据的动效不写；⑥ 注 1 只写**实际可编辑范围**一句话，不写 AI 披露、不写「仅供教学交流」、不写「全部为本人原创」（商品权属与成品另按实物核实）；⑦ 注 2 虚拟商品条款必写（实际领取方式、已确认的售后条款），**领取方式按实际填、不固定写「网盘链接＋提取码」**；发货方式单列一行，按实际通道填；⑧ 落点 100% 来源于教学设计。

> **为什么详情页用清单、笔记里却按形态分**：详情页读者已点进来、已具购买意向，要的是「你到底交了哪些东西」的逐项清单；信息流读者还没决定要不要看，M1—M3 先给处境，M6 先报规格。三种读者状态、三种形状，不是口径不统一。

**变体 F 付款后发货文案**：买家付款后使用，说明所购资源、领取方式和售后。先核已有链接及采用版，按实际约定渠道写纯文本。六段模板、权限和核验步骤见 [履约与网盘规程](references/fulfillment.md)。这是站外网盘链接的发货入口。

**分课时发**：承接句换成「X 课时教学设计核心要点👇」，只写本课时 `■` 要点（本课时有几个点写几个，3—4 条只是常见量），💫 想法只写本课时相关的 1 条。**标题里的课时口径按 3.1：「第一课时／单课时」属课型定位可写，「共2课时」属技术参数不写。**

**多账号矩阵（变体 G1—G4）**：为避平台判定同质化批量搬运而设的 5 套隔离人设，账号级分流，**不得在同一账号按篇轮转**——同构伤推荐，人格分裂伤成交。同账号连续出稿时人格、人称、文风一律不变，变的是形态级（M1—M6 轮换）与形态内槽位级（定位词／第一句／切法／收束／符号／封面，连续 3 篇不得 3 个槽位同选）。各账号范式里的 `【篇名】` 是占位符，替换后须重跑 3.1 校验。

- **G1 一线带班手记／避坑实录（账号 B）**：有实授记录时，写可核对的课堂偏离及如何拉回；只有教案时，写备课预判、判断依据与设计支架。第一人称可用于实际做过的备课和有记录的授课，详见 [矩阵规范](references/account-matrix.md)。
- **G2 新手保姆救急包（账号 C）**：`四上《【篇名】》保姆级备课指引｜40分钟怎么安排？`；40 分钟节奏卡片 → 3 个必须问出声的核心设问 → 防冷场支架 → 资源全包定心丸＋标签。极短句、高量化。
- **G3 公开课亮点拆解（账号 D）**：`四上《【篇名】》眼位不在【类型】｜这课在第三层`；传统两层教法局限 → 三个高阶眼位 → 教学哲理收束＋标签。评课名师视角。
- **G4 美育课件／板书赏析（账号 E）**：`四上《【篇名】》极简课件与板书设计`；极简审美发声 → 视觉设计思考 → 课堂逻辑动线（图1–3整体／图4–7精读／图8–9板书）→ 留白收束＋标签。文字极度精炼。

**变体 B／C／D**：B1 成果展示（共识反转＋证据密度页码）、B2 难点诊断（共同恐惧＋精准归因＋可执行动作）；C 家长会课件（正文 3—5 行，价值在 PPT 实拍图集，走封面场景＋焦虑页＋能力页页序）；D 互动／游戏化课件（课堂原话痛点＋第二人称代入＋双数字量化＋交付承诺四段式）。详见 [特殊变体](references/special-variants.md)。

## 五、标签（双层法）

| 层 | 作用 | 个数 | 怎么写 |
|---|---|---|---|
| **精确层（课文名系）** | 接**搜索**，老师搜的就是课文名，越细越能撞长尾 | **4—6** | 同一课文名**允许反复出现**，组合不同即可——它们不是重复，是六个不同搜索入口 |
| **大类层** | 进**大流量池**，让不搜本课的人也刷到 | **4—6** | 学科／学段／课型／交付词 |
| 合计 | — | **10** | 样本众数（19 条有标签样本中 13 条正好 10 个） |

**精确层六种组合轴**（以《陀螺》为例）：裸篇名 `#陀螺`（20/21 有，**必含**）／篇名＋交付 `#陀螺课件` `#陀螺教学设计`／篇名＋课型 `#陀螺公开课`／册次＋篇名 `#四上陀螺`／版本学段＋篇名 `#统编版陀螺`／篇名＋课时或册次课型组合 `#四上语文陀螺课件`。

**生成算法（对任意一篇课文同一套，不需要任何外部核实）**：

1. 取篇名，剥掉书名号与课题编号，得到**原子词 A**（《陀螺》→ 陀螺；《蟋蟀的住宅》→ 蟋蟀的住宅）。
2. **按原子词长度分三档**——不分档就会出现「#延安，我把你追寻教学设计」这种 12 字废标签：

| 档 | 原子词 | 精确层怎么写 |
|---|---|---|
| **短（≤4 字）** | 篇名即原子词 | 六轴全可用，取 4—6 个 |
| **中（5—6 字）** | 篇名即原子词 | 只取含篇名的最短组合（裸 A／A+课件／册次+A／版本+A），取 4 个，不加长尾 |
| **长（≥7 字或含标点）** | 篇名剥标点、去虚词后的**核心词**（《延安，我把你追寻》→ 延安；《为中华之崛起而读书》→ 中华崛起） | 核心词走轴取 3—4 个，**加 1 个篇名全称去标点**（`#延安我把你追寻`），全称是搜全名的人唯一的入口 |

3. 从候选里取 4—6 个，**必含裸原子词**。
4. **合集类篇名另走一条**（《古诗三首》《文言文二则》《寓言二则》这类含「N 首／则」的）：合集名走轴取 2—3 个（裸合集名／合集名+课件／册次+合集名），**分篇名各占 1 个**——老师常搜单篇（搜「凉州词」的人不会搜「古诗三首」）。分篇名以在手教材为准，拿不到就只用合集名轴，按 2.4 降级。
5. 大类层从池中取 4—6 个，至少 1 个全书通用大类；**精确层不足 5 个时，大类层补到 6 个**，保证合计恒为 10（中档 4＋6，其余 5＋5）。
6. 逐个自检：**短／中档含完整原子词原样字串；长档含核心词，且全称那一个不得省略**；组合轴互不相同（同轴换词不算新入口）。

**为什么这一步不需要用户去搜**：标签是自由输入，平台不做话题白名单校验——输入一个尚无同名话题的词，它照样作为该词被索引、被搜索命中。所以精确层的功能是**覆盖搜索词**，不是**抢占某个话题页**。「有没有同名话题」是加分项（命中了多一层曝光），不是前提。

**生造词的界定**：禁的是**没有对应搜索意图的概念词**（如给单课标 `#大单元任务群`、给通用课标 `#ppt定制`），不是「自己组合的篇名词」——后者正是精确层的产出方式。篇名不得拆词、不插空格、不换字（《蟋蟀的住宅》不能写成 `#蟋蟀住宅`，那是另一个词）。

**大类层常用池**（按学段替换）：`#小学语文` `#语文课件` `#教师备课` `#备课` `#公开课` `#ppt` `#教案` `#语文教学设计` `#四年级语文` `#小学语文备课` `#语文老师`

**禁止仅四类**（其余不设限）：引流标签（`#发文档领流量`／`#评论区领取`／`#私信领取`，平台重点打击，教师号用了直接显营销号）、虚标（`#大单元任务群` 用于单课）、接单（`#ppt定制`）、无搜索意图的概念词。

> 依据：586 赞用 4 个课文名系、316 赞用 4 个、Coco 藏率最高那条 9 个；反证是小苏 67 赞那条 10 个全是泛词、零课文名，评论区 22 条「求课件」，搜索需求全落空。

## 六、语言规范

**必须**

- **全篇零人称**：不写「我」，也不称呼读者（不用「姐妹」「家长们」）。变体 B／G1 依人设可克制使用第一人称。
- 段落以陈述句为主，每句只讲一件事。
- **按正文需要使用核实过的课文原词／教材要素**（「皲裂的手指」「呢喃细语」「关注主要人物和事件」）：同类样本 90% 具备，可作内容依据或搜索词；实授经历须另有真实记录或用户确认。
- 各逻辑模块之间空一行；代码块内一律纯裸文本。
- **正文不写配图来源披露**（AI 绘或手绘都不写）：有 AI 生成图时在发布界面勾选「内容由 AI 生成」，不写进文案。

**禁止**

- 感叹号连用、导流型互动与召唤（「需要的扣 1」／私信／看主页／加V）、表情堆叠。同行讨论式提问属例外（「你们班批注一般写几条？」），仅该句允许第二人称，限常规课题、不得导流或承诺，红色题材仍全禁。
- 极限词（最／第一／唯一／天花板）、夸张词（震撼／封神／绝了）。
- 假大空大词（赋能／沉浸式／激荡出思维火花）、机械八股连词（显而易见／总而言之／值得注意的是）。
- 做作浮夸拟态（春风化雨的微笑／求知的光芒）、不相干提示性括注（根据学情调整）。
- 技术参数：分钟数、页码数、动画个数，以及**课件总页数（一律不写，含正文与封面叠字；对标样本标页数不作为本账号依据）**。**例外**：变体 B1 允许课文证据页码（「第 X 页」，不是课件页数）。
- 清单里写产品实际没有的交付项（虚标「板书设计」「微课」「放映动态」）。
- 结尾效果承诺与行动召唤（「直接打印上课」「解放备课时间」「来啦」）；`#ppt定制` 接单信号；成交只走左下角官方组件。

## 七、合规门禁（出稿必检，不检不交付）

### 7.1 四位置全覆盖扫描

标题各备选、正文全文、标签逐个、配图内页字画面。

### 7.2 门禁 -1｜教材版次标记（P0，先于一切优化）

**对任意课文同一套动作**：稿子末尾固定附一行 `教材依据：{版本}{年级}{册次}第{N}课《{篇名}》`，并在交付说明里标「篇目按此版本，若在用教材版本不同请告知，我再调整」。这是通用机制，不是某一课的额外要求。

- **不阻塞出稿**：版本拿不到时照常出完整稿，只在这行标「版本待确认」，不默认通过，也不需要停下来等。
- **发现冲突则归零**：已知《古诗三首》存在两套篇目口径（旧组《出塞》／《凉州词》／《夏日绝句》；2026 秋新版组《暮江吟》／《题西林壁》／《雪梅》）。这类篇目本身有版本分歧的课文，动笔前先按 2.4 处理；篇目不符时任何优化都无意义。

### 7.3 门禁 0｜物理规格强拦截（P0，超限判失败）

① 显式输出 `标题字符数：N/20`，严格 ≤20（见 3.1）；② 标题框与正文框物理分离，禁止单代码块混排；③ 显式输出 `课题：✅` 与 `年级册次：✅`，缺课题判失败。

### 7.4 脱敏五层清单

（逐层核对，零残留）

| 层 | 必删／必改 | 安全写法 |
|---|---|---|
| 1 未成年人 | 学生真实姓名、学校全称、班级号、校服校徽／班级牌、正面清晰人脸、成绩与评语、固定作息与上下学路线 | 只写「学生」「同桌」「班里」；配图只用课件方法页，不放课堂实拍 |
| 2 证件与标识 | 条形码、二维码、编号、微信号、手机号、店铺水印 | 裁掉或打码；**含二维码的图一律不用**（按隐性导流处理） |
| 3 教师与机构 | 教师真实姓名、任教班级、学校名称、地区定位、发布时开启的地理位置 | 零人称本就天然规避；发布前关闭定位 |
| 4 交易与内部数据 | 网盘链接／提取码／fid／fsid、价格、销量、成交数、内部文件路径、文件大小 | 只在变体 F 通道出现；笔记、详情页与发货文案一律不写课件页数 |
| 5 时政与人物 | 人物姓名与职务、讲话原文长句、会见场合／国别／时间、以领导人语句做话题标签 | 用「课题这句话」「课文里的一个例子」等中性指代；**教材篇名作标题不等于违规，保留** |

**排查重点权重**：① 营销推广与接单链路（首要阻断）——`#ppt定制` 等接单标签、「直接打印上课」等效果承诺、正文引导私信／看主页／加V；② 常规违禁词——极限词／虚假承诺／站外导流；③ 敏感信息与信息层残留——按 7.4 彻底匿名化。

**两套扫描并列**：词面合规扫描 ＋ 信息层残留扫描，结果随稿给出，零残留方可交付。完整清单见 [规则与出稿自检清单](references/rule-selfcheck.md)、[合规自检与脱敏清单](references/compliance.md)。

## 八、交付

### 8.1 双容器物理隔离

信息流用独立的「小红书标题框」和「小红书正文框」，正文含平台话题标签。变体 E 按实际上架界面交付：有独立商品标题字段时单列商品标题，详情直接从实际内容写起；只有一个输入框时在首行放商品名。两种填法都保证商品名只出现一次，详情零标签。变体 F 无标题，只交一个纯文本复制块。

### 8.2 封面 brief（随稿附，只给文字与形态，不生成图片）

**素材现状**：封面与配图用课件页截图（PPT 页），常再加一张逐字稿预览。按这个前提写 brief：

| 项 | 要求 |
|---|---|
| 首图 | **必须是教学内容页**——结构图／板书／核心问题／学习单页之一，不能只是课题页（首图是课题页就调页序，不用换形态） |
| 帧数 | 3—6 张，够看清一课教什么即可；**禁九宫格缩略图预览墙**，缩略后谁也看不清 |
| 第二张起 | 可放逐字稿预览（证明有这份交付）；它字密，**只作补充，不占首图** |
| 主文案 | ≤12 字，与标题不重复，可以是一句教学判断 |
| 叠字 | 带交付项；不写课件页数 |
| 禁忌 | 满屏卖点字、全部笔记同一套版式、把「可编辑」「原创」做成封面主视觉 |

**为什么首图必须上内容页**：刷到封面的人只花 1 秒判断「这跟我这课有关吗」。课题页只回答「是哪一课」，内容页回答「你能给我什么」——后者才让人点进来。这也是 M4／M5 敢用短正文的唯一理由（见 4.2）。

### 8.3 裸文本

代码块**里面**的稿子不带任何 Markdown 标记——不加 `**`、不用 `#` 做层级、不用 `-`／`*` 项目符号、不加 `>`、不夹 `---`。发布框、私信框、自动发货框都不渲染语法。要列表只用数字编号（`1.` `2.`）；要强调靠短句、位置和 emoji 前置；`■`「📌」「💚」属纯文本符号，可正常用。

### 8.4 移动端间距

模块之间单次空行；模块内部紧凑，严禁行行空行把内容拉长到 3—4 屏。

## 十、持续迭代

支持用户提供多篇新对标帖或爆款文案，走「拆解 → 逐条收录优秀点（并集，不取交集）→ 出改良稿 → 列拟固化条目 → 用户确认 → 固化进 skill」的循环。

**融合第一原则**：只要是一个优秀点就收录进手法池，标注来源与适用条件，**不得因它与其他优秀样本冲突、或样本量不足就否决**。冲突按形态分配，无数据进备选层，只有平台合规风险一票否决。

**固化时的硬要求**：新规则先写进 [规则总账](references/rule-index.md) 并入 1.1 的 A/B/C 分级，再在正文找它唯一的家；正文已有同类规则就**改写那一条**，不另起一段。同一件事在手册里出现两次完整表述即为规则缺陷，与篇幅无关。

**通用性验收（改规则后必做）**：拿 4 篇类型不同的课文各跑一遍，能跑通才算规则——① 短篇名（≤4 字，如《陀螺》）② 中篇名（5—6 字，如《蟋蟀的住宅》）③ 长篇名或含标点（如《为中华之崛起而读书》）④ 合集（如《古诗三首》）。任一篇跑不通，说明规则绑定了特定课文，回去改规则而不是改例子。

> 这条验收来自实测：标签算法最初没有分档，跑到长篇名时产出了 `#延安，我把你追寻教学设计`（12 字、带逗号）这种废标签；加上分档后又发现中档只有 4 个精确层、凑不满 10。**两个漏洞都不是想出来的，是跑出来的。**
