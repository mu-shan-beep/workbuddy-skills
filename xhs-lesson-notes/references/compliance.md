# 小红书文案合规自检与五层脱敏清单

> 唯一归属：四位置合规扫描（标题/正文/标签/配图）及五层脱敏清单（未成年人/证件/教师机构/交易数据/时政）。

## 八、合规自检清单

### 脱敏规则（2026-11-11 定，强制，全形态适用）

> 用户说「注意脱敏」，或涉及课堂实拍／学生信息／课件内页截图时，本规则与第 4 步「出稿必检」**同时执行**，结果随稿给出。法规部分只作方向性判断，**以最新法规及平台规则为准，不作法律定论**。

**定义**：脱敏＝把可识别到具体个人、机构、账号、交易的信息，从文案与配图里移除或改成中性指代。按《个人信息保护法》口径，加密／打码属**去标识化**，处理后的信息仍是个人信息；只有**匿名化**（无法识别且不能复原）才不算个人信息。所以**打码不是免死金牌**——能删就删、能不拍就不拍，打码是最后一道。

**五层清单（逐层扫，缺一层不算做完）**

| 层 | 必删／必改 | 安全写法 |
|---|---|---|
| 1 未成年人 | 学生真实姓名、学校全称、班级号、校服校徽／班级牌、正面清晰人脸、成绩与评语、固定作息与上下学路线 | 只写「学生」「同桌」「班里」；配图只用课件方法页，不放课堂实拍 |
| 2 证件与标识 | 准考证／学生证／获奖证书上的条形码、二维码、编号；二维码、微信号、手机号、店铺水印 | 裁掉或打码；**含二维码的图一律不用**（平台按隐性导流处理） |
| 3 教师与机构 | 教师真实姓名、任教班级、学校名称、地区定位、发布时开启的地理位置 | 零人称本就天然规避；发布前关闭定位 |
| 4 交易与内部数据 | 网盘链接／提取码／fid／fsid、价格、销量、成交数、内部文件路径、文件大小与页数 | 只在变体 F 发货通道出现；笔记与详情页一律不写 |
| 5 时政与人物 | 人物姓名与职务、讲话原文长句、会见场合／国别／时间、以领导人语句做话题标签 | 用「课题这句话」「课文里的一个例子」「一项成就」等中性指代；**教材篇名作标题不等于违规，保留**（见第 4 步实证口径） |

**必做 / 人工确认分清**

- **必做**：1–4 层零残留；配图逐张读内页文字与画面（含叠字、页眉页脚、水印）；封面叠字不写课题整句；标签不拿课题整句做话题标签；正文不重复人物称谓与职务；不整段抄录课文原文。
- **人工确认（不据此停发题材）**：教材篇名、课题话题标签、课件内页的课文标题。技能实证记录过「同课题纯教学分享笔记可正常过审」，此前因误判政治敏感所做的整页打码**已撤销**；只有与营销推广叠加时才从严。用户明确要求「连标题一起脱敏」时另出一版，**不擅自改固定格式标题**。
- **不做**：为脱敏把教学落点改成含糊空话。**脱敏只换指代，不删方法**——换掉人名职务后，事件链、支架、追问这些可核对的细节必须原样留着，否则零虚构稿会退化成空话。

**依据（2026-11-11 检索，方向性引用）**：《个人信息保护法》第 4／6／25／28／29／31／51 条（去标识化与匿名化的区分、最小必要、不得公开、不满十四周岁未成年人信息属敏感个人信息、单独同意与监护人同意、去标识化措施）；《未成年人保护法》第 4 条；《民法典》第 1019 条肖像权；《可能影响未成年人身心健康的网络信息分类办法》（2026-03-01 施行）第 5／6 条；教育部主管中国教育新闻网「三不晒」实操口径（不晒身份定位信息、不晒带码证件、不晒规律轨迹，分享前打码、关定位）；国家网信办关于个人信息／敏感个人信息的答记者问；小红书未成年人保护治理中的隐私肖像保护机制。平台规则与法规持续更新，出稿时以最新规则为准。

**脱敏出稿必勾（三条，与下方通用清单一起过）**

- [ ] 五层脱敏逐层扫完，1–4 层零残留；第 5 层按实证口径处理，正文与标签无课题整句
- [ ] 配图逐张核过内页文字与画面：无课堂实拍、无人脸与校牌、无二维码／水印／联系方式、无内部路径
- [ ] 脱敏后教学落点仍可核对（只换指代，未删方法）；发布端已关闭地理位置

- [ ] **未在本地产生任何副本**：没有写 .md／.docx／.txt，没有往课题目录或「文案」文件夹存稿；成品只在对话代码块里给，自检与核验结论写在回复正文
- [ ] 扫描风险词与站外导流词（微信号、二维码、「私我」等）= 0
- [ ] **交付物是裸文本**：代码块内整篇无 `**`／`#`／`-` 项目符号／`>`／反引号／围栏标记（小红书发布框与私信框都不渲染，会原样露出符号）
- [ ] 已按第 4 步「出稿必检」扫完标题／正文／标签／配图四位置，**风险权重以营销链路为先**（正文商品清单／强营销标签／交易引导），检查结果随稿给出；政治／时政表述只作人工确认，不据此停发题材
- [ ] 无极限词、无效果承诺（「保提分」「必上优课」）
- [ ] 个人售卖笔记已带原创声明（AI 配图声明按用户要求，事实属实才写），结尾无效果承诺与行动召唤；成交只走左下角官方组件
- [ ] 描述性表述（「路线写得极清楚」「可以停下来慢慢读」）不构成绝对化宣称
- [ ] 课文篇名、作者、数字（如「二百七十三间」）与教材一致，无杜撰
- [ ] **涉及教案／设计思路的内容已对照真实教学设计逐条自检**：商品详情页（变体 E）每条 ■ 落点、备课笔记的脉络与想法、任何写到的环节／数字／课文原句／写法，都能在本课教学设计中找到依据，零虚构、零凭空想象；原词照实写（如「人类作品与自然和谐相融」不可漏成「自然相融」）。自检通过再交付，未自检不出稿
- [ ] 版本与年级对得上（如《秦兵马俑》属人教版四上，不可标「统编四上」）
- [ ] 零人称、无引导互动、表情不过量
- [ ] 清单每一项交付物都真实存在，无虚标
- [ ] 有 AI 配图时已写声明，发布端已勾选 AI 辅助创作（用户明确不写 AI 声明时，确认插图非 AI 生成再省）
- [ ] 若为商品详情页（变体 E）：只有一行标题（走固定格式）、零标签、可编辑只写「可编辑 PPT」（不写文本可编辑、不写配图不可编辑）、不写放映动态、注 2 与发货方式齐全
- [ ] 若为发货文案（变体 F）：**开场第 0 步预检已过**（路径走底稿未全盘扫描、两端能力已按能力指定表调用、缺装已自动安装并经用户授权、登录态有效）；站外链接只在发货通道出现（未进笔记正文／评论区／详情页）、**每条链接均由夸克／百度各自网盘能力现生成、已核对返回的有效期为永久**（非编造、非复用旧链接；有限期旧链接已重建、回填底稿并在回复中列出待取消）、两个网盘同源同版、「任意一种」与「同一份」成对、链接与提取码各自一行、售后只写「协助处理」不预设退款、无「永久有效／好评返现」一类**承诺**（配置永久≠可写承诺）、**整段零 Markdown 标记（无 `**` `#` `-` `>`、无反引号与围栏）**
