# 小红书备课笔记与文案常见坑与避坑对照表

## 九、常见坑

| 现象 | 原因与处理 |
|---|---|
| 正文写得越精致，互动反而越低（2026-11-16 实证） | 同类 10 条带数据样本：正文 0 字 67 赞、3 行纯商品说明 345 赞、最有「小红书味」的精致短文 9 赞。资料型内容里正文只承担两件事——确认「这是我这一课」、给出获取方式。**处理**：用 `■` 内容要点替代课时流程叙述；教学主张改写成「这份资料里教什么」。字数随条数走，不设独立上限 |
| **首屏与声明的形态不一致**（2026-11-16 用户两次纠偏，最高优先防） | 声明写 M1 卡点型，实际第一行却是「统编版X上第N课」＋「【内容包含：N页PPT＋教案＋逐字稿】」，到第 5 行才出现人话——手机首屏约 4—5 行，读者打开看到的是报名号和报价单，直接划走。**注意**：这不是「规格不能进首屏」（M4 首屏本就是规格；M6 清单已在末尾），而是**形态声明与首屏实际不一致**。**处理**：先定形态，再按该形态的首屏定义写；要报规格就选 M6，要痛点开场就选 M1，二者不可混。见 `SKILL.md` 4.3 |
| **用交集提炼规则，把优秀点全筛掉**（2026-11-16 新立，方法论级） | 拿「几条样本都有」当收录标准，结果：①张主任 3 行报货 345 赞 → 因为「只有一条这么写」被判例外；②景之四任务 316 赞 → 同上；③用户实测「堆课文名标签流量好」→ 因为「与赞数无稳定相关」被撤销。**最后只剩最小公约数，篇篇一样，还美其名曰「对齐对标」**。**处理**：改并集收录——有样本在用就收录，有数据提权重，只有合规风险才否决；冲突按形态分配，不判优劣。见 [优秀点融合库](excellence-fusion.md) |
| **把学情预设写成课堂纪实**（2026-11-16 用户指出，A 类） | 模板写「开篇还原课堂真实场景（来自教学设计学情预设）」，等于教模型把备课时的预测写成「我班学生当时就是这样」。教案的学情分析是**预判**，不是课堂记录；读者是同行，一问细节就露。**处理**：有实授记录才写课堂所见（「我班孩子圈了一页词句，问从哪个词看出来就卡住了」）；只有教案就写备课判断（「这一环节容易停在找词，可以接着追问…」）；两者都没有就不用带班号人格 |
| **详情页照模板承诺交付，不核成品**（2026-11-16 用户指出，A 类） | 变体 E 固定写「可编辑 PPT」「均可自行编辑调整」「网盘链接＋提取码」，而教案包实际交什么形态由制作阶段决定（可画链接或 pptx 都可能），网盘也允许无码 → 文案承诺与实际交付不一致，买家改不动就来纠纷。**处理**：教学卖点只能从教学设计取，**交付承诺只能从本课已确认交付清单＋实物取**，格式／可编辑范围／页数／领取方式四项逐项核，不套默认值 |
| **种草笔记出现【内容包含】报货块**（2026-11-16 用户定，A 类） | 交付清单含课件、逐字稿、学习清单等商品词，放在种草笔记里易被平台判营销导流而限流。**处理**：M1—M6 一律不写该块，交付信息只在商品详情页（变体 E）与发货文案（变体 F）出现；删掉不算形态缺失 |
| **让两个优秀样本互相否决** | 写法 A 与 B 冲突时（如「首屏写痛点」对「首屏写规格」），判一方违规、另一方靠豁免条款才能用——结果两边都没学成，还留下「豁免」这种自欺机制。**处理**：冲突＝形态差异，各自归入一个形态；**规则里不得出现永久禁令**，只能写「X 适用于 Y 情况」（平台红线除外） |
| **标签全用泛词，课文名系不足** | 小苏那条正文 0 字、10 个标签全是 `#备课 #小学语文 #语文课件` 这类泛词，课文名一个没有 → 评论区 22 条「求课件」，搜索需求全落空。**处理**：合计 6 个里精确层（课文名系）**固定 3 个、第一位必为裸篇名**，允许同一课文名多次出现（`#陀螺`／`#陀螺课件`／`#四上陀螺`），它们是不同搜索入口，不是重复；大类层取 3 个，不因精简挤掉精确层 |
| **把无数据样本当模板标准** | 拿 4 条连赞数都没有的样本，去推翻有数据的结论（3 行报货 345 赞、细读 43 赞）。**没有数据的样本只能提供写法可能性，不能提供写法优劣**。**处理**：拆解先标数据，未提供就写「未提供」；跨账号跨课题的数字不可直接比较 |
| **只有「主骨架」一个形态** | 有一个默认骨架，九成笔记就会长成同一个样子；每篇都「痛点＋六条要点」，读者第 3 篇就不点了。**处理**：M1—M6 六形态平等（含 M6 清单型），每篇按本课素材选并声明。**去重不压形态，压文字**——开头首句／核心判断／收束三处不得与近 4 篇雷同（形态连用本身不违规，换课文名不换话才违规） |
| **为了对齐模板而硬凑要点**（最高优先防） | 看过一批样本就定「必须 6 条」「必须 380—460」，下篇课文凑不够就拆一条、编一条。**根本错误：把单账号的单次形态当成了规则**。4 条样本只能进形态选项池，不能定硬约束。**处理**：条数＝本课真实教学点数（4—7），宁可 3 条不全凑；每条必须能指回教案某个环节，指不回就删 |
| **把「共性」理解成「每篇一致」** | 共性是「都有清单、都零人称、都写内容要点」这类结构层共同点；把它执行成「条数一样、字数一样、句式一样、标题一个公式」，产出就变成批量复制品。**处理**：结构层守共性，可见层（标题定位词／开场／切法／条数／符号／封面）每篇必变 |
| emoji 清单行与「仅供教学交流」免责声明 | 21 条同类样本两项出现次数均为 **0**，本账号 3 篇全有；且「仅供教学交流」与售卖定位自相矛盾。**处理**：交付物并进一句叙述；**收尾不放任何声明块**（含 AI 配图披露，2026-11-16 用户定），见 `SKILL.md` 3.2。 |
| 写成平台运营方案 / 销售话术 | 用户要的是「设计思路、上课思路」，不是卖货文案；回到「痛点 + 流程 + 取舍」三件套 |
| 出现「我」「姐妹们」 | 对标体是零人称陈述，删掉所有第一/二人称 |
| 堆极限词、感叹号 | 直接违规风险，按「禁止」清单逐句过 |
| 分课时发但清单写成「1课时」 | 整包产品别写成单课时；课时信息按第 1 步由标题或正文交代，C 式清单不强制前置「2课时」 |
| 写进分钟数 / 页码 / 动画数 | 分钟数与动画数任何体裁都删；页码仅变体 B1 可留（那是点评体的信任资产），M1—M6 与 B2 一律不写 |
| 引号乱用 | 只引课文原词 / 单元要素词，别给普通词加引号 |
| 照抄说明型对标，整篇只剩清单 + 三句总述 | 缺痛点与取舍，和同类帖同质、不记人；至少补回痛点两行或想法两句 |
| 清单照搬对标末项「板书设计」 | 产品没有独立板书文档就是虚标；先补齐文档，或删掉该项 |
| 标错教材版本 | 对标写「统编三上」不代表本课题也在统编；编号对不上时宁可不写版本 |
| 正文结尾报货架（「围绕…等环节展开」「整理了配套…思路」） | 「等环节」是敷衍词，整句在报货架，把前面积累的专业感一次清零；改成接住开场的判断句 |
| 点评体写「我很喜欢这一页」 | 主观词不是判断，读者拿到的是情绪不是理由；换成「这一页最实用，因为它把 X 换成了学生能做的动作」 |
| 五个亮点写成五个平行优点 | 读者读完只记得「挺好」记不住「好在哪」；必须落在一条课堂动线上（入→讲→法→用→出），有权重差别 |
| 开场抛了「我最怕…」但中段不回收 | 恐惧开场只抛不接，读者被撩一下又落空；必须补一句「所以全课没有一句直接…」 |
| 家长会笔记套了 M1 块序 | M1 靠正文承载信息；家长会型价值在图，硬套会写成没人看的长文 → 改按变体 C：正文 3–5 行 + 页序模型 |
| 家长会笔记写成「老师 vs 家长」对立 | 立场页没先站队家长，家长读完只会更焦虑；先立「家校在同一边」再逐页拆焦虑 |
| 标题写成「一年级家长会」 | 既无搜索词也无矛盾；改成「用一节【场景】解释清楚，为什么【阶段】」 |
| 直接搬对标笔记的 PPT 实拍图 | 版权风险；只复用文字骨架，图片必须原创重制 |
| 评论区写「私我拿资料」 | 站外导流违规；改为在评论区给可复制的口播要点，正文不挂链接 |
| 只扫文案文字，漏了清单与标签 | 真正的命中常是正文商品清单 + 营销标签 + 交易引导，不在课文措辞 → 按第 4 步四位置全扫，风险权重以营销链路为先；别把课题名当主因，更别整页打码 |
| 把站内 AI 的推测当平台规则 | 「公开课／教案是敏感词」「需教师资格认证」等是汇总笔记生成的推断，已被实际反例证伪 → 只采信可追溯的归因，其余按第 4 步人工确认 |
| 个人售卖稿硬改成纯分享 | 账号要成交，删掉清单与售卖意图等于放弃转化 → 保留 C 式清单 + 官方组件，只降营销语气 |
| 误判成政治敏感就整课题停发 | 同课题纯教学分享笔记可正常过审 → 先查营销链路，题材只作人工确认（见示例九） |
| 拆解结果只存进本地目录 | 工作流中间产物不入库：归档走飞书表 + IMA 全文副本，本地不留（见 [iteration.md](iteration.md)） |
| 写完文案顺手存一份 md／docx 到课题目录 | 用户明确不要本地副本（2026-11-10 定）：成品只在对话代码块给，自检记录与链接核验结论写在回复正文，不落盘、不建「文案」文件夹 |
| 互动课件笔记写成教学设计全文 | 变体 D 的正文只负责「让人相信这东西值得买」，教学设计在商品里 → 按痛点原话→角色代入→规模量化→交付承诺四段写 |
| 互动课件笔记只写「本课件包含…」 | 干巴巴的清单没有说服力 → 换成学生真实痛点原话 + 「你是……」角色代入开场 |
| 抄了「纯标签无正文」的对标帖 | 那是封面扛流量的上游写法，不是正文写法 → 必须自己补「痛点＋解法＋交互亮点」三段文案 |
| 主页笔记列表抓不到互动数 | 主页 SSR 的 `userNotes` 为空，互动数必须逐篇抓：用移动端 UA + `/discovery/item/{id}` + `xsec_token`（见 [iteration.md](iteration.md) 数据采集） |
| 另起思路 / 把脉络写成动作细节清单 | 讲解思路只从教学设计浓缩，详略按第 3 步「唯一口径」；课件与板贴不提供立意 |
| 结尾写「直接打印上课／解放备课时间／来啦」 | 效果承诺 + 行动召唤，四样本里最稳的风险信号 → 整句删，成交只走左下角官方组件，正文与评论区不引导 |
| 照抄对标的页数／✅／👇／✔️ 图标堆叠／「配套…全部配齐」 | 技术参数、引导互动、表情堆叠、报货架都属「禁止」清单；该学的是**内容要点密度**与段落顺序，不是版式符号 |
| 把站内 AI 逐篇漂移的分析当规则库 | 同一套样本它先后归因为售卖、意图、原创、清单，是结果倒推理由 → 只作样本，差分结论按第 4 步「判定逻辑」 |
| 照着官方 AI 给的「安全版」改稿 | 其示范自相矛盾（说删营销标签却留、说别引导却写「左下角链接」）且第一人称＋动作细节 → 只借「分享口吻」，写法仍按第 3 步唯一口径 |
| 详情页套用固定的「可编辑 PPT」 | 先核买家打开的是可画链接还是 PPTX，再写买家实测具备的查看、另存或编辑权限 |
| 详情页承诺整份可编辑但部分对象锁定 | 按实际权限写具体范围，确认哪些对象能改。未核到的能力省略 |
| **按文件名写「整图不可编辑」** | 看到课件文件名带「整图课件」就写成「页面整图呈现、不支持逐字改字」，实物却是原生 pptx（实测 15 页含文字节点 182／形状 450，图片仅 6）→ 把可编辑的课件说成死的，等于自降交付价值。**处理**：文件名、旧标题、历史命名一律不作证据；打开实物核对象构成再写，写不出"不可编辑"的证据就不写 |
| 详情页标题在两个位置重复，或正文带话题标签 | 有商品标题栏时填标题栏，单输入框时标题占首行。两种界面都只出现一次标题，零标签 |
| 详情页注写成绕弯条款或缺位 | 「付款后按订单约定方式交付」这类表述读起来完整、实际什么都没说 → 固定写「虚拟商品，发货后不支持退换，如有问题请在订单内联系客服」；不写领取渠道、不写「发货方式」块（2026-11-21／11-22 用户约定） |
| 详情页清单写两遍（顶部【内容包含】行＋注 1 重复） | 顶部先报一遍货，注 1 再列一遍清单 → 同一信息出现两次，且开头被报名号挡住痛点 → **正文不报货，清单只在注 1 写一次**（2026-11-22 用户约定） |
| 详情页清单写成报价单（堆件数与份数） | 「共9件——pptx×2＋逐字稿×2＋学习清单×2」这类写法把商品页写成账目，读者要读两遍才提取出「交了什么」 → 写成课时＋品类短语串：`内容包含：2课时可编辑课件＋配套逐字稿＋教学设计＋2课时学习清单＋板贴`；件数只在内部与实物核对，不进文案（2026-11-22 用户约定，与「页数一律不写」同理） |
| 定语逆序：「可编辑2课时课件」 | 描写性定语压在数量词前，属逆序，读者要多半秒才理清「可编辑的两份课件」 → 数量在前、描写在后：`2课时可编辑课件`（2026-11-22 用户约定） |
| 详情页落点写成「流程完整／环节清晰」 | 空话无法核对，与同类商品无差别 → 每条落点带生字数、正音字、原句、动作串、篇名 |
| 商品介绍/笔记的设计思路凭记忆写、不回查教案 | 漏字漏环节、把教材原词写错（如「自然和谐相融」写成「自然相融」）、编造教案没有的环节 → 出稿前对照真实教学设计逐条自检，每条落点/数字/原句/写法都能在教案找到依据，零虚构再交付 |
| 发货文案给的是 Markdown 稿（带 `**` 加粗、`#` 标题、`-` 列表） | 买家看到的是满屏星号井号，像故障信息 → 变体 F **一律交裸文本**，强调靠独立成行＋emoji，不靠加粗 |
| 发货文案把链接与提取码挤在一行 | 买家复制时漏码或带上「提取码：」字样，售后量直接上升 → 链接、提取码各占一行 |
| **把「复制到浏览器打开」当买家常识删掉**（2026-11-22 用户纠偏） | 以为「会点链接的人不需要教程」而删去，结果手机端买家把链接直接粘进网盘 APP，部分机型／系统**不触发识别弹框**，页面没反应 → 买家判为链接失效，来问客服。**处理**：领取说明必须有「复制链接到浏览器中打开」这一条，并附一句原因「直接粘到网盘 APP 有时不弹窗」；判据是**排障指引必写、纯教程不写**（输入提取码属后者，已在上一行给出，不重复） |
| 开头写「任意一种网盘」但说明里没说「同一份」 | 买家以为两个网盘内容不同，重复下载 → 成对出现，说明第 1 条固定写同源 |
| 两个网盘其中一个放的是旧版／空目录 | 比只挂一个网盘更伤——买家拿到缺文件又不敢确认 → 发前各下一次核对文件数与版本 |
| 发货文案写「永久有效／长期更新」 | 链接仍可能因平台规则／账号状态失效，写成承诺就是虚假宣传 → 只写「及时转存」，失效走售后兜底。**这与「生成时设永久」不冲突**：前者是文案承诺（禁），后者是技术配置（必做，见硬写法第 9 条） |
