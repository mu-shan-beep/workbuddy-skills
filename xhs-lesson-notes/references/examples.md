# 示例（few-shot）

> **本文件只放符合现行规则的定稿**，废止写法一律不进（清单行、课时块、免责声明、接单标签、AI 披露）。
> 每个示例都标明形态，用途是校准语气、密度与结构；**块序按各自形态，不得跨形态照搬**。
> 正文一律裸文本。示例中的交付句已改为事实占位，出稿前用本课实际采用的形式和清单替换（不写课件页数）。不确定的非必要信息可省。

## 一、M1 卡点型｜《颐和园》第一课时（分课时发）

> 为什么用 M1：本课教学点密集（字词、写字、过渡句、路线图），读者需要逐条验货。
> 标题走课型定位「第一课时」。**课时总数**（2 课时）不写进标题，属技术参数。

**标题**：`四上《颐和园》第一课时课件`（13 字）

**正文**

```
很多孩子读完，能说出长廊、万寿山、昆明湖，
却说不清作者是怎么一路走过去的。
顺序不在景点里，在句子和句子的接缝处。

第一课时完整教学设计核心要点👇

■字词分两组带：注音字与建筑词（殿、漆、琉、佛、煌；长廊、枋梁、画舫、远眺），语境词（神清气爽、金碧辉煌），长句单独练停顿
■写字不全铺开，只攻「栽、耸」：栽的斜钩舒展、撇点不漏，耸的上部左收右放、末横封底
■抓四组过渡句，圈住「进、绕、走完、登上、下来」五个行踪词，把脚步变成路标
■删句对比讲承上启下：去掉「走完长廊，就来到了万寿山脚下」再读，景点接不上，学生自己就明白
■补全游览路线图，同桌互评顺序与行踪词，这张图第二课时开课还要用

四上《颐和园》，【按实填写课件形态和交付物】。

#颐和园 #颐和园课件 #颐和园教学设计 #四上颐和园 #统编版颐和园 #小学语文 #语文课件 #教师备课 #四年级语文 #ppt
```

**要点来源**：全部来自本课教学设计第一课时——词两组、写字只攻两字、四组过渡句与五个行踪词、删句对比、路线图互评。没有一条是补的。

## 二、M2 骨架型｜《秦兵马俑》两课时（合发）

> 为什么用 M2：这一课有明确的递进依赖——先把规模算出来，再看兵俑像不像人，两步拆开就散。
> 与 M1 的分界：M1 的要点彼此并列、可单独看；M2 的步骤有先后，缺一步后面接不上。

**标题**：`《秦兵马俑》完整课件`（11 字）

**正文**

```
两课时这一课的骨架就两步：先把规模算出来，再看兵俑像不像人。

①先读数字：找第3段过渡句，一句「不仅……而且……」搭起全篇骨架，全篇分「规模宏大」「类型众多」两条线
②再读数据：圈第2段六组数据，14260 平方米换成 285 间教室，删掉数字再读一遍，比较差在哪里
③比虚实：第8段三个「有的」用分号连读，省略号留给学生补，读懂「好像」背后的虚实笔法
④写排比：四人拼一句「有的……好像……」，贴成排比画卷，对接单元习作

这一课最容易讲偏的地方：把「举世无双」讲成形容词堆叠。它靠的是数字、分号和那半句「好像」。

《秦兵马俑》，【按实填写课件形态和交付物】。

#秦兵马俑 #秦兵马俑课件 #秦兵马俑教学设计 #秦兵马俑公开课 #人教版秦兵马俑 #小学语文 #语文课件 #教师备课 #四年级语文 #ppt
```

## 三、M6 清单型｜《牛和鹅》（交付物齐全时）

> 为什么用 M6：四份材料全齐、教学点密集、第一屏就想把「买什么」说清。
> 与 M1 的唯一差别是首句报规格（学段课号课题＋交付类型）；种草笔记不写【内容包含】报货块，交付信息放商品详情页，要点部分写法完全相同。

**标题**：`四上《牛和鹅》备课干货`（10 字）

**正文**

```
四上《牛和鹅》备课设计来啦📒

很多老师上这一课，容易停在「不要怕鹅」的道理上，忽略批注方法和前后对比。
学生圈了一页词句，却写不出一条有依据的批注。

2课时完整教学设计核心要点👇

■夯实生字，认读书写12个生字，重点解决「捶」的动作、「膊」的识记和「吁哩哩哩」的读音
■借助四个短语理清故事经过：不怕牛怕鹅→遭到鹅袭击→金奎叔解救→认识发生变化
■品读「贴着墙壁」「脚也软了」，从动作、语言、心理三层体会心情变化
■借教材六处旁批，归纳提问、关注表达、记录感受、表达启发四个角度，换到无旁批的句子写第一条
■圈金奎叔「跳、走、握、提、甩」五个动作，与鹅的前后表现并排看，读懂「不再怕鹅」与「不再欺负牛」的联系
■联读《牛的写意》，撤掉旁批支撑，独立选句写批注

#牛和鹅 #牛和鹅课件 #牛和鹅教学设计 #四上牛和鹅 #统编版牛和鹅 #小学语文 #语文课件 #教师备课 #四年级语文 #ppt
```

## 四、变体 A 总述式短帖｜《秦兵马俑》

> 用途：同一课题的第二个角度，不重复 M2 的骨架。四句分工固定——总述／内容／重点／落点。

**标题**：`《秦兵马俑》完整课件`（11 字）

**正文**

```
《秦兵马俑》教案整理好了，按 2 课时教学思路设计。
从红领巾解说员的情境任务进入，依次安排识字写字、整体感知、精读品读、读写迁移。
重点带学生理清总—分—总骨架，沿「规模宏大」「类型众多」两条线走，品味列数字与「好像」背后的虚实笔法，读懂为什么是举世无双，完成排比段仿写。

很多孩子看完视频只会说「很大」「数不清」，却说不清一篇说明文凭什么让人信。让人信的东西不在形容词里，在数字、分号和那半句「好像」里。

含【按实际填写的交付物】。

#秦兵马俑 #秦兵马俑课件 #秦兵马俑教学设计 #秦兵马俑公开课 #人教版秦兵马俑 #小学语文 #语文课件 #教师备课 #四年级语文 #ppt
```

## 五、红色题材 M1（四剥离）｜《我将无我，不负人民》第一课时

> 本例省略交付清单、交易和普通功能词标签、商业免责声明和 AI 历史场景。题材规范见[合规原文](compliance.md)。全篇是教研笔记，成交只靠官方组件。
> 标签以纯教研为准，**不凑满 10 个**，也不写 `#课件 #ppt #教案` 这类功能词。

**标题**：`四上《我将无我，不负人民》第一课时`（17 字）

**正文**

```
很多孩子能把课文读通，概括时却容易漏掉人物和场合。

第一课时备课脉络
■读课题留下两个问题，先解决字音和长句，把课文读通
■梳理人物对话里的关键信息，用一条事件链串起提问、回答和结尾，再让学生自己把事情说清楚
■讲完事情再集中写字，重点只看两个字；核心语句留到下一课时

💫一点教学心得
概括不给统一答案，把组织语言的过程留给学生。
词语随文理解、写字留一段连续时间，都不铺开讲。

#我将无我不负人民 #小学语文 #四年级语文 #语文教学设计 #阅读教学 #语文老师 #公开课 #备课
```

## 六、变体 C｜家长会课件（正文极短，价值在配图）

> 与 M1—M6 并列的独立类别，不参与形态轮换。正文 3—5 行，信息全在页序里。

**正文（示范）**

```
一年级期中家长会课件做好了。
孩子在学校和在家判若两人，这一场想把这件事讲清楚。
12页，座位、批评、进度、语文数学的具体能力，一页说一件事。
页序在图中。

#家长会 #家长会课件 #一年级家长会 #期中家长会 #班主任 #小学语文 #教师备课 #家长会ppt #ppt #新手老师
```

**配图页序模型（12 页，可伸缩到 6—14 页）**

| 页 | 角色 | 内容要点 |
|---|---|---|
| 1 | 封面 | 实拍讲台场景＋便签叠字；主标「我用一节家长会解释清楚为什么上了一年级」，副标「孩子在学校和在家判若两人」 |
| 2 | 立场页 | 家里的他＋学校里的他＝更完整的孩子；老师和家长不必站在彼此对面 |
| 3—6 | 家长焦虑页 ×4 | 座位（班级管理的一部分，不是好坏评价）／老师今天批评我了（先听完整＋4 个追问）／别人写完我还没写完（姿势→方法→熟练度→最后才看进度）／老师没及时回复（老师一天在做什么） |
| 7—11 | 学科能力页 ×5 | 会读韵母≠会拼音节／会认词语≠能独立认读／《洗手歌》先看→再问→最后说顺序／会算了为什么列错算式（摆一摆→问一问→说一说→再列式）／写字前先让孩子看一眼（先看→再说→后写） |
| 12 | 结尾页 | 从牵着走，到陪着走；成长不在一朝一夕（呼应封面，首尾闭环） |

**五条可迁移规律**：① 标题即矛盾（场景＋动作＋结果对比，不写「一年级家长会」这类平铺标题）② 一页只解决一个焦虑，不合并 ③「会 X 不等于会 Y」贯穿全篇，替家长卸掉焦虑 ④ 每页结尾落在动作，不给空话 ⑤ 首尾闭环立意。

## 七、变体 D｜互动／游戏化课件（工具型商品）

> 适用：真正有交互的 HTML 课件。**没有真实交互就不许用「沉浸式」「游戏化」**，那是标题党。

```
【标题】规模双数字 + 品类明示
14章70个情境！！《乡土中国》沉浸式探索课件！

【① 痛点用课堂原话】
学生翻三页就困的一本书，换了个讲法。

【② 角色代入式开场】（第二人称 + 身份 + 任务）
打开课件，你是一个刚下乡的人类学学生，导师交代：住半个月，别带问题，先看他们怎么过日子。

【③ 交互亮点 / 规模量化】
14章70个情境，每章都是一次真的下乡。

【④ 交付形态与兼容性】
HTML单文件，离线可用，支持希沃/手机/电脑，可插入PPT。
```

**五条写法要点**：① 痛点必须是学生或老师的原话，不写「教学难点」「知识点抽象」② 角色代入＝第二人称＋身份＋具体任务 ③ 规模双数字量化（14章70个情境／30幕分镜／24个可交互章节），比形容词有力 ④ 交付形态承诺必写（离线可用、支持设备、可插入 PPT），这是老师决策的最后一关 ⑤ 可选加分：时间叙事（「讲〈琵琶行〉第九年」）、第三方证言反差钩。

## 八、落点核对示范（防虚标）

示例五那 6 条落点，逐条都要能指回源头。写任何详情的落点都照这个做，指不回去就删：

| 落点 | 依据 |
|---|---|
| 两课时分工、共用路线图 | 教学设计「板书设计」两课时共用一张游览路线图；第一课时理顺序、第二课时品写法 |
| 删「走完长廊，就来到了万寿山脚下」 | 教学设计第一课时「删句对比」，原句为教材过渡句 |
| 三个数字＋二百米跑道 | 教材原文「七百多米」「二百七十三间」「一万多幅」；教学设计第二课时长廊环节比学校 200 米跑道 |
| 三个方位、观察点没动 | 教学设计第二课时佛香阁前「向下望、正前面、向东远眺」 |
| 「滑过」换「划过」 | 教学设计第二课时昆明湖环节，教材原文用「滑」 |
| 世界遗产材料「人类作品与自然相融」 | 语文园地世界遗产材料原句；教学设计第二课时收课环节 |

## 九、形态与示例对照

| 形态 | 示例 | 关键差异 | 何时用 |
|---|---|---|---|
| M1 卡点 | 一 | 痛点开场，要点并列可单独看 | 教学点密集、需逐条验货 |
| M2 骨架 | 二 | 步骤有先后，拆开就散 | 本课有明确推进结构 |
| M3 单点 | 无 | 只讲一个取舍，不分条 | 有一个反常识判断，或教学点本来就少 |
| M4 直给 | 无 | 3 行报货 | 封面能被独立看懂 |
| M5 极简 | 无 | 一句取舍＋去处 | 封面本身是完整信息图 |
| M6 清单 | 三 | 课题句开头，要点清单为主、无报货块 | 交付物齐全、教学点密集，交付放商品页 |
| 变体 A 总述 | 四 | 四句总述，不列要点 | 同课题第二个角度 |
| 变体 E 详情页 | 五 | 零标签、含交易条款 | 商品详情页 |
| 红色四剥离 | 六 | 本例省略清单和普通功能词标签 | 革命历史／党史地标题材 |
| 变体 C 家长会 | 七 | 正文极短，价值在页序 | 家长会类图集 |
| 变体 D 互动 | 八 | 角色代入＋双数字 | 真有交互的 HTML 课件 |

> 示例一、二、三都写于同一批教学设计的真实落点，**不是模板填空**。写新课时照这个流程：先数本课有几个真实教学点，再决定写几条；写不满就少写，绝不为凑条编一条教案里没有的。
