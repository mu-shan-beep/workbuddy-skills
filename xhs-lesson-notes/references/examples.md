# 示例（few-shot）：小学语文课件备课笔记

> **本文件持续累积**：用户后续提供的对标帖 / 爆款文案，经拆解确认后按「课题 / 类型」追加到对应章节；文末「写法对照小结」同步补充新维度。新增示例须与现有示例「同调性、不同课题」，避免互相打架。

以下八篇是实际定稿，供写新课题时校准语气、密度与结构。

- **示例一至三**：《颐和园》，四年级上册第 18 课（袁鹰）。前两篇为分课时发，第三篇为长稿。

- **示例七**：互动/游戏化课件型（跨体裁独立类别 · 变体 D），工具型商品种草笔记，痛点原话→角色代入→规模量化→交付承诺四段式。
- **示例八**：《我将无我，不负人民》第一课时，思路级分课时短帖（默认档，约 240 字）。

3. 四年级《颐和园》第一课时｜删掉一句，学生就懂过渡句了

**正文**

```
四年级《颐和园》备课｜先带学生把路走明白
一篇路线写得极清楚的游记

[星R][星R]（2课时 可编辑放映动态的ppt课件+教案+逐字演讲稿+学习单+课件笔记）[星R][星R]

很多孩子读完，能说出长廊、万寿山、昆明湖，
却说不清作者是怎么一路走过去的。
顺序不在景点里，在句子和句子的接缝处。

📖第一课时课堂脉络
▪️借中国地图和单元导语进课，给学生一个身份：小导游，先把作者的路线走明白。
▪️分类认读两组词：注音字和建筑词（殿、漆、琉、佛、煌，长廊、枋梁、画舫、远眺）、语境词（神清气爽、金碧辉煌）；长句单独练停顿。
▪️九个会写字不全铺开，只攻"栽、耸"，范写、书空、描一临二、投屏共评、当堂订正。
▪️横线画出四组过渡句，圈出"进、绕、走完、登上、下来"，把脚步变成路标。
▪️删掉一句再读，让学生自己发现景点接不上，最后补全游览路线图，同桌互评。

💫一点备课小想法
过渡句不讲定义。删掉"走完长廊，就来到了万寿山脚下"再读一遍，接不上，学生自己就明白什么叫承上启下。
"枋梁""画舫"不做辨析，配一张长廊图就够，词是为读课文服务的。
路线图不印现成的，留空让学生补。这张图第二课时开课还要用。
```

## 示例三：长稿版「设计思路 + 上课思路」（约 950 字 · 适合长笔记 / 公号）

**标题三选一**
1. 四上《颐和园》两课时怎么上，说说我的设计思路
2. 《颐和园》我这样分两节课：第一节走路，第二节读景
3. 上《颐和园》别上成看图说话，我的处理办法

**正文**

```
《颐和园》这课我备了挺久。难的不是课文本身，而是两节课容易上重复：第一节课找过渡句，第二节课还在找句子，学生很快就腻了。所以我把两节课的重心彻底分开：第一节课只管把路走清楚，第二节课只管把景读进去。

先说整体怎么想

一是两节课分工。80 分钟，第一课时理顺序，第二课时品语言，第一节不碰写法，第二节不重讲路线。

二是两节课共用一张游览路线图。第一课时学生自己补全，第二课时一开课就把它当作复习导入来用，不用重新开始。

三是给学生一个身份：小导游。带着任务去读，"找过渡句"就不再是老师让找，而是当导游必须找。

第一课时：把路走明白

导入 3 分钟。中国地图加单元导语，说清楚这单元要看中国的世界文化遗产，今天我们跟着袁鹰逛颐和园。板书"颐"，左窄右宽，不讲字理。

初读 12 分钟。词语分两组：一组是注音字和建筑词，殿、漆、琉、佛、煌，长廊、枋梁、画舫、远眺；一组是语境词，神清气爽、金碧辉煌。"远眺"让学生站起来往窗外看，动作一到位就懂了。"枋梁"配长廊图讲，不辨析。长句"每一间的枋梁上，都有五彩的画……"单独练停顿。

写字 9 分钟。9 个会写字不全铺开，只集中攻"栽、耸"。栽的斜钩要舒展、撇点不能漏；耸的上部左收右放，下面"耳"的末横封底。范写、书空、描一临二、投影展示共评、当堂订正，一步不省。

路线 13 分钟，这是重点。先画线标出四组句子，圈"进、绕、走完、登上、下来"。然后删句对比：把"走完长廊，就来到了万寿山脚下"去掉再读一遍，学生自己就会发现两处景接不上。承上启下不用讲，删一次就懂了。最后在学习单上补路线图，同桌互评顺序和行踪词。

小结 3 分钟。这条路是下节课的地图。

第二课时：把景读进去

复习 3 分钟。指路线图，让一个学生用过渡句连贯说一遍。

长廊 5 分钟。抓三个数字：七百多米、二百七十三间、一万多幅。列数字不是罗列，是让人信。跟学校 200 米跑道比一比，"长"就有感觉了。

山脚 3 分钟。佛香阁八角宝塔形、耸立半山腰；排云殿一排排、金碧辉煌。两个建筑先分清，仰视才立得住。这里随文写"煌"。

佛香阁前 6 分钟，最难的一段。向下望、正前面、向东远眺，观察点没动，只是视线在转，不是由远及近。板书画箭头。"滑过"换成"划过"读一遍，学生自己就说得出"滑"更轻更静。

昆明湖 4 分钟。点一句"没有哪两只是相同的"，和长廊"没有哪两幅是相同的"对一下，同一个眼光。

抄写 6 分钟。课后第 2 题放到课上做。先说喜欢哪句、为什么，再工整抄一两句，投影展示评标点占格和涂改。

世界遗产 7 分钟。读材料圈关键词，别只抓"和谐相融"。让学生把课文画面和材料原句对上：佛香阁、排云殿掩在树丛里，就是"人类作品与自然相融"。

资料方法 5 分钟。殷墟示范渠道要权威，土楼示范角度能一步步深入。同桌互看资料卡。

教案、课件、逐字稿、学习单都是对齐的，页码一一对应，上课不用再翻别的。
```

## 示例四：整篇两课时合发（约 440 字 · 6 块）

> 课题背景：人教版四年级上册第 19 课《秦兵马俑》，2 课时整包。**合发时保留「▪️课时 1／▪️课时 2」标记**，课时下用连续句子，不再逐句加 ▪️，避免与课时标记撞层级。本篇是**详细版**；两课时合发默认走思路级（见 `SKILL.md` 第 3 步），只给方向句，不铺具体词句与动作。

**标题三选一**

1. 四年级《秦兵马俑》备课｜宏大是能算出来的
2. 四年级《秦兵马俑》备课｜把「很大」换成 285 间教室
3. 四年级《秦兵马俑》备课｜陶俑站起来，靠的是那半句「好像」

**正文**

```
四年级《秦兵马俑》备课｜宏大是能算出来的
一支在文字里重新列队的军队

[星R][星R]（2课时 可编辑放映动态的ppt课件+教案+逐字演讲稿+学习单+课件笔记）[星R][星R]

很多孩子看完视频只会说「很大」「数不清」，
却说不清一篇说明文凭什么让人信。
让人信的东西不在形容词里，在数字、分号和那半句「好像」里。

📖两课时课堂脉络
▪️课时 1
认「俑」字，带着解说员身份进课。默读找第 3 段过渡句，一句「不仅……而且……」搭起全篇骨架→圈第 2 段六组数据→14260 平方米换成 285 间教室。删掉数字再重读，比较差在哪里。鸟瞰一段齐读收势。
▪️课时 2
重心从「有多大」转到「像不像人」。四张档案卡分两栏，一栏写看到的，一栏写想到的，将军、武士、骑兵、陶马各一张。第 8 段三个「有的」用分号连读，省略号留下来给学生补。四人拼一句「有的……好像……」贴成排比画卷。收在陶文里的工匠地名。

💫一点备课小想法
过渡句不讲定义。删掉它读一遍，接不上，学生自己就懂什么叫承上启下。
换算到 285 间教室就停，手里有画面比算得准重要。
第 8 段「思念家乡的亲人」不绕开，威武和想家放在一起才有人味。

#课件 #ppt #语文 #秦兵马俑 #ppt定制 #教案 #四年级语文 #教师备课 #公开课 #小学语文备课
```

**写作要点**：课时 1 用「认…→找…→圈…→换…→删数字重读」，五步一条线；课时 2 换重心，从「多大」转到「像不像人」。想法三条对应减法（不讲定义）／取舍（换算停在哪）／升人文（威武与想家并置）。

## 示例六：家长会课件型（变体 C · PPT 实拍图集笔记）

> **跨体裁独立类别**，不套主骨架。完整归档（原文、12 页逐页文字、数据快照、合规自检）走双落点——飞书表格「小红书爆款笔记与对标博主记录表」→ 爆款笔记（结构化字段）＋ IMA 知识库「小红书学习笔记」同名 .md（全文副本，供全文检索）；本篇只留可复用的文字骨架，本地不留副本。
> 对标：@小秋老师的记事本《我用一节家长会解释清楚，为什么上了一年级》（2026-11-05 19:18，赞 98 / 藏 103 / 评论 7 / 分享 8；收藏 > 点赞＝「留着用」型工具笔记）

**正文（原帖照录 · 只有 3 行）**

```
26秋季一年级家长会
求分享。
来啦
```

**标签**：#家长会 #家长会发言稿 #新手老师 #期中家长会课件 #一年级家长会 #一年级期中家长会 #家长会ppt #期中家长会ppt #期中家长会 #班主任

**配图页序模型（12 页，N 可伸缩到 6–14 页）**

| 页 | 角色 | 内容要点 |
|---|---|---|
| 1 | 封面 | 实拍讲台场景照＋白色便签叠字；主标「我用一节家长会解释清楚为什么上了一年级」，副标「孩子在学校和在家判若两人」 |
| 2 | 立场页 | 我们不是两支队伍——家里的他＋学校里的他＝更完整的孩子；老师和家长不必站在彼此对面 |
| 3–6 | 家长焦虑页 ×4 | 座位（班级管理的一部分，不是好坏评价）／老师今天批评我了（先听完整＋4 个追问＋2 个别追问）／别人写完我还没写完（姿势→方法→熟练度→最后才看进度）／老师没及时回复（老师一天在做什么，先照顾眼前的孩子） |
| 7–11 | 学科能力页 ×5 | 翻开语文书真都会了吗（会读韵母≠会拼音节／会认词语≠能独立认读／会读儿歌≠读懂内容）／儿歌读出来意思说得清吗（《洗手歌》：先看→再问→最后说顺序）／会算了为什么列错算式（摆一摆→问一问→说一说→再列式）／拼音学过了为什么读不顺／写字前先让孩子看一眼（先看→再说→后写） |
| 12 | 结尾页 | 从牵着走，到陪着走；成长不在一朝一夕，陪伴藏在点点滴滴（呼应封面，首尾闭环） |

**五条可迁移规律**

1. **标题即矛盾**：场景＋动作＋结果对比（「用一节【场景】解释清楚，为什么【阶段】」），不写「一年级家长会」这类平铺标题。
2. **一页只解决一个焦虑**：座位、批评、进度、消息——各占一页，不合并。
3. **「会 X，不等于会 Y」贯穿全篇**（6 处）：把教学结果翻译成能力差别，替家长卸掉「孩子是不是不行」的焦虑。
4. **每页结尾落在动作**：先看→再说→后写；摆一摆→问一问→说一说→再列式；不给空话。
5. **首尾闭环立意**：封面抛出「从牵着走，到陪着走」，结尾原句收束。

**写此类笔记时的边界**

- **只复用文字骨架**：原图是他人 PPT 实拍／截图，商品化必须原创排版重制，否则有版权风险。
- 正文不挂链接；评论区给「可复制的口播要点」承接转化，不写「私我／加V」。
- 第二人称「你／家长」可用（说话对象就是家长），但不写「亲爱的家长朋友们」这类套话。

## 示例七：互动/游戏化课件型（变体 D）

对标：@墨雨《讲〈琵琶行〉第九年，今年终于把"学写文学短评"这节课做出了想要的样子》（282赞／363藏）
对标：@墨雨《14章70个情境！！〈乡土中国〉沉浸式探索课件！》（230赞／264藏）
对标：@化境可视化《从一片叶子的整体结构，到叶片内部组织，再到细胞和叶绿体层级，都可以通过3D模型进行观察》（18赞／33藏）

### 变体 D 正文模板（互动/游戏化课件型）

```
【标题】规模双数字 + 品类明示
14章70个情境！！《乡土中国》沉浸式探索课件！

【① 痛点用课堂原话】
学生翻三页就困的一本书，我换了个讲法。

【② 角色代入式开场】（第二人称 + 身份 + 任务）
打开课件，你是一个刚下乡的人类学学生，导师交代：住半个月，别带问题，先看他们怎么过日子。

【③ 交互亮点 / 规模量化】
14章70个情境，每章都是一次真的下乡。

【④ 交付形态与兼容性】
HTML单文件，离线可用，支持希沃/手机/电脑，可插入PPT。
```

### 写法要点

1. **痛点必须是学生或老师的原话**——「学生翻三页就困」「学生在"看不出哪里有病"和"改完不知道对不对"之间反复横跳」。不要写「教学难点」「知识点抽象」。
2. **角色代入式开场**——「你是刚下乡的人类学学生」「你先"成为"江州司马白居易」「你是孔门守简的年轻弟子」。第二人称 + 身份 + 具体任务，一次把静态课件讲成故事。
3. **规模双数字量化**——「14章70个情境」「30幕电影级分镜」「24个可交互章节」「41道题」。标题里的数字比形容词有力。
4. **交付形态承诺必写**——HTML离线可用 / 支持希沃手机电脑 / 可插入ppt / 持续更新。这是老师决策的最后一关。
5. **可选加分**：时间叙事（「讲〈琵琶行〉第九年」）替代「精心制作」；第三方证言反差钩（「同事问我这是哪个游戏，我说是《琵琶行》课件，她不信」）。

### 三种流量模型对照（选对标对象用）

| 类型 | 赞藏关系 | 评论 | 流量来源 | 对标价值 |
|---|---|---|---|---|
| 互动/游戏课件型（@墨雨） | 1:1（工具型） | 中（均12） | 推荐流 + 标签矩阵 + 日更 | **高**，文案骨架可学 |
| 3D/工具展示型（@化境可视化） | 藏 > 赞 | **近零（均0.4）** | 精准长尾搜索 | 中，话术可学、模型不可复制 |
| 纯标签无正文型 | — | — | 封面扛流量 | ⚠️ 只可学标签矩阵，正文必须自写 |

### 边界

- ⚠️ 「沉浸式」「游戏化」若无真实交互支撑＝标题党，自研必须确保交互真的能跑。
- ⚠️ **不要抄「纯标签无正文」**：那是封面扛流量的上游写法，不是正文写法。
- 交付物（课件本体）在商品里，笔记正文不写教学设计全文。

完整归档（两位博主档案 + 53 篇笔记清单 + 横向对比）在飞书表格「小红书爆款笔记与对标博主记录表」→ 对标博主第 4/5 行、爆款笔记第 4/5/6 行；IMA 全文见「对标博主拆解-墨雨与化境可视化.md」。

## 示例八：思路级分课时短帖（默认档 · 约 240 字）

> 课题背景：四年级上册第 24 课《我将无我，不负人民》第一课时。演示第 3 步「唯一口径」：讲解思路只从教学设计浓缩，脉络只给方向句，不写动作细节。产品清单按工作区实际文件写（本课题无逐字稿，不虚标）。
>
> ⚠️ **风险记录**：该稿发布后被平台处理，归因**政治敏感**（课题名做话题标签 + 课件截图内页含人物职务称谓与讲话原文），不是常规违禁词。本篇仅作「思路级」写法示范，**标签与配图方案不得照搬**；本课题不建议在平台做图文推广，出稿一律先过第 4 步「出稿必检」。

**标题三选一**
1. 四年级《我将无我，不负人民》第一课时｜先读懂对话，再说清这件事
2. 四年级《我将无我，不负人民》备课｜第一课时从找信息到自己概括
3. 四年级《我将无我，不负人民》第一课时｜事件链是这节课的骨架

**正文**

```
四年级《我将无我，不负人民》第一课时｜先读懂对话，再说清这件事
一篇靠人物对话展开叙事的课文

[星R][星R]（2课时 可编辑ppt课件+教学设计+两课时学习清单）[星R][星R]

很多孩子能把课文读通，概括时却容易漏掉人物和场合。

📖第一课时课堂脉络
▪️读课题留下两个问题，先解决字音和长句，把课文读通。
▪️梳理人物对话里的关键信息，用一条事件链串起提问、回答和结尾，再让学生自己把事情说清楚。
▪️讲完事情再集中写字，重点只看两个字；核心语句留到下一课时。

💫一点备课小想法
概括不给统一答案，把组织语言的过程留给学生。
词语随文理解、写字留一段连续时间，都不铺开讲。

#课件 #ppt #语文 #我将无我不负人民 #ppt定制 #教案 #四年级语文 #教师备课 #公开课 #小学语文备课
```

**写作要点**：脉络 3 句分别对应教学设计环节一＋二／环节三／环节四，只给走向；痛点来自学情分析「概括事件时可能遗漏关键信息」；想法 2 条来自环节二与环节四的设计意图；「核心语句留到下一课时」来自机动环节。课件与制作笔记只用于核对，不提供立意。
