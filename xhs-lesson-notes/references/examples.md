# 示例（few-shot）

> **本文件只放符合现行规则的定稿**，废止写法一律不进（清单行、课时块、免责声明、接单标签、AI 披露）。
> 每个示例都标明形态，用途是校准语气、密度与结构；**块序按各自形态，不得跨形态照搬**。
> 正文一律裸文本。示例中的交付句已改为事实占位，出稿前用本课实际采用的形式和清单替换（不写课件页数）。不确定的非必要信息可省。
> **口径基准（2026-11-22）**：标题＝课题＋一个定位元素，定位元素优先内容抓手且须装进张力六式（`SKILL.md` 3.1）；要点每条 15—25 字三截短句（3.3）；标签精确 3＋大类 3＝6、首位裸篇名（第五节）。

## 一、M1 卡点型｜《颐和园》第一课时（分课时发）

> 为什么用 M1：本课教学点密集（字词、写字、过渡句、路线图），读者需要逐条验货。
> 标题走内容抓手＋认知冲突式。**课时总数**（2 课时）不写进标题，属技术参数；「第一课时」是课型定位。

**标题**：`四上《颐和园》顺序不在景点里`（14 字）

**正文**

```
很多孩子读完，能说出长廊、万寿山、昆明湖，
却说不清作者是怎么一路走过去的。
顺序不在景点里，在句子和句子的接缝处。

第一课时完整教学设计核心要点👇

■字词分两组带，建筑词与语境词分开认，长句单练停顿
■写字只攻「栽、耸」，斜钩舒展、撇点不漏
■圈进、绕、走完、登上、下来五个行踪词，脚步变路标
■删过渡句再读，景点接不上，学生自己说出承上启下
■补全游览路线图，同桌互评，第二课时开课还用

四上《颐和园》，【按实填写课件形态和交付物】。

#颐和园 #颐和园课件 #四上颐和园 #小学语文 #语文课件 #教师备课
```

**要点来源**：全部来自本课教学设计第一课时——词两组、写字只攻两字、四组过渡句与五个行踪词、删句对比、路线图互评。没有一条是补的。

**逐条落点核对（防虚标）**

| 落点 | 依据 |
|---|---|
| 两课时分工、共用路线图 | 教学设计「板书设计」两课时共用一张游览路线图；第一课时理顺序、第二课时品写法 |
| 删「走完长廊，就来到了万寿山脚下」 | 教学设计第一课时「删句对比」，原句为教材过渡句 |
| 五个行踪词 | 教学设计第一课时过渡句环节圈「进、绕、走完、登上、下来」 |
| 「栽、耸」两字 | 教学设计第一课时写字环节只攻这两字 |

## 二、M2 骨架型｜《秦兵马俑》两课时（合发）

> 为什么用 M2：这一课有明确的递进依赖——先把规模算出来，再看兵俑像不像人，两步拆开就散。
> 与 M1 的分界：M1 的要点彼此并列、可单独看；M2 的步骤有先后，缺一步后面接不上。
> 标题走认知冲突式：课文常被当成「大气」来教，真实门道在数字与分号。

**标题**：`《秦兵马俑》难的不是大，是数字`（15 字）

**正文**

```
两课时这一课的骨架就两步：先把规模算出来，再看兵俑像不像人。

①先读过渡句，「不仅……而且……」搭起两条线
②圈六组数据，14260 平方米换 285 间教室
③三个「有的」用分号连读，省略号留给学生补
④拼一句「有的……好像……」，贴成排比画卷

这一课最容易讲偏的地方：把「举世无双」讲成形容词堆叠。它靠的是数字、分号和那半句「好像」。

《秦兵马俑》，【按实填写课件形态和交付物】。

#秦兵马俑 #秦兵马俑课件 #人教版秦兵马俑 #小学语文 #语文课件 #教师备课
```

## 三、M6 清单型｜《牛和鹅》（交付物齐全时）

> 为什么用 M6：多份材料齐备、教学点密集、第一屏就想把「买什么」说清。
> 与 M1 的唯一差别是首句报规格（学段课号课题＋交付类型）；种草笔记不写【内容包含】报货块，交付信息放商品详情页，要点部分写法完全相同。
> 标题走内容抓手：本课真正的难点是「写出第一条有依据的批注」。

**标题**：`四上《牛和鹅》批注只写关键词`（14 字）

**正文**

```
四上《牛和鹅》备课设计整理好了📒

很多老师上这一课，容易停在「不要怕鹅」的道理上，忽略批注方法和前后对比。
学生圈了一页词句，却写不出一条有依据的批注。

2课时完整教学设计核心要点👇

■认读12个生字，攻克「捶」「膊」与「吁哩哩哩」
■四个短语串经过：不怕牛→遭袭→解救→转变
■品读「贴着墙壁」「脚也软了」，三层读心情
■六处旁批归四角度，换无批注句子写第一条
■圈五个动作并排看鹅的表现，读懂两重转变
■联读《牛的写意》，撤支架独立写批注

#牛和鹅 #牛和鹅课件 #四上牛和鹅 #小学语文 #语文课件 #教师备课
```

## 四、变体 A 总述式短帖｜《秦兵马俑》

> 用途：同一课题的第二个角度，不重复 M2 的骨架。四句分工固定——总述／内容／重点／落点。
> 标题走设问留白式：与 M2 的「难的不是大」换切角，不复用同一判断。

**标题**：`《秦兵马俑》说明文凭什么让人信`（15 字）

**正文**

```
《秦兵马俑》教案整理好了，按 2 课时教学思路设计。
从红领巾解说员的情境任务进入，依次安排识字写字、整体感知、精读品读、读写迁移。
重点带学生理清总—分—总骨架，沿「规模宏大」「类型众多」两条线走，品味列数字与「好像」背后的虚实笔法，读懂为什么是举世无双，完成排比段仿写。

很多孩子看完视频只会说「很大」「数不清」，却说不清一篇说明文凭什么让人信。让人信的东西不在形容词里，在数字、分号和那半句「好像」里。

含【按实际填写的交付物】。

#秦兵马俑 #秦兵马俑教学设计 #人教版秦兵马俑 #小学语文 #语文课件 #教师备课
```

## 五、红色题材 M1（四剥离）｜《我将无我，不负人民》第一课时

> 本例省略交付清单、交易与商业免责声明、AI 历史场景。题材规范见[合规原文](compliance.md)。
> **功能词标签在本题材下省略**（`#课件`／`#ppt`／`#教案` 这三个泛词，按 F-10 保守默认不用）；**精确层与大类层仍取满 3＋3＝6**，课文名系标签不受此限。
> **标题只走课型定位，不做张力钩子**——红色题材合规优先于点击率，钩子留给常规课题。

**标题**：`四上《我将无我，不负人民》第一课时`（17 字）

**正文**

```
很多孩子能把课文读通，概括时却容易漏掉人物和场合。

第一课时备课脉络
■读课题留两个问题，先解决字音长句
■用一条事件链串起提问、回答和结尾
■讲完事情再集中写字，重点只看两个字

💫一点教学心得
概括不给统一答案，把组织语言的过程留给学生。
词语随文理解、写字留一段连续时间，都不铺开讲。

#我将无我不负人民 #我将无我不负人民课件 #四上我将无我不负人民 #小学语文 #四年级语文 #语文教学设计
```

> 本例保留 1 条 💫，属「这一条取舍正是读者最需要的判断」的用法（3.4 默认不写，此处说明理由而非破例）。
> 本例 3 条要点、约 137 字，落在 M1 参考带下沿以下——**四剥离后不留规格句与清单，字数自然少**，属正常；不为凑字数补写。

## 六、变体 C｜家长会课件（正文极短，价值在配图）

> 与 M1—M6 并列的独立类别，不参与形态轮换。正文 3—5 行，信息全在页序里。
> 家长会类无课文篇名，标题以「家长会」承担课题位（3.1 课题位的合法变体）。

**标题**：`一年级期中家长会，一页说一件事`（15 字）

**正文（示范）**

```
一年级期中家长会课件做好了。
孩子在学校和在家判若两人，这一场想把这件事讲清楚。
座位、批评、进度、学科能力，一页说一件事。
页序在图中。

#家长会 #家长会课件 #期中家长会 #班主任 #小学语文 #教师备课
```

**配图页序模型（课件 12 页，可伸缩到 6—14 页；发布配图另按 8.2 取 3—6 张关键页，不是把 12 页全发）**

| 页 | 角色 | 内容要点 |
|---|---|---|
| 1 | 封面 | 实拍讲台场景＋便签叠字；主标「我用一节家长会解释清楚为什么上了一年级」，副标「孩子在学校和在家判若两人」 |
| 2 | 立场页 | 家里的他＋学校里的他＝更完整的孩子；老师和家长不必站在彼此对面 |
| 3—6 | 家长焦虑页 ×4 | 座位（班级管理的一部分，不是好坏评价）／老师今天批评我了（先听完整＋4 个追问）／别人写完我还没写完（姿势→方法→熟练度→最后才看进度）／老师没及时回复（老师一天在做什么） |
| 7—11 | 学科能力页 ×5 | 会读韵母≠会拼音节／会认词语≠能独立认读／《洗手歌》先看→再问→最后说顺序／会算了为什么列错算式（摆一摆→问一问→说一说→再列式）／写字前先让孩子看一眼（先看→再说→后写） |
| 12 | 结尾页 | 从牵着走，到陪着走；成长不在一朝一夕（呼应封面，首尾闭环） |

**五条可迁移规律**：① 标题即矛盾（课题位「家长会」必留＋一个张力落点；只写「一年级家长会」五个字才是平铺）② 一页只解决一个焦虑，不合并 ③「会 X 不等于会 Y」贯穿全篇，替家长卸掉焦虑 ④ 每页结尾落在动作，不给空话 ⑤ 首尾闭环立意。

## 七、变体 D｜互动／游戏化课件（工具型商品）

> 适用：真正有交互的 HTML 课件。**没有真实交互就不许用「沉浸式」「游戏化」**，那是标题党。
> 标题走数字锚定式；交付形态四句按**本课实物**核填，不套本例字面。

**标题**：`14章70个情境，《乡土中国》这样读`（18 字）

```
【① 痛点用课堂原话】
学生翻三页就困的一本书，换了个讲法。

【② 角色代入式开场】（第二人称 + 身份 + 任务）
打开课件，你是一个刚下乡的人类学学生，导师交代：住半个月，别带问题，先看他们怎么过日子。

【③ 交互亮点 / 规模量化】
14章70个情境，每章都是一次真的下乡。

【④ 交付形态与兼容性】
按实物填写：文件形态、是否离线可用、支持设备、能否插入 PPT。

#乡土中国 #乡土中国课件 #乡土中国整本书阅读 #高中语文 #语文课件 #教师备课
```

**五条写法要点**：① 痛点必须是学生或老师的原话，不写「教学难点」「知识点抽象」② 角色代入＝第二人称＋身份＋具体任务 ③ 规模双数字量化（14章70个情境／30幕分镜／24个可交互章节），比形容词有力 ④ 交付形态承诺必写（离线可用、支持设备、可插入 PPT），这是老师决策的最后一关，但**只能写实物核过的项** ⑤ 可选加分：时间叙事（「讲〈琵琶行〉第九年」）、第三方证言反差钩。

## 八、形态与示例对照

| 形态 | 示例 | 关键差异 | 何时用 |
|---|---|---|---|
| M1 卡点 | 一 | 痛点开场，要点并列可单独看 | 教学点密集、需逐条验货 |
| M2 骨架 | 二 | 步骤有先后，拆开就散 | 本课有明确推进结构 |
| M3 单点 | 无 | 只讲一个取舍，不分条 | 有一个反常识判断，或教学点本来就少 |
| M4 直给 | 无 | 3 行报货 | 封面能被独立看懂 |
| M5 极简 | 无 | 一句取舍＋去处 | 封面本身是完整信息图 |
| M6 清单 | 三 | 课题句开头，要点清单为主、无报货块 | 交付物齐全、教学点密集，交付放商品页 |
| 变体 A 总述 | 四 | 四句总述，不列要点 | 同课题第二个角度 |
| 红色四剥离 | 五 | 省略清单、功能词标签与免责 | 革命历史／党史地标题材 |
| 变体 C 家长会 | 六 | 正文极短，价值在页序 | 家长会类图集 |
| 变体 D 互动 | 七 | 角色代入＋双数字 | 真有交互的 HTML 课件 |
| 变体 E 详情页 | 无（见 `SKILL.md` 4.5 骨架） | 零标签、含交易条款 | 商品详情页 |
| 变体 F 发货 | 无（见 `fulfillment.md` 六段） | 纯文本、站外链接唯一通道 | 付款后发货 |

> 示例一、二、三都写于同一批教学设计的真实落点，**不是模板填空**。写新课时照这个流程：先数本课有几个真实教学点，再决定写几条；写不满就少写，绝不为凑条编一条教案里没有的。
> **本表只登记有定稿的示例**；变体 E／F 的骨架唯一归属 `SKILL.md` 4.5 与 `fulfillment.md`，不在本文件重复展开，避免两处各写一套。
