## 张力六式（标题句式，见 SKILL.md 3.1）

**张力六式（内容抓手必须用其中一式表达，不写平铺陈述句）**：

| 式 | 结构 | 本课示例 | 字数 |
|---|---|---|---|
| 反常识 | 写清楚不靠 X | `四上《爬天都峰》写清楚不靠写多` | 15 |
| 设问留白 | 凭什么／怎么 X | `四上《爬天都峰》凭什么写清楚` | 14 |
| 数字锚定 | 靠这 N 样 | `四上《爬天都峰》想说做，就3样` | 15 |
| 否定纠偏 | 别只教 X | `四上《爬天都峰》别只教登顶` | 13 |
| 认知冲突 | 难的不是 X | `四上《爬天都峰》难的不是爬` | 13 |
| 细节钩子 | 具体反差 | `四上《爬天都峰》两次致谢不一样` | 15 |

- **与「内容抓手 6 型子型」的分工（防双套打架）**：张力六式管**标题句式**（怎么把抓手说得抓人），6 型子型管**去同构**（连续出稿换内容切角，见 anti-repetition.md 槽位 1）。两者正交：每篇标题＝**一个内容切角（6 型之一）＋一个张力句式（6 式之一）**；去同构只换内容切角即可，张力句式可自由选、不作第二套去重维度（否则两套六同时约束会锁死）。
- **主推反常识式**：`四上《爬天都峰》写清楚不靠写多`（15 字）——呼应课文「奋力攀爬」与「我爬上了山」的对比，出自教案真实教学点，制造"不靠写多那靠什么"的缺口。
- **取证不变**：张力点必须由本课教案推导（按 1.3），写不出真实冲突就退回平实直陈，不编造钩子。张力≠标题党，仍受 ≤20 字、课题必写、零效果承诺、零夸张词约束。

## 六型对照（见 SKILL.md 4.2）

### 4.2 六型对照

| 形态 | 第一屏写什么 | 中段 | 依据（各自有出处，不互相否决） |
|---|---|---|---|
| **M1 卡点型** | 同行误区／学生卡在哪 | 4—7 条内容要点 | 1-1~1-4 痛点段（无数据）、景之 316 赞 |
| **M2 骨架型** | 这一课怎么走，几步走完 | 每步一句，挂课后题／习作 | 景之 316 赞（四任务） |
| **M3 单点型** | 一个取舍的处境 | 只讲这一点、讲透、不分条 | 无对标，自创形态，待验证 |
| **M4 直给型** | 交付形态一句＋怎么拿（截图在图中、走官方组件） | 无，3 行结束 | 张主任 345 赞（同课题最高）；**页数按 F-11 不写** |
| **M5 极简型** | 一句最硬的取舍＋获取方式 | 无 | 小苏 67 赞（正文 0 字） |
| **M6 清单型** | 学段＋课号＋课题＋交付类型一句开头 | 痛点两行 → 承接句 → 4—7 条要点（**种草笔记一律不写【内容包含】报货块**，避免平台限流） | 1-1~1-4 同结构四条（同账号、无数据）；首句另有 4-3（29 赞）、2-2 |

**六种平等，没有主形态。** M6 是一个真实账号的成熟写法，与其余五型地位相同，只是它不能是默认。

**M4／M5 的前提：封面首图是教学内容页**（结构图、板书、核心问题、学习单页之一），不是纯课题页。短形态的全部信息都在图上，图撑不住就是空帖子。

已有课件截图要在实际手机预览大小看得清主要材料或学习任务。找不到符合条件的首图时，选能靠正文说清的形态。

## 逐型模板（见 SKILL.md 4.4）

### 4.4 逐型模板

**M1 卡点型**（用得最多，但不是默认）：教学点密集、需逐条验货的课文。块序固定为：痛点 → 承接句＋要点 → 首句＋规格合并句 → 标签。**这是本形态的定义，不是通用规定，不得搬到 M2—M6。**

```
【小红书标题框】{年级}{册次}《{篇名}》{定位词}      ← 门禁见 3.1

【小红书正文框】
【痛点一：这一课容易被上成什么，忽略了什么】。
【痛点二：学生能做到什么，却做不到什么】。

{课时}完整教学设计核心要点👇

■【字词】落实哪部分字词，攻克哪个读音或易错字，怎么辨
■【方法】教给什么方法，几个角度或几步，落实哪项课后任务
■【迁移】读写迁移，借鉴哪种写法，练习写什么，对接哪项任务

统编版{年级}{册次}第{N}课《{篇名}》，{按实际交付填写课件形态和交付物清单}。

#标签（第五节双层法）
```

> 三行 `■` 是**占位示例，不是三类全写**：本课有哪几类真实教学点就写哪几条、按教案环节排。

**M2 骨架型**（景之 316 赞）：本课推进顺序本身就是卖点（任务群、四步法、层层递进）。与 M1 的分界——**M1 要点彼此并列、可单独看；M2 步骤有先后依赖、拆开就散**。

```
{课时}这一课的骨架就{N}步：
①【第一步做什么，落到哪】（{对接哪道课后题／哪个单元要素}）
②【第二步做什么，落到哪】（{…}）
③【第三步做什么，落到哪】（{…}）
④【第四步做什么，落到哪】（{当堂写／当堂评}）

【这一课最容易讲错的一处，一句判断】

{已核实的教材版本、课号和课题}，{按实际交付填写课件形态和资料项}。
#标签
```

每步必须挂一个可核对落点（课后题／单元要素／当堂产出），只写「初读—精读—拓展」＝空骨架。步骤数＝教案真实环节数，常见 3—5 步，为凑「四步」硬拆一环是最典型的造假。

**M3 单点型**（无对标，自创形态）：本课有一个反常识取舍值得讲透，或教学点本来就少、凑不出清单。**只讲一件事，不列清单。** 使用后必须回填数据。

```
【多数人会怎么做】，【代价是什么】。
【换一种做法是什么，一句话说清】（零人称，不写「我反过来」）。

【为什么这么判断：一句教学判断，带一处课文原词】

【这份资料里具体怎么落地：一个做法，说细】

{按实际交付填写课件形态和资料项}。
#标签
```

**M4 直给型**（张主任 345 赞，同课题最高）：第一屏就是规格。不照抄的地方——对标原文写了「有偿2元」和商品编号，**明码标价属平台灰区，不写价格**，只留「截图展示＋官方组件」。

```
课件为{实际形态}
内容已在笔记中截图展示。
需要时走笔记下方官方商品组件。

#标签
```

**M5 极简型**（小苏 67 赞，正文 0 字）：封面承担全部教学展示，适用于封面本身已是完整信息图。

```
【本课最硬的一处取舍或最特别的一处设计】，都在课件里。
需要的话看左下角。

#标签
```

**M6 清单型**（1-1~1-4 同结构四条；首句另有 4-3、2-2）：交付物齐全（4—5 件）、教学点密集、且希望第一屏就把规格说清。与 M1 的**唯一差别**是首句报规格（学段课号课题＋交付类型），痛点、要点照常在前；**种草笔记不写【内容包含】报货块**，交付信息只放商品详情页（变体 E），避免平台限流。

```
【小红书标题框】四上《{篇名}》{定位词}

【小红书正文框】
{年级}{册次}第{N}课《{篇名}》备课设计整理好了📒

【痛点一：这一课容易被上成什么，忽略了什么】。
【痛点二：学生能做到什么，却做不到什么】。

{课时}完整教学设计核心要点👇

■【字词】落实哪部分，攻克哪个读音或易错字，怎么辨
■【方法】教给什么方法，几个角度或几步，落实哪项课后任务
■【品读】品读哪一片段，抓住什么对比或写法，看出什么
■【迁移】读写迁移，借鉴哪种写法，练习写什么，对接哪项任务

#标签（第五节双层法）
```

融合来源（逐项标明，不凭偏好增删）：首句「学段＋课号＋课题＋交付类型」←4-3 AAA；痛点两行 ←1-2~1-4；承接句 ←1-1~1-4（4/4）；要点式 ←1-1~1-4（24/24）；**收尾不写声明**（声明块整块废除，21 条样本此类声明零出现）；标签 ←586 赞／316 赞／Coco 藏率最高。**emoji 只许一个 📒 或一个主题 emoji 起首句**，不得做成 `[星R]` 框清单行。

## 特殊形态与变体模板体（见 SKILL.md 4.5）

**红色题材专属骨架（四剥离，纯教研形态）**：适用《延安，我把你追寻》《为中华之崛起而读书》《我将无我，不负人民》《梅兰芳蓄须》等。① 正文去掉商品清单行，直接以学情痛点开篇；② 去掉接单、交易标签；普通功能词标签按保守默认省略，详见[合规原文](compliance.md)；③ 正文去掉商业免责声明；④ 配图禁用 AI 捏造历史人物或事件场景。全篇保留教学内容，交易由官方店铺组件承接。

```
【小红书标题框】{年级}{册次}《{篇名}》{第一课时／单课时}

【小红书正文框】
【学生面对该篇的表面理解】，
却很难真正读懂【文本背后的精神内核/时代背景】。
这篇课文真正的门道，藏在【具体对比/关键语句/历史背景】里。

备课脉络
【落实哪部分字词与背景铺垫，攻克哪些读音或难句】。
→ 【核心思辨：抓住哪处对比／关键语句，读懂为什么】。
→ 【诵读或练笔收束：怎么把体会落回语文实践】。

💫一点教学心得
【一条减法：不讲成冗长历史课/不生硬拔高】。
【一条取舍：抓住核心意象与比喻，把时间留给学生思辨交流】。

#【篇名】 #【篇名】课件 #四上【篇名】 #小学语文 #【年级】语文 #语文教学设计
```

> **标题只走课型定位**（第一课时／单课时），**不装张力钩子、不加 ✨**——红色题材合规优先于点击率（与 `examples.md` 示例五同一口径）。标签仍取满 3＋3＝6，首位为裸篇名；`#课件`／`#ppt`／`#教案` 三个泛功能词按 F-10 保守默认省略。


**变体 A 总述式短帖**（常规课文快速转化；红色题材禁用，须走上一节）：

```
【主题emoji】《【篇名】》教案整理好了，按【单课时／2课时】教学思路设计。
从【情境/导入方式】进入，依次安排识字写字、整体感知、精读品读、读写迁移。
重点带学生理清【结构】，沿【两条线/几个方面】走，品味【关键词语/写法】，读懂为什么是【课文结论词】，完成【表达训练】。

【可选：痛点两行，同 M1 写法】

含【按采用成品填写交付物与课件形态】。

【可选：💫一句备课想法，写成「这份资料里怎么做」】

#标签（第五节双层法）
```

四句分工固定：总述（教案整理好了，按课时思路设计）→ 内容句（教什么、怎么教）→ 重点句（重点读懂什么、靠什么带）→ 落点句（落到哪个语文实践）。四句都写内容要点，不写纯观点，也不写琐碎操作。


**变体 E 商品详情页**（不是笔记）：带价格、立即购买的商品详情页。**四块顺序固定，可整段照抄**，正文零标签，全篇只承载三件事——买什么、懂不懂这一课、能改什么；**清单写在注 1、售后写注 2 退换一句**（2026-11-22 用户约定：直接写「虚拟商品，发货后不支持退换」），领取指引交给变体 F 发货文案，**详情页不写领取渠道、不写「发货方式」块**（2026-11-21 用户约定）。**标题只填一次**：有独立商品标题字段时单列标题，详情直接进内容；只有一个输入框时把商品名放首行。见 8.1。

```
【商品标题字段】四年级上册《【篇名】》完整课件 · 【1课时／2课时】

【商品详情正文】

很多老师上这一课，容易停在「【读者最可能的偏解】」上，忽略【真正的方法／落点】，【学生最可能的卡点】。

【单课时／2 课时】完整教学设计核心要点 👇

■落实【哪部分】教学，重点攻克【读音词语／易错字】，认读【N 个生字】，【正音或辨析】
■教给【方法名】，【几个角度或几步】，落实【哪项课后任务】
■依托【学习单哪一栏】梳理【什么】，读懂【从…到…的变化／几层意思】
■品读【哪一片段】，抓住【什么对比或写法】，体会【哪一处反转／表达效果】
■联系【课文哪处】，读懂【课文结论句／古话】，引导联系生活谈感悟，不空洞说教
■读写迁移，借鉴【课文哪种写法】，练习写【什么片段】，对接【习作／阅读链接】

注：

1、内容包含：【N】课时可编辑课件＋配套逐字稿＋教学设计＋【N】课时学习清单＋板贴

2、虚拟商品，发货后不支持退换，如有问题请在订单内联系客服。
```
