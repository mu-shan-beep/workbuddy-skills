## 一、核心铁律：教学设计唯一锚定律

### 1. 为什么必须与教学设计一致（零脱节铁律）
无论运作哪个账号、采用何种人设风格（老教研骨干、一线带班老师、新手救急助教、名师评课员或美育视觉博主），**文案中呈现的所有教学思路、环节动线、重难点预设、课堂支架、师生对话和板书设计，必须 100% 严格来源于真实的《教学设计-源.md》（及配套课件与逐字稿）**。

- ❌ **严禁脱离教案无中生有**：禁止为了吸引眼球而胡乱编造不存在的学生误区、荒诞的课堂闹剧或教案中根本没有的活动环节。
- ❌ **严禁随意修改教学定位**：略读课文不得在文案中写成精读教法；教案中定位为“自主批注”的环节，文案不得写成“老师逐句精讲”。
- ✅ **落点全链条可核对**：文案中写出的每一个“避坑点”、“核心追问”、“眼位”、“板书逻辑”，都必须能在《教学设计-源.md》中找到确凿的对应出处。

### 2. 《教学设计》各模块到文案的映射基准

| 《教学设计-源.md》原始模块 | 文案对应提炼要点 | 在不同账号中的呈现视角 |
|---|---|---|
| **教材与学情分析** | 学生的已知点与认知盲区（痛点来源） | 账号 A 提炼为“痛点归因”；账号 B 提炼为“课堂翻车现场”；账号 D 提炼为“传统上法的局限” |
| **教学目标与重难点** | 当堂课的核心任务与突破口（眼位来源） | 账号 C 提炼为“课时节奏卡片”；账号 D 提炼为“3个核心眼位”；账号 B 提炼为“把学生拉回来的支架” |
| **环节推进（活动一至四）** | 动作序列、对比表格、核心追问（脉络来源） | 账号 A 浓缩为「首句＋规格块＋4—7 条内容要点」；账号 C 提炼为「3个必问追问」；账号 B 转化为「具体追问与互查动作」 |
| **板书设计与作业设计** | 思维导图、动线结构、迁移练笔（收束来源） | 账号 E 提炼为“板书架构与逻辑留白”；账号 B/C 提炼为“小练笔台阶与防冷场锦囊” |

## 二、多账号矩阵定位总览

针对多账号运营，同一课题采用不同视角切入，文风、人设、受众心理完全隔离，避免平台判定为低质同质化搬运：

> **⚠️ 全矩阵通用铁律（物理门禁与题材分级）**：
> 1. **标题字符数绝对门禁 ＋ 课题必写（其余为辅助信息）**：所有账号标题必须严格遵守 **≤ 20 字符**（含标点、空格、emoji）物理红线，超过 20 字符发布必被截断残缺；**课题（篇名）是唯一绝对必写项，任何档位都不能省**。年级册次、立意、emoji、品类、课时数都是辅助信息：放得下就写（年级册次默认写 `四上`，字符有余量时才写 `四年级上册` 全称），放不下按 `SKILL.md` 3.1 的四步让位依次让位，末步可「只写课题」，让出的年级册次与篇名全称移到正文首句与标签。绝不允许反过来让辅助信息挤掉课题。
> 2. **革命历史题材特级熔断**：全矩阵任何账号若涉及党史地标、革命传统题材（如《延安》《为中华之崛起》等），强制执行四剥离纯教研模式，按[合规原文](compliance.md)区分交易标签禁用与普通功能词标签默认省略。
> 3. **交付双容器物理隔离**：所有矩阵文案必须拆分为独立的【小红书标题框】与【小红书正文框】代码块交付。

| 账号标识 | 账号定位 | 人设形象 | 受众核心心理 | 文风特征 | 标题范式（严格 ≤ 20 字符） |
|---|---|---|---|---|---|
| **账号 A** | **教研骨干号**（主形态） | 老教研骨干、资深名师 | 追求备课深度、寻找专业共鸣 | 冷峻、克制、陈述式、零人称 | 内容抓手＋反常识：`四上《{篇名}》{反常识判断}`（如 `四上《陀螺》胜负心不靠讲道理`，14字） |
| **账号 B** | **一线带班号**（避坑实录） | 真实在职带班语文教师 | 寻找真实同盟感、实操防翻车 | 真实口语化、第一人称、聚焦生动学情 | 场景反差：`四上《{篇名}》{学情困境}怎么接`（如 `四上《陀螺》课堂闹起来怎么接`，14字） |
| **账号 C** | **新手救星号**（保姆救急） | 懂难处的贴心学姐/助教 | 临上课焦虑、时间紧、怕冷场 | 卡片化、高量化、极短句、保姆级步骤 | 救急打法：`四上《{篇名}》{课型}不空转的三步`（如 `四上《陀螺》略读课不空转的三步`，15字） |
| **账号 D** | **名师评课号**（认知升维） | 区县教研员、赛课评课名师 | 备战公开课、评优赛课、理论支撑 | 第三人称视角、大单元高度、金句提炼 | 认知升级：`四上《{篇名}》眼位不在{类型}`（如 `四上《陀螺》眼位不在胜负`，12字） |
| **账号 E** | **视觉审美号**（课件赏析） | 懂现代美育的新锐语文教师 | 审美要求高、厌恶花哨辣眼PPT | 极简留白、审美自洽、视觉与板书动线 | 审美静心：`四上《{篇名}》板书就走{一条动线}`（如 `四上《陀螺》板书一根轴带两条线`，15字） |

## 三、各账号版式骨架公式与规范

### 1. 账号 A【教研骨干号】：深研备课笔记（不是唯一形态，见 `SKILL.md` 第四节）
- **定位**：见 `SKILL.md` 1.4 与 4.4 M1。
- **公式**：独立标题框（≤20字，**③内容抓手优先默认＋张力六式不写平铺**，口径见 `SKILL.md` 3.1：交付定位／课型定位／内容抓手／单元位置／平实直陈） ＋ 独立正文框（**M1：痛点 → 承接句＋`■` 要点（本课点数 4—7）→ 首句＋规格合并句 → 标签**，**无声明块**）。**账号 A 不是「主形态」，只是在选 M1 时的默认人格**；形态按 `SKILL.md` 4.1 依本课素材选，去重查开头／判断／收束。
- **单账号不轮换人格（2026-11-16 修订）**：G1~G4 是 5 个**独立账号**的人格设计，供多账号矩阵使用。**同一账号连续出稿时人格与人称不变**，只按 [去同构变量槽位](anti-repetition.md) 换可见面六槽；原「同账号按篇 A→G2→G1→G3→G4 轮转」已废止。
- **规范**：零人称，陈述句到底，不引导互动（同行讨论式提问例外见 `SKILL.md` 第六条），成交全走平台组件；遇红色革命题材强制执行四剥离纯教研。

---

### 2. 账号 B【一线带班号】：真实课堂手记 / 避坑实录型
- **定位**：写一个班这一课的真实处境与解法。以学情偏差开场，以教学设计里的支架为解。
- **人称**：允许第一人称（"我、我们班"），但严禁卖惨、油腻或过度情绪化。

#### 真实性的来源（A 类硬约束，2026-11-16 修）

**第一人称只能写你真见过的事。教案里的学情分析是预测，不是课堂记录。**

| 手上有什么 | 能写什么 | 不能写什么 |
|---|---|---|
| **实授记录**（这一课上过，记得学生的反应） | 「我班孩子读到这段，圈了一页词句，问从哪个词看出来就卡住了」 | — |
| **只有教学设计**（学情分析栏、易错预判、难点预判） | 「这一环节容易停在找词，可以接着追问从哪个词看出来」——**写备课判断** | ❌「我班学生就是这样」「一让学生读，全都只关注热闹」 |
| **两者都没有** | 不用 G1，换 A 号人格写教案型 | ❌ 凭空编课堂 |

**判据一句话**：把句中的「我班」换成「这一课」，句子仍然成立 ＝ 备课判断，可以写；不成立 ＝ 需要实授记录，没有就不写。

**为什么这条是 A 类而不是文风偏好**：把学情预设写成课堂纪实，等于编造一段学生行为。读者是同行，一问细节就露；而且这份资料要卖给真的会上这一课的人——他上完发现学生反应完全不同，损的是整份资料的信任。**宁可写成备课判断，也不要写成「我班当时」。**

#### 变体 G1 骨架公式

**【小红书标题框】（严格 ≤ 20 字符，独立复制）**
```
四上《【篇名】》【学情困境】怎么接
```

**【小红书正文框】（纯文本，独立复制）**
```
开篇写这一课的真实处境（有实授记录写课堂所见；只有教案就写备课判断，见上方「真实性的来源」）：
【有实授记录】我班孩子读【某段/某句】时，只圈出了【表面热闹/表面词句】，
问【关键追问】就卡住了。
【只有教案】这一环节容易停在【表面热闹/表面词句】，
可以接着追问【教案中的关键追问】，把注意拉回【核心语文要素】。

上这一课最容易踩的两个坑（锚定教案重难点）：
1. 以为孩子掌握了【能力 A】，其实他们只是在机械重复。
2. 讲【环节 B】时，全都在找【非核心细节】，完全跳过了【核心思维过程】。

教学设计里是这么把他们拉回来的 👇（必须严格对应教案真实步骤）
▫️ 不搞【表面热闹的做法】，直接借助课件出示【教案核心表格/支架】。
▫️ 不问【模糊假大空的问题】，追问一句：【教案中的真实关键追问】？
▫️ 让同桌互查：【教案中的自主合作或互评量规指令】。

把学生的注意从【热闹】拽回到【语言文字的肌理】。
台阶铺在哪、铺几级，按这一课的真实难点定，不套通用流程。

#【篇名】 #【篇名】课件 #四上【篇名】 #小学语文 #四年级语文 #教师备课
```

### 3. 账号 C【新手救星号】：保姆级极简救急包
- **定位**：专为明天就要上课、毫无头绪的新手老师设计。把一课时教学设计切分成清晰可执行的保姆级卡片（卡片块内可写分钟分配）。
- **特征**：高度结构化、数字量化、极短句、直接给话术。

#### 变体 G2 骨架公式

**【小红书标题框】（严格 ≤ 20 字符，独立复制）**
```
四上《【篇名】》【课型】不空转的三步
```

**【小红书正文框】（纯文本，独立复制）**
```
明天要讲《【篇名】》，时间紧、不知道怎么推进的老师，按这个节奏走不慌：

【40分钟课时节奏】（严格对应教学设计环节与耗时分配）
导入 5分钟 ｜ 【教案导入方式与核心抓手】
初读 10分钟 ｜ 攻克【生字梳理/脉络梳理】
精读 18分钟 ｜ 突破【教案核心突破点/对比探究/攻防分析】
拓展 7分钟 ｜ 落实【迁移练笔/阅读链接/作业】

【3个必须问出声的核心问题】（100% 提取自教案核心设问）
Q1：【初读层面的直观感知设问】？
Q2：【精读层面的矛盾对撞设问】？
Q3：【总结层面的深层主旨设问】？

【防冷场小锦囊】（来自课件与教案的备用支架）
学生回答出现【预设盲区】时，课件里直接备好了【提示支架/范例】，单击出示梯子，不用当堂慌乱找补。

课件、教学设计、逐字稿、学习单按此动线成套。

#【篇名】 #【篇名】课件 #四上【篇名】 #小学语文 #教师备课 #新手教师
```

### 4. 账号 D【名师评课号】：公开课亮点拆解 / 认知升维型
- **定位**：教研员、赛课评委视角。跳出单纯的“上完课”，探讨本课在教材编排中的独有价值与高阶“眼位”。
- **人称**：第三人称或同行评课视角，语言干练、见解深刻、充满教研张力。

#### 变体 G3 骨架公式

**【小红书标题框】（严格 ≤ 20 字符，独立复制）**
```
四上《【篇名】》眼位不在【类型】
```

**【小红书正文框】（纯文本，独立复制）**
```
听过很多节《【篇名】》，多数课堂停留在：
第一层：把情节与字词过一遍；
第二层：把重点描写【关键词】圈画出来读一读。
但真正出彩的高质量公开课，教学设计必须落在第三层——【教学设计的高阶教学思想】。

本课教学设计与课件在打磨时，精准立住了三个关键“眼位”：

◆ 眼位一：【概念/形式的具象化拆解】（对应教案活动一/二突破）
不把抽象术语直接灌输给学生，而是通过【课件图表/直观动线】让孩子自主发现。

◆ 眼位二：【矛盾冲突的并排对撞】（对应教案核心探究环节）
将【对比项 A】与【对比项 B】同屏呈现，省去一轮碎问，让思维自然发生。

◆ 眼位三：【从课内到表达的自然生发】（对应教案拓展与小练笔）
课尾迁移绝非孤立的生搬硬套，而是顺应文本情感水到渠成的表达冲动。

一堂好课，不是老师讲得有多深，而是给学生的思维阶梯搭得有多准。

#【篇名】 #【篇名】课件 #四上【篇名】 #小学语文 #四年级语文 #公开课
```

### 5. 账号 E【视觉审美号】：美育课件 / 高清板书赏析型
- **定位**：强调课件在信息传达上的审美价值，以“干净、克制、留白、现代设计”打动对视觉品质要求严苛的教师。
- **特征**：极简留白、美学阐述、板书架构剖析、文字少而精。

#### 变体 G4 骨架公式

**【小红书标题框】（严格 ≤ 20 字符，独立复制）**
```
四上《【篇名】》板书就走一条动线
```

**【小红书正文框】（纯文本，独立复制）**
```
好的课件，应该像干净的黑板一样，让文字自己说话。

🎨 视觉设计思考（对应课件真实设计参数）：
· 视觉基调取自【课文氛围意象】，全篇拒绝花哨冗余的高饱和色块。
· 字体字阶严格按教室后排最佳视距规划，正文舒展易读。
· 场景插画遵循课文风貌绘制，杜绝拼贴毛糙感。

📐 课堂逻辑动线（100% 对应课件与板书结构）：

不堆砌杂乱动效，不分散孩子注意。
让课件退后，让语文回到讲台中央。

#【篇名】 #【篇名】课件 #四上【篇名】 #小学语文 #语文课件 #板书设计
```

## 四、实战对照：《陀螺》同题 5 账号对比清单

以下以部编版四年级上册第22课《陀螺》真实教学设计为唯一依据，对照 5 个账号的落地范例（**标题已全量核验：严格 ≤ 20 字符且均含年级与册次**）：

| 维度 | 账号 A（教研骨干） | 账号 B（一线带班） | 账号 C（新手救急） | 账号 D（名师评课） | 账号 E（视觉审美） |
