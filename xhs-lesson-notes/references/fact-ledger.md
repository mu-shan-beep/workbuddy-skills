# 事实台账

> 规则总账（`rule-index.md`）记「该怎么做」，本台账记「这件事到底是什么」。
> **改规则前先查这里**：同一事实会被几个文件复述，只改主规则等于没改——模型最先照抄的往往是示例。
> 建法与用法见 `~/.workbuddy/skills/rule-review/references/fact-ledger-template.md`。
> **投影位置只写章节名，不写行号**——行号会随每次编辑漂移，写死的行号比不写更快失效（2026-11-22 统一）。

## 一、怎么用

```
改一条规则 →
1. 在本表找到对应 F-xx
2. 看「投影位置」有哪几处
3. 逐处改（主规则、模板、示例、自检清单、避坑表，一处不漏）
4. 按本机 rule-review 把上游和各处原文并排核对，有前置条件时验算
5. 只更新实际核过的事实行
```

**用多种说法筛候选，再沿引用核对未命中处**：

```bash
python3 ~/.workbuddy/skills/rule-review/scripts/scan.py <本目录> --fact 交付形态 --same 可画,可编辑,PPTX
```
