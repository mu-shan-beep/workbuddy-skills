# WPS 全家桶 · 适用边界与场景清单

## 一、适用场景（直接调用）
- Word / Excel / PPT 的排版、模板生成、批量合并
- 公文一键套红头、会议纪要要素化
- 批量水印、敏感信息打码（身份证 / 手机号 / 银行卡 / 邮箱）
- 跨文档检索与问答、文档格式转换
- 报表自动化（排序 / 筛选 / 图表 / 公式 / 统计）

## 二、不适用场景（勿调用）
- 纯视觉 / 美学设计（界面美化、配色、动效）→ 用 `前端美学·雕琢大师`
- 后端服务 / 云部署 / 数据库 → 用 `CloudBase云开发·部署官`
- 矢量图标检索导出 → 用 `SVG 图标猎手`
- 复杂 PDF 内页编辑（本技能以 Office 三件套为主，PDF 仅做基础转换）

## 三、运行边界与依赖
- 四引擎自动识别本机已装软件：WPS / MS Office / LibreOffice / 纯 Python
- **纯 Python 模式**无 Office 安装时可用，但仅支持排序 / 筛选 / 图表 / 公式 / 统计，不支持 COM 级排版（红头、水印、打码）
- 需文件系统写入权限；批量处理大文件时注意内存占用

## 四、常见误区
- 误区：没装 Office 也能做红头文件 → 纯 Python 模式做不到，需至少装 WPS / LibreOffice
- 误区：一次处理上千个文件不分组 → 建议分批，避免超时与内存峰值
- 敏感打码后务必二次确认脱敏字段已覆盖
