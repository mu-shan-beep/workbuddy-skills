# 域配置：教学交付

`SKILL.md` 里的机制对任何业务都成立。这一份只补"教学"这一域特有的判据——**换业务就换一份，主文件不动**。

> 本文件是**域配置**；同域的重资产在**同名子目录** `domains/teaching/` 下：`routing.md`（判型样例）、`types.md`（十类件）、`contract.md`（契约字段）、`calibration.md`（五科口径）、`units-and-scale.md`（量纲）。**换业务时这个子目录整个不用带。**

## 1. 加载条件

需求里出现任一条就加载：册 / 单元 / 课 / 学段 / 班级 / 课时 / 课标 / 考试 / 课件 / 板书 / 课堂使用。

一条都不出现就**不要加载**：商业合同、内部工具、纯数据报表不属于本域；硬套教材坐标只会把一份报价单判成 A 级。

## 2. 形态判据

| 要做的动作 | 形态 | 误判信号 |
|---|---|---|
| 转、剖、看内部、跟一遍过程 | 3D 装置 / 机理 | 全片只有一条曲线在动 |
| 建立空间想象（键角、二面角、天体） | 3D 空间 | 一张平面图就能标清 |
| 拖参数、看图形跟着变 | 2D 动态图 | 有第三个空间轴被浪费 |
| 做价值判断、承担后果 | 互动叙事 | 有标准答案，选错能改 |
| 在约束下反复练到熟 | 教学游戏 | 理解一次就够，不需要练 |
| 多变量互相牵制着权衡 | 回合推演 | 单一因果，一步到底 |
| 建立情绪或叙事节奏 | 成片 | 需要当场操作 |

形态由动作决定，不由学科、不由知识点类型。20 个跨科样例见 `teaching/routing.md §〇`。

**判成 3D 的，加载 `domains/3d.md`**（取用顺序、复刻三闸、检查器都在那里，本文件不重复）。

### 2.1 工单的补充字段（本域比通用模板多填这些）

| 字段 | 填什么 |
|---|---|
| 知识点 | 一句话，能对应教材上的一节 / 一个实验 |
| 学科 / 学段 / 教材版本 | 三者必须齐全，决定口径与说法 |
| 页面口径 | 标题、副标题、页脚要出现的版本信息 |

通用模板的三键照填，这三行是**追加**。"受众与场景"在通用块里写教室投影 / 学生平板 / 课后自学即可，不另设字段——重复设字段会让人以为要填两遍。

## 3. 齐备清单（课件类）

一"节课"的组成件六项：**课件本体 / 教师使用卡 / 学生活动单 / 板书图 / 配套练习 / 技术说明**。

这是"一节课"的组成件，不是"一个文件"的组成件。**列不全不许开工**——缺件留到验收才发现，等于整轮返工。

## 4. 查重：路径 + "A 级"怎么算

**四级各在哪**（一律走 `checkup.md §1`：①级零配置现查本机已装技能；③级只在配置了资产根时查。本域不绑定任何具体技能名或样课库名）：

| 级 | 教学域的查法 |
|---|---|
| ① 本地自有 | `sourcing.mjs --grep` 现查本机已装技能——谁能做教学件，看命中技能的 SKILL.md 边界 |
| ② 自有在线 | 自己发布过的学科站（没有就记 `N/A + 理由`） |
| ③ 本地资产 | 已配置资产根里的样课库 / 数据集 / 已拆开源库，按机制找不按名字找；未配置记 `N/A + 未配置` |
| ④ 公共生态 | GitHub / three.js 示例 / 学科素材站 / 教育平台 |

**"A 级"怎么算**：主文件的通用判据是"同对象 + 同问题 + 同关键变量"。教学域里：

- 对象 = 同册、同单元、同课（跨册同题只算 B）
- 问题 = 学生要看到的那件事（不是章节标题）
- 关键变量 = 教材给出的那个变量

三者全中才算 A。

## 5. 口径从哪儿来

- 常量键名走 `teaching/calibration.md` 五科卡，不许裸数字。
- **同一知识点跨学段不能混用**：初中讲法、高中讲法、旧课标设定值各自成立，抄数值就是 B 级以下。
- 常见坑：25 ℃ / 24.5 L·mol⁻¹ 与 22.4 L·mol⁻¹ 这类差一档就错的常数。

## 6. 本域加闸 + 验收岗

**验收岗：按能力现查指定**——用 `inventory.mjs --grep "验收 qa 检查"` 找本机承担"成品验收"的技能；本机没有验收岗技能，就由**不参与执行的任一岗位**按 `baseline.md` 通用四道过，工单里记谁验的。不许自己验自己。

通用四道之外，本域自加**课堂三问**：

1. 40 分钟内投得出来吗？
2. 学生手上有没有对应的活动？
3. 老师不看说明能不能操作？

三问任一否，退回改单。课堂三问写在工单验收线里，不依赖特定技能。
