# 实例：岗位说明书长什么样（`model-parts` · 零件铸造）

> 这是 2026-11-27 按实测缺口立的第一单。**看结构不看业务**——通用招人流程不依赖它的领域内容，换业务时整份换掉。

```markdown
# 岗位：零件铸造 model-parts

## 能接什么
跨领域通用的参数化几何原语，按"件"供给，不按"整单交付"供给。
三个典型：剖切管腔（细胞/血管/气缸）、曲柄滑块（发动机/缝纫机/蒸汽机）、
透镜组（光路/眼睛/相机）。

## 不能接什么
不做整节课（没有步骤/读数/图表）；不做版式（版式归视觉岗，本技能只供几何件）；
不做写实渲染（要质感的派 blender 系）。

## 输入 / 输出契约
- 输入：一个参数对象，例如 `shell({rIn, rOut, y0, y1, gap, seg})`
- 输出：`{ group, anchors, update(t) }`
  - `group`：可直接 `scene.add()` 的 THREE.Group
  - `anchors`：语义锚点表（`piston` / `rodMid` / `pin` / `tdc` / `bdc` / `mouth`），
    供标注系统投影定位，**不许让下游手算偏移**
  - `update(t)`：单一驱动变量的姿态更新，内部不许有第二个时间源
- 硬约束：零依赖（只用 three 核心，不引 examples/addons）；每次调用生成新几何，
  不复用全局状态；所有尺寸按"1 单位 = ？mm"显式传入，不写死。

## 验收线
- 每个件自带一个最小示例页，六闸绿；
- 参数变化 ±30% 不出现自交/翻转/穿模；
- 同一件在两个不同课题里调用，代码零修改（只改参数）；
- `anchors` 投影到屏幕后，标注框不压主体（自动偏移要能算出来）。
```

**为什么是它，不是别的**：`shellGeo` 十四天内在两个产物里各手写一遍，曲轴改四版 —— 命中触发条件 1 和 2。这一单招成之后，下次做血管、做细胞、做冷凝管，都只传参数。
