# 口径卡（按学科分节）

常量不是知识，是**口径**。同一个量在不同学段、不同教材里取值不同，用错就整题错。
写契约时 `from` 填这里的键名；渲染时不要把数字写死在代码里。

新增一科 = 加一节，不改流程。

## 三、生物

| 键 | 值 | 单位 | 适用 |
|---|---|---|---|
| `bio.t_body` | 37 | ℃ | 人体核心温度 |
| `bio.hr_adult` | 60–100 | 次/分 | 静息心率 |
| `bio.ph_blood` | 7.35–7.45 | — | 动脉血 |
| `bio.ph_stomach` | 1.5–2.0 | — | 胃液 |
| `bio.atp_per_glucose` | 约 30–32 | ATP | 细胞呼吸（教材取 38 的版本也有） |

固定反应（写死，不要临时配）：
- 光合：`6CO₂ + 6H₂O →(光能/叶绿体) C₆H₁₂O₆ + 6O₂`
- 呼吸：`C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O + 能量`
- 遗传分离：一对相对性状 F₂ 表现型比 3:1；两对独立 9:3:3:1

高频错：把"光合只在白天"当定律（有光即可）；ATP 数目直接写 38 而不说明版本；把"血液 pH 恒定"说成"不变"。

### 神经生理（HH 参数，枪乌贼巨轴突，6.3 ℃）

出处：Hodgkin & Huxley, *J Physiol* 1952；后续教材与模拟一律沿用这组值，别自己调。

| 键 | 值 | 单位 | 说明 |
|---|---|---|---|
| `bio.hh_Cm` | 1.0 | μF/cm² | 膜电容 |
| `bio.hh_gNa` | 120 | mS/cm² | Na⁺ 最大电导 |
| `bio.hh_gK` | 36 | mS/cm² | K⁺ 最大电导 |
| `bio.hh_gL` | 0.3 | mS/cm² | 漏电导 |
| `bio.hh_ENa` | +50 | mV | Na⁺ 平衡电位 |
| `bio.hh_EK` | −77 | mV | K⁺ 平衡电位 |
| `bio.hh_EL` | −54.4（−54.387） | mV | 漏电流平衡电位 |
| `bio.hh_radius` | 0.025 | cm | 轴突半径（直径 0.5 mm） |
| `bio.hh_Ri` | 35 | Ω·cm | 轴浆电阻率 |
| `bio.V_rest` | −65 | mV | 静息电位（算得，非设定） |
| `bio.V_th` | 约 −55 | mV | 阈值（刺激时长相关，别当常数） |
| `bio.v_cond` | 18–21 | m/s | 传导速度实测；HH 计算值 18.8 |

三条纪律：
- **静息电位不要硬写 −65 再画曲线**，必须让 ODE 自己收敛到 −65；否则改参数时读数与波形会分家。
- **阈值不是常数**，它随刺激时长与膜片大小变。要标阈值就给"多长、多大膜片"，否则只写"阀刺激/阀上刺激"。
- **传导速度要报测法**（哪两点、跨多久、0 mV 还是峰值计时）。同一次仿真换个测法能差 ±20%，不报测法等于没报。

高频错：把 gNa 单位写成 S/cm²（差 1000 倍）；用 25 ℃ 的参数配 6.3 ℃ 的曲线；网格太粗导致速度偏低却当成模型结论（dx 应 ≤ 空间常数 λ 的 1/20，本轴突 λ≈1 cm）。

## 四、数学

| 键 | 值 | 说明 |
|---|---|---|
| `math.pi_3_14` | 3.14 | 小学 |
| `math.pi` | 3.14159… | 初中以上，或直接用符号 π |
| `math.sqrt2` `math.sqrt3` | 1.414 1.732 | 需要近似时 |
| `math.keep_radical` | true | 立体几何答案优先保留根式与分数 |

学段差异：小学取 π=3.14 并接受近似；初中起要求"保留根号"；高中要求化简到最简。
高频错：把 $\sqrt{2}$ 写成 1.41 当精确值；角度与弧度混用；定义域不写就画图。

## 六、使用方式

1. 先读对应一节，把要用的常量键名抄进契约 `model.consts[].from`。
2. 若需要的量不在这里：**先在 `meta.source` 里写清出处，再补进本节**，不要就地写数字。
3. 学段不确定时，按用户给的年段选；用户没说，按教材默认（初中人教）。
