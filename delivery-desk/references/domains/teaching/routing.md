# 路由：四问定类型与载体

## 〇、先判形态，再谈画什么（2026-11-27 整段重写）

**旧版这里写着"默认上 3D，只有三种情况才降级"。这条已作废。**

作废的理由不是 3D 不好，是那个默认值本身错了两处：

1. **它把别的形态定义成 3D 的"降级"。** 互动叙事、教学游戏、回合推演不是"3D 做不了的退路"，
   它们是另一类课。文言文里"要不要告密"这种抉择，3D 做不出来 —— 不是做得差，是无处可画。
2. **它拿"有没有空间形态"当判据。** 这个判据只对"看懂一个东西长什么样"有效，
   对"学生得做个决定""学生得练到熟"这两类课完全失效。

### 唯一判据

> **这节课上，学生必须亲手做的那个动作是什么？**

形态由动作决定，不由学科决定，也不由知识点类型决定。

| 学生要做的动作 | 形态 | 非它不可的理由 | 误判信号（出现就该换） |
|---|---|---|---|
| 转、剖、看内部、跟一遍过程 | **3D 装置 / 3D 机理** | 遮挡、剖切、体积、三维轨迹，缺一条就说不清 | 全片只有一条曲线在动 |
| 建立空间想象（键角、二面角、天体位置） | **3D 空间** | 关系只在三维里成立 | 一张平面图就能标清 |
| 拖参数、看图形跟着变 | **2D 动态图** | 参数→图形就是全部信息 | 有第三个空间轴被浪费 |
| **做价值判断、承担后果** | **互动叙事** | 后果延迟、不可撤销、暴露"我是谁" | 有标准答案，选错能改 |
| 在约束下反复练到熟 | **教学游戏** | 熟练度/策略只能靠重复获得 | 理解一次就够，不需要练 |
| 多变量互相牵制着权衡 | **回合推演** | 决策互相咬合、反馈延迟 | 单一因果，一步到底 |
| 建立情绪或叙事节奏 | **成片** | 剪辑/配乐/旁白本身就是内容 | 需要学生当场操作 |

### 判错的代价不对称

判成 3D 而该做叙事：学生看了一场跟自己无关的动画，40 分钟里最贵的"他做决定"的时间被浪费。
判成叙事而该做 3D：学生缺了空间感，但课文还在，课后能补。

**所以拿不准时先问一句"学生有没有可能在这节课上什么都不用做"。有可能，就别上 3D。**

### 例外

用户明确说"要 3D""做成能转的" —— 没有例外，照做。用户指定了载体就是指定了，不再讨论。

### `carrier.why` 的新写法

三句话，缺一不可：

1. **学生在做什么** —— 动词，具体到"拖动滑块看液面怎么降""选报官还是守诺"；
2. **为什么非得这个形态** —— 这个动作换到别的形态里会丢什么；
3. **这个形态会让什么变难** —— 诚实写，不许只写好处。

写不出第 1 句，说明这一课还没想清谁在学。

## 一、四问：形态已定之后才走这里（3D / 2D 图形专用）

**四问只在 §〇 已把形态定为"3D"或"2D 图形"之后使用。** 形态还没定，先回上一节 ——
这四问问的全是"怎么画"，问不出"该不该画"。拿它当入口筛子，结果永远是 3D。

```
Q1 时间尺度是什么？
  ├ 瞬间（<1 帧）/ 秒级 → 需要"实时态"：单变量驱动 + render(t) 或滑块
  ├ 分级（秒→分）→ 需要时间轴 + 节拍：过程时序
  └ 年/亿年 → 需要"阶段化"：只做 4–6 个关键态 + 过渡，不做连续动画

Q2 空间尺度落在哪一档？
  ├ Å–nm（分子、原子、晶格）→ 必须声明"1 单位 = ?"和"每个球代表 N 个"
  ├ μm–mm（细胞、组织、器件）→ 必须给比例尺，允许剖面
  ├ m（器材、机构、人体）→ 真实尺寸 + 真实单位，禁"随便给 100 单位"
  └ km 以上（地形、洋流、气候带）→ 必须声明投影，禁直接画地图轮廓充数

Q3 要看清的是哪一样？（只能选一个主的）
  ├ 形状 → 3D 或等轴测剖面，主画面是几何
  ├ 数值 → 仪表 + 曲线，主画面是读数，几何退为背景
  ├ 过程 → 时间轴 + 状态切换，主画面是"现在到哪一步"
  └ 关系 → 图/网络/坐标系，主画面是连线与坐标

Q4 观众是看进去还是看明白？
  ├ 看进去 → 允许剖切、镜头推进、景深；一镜一事
  └ 看明白 → 固定机位、标注齐全、每步一句结论；禁炫技
```

四问的答案合起来直接给出 `type` 与 `carrier`。**不要用学科当键**，否则"心脏""洋流""电路"都会卡在分类上。

## 二、载体选择表

| 载体 | 什么时候必须用它 | 什么时候不能用 |
|---|---|---|
| three.js 3D | 需要空间关系、剖切、透视、真实体积 | 只有一条曲线或一组读数 |
| 等轴测 SVG | 要打印、要选中文字、要"器材感"、件数多但静止 | 需要真实透视、需要大量粒子 |
| 2D canvas | 曲线、光路、受力图、坐标图、地图图层 | 需要遮挡关系与体积 |
| WebGL shader | 火、烟、水、光、焦散、辉光 | 能用线条画清楚的 |
| DOM 图表 | 数据表、柱状/折线/散点、进度 | 需要空间运动 |
| 视频/序列帧 | 必须交付成片（课赛、公众号） | 课堂现场交互 |
| **互动叙事** | 学生要做抉择、承担后果、想看"换一种选法会怎样" | 有唯一正确答案；后果可撤销 |
| **教学游戏** | 要练到熟：词汇、运算、分类、反应、策略 | 理解一次就够；不用知识点也能赢 |
| **回合推演** | 多变量互相牵制，一步错要几回合才显出来 | 单一因果链；没有真正的权衡 |

## 四、判不准时的兜底顺序

1. **先问"这一课有什么是非 3D 不可的"**：管壁、腔体、遮挡、剖切、三维轨迹、体积——只要有一条，就上 3D。
2. 一条都没有，再对照上面三条降级条件；命中哪条就写进 `carrier.why`。
3. 仍然判不准 → **上 3D**。错在 3D 只损失一点效率，错在 2D 会把"空间是知识点"的课讲成图表课。

## 五、3D 课的硬成本（提前算，别中途崩）

- **库要内联**：`three.min.js` 654 KB，单课 700 KB 左右，远在 3.5 MB 上限内；不要用 CDN（断网就废，G-E 直接判死）。
- **内联库会污染 G-D**：three.js 内部有 `Math.random`。检查器已支持 `<script id="vendor">` 整段排除，打包时必须给库加这个 id，否则五闸永远过不了。
- **几何要程序化**：管、壳、腔一律用参数化 BufferGeometry（自己写环与索引），不要手摆顶点；否则改一个尺寸就要重做。
- **颜色与位置同源**：膜色、环位置、粒子位置全部从同一份仿真帧里取，禁止在渲染层另算一份。

## 六、投影硬指标（G-F，2026-11 返工事故后补）

一次真实返工：课件做成 1024×768 流体布局，投到宽屏只占左上角，右侧三分之一是空的；正文 9–11px、滑块拇指 13px、浅灰字对比度 3:1，后排学生看不见。**"能读数"不等于"能上课"**，从此单独设闸。

三条可量化的账（`scripts/check_model.mjs` 的 G-F 会自动查）：

1. **画布写死 16:9**，最小 1280×720，推荐 1600×900。`#app` 上必须写死 `width/height` 的 px 值；流体布局在投影仪上必翻车。
2. **屏幕字号下限 16px**。换算依据：1024px 投 2 m 宽时 1px≈1.95 mm，16px≈31 mm 字高，按"字高≥观看距离/200"够 6 m 内看清。教室后排 8–10 m 的，把关键读数做到 28–34px。
3. **画布内（canvas）文字按 2 倍备份绘制**，所以代码里 `ctx.font` 的字号下限是 32px，等于屏幕 16px。

2026-11-27 又补两条（同一节课上连着翻车）：

4. **写死 16:9 之外，还必须整体自适应**。写死画布只保证"画得准"，不保证"装得下"：Windows 125% 缩放下视口只有 1344 px，
   写死 1600 的页面右侧被硬切——**整块读数卡（H₂/O₂ 体积）消失**，比字小更致命，这节的证据直接没了。
   做法固定三行：外层 `#stage` 用 flex 居中 + `overflow:hidden`；内层 `#app` 保持 1600×900 不动；
   JS 里 `scale = min(innerWidth/1600, innerHeight/900)` 写到 `#app.style.transform`，`resize` 时重算。
   注意：窄窗口下整页等比缩小，字会低于 16px —— 这是"宁小不裁"的取舍，投影全屏（1920）时 scale>1，字反而更大。
5. **过程要看得见在变**。600 s 的驱动量按 60× 播完只要 10 秒，读数在跳、画面像静态图，学生会直接问"这个过程呢"。
   规矩：**总时长 25–40 秒播完（15–24×）**；并且**动画量与读数不许共用一个时钟**——
   读数走模拟时间（`t`），气泡/粒子走真实时间（`anim`），否则播放倍率一变，气泡就变成闪噪点。

6. **浅色面板必须过"投影劣化"这一关**。正常截图永远看不出对比度问题——屏幕上看清爽的白卡，投出来是一块会发光的糊。
   判定模型（`scripts/proj.mjs`）：对比度 `.82`、亮度 `1.07`、饱和 `.88`、再压 17% 白雾（模拟开灯教室 + 投影仪黑位抬升 + 白墙反光）。
   过线标准：**卡片边界仍分得清、图表网格仍看得见、正文不糊**；只保住主读数的算不及格——那是"能读数但不能上课"。
   经验色值（白底）：正文 ≤ `#46564F`（约 8:1），次要文字 ≤ `#3A4A45`，图表网格 ≤ `#C6D5D0`，
   卡片边框 ≤ `#AFC2BC`，纸底从 `#E9EFEC` 起（纯白大面积会眩光，反而压暗字）。
   命令（必须放在装了 playwright 的目录里跑，ESM 的 `node_modules` 按文件位置解析）：

   ```
   node proj.mjs "file:///绝对路径/xx.html" "P-投影模拟-xx.png" 1600 900 2000 "#3"
   ```

   产出文件名**必须以 `P-` 开头**，G-F ⑥ 靠这个前缀认它，且要求不比 html 旧。

   **深色（暗室）要另换一套账**，不能把浅色反着刷一遍：黑位抬升是主要杀手（纯黑会显脏，用 `#0F1A17`）；
   卡片靠边线分组（阴影在深底上无效）；品牌蓝必须提亮（`#0F5E86` 在深底会沉下去，用 `#63B4D8`）；
   3D 件的深色材质**从调用处传**，别改件的默认值（件要服务两种主题）。可直接抄的色板：

   | 位置 | 深色 | 浅色 |
   |---|---|---|
   | 纸底 / 卡片 / 边 | `#0F1A17` / `#172722` / `#33463F` | `#E9EFEC` / `#FFFFFF` / `#AFC2BC` |
   | 主文 / 正文 / 次要 | `#EAF2EF` / `#C3D4CE` / `#93A8A2` | `#0F1C19` / `#2E3D38` / `#46564F` |
   | 品牌蓝 / 强调橙 | `#63B4D8` / `#F08050` | `#0F5E86` / `#C6481C` |
   | 图表网格 | `#233530` | `#C6D5D0` |

   暗室模型用第 7 个参数切：`node proj.mjs <url> "P-…png" 1600 900 2000 "#3" dark`
   （`contrast .9 + brightness 1.03 + 6% 白雾`；不传则按开灯教室 `contrast .82 + 1.07 + 17% 白雾`）。

配一条纪律：**先截图，再跑闸门**。G-F 会检查同目录是否存在比当前 html 更新的 `.png`；没有就判失败。理由是这条闸门本身就是靠看像素发现的——结构全绿、页面全废的情况真实发生过（一个少了 `position:absolute` 的控制条被排到 y=0，压在页眉底下，任何字段检查都查不出来）。

字号之外还有两条软指标（闸门查不了，靠自觉）：

- **量级差**：一屏里最大的字与最小的字至少差 3 倍，主读数才抓得住眼睛。
- **模型占画面**：主体（机器/结构）垂直方向占 60–70%。高瘦对象（单缸机、试管、单摆）注定占不满宽度，别为了填满去压扁比例——用**标注引线**把两侧空白变成教学内容。
