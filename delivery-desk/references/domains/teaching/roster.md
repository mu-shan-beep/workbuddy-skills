# 承包商实测档案（教学域）

> **这是教学域台账，不是通用台账。** 现有 8 家档案全是 3D / 教学承包商，待招 11 岗也全是教学岗。换业务另建一份 `<业务>-roster.md`，由域配置引用；通用层只说"查域台账"，不直接点这份。

**这不是路由表。** 想知道"今天谁能接活"，先跑 `node scripts/inventory.mjs` 现查（新装的技能会自动出现）；本文件只用来查"它试过什么、接不了什么、踩过什么坑"。查的顺序：**能力边界 → 接单前必读 → 验收线归谁**。

本文件只记实测过的事实，不重抄 description。没实测的标 ⬜，实测过的写清"接不了什么"——那一条最值钱。下文的"家底"表是 2026-11-27 快照，**会过期，不作派活依据**。

三条使用纪律：

1. **看边界，不看标签。** "能做机械"没有信息量；"能做它已建的三台机器及其同构件"才是可执行的判断。
2. **接单前必须整读它的 `SKILL.md`**，不许凭这张表的摘要派活 —— 摘要只用来筛人，不用来指挥。
3. **验收线优先用承包商自己的。** 它写了"标签不小于 34px"，就按它的标准查；冲突时以更严的那条为准，并记进工单。

## 二、逐家档案

### teardown ✅ 已实测

- **能接**：真实机械装置的交互 3D（发动机、起落架、连杆机构）；要求"剖开看内部""跟着节奏看一遍"；顺手能出带音轨的成片。
- **边界（实测）**：
  - 它的机器几何是**手写件**：`v8-shared/engine.js` 29,511 B，没有缸数参数。想在 V8 上改单缸，等于重画。
  - 版式锚在 1080×1350 的成片画幅：放到 1600×900 时字号会缩到 2/3，图注实测 **6 px**，课堂后排看不见。
  - 构建要 `npm install`，截图必须走 Playwright + SwiftShader（`chrome --headless` 直截是空白页）。
- **接单前必读**：它的 `SKILL.md`（七条硬规则：从参考物起步 / 真数字单一来源 / 一个输入驱动全部 / 干活件要能剖开 / 亮棚加单一强调色 / 相机按机构选 / 碰撞用数字修）。
- **验收线**：它自己的（1600×900、标签下限、contact sheet 复核）**叠加**本技能六闸（投影那条会判它不合格，需要在工单里写明"课堂版"改法：字号按 16px 下限重排）。

### interactive-3d-lesson ✅ 已在用

- **能接**：中学理科单个知识点的单文件 3D 课件；要"能投影、能拖动、有步骤"的常规课。
- **边界**：它是**基座**不是专家 —— 几何要自己给（这正是它 54 节里每节都重画的原因）；复杂机构（多杆、凸轮）不如 teardown。
- **接单前必读**：`SKILL.md` + `references/sourcing.md`（查重方法）+ `references/fusion-ledger.md`（哪家的什么被吸收进来了）。
- **验收线**：本技能六闸。

### anatomy ⬜ 未实测

- **能接**：器官、关节、细胞器、组织的**结构图解**（等轴测 SVG），标注体系成熟。
- **边界**：SVG 平面图解，不是 three.js —— 要"能转、能剖、能看体积"的，它接不了，得换 3D 承包商。
- **接单前必读**：`SKILL.md`（它的图元构造法与标注规范）。

### edulab 系（edu-solid-geometry / edu-analytic-geometry / edu-chem-reaction / *-video / edulab-pro）⬜ 未实测

- **能接**：**单题、单知识点**的交互网页或讲解视频，带分步解析、KaTeX/公式同步、动态参数滑块。
- **边界**：题目级，不是课节级。一节课的导入、活动、小结它不管 —— 那是工单里 `steps` 的事，要自己补结构。
- **接单前必读**：对应 `SKILL.md`，确认它要什么输入（题面文字 / 上传题目图 / 随机出题）。

### wang-motion / huashu-art-motion ⬜ 未实测

- **能接**：已有素材的成片（图片卡片动效、口播整片、解说动画）。
- **边界**：出片，不是课堂现场交互。要"学生自己拖"的，别派给它们。

### blender-skill-harmonizer ⬜ 未实测

- **能接**：需要 Blender 管线的高精度外形（复刻实物、要渲染质感）。
- **边界**：产出是模型/渲染，不是网页。要用在课件里还得走一次"导出 → 内联"的转换，工时按两天起算。

### №1 已招：零件铸造 `model-parts`（首单实测边界）

- 上岗凭证：`样例-电解水/电解水-3D.html`，六闸全绿；`__READOUT__` 与手算逐位一致（t=360 s → 20.89 / 10.45 / 2.000）。

  外加 `placeLabels`（投屏标注自动排布）、`addTicks`（刻度）、`lcg`（固定种子）。
- **能接**：玻璃器皿 / 管腔 / 液面 / 刻度 / 剖切壳 / 活塞连杆这类"旋转体 + 板"的东西，只改参数即可。

### №4 已招：课题拆解师 `lesson-architect`（2026-11-27，用户点名）

- **能接**：给定课题（学科/学段/教材位置）+ 可选在制产物，输出《课题拆解单》六节：

  技能型课题（实验操作、体育动作）的证据链模型不适用，要换"动作分解 + 常见错误"结构。
- **接单前必读**：它的 `SKILL.md`（五步拆解法 + 科学性硬检查六条）
  + `references/chain.md`（证据链"现象→排除→结论"三格画法、40 分钟环节模板）
  + `references/lesions.md`（24 条病灶，分 A 科学性 / B 结构 / C 体验）。
- **验收线**：拆解单四条自查——证据链每格都能落到环节表的"课件要出现什么"；
  每条病灶都写"落到哪个环节"；P0 项对应硬检查编号；§5 有明确落点句。
- **实测（首单 电解水）**：模型六闸全绿、读数 20.89/10.45/2.000 全对的情况下，仍拆出 **4 条 P0**：
  ① 纯水几乎不导电，课件未交代需加硫酸钠（学生照做必失败）；
  ② "水由氢氧组成"缺元素守恒那一格（推理不闭合）；
  ③ 体积比 → 分子个数比被写成"因此必然"（实为印证，需阿伏伽德罗定律，初中不讲）；

  另有 5 条 P1（氢气前备缺失、爆鸣与燃烧混作一个判据、实际比值略大于 2 未声明、
  单质/化合物落点缺失、方向映射无口诀）。
  **结论：模型正确 ≠ 课成立。** 这条边界是它最值钱的资产。
