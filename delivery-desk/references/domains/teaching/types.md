# 十类对象：内核、载体、硬律、最小骨架

每类只守**一条**律。不是别的都不管，而是这条一旦破了，画面再好也是错的。

## 1. 刚体机构

- **判据**：由刚性件与铰接组成，位置由少数几个自由度决定（连杆、齿轮、凸轮、滑轮组、折叠架）。
- **内核**：闭式运动学。一个驱动量 → 全部位姿。约束写成方程，不写成关键帧。
- **硬律**：**杆长与闭环不变**。任意两铰点间距在整个运动范围内恒定（误差 < 0.1%）。
- **怎么验**：在 5 个驱动值上，打印每根杆的长度，最大偏差 / 原长 < 1e-3。
- **最小骨架**：
  ```
  for t in 0..1:
     θ = f(t)                      // 唯一驱动
     P = solve_closed_form(θ)      // 解析或两圆求交，不迭代
     assert max|‖P[a]-P[b]‖ - L| < 1e-3·L
  ```
- **常见错**：用关键帧硬摆（改一个尺寸全崩）；用迭代逼近且不收敛检查；多驱动量互相打架。

## 2. 连续介质

- **判据**：液体、气体、颗粒堆积、扩散、压强、浮力、层流。
- **内核**：守恒 + 场。质量/能量进出必须记账；空间上可用格点或粒子，但总量要对。
- **硬律**：**质量/动量守恒**。投入 = 存量变化 + 流出。
- **怎么验**：每个时间步累加进出量，与存量差比对，相对误差 < 1%。
- **最小骨架**：
  ```
  for step:
     inflow, outflow = flux(boundary)
     store += inflow - outflow
     assert |store - expected| < 0.01*expected
  ```
- **常见错**：粒子凭空生成/消失；液面高度与体积关系对不上；把"看起来满了"当守恒。

## 3. 微观粒子

- **判据**：原子、分子、离子、晶格、电子排布、细胞器级别的结构。
- **内核**：结构 + 规则。几何由键长/键角决定；运动由规则驱动（振动、迁移、碰撞）。
- **硬律**：**原子/电荷计数守恒**。左右两侧元素与电荷数量必须相等。
- **怎么验**：解析场景数据，按元素计数比对；电荷总和为 0 或等于外加。
- **最小骨架**：
  ```
  before = count(atoms, side='left')
  after  = count(atoms, side='right')
  assert before == after          # 每种元素
  assert sum(charge) == 0
  ```
- **常见错**：只画"看起来像"的球棍，键长随手给；每个球不加"代表 N 个"的声明；离子电荷漏标。

## 4. 场与波

- **判据**：电场、磁场、光路、声波、水波、地震波、热传导。
- **内核**：场方程或射线。能用闭式就用闭式（成像、折射、反射）；不能就解方程。
- **硬律**：**边界条件成立**。在界面处，方向、相位或强度的跳变符合物理（折射定律、反射角、连续性）。
- **怎么验**：取 3 条特殊光线/射线手算交点，与程序结果比对（位置误差 < 1 px）。
- **最小骨架**：
  ```
  for ray in [parallel, center, focus]:
     hit = intersect(ray, surface)
     out = refract_or_reflect(ray, hit, n1, n2)
     assert |snell(hit)| < 1e-6
  ```
- **常见错**：三条特殊光线不共点（说明公式或坐标错了）；只画一条"示意光线"；把像画在"看起来对称"的位置。

## 5. 几何度量

- **判据**：立体几何、解析几何、投影、距离与角度。
- **内核**：符号运算（sympy 优先）。答案保留根式与分数，不落浮点。
- **硬律**：**符号恒等**。同一步骤的不同算法给出同一表达式（simplify 后差为 0）。
- **怎么验**：`simplify(a - b) == 0`，且答案与教材标准答案符号一致。
- **最小骨架**：
  ```
  A = solve_by_vectors(...)
  B = solve_by_coordinates(...)
  assert simplify(A - B) == 0
  ```
- **常见错**：坐标交换引入镜像（det = -1）；浮点四舍五入后当成精确值；只验数值不验符号。

## 6. 过程时序

- **判据**：有明确阶段与计量关系的流程（化学反应、光合、消化、地质循环、工艺流程）。
- **内核**：状态机 + 计量。阶段用状态表示，每阶段的进出量用配平/守恒算。
- **硬律**：**计量守恒**。每阶段的输入 = 输出 + 累积（元素、能量、物料）。
- **怎么验**：对每个状态做一次账，误差 < 1%；配平用符号解而非试算。
- **最小骨架**：
  ```
  state = init()
  for stage in stages:
     state = transition(state, stage)
     assert balance(state) < 1e-6
  ```
- **常见错**：阶段之间"跳过去"而不交代物质去向；配平靠猜；把速率与平衡混为一谈。

## 7. 统计关系

- **判据**：函数、分布、比例、相关性、概率。
- **内核**：解析或统计。公式显式写出来，参数可调。
- **硬律**：**定义域与单调性**。曲线在定义域外不画，单调区间与实际一致。
- **怎么验**：取 3 个点手算代入；检查端点与渐近线行为。
- **最小骨架**：
  ```
  for x in domain:
     y = f(x, params)
     assert is_finite(y) or x in singular_points
  ```
- **常见错**：把离散数据画成连续曲线而不说明；坐标轴不从 0 起却不标断轴；概率和不为 1。

## 8. 空间地图

- **判据**：地形、洋流、气候带、行政区、天体位置。
- **内核**：投影 + 图层。先定投影，再叠图层；比例尺必须显式。
- **硬律**：**投影一致**。同一要素在缩放/平移后位置关系不变；经纬网与图形对齐。
- **怎么验**：取两个已知点，量算距离与真实距离比对（误差 < 5%，或声明为示意）。
- **最小骨架**：
  ```
  project = make_projection(kind, extent)
  for layer in layers: draw(layer, project)
  assert scale_bar and graticule_aligned
  ```
- **常见错**：拿一张图当底图直接画箭头（投影不明）；没有比例尺；把示意当精确。

## 9. 生物结构

- **判据**：器官、组织、系统、细胞结构——以"里面有什么、谁包着谁"为主。
- **内核**：剖面 + 层序。件数与包含关系是主要内容。
- **硬律**：**包含不穿模**。子结构必须完全落在父结构内，相邻件不互相穿透。
- **怎么验**：件数清点一致；逐对检查包围盒包含关系；剖面处不出现"悬空"。
- **最小骨架**：
  ```
  for child in children(parent):
     assert contains(parent.bbox, child.bbox)
  assert no_pair_overlap(siblings)
  ```
- **常见错**：件数随手加减（学生数不出来）；剖面切开后内部件"漂浮"；用相机角度掩盖穿插。

## 10. 抽象机制

- **判据**：电路、算法、协议、信息系统、逻辑结构——拓扑与状态为主。
- **内核**：状态流。节点与边是结构，动画是"当前状态走到哪"。
- **硬律**：**状态可达**。每个显示的状态都能从初始态经合法转移到达；不存在"跳变"。
- **怎么验**：录一遍状态序列，逐步检查转移合法性；非法转移直接报错。
- **最小骨架**：
  ```
  s = init
  for step in steps:
     assert (s, step.next) in edges
     s = step.next
  ```
- **常见错**：动画跳跃（视觉上"瞬移"）；边与节点不对应；把实现细节当机制讲。
