# 制作、验证与交付

## 最小样例

本阶段必须在用户已确认教学脚本、整体 UI 界面图、建模预览图和建模方案后开始。读取 [逐步确认与预览规范](stage-approval.md)，分别检查两类图的版本与确认范围。简单模型也不能跳过预览。

先实现核心规则、一个操作对象、一个观察结果和一个学习回合。优先暴露空间风险：运动是否只在单切面、剖面是否有内部、关键结构是否被遮住、目标设备是否可用。通过后才扩展模块、图层、任务和视觉细节。

默认只开当前任务所需图层，标签邻近部件；颜色同时配文字或形状。主要操作有真实指针、适用的触控及键盘或原生控件替代；悬浮提示可点击/聚焦，拖拽任务有等效操作。明确视角复位和实验复位的区别。时间模型支持暂停、单步或稳定状态。

## 课堂投影布局检查

执行技能正文的“中间观察、两侧操作”原则。桌面检查1024×600、1280×720和1600×900窗口，若已约定目标设备则一并覆盖。实际点击播放、调时间、改参数、切换参考系、显隐读数及揭示结论，确认常用操作无需页面滚动，关键模型与参考物不被控件遮挡，场景不因面板展开而跳位。检查所选时段起点、中间态和终点，不能只验收静止首屏或无横向溢出。对照时核对同刻、同尺度及共享播放状态。记录真实截图与未测范围；不以静态设计稿代替运行验证。

## 响应式与手机验收

默认加入手机竖屏360×640、390×844及横屏640×360视口；检查断点前后的中间宽度，不只验证几张固定尺寸截图。按技能正文的最低支持尺寸验收，不能只靠整页缩放或隐藏溢出来掩盖控件被裁切。

实际用触控方式完成播放/暂停、修改主要参数、调时间、揭示读数、打开和关闭工具、恢复视角。检查文字和点击区域、画布与标签、滑杆手势、页面横向溢出、安全区和可用高度。窗口变化与横竖屏切换前后比对时刻、参数及揭示状态，确保画布更新后模型比例正确、关键对象可见。对照在小屏可改为同刻切换视图，不能将两个画面缩小到无法观察。

记录浏览器、模拟视口和触控配置；可用真机时再覆盖移动浏览器实际地址栏、旋转和手势。没有真机证据就注明“通过移动视口模拟，未做真机验收”。性能用实际运行结果说明，必要时降低装饰细节和渲染采样，不以删除教学机制作为手机适配。

## img2threejs 接口

复杂或精细造型默认读取已安装 `img2threejs/SKILL.md`，以用户已确认预览及可靠参考进入建模，本文不替代其完整流程。基础几何和简单示意模型优先用 teachable-figures；路线及理由在预览阶段明确并获用户确认。

传入：已确认预览的版本及路径、参考资料、身份关键轮廓和结构、允许的风格化、教学部件编号、枢轴/连接关系、观察与动作、目标设备。生成预览确定视觉目标，教材等依据约束知识和结构正确性，两者不能相互替代。

按当前技能的 `forge/next.py` 入口检查或初始化本次重建状态；建立质量约定与雕塑规格，遵循体块、结构、形体、材料、灯光、交互、优化的分阶段流程。开始、恢复和修正继续经过状态入口，保留上游质量门槛和有界修正限制；硬停止不绕开。

每轮参考图和实际渲染对照，验证关键特征、多角度和连接关系；不以总体分数掩盖关键部件错误。展示本轮渲染与问题修正，用户确认后才开始下一轮。单张图不能保证背面精确。形体检查不替代学科正确性。

接收：可集成模型工厂、稳定部件身份、坐标/单位、枢轴和连接点、可操作层级、假设与检查记录。导出使用上游实际能力，不为换格式重建第二套模型。

教学状态驱动模型动作。可点击、可拆解等模型能力按需进入课件界面，不把所有能力都堆给学生；观察性拆解与具有教学后果的拆装区分。

## 分层验收

| 层次 | 实际动作与证据 |
|---|---|
| 资料与知识 | 核对结论、公式、单位、术语与范围；记录依据及待教师核实项 |
| 模型规则 | 检查初始、边界和关键中间值；独立计算或依据规则核对；相机不改答案 |
| 学习路径 | 实际选择典型误解，完成预测—操作—观察—解释，检查一个新情境 |
| 形体视觉 | 对照建模图检查轮廓、特征和材料，对照已确认 UI 图检查布局、文字、控件与遮挡；看过实际渲染截图 |
| 真实操作 | 实际点击、拖动、键盘、切场景、任务、提示、复位、暂停，检查控制台与资源错误 |
| 环境交付 | 目标设备、窗口、启动方式、断网冷启动及约定备用路径，记录环境与未测范围 |

使用项目现有工具或可用浏览器能力；本地网页实际交互测试按 `webapp-testing` 执行。直接调用状态函数不替代界面操作。3D覆盖有意义的多个视角及运动中间态；机械模型另查连接、接触、间隙、穿插和拆装路径。声称完整几何审计时按所选工具执行完整范围；快速或局部检查只报告相应范围。

减少动态效果时仍能学习，画布旁有文字结果；关闭或离屏时停止不必要的动画和监听。性能从实际场景和设备测得，记录加载与交互表现，不套文章的体积或工具的帧率。手机按上述响应式与手机验收执行，不再作为默认忽略的可选目标。

## 离线与压缩

单HTML优先而不强制，内联不合适时提供完整本地资源包。需要本地服务就明确启动步骤，不声称双击即用。Three.js、贴图、字体、音频和解压库均计入依赖。断网冷启动不得依赖CDN、远程TTS、线上模型或已有缓存；实测后才标记离线通过。

先优化资源与几何，再按实际收益压缩。base64不是压缩。gzip/运行时解压仅在实测收益与兼容性支持时使用，检查不能解压时的回退，不固定案例中的MB、帧数和超时。

明确要求链接时才做对应发布，保留已有文件和链接约定。线上与离线分别验证，不能由一个推断另一个成功。

## 交付

完整课件、验收候选都需分别展示并获得确认。最终只打包用户已确认的候选版本；打包自查发现实质变化时返回相应阶段重审。

交付可运行入口、完整依赖或自包含文件、可修改源码，以及短说明：目标、操作、假设、启动、测试环境、限制和恢复默认状态的方法。这些是随附资料，不另做PPT或宣传文档。

知识错误、模型/画面/答案矛盾、核心任务无法完成、目标设备打不开必须修复。关键内容待核实、视觉未达到要求或核心运行未测时标为草稿或部分验证。只有学习者实际解释和迁移证据才能支持学习效果判断。
