# 教学与模型约定

这是设计记录，不是强制 JSON 结构。已有应用沿用其类型，额外作者说明另存，不静默增加顶层字段。

## 单元设计卡

每个单元记录以下信息：

| 项目 | 约定 |
|---|---|
| 编号、标题、资料位置 | 稳定知识点编号，能追溯教材或材料位置 |
| 学习者和场景 | 学段，教师演示或学生自学；先备知识注明教师说明、诊断所得或暂定假设 |
| 核心结论与目标 | 一句话结论，学生能完成的行为和对应检查任务 |
| 误解与预测 | 可能误解及依据；问题、选项和判断依据；预测阶段隐藏答案线索 |
| 操作 | 改变的原因或可操作结构；通常2—4个主要教学控件；首次比较固定什么 |
| 观察 | 部件、读数、单位、前后对比；每步看哪里；术语与部件对应 |
| 有效尝试 | 怎样算完成一次有意义的实验或观察，而非任意点击 |
| 解释与反馈 | 合格解释必须包含的关系；不同误答对应不同反馈 |
| 练习与迁移 | 提示何时撤掉；独立练习和一个新情境，不只是重复原题 |
| 模型边界 | 规则、初始状态、合法范围、单位、简化、示意参数与不适用情况 |
| 表达与来源 | 渲染方式、参考形体、模型来源、关节和坐标约定 |
| 预览与确认 | 整体 UI 界面图、模型视图与关键状态、模型分支及理由；两类图的版本、路径和用户确认范围 |

## 场景差异

教师授课：大舞台、少文字、教师控制焦点和答案。预测、解释可通过口头或课堂活动完成，不强制增加学生输入表单。教师主导时不自动朗读整屏。

学生自学：未知先备条件时用少量诊断题探查；内置误解反馈，从有支持练习过渡到独立练习，再迁移。重复答对原题不等于迁移。

## 分别选择机制与表达

- 参数、分布、曲线、流程和计算：优先 SVG/DOM/二维 Canvas，直接比较原因和结果。
- 简单设备、开关、抽屉和仪表：等距图解即可时不升级复杂三维。
- 遮挡、空间几何、关节、剖面和装配：视角或空间状态提供必要信息时选真三维。
- 简单结构：使用 teachable-figures 的合适表达，先绘制并确认结构预览再建模。
- 复杂或精细造型：默认使用 img2threejs，以已确认建模预览和可靠资料为输入；单图未显示的背面结构明确为假设。
- 不规则生物体或复杂曲面：使用忠实建模或有来源的合适网格，不用通用球盒拼接冒充精细形体。显式要求程序化图像重建时不静默改为下载模型。

用户明确要真3D时尊重选择；不适合或资料不足时说清具体原因并提出替代，不能静默交付伪三维。教学模型与工程/医学仿真精度分开声明。

## 模型与显示状态

按需分开内容配置、教学状态、规则函数、场景、界面和讲解轨道，不强制增加工程层数。

规则负责初始状态、输入处理、时间推进和派生结果。答案由规则或可靠题目依据产生；相机、标签布局和观察用爆炸图不能偷偷改数值或答案。理想/复杂模型切换应解释新增假设；不合法旧状态需明确转换或复位。

画面、读数、标记、答案和讲解上下文随状态一致更新。缓动只是显示过渡，时间推进依赖经过的时间，避免帧率改变实验速度。随机模型分开显示理论分布与采样结果，支持可复现对比，不凭一次随机结果证明一般结论。

机制可复用，学科事实、形体、公式和评价需重新确认。换学科不是只替换名词；用稳定知识点编号关联场景、任务、术语、讲解和验收证据。
