# 搜索关键词 风格拆解与预览绘制

本用户的样稿与正式绘制先遵守 [lesson-pack.md](lesson-pack.md)。教案包已经指定默认半写实童话绘本、水彩与水粉方向，可直接制作样稿，不以缺少另一份风格图片阻塞；确认样稿后每次调用实际复用同一份单页主参考，不能凭文字风格名猜测或用未确认的新图逐页替换。样稿/批次确认点优先于以下通用自动衔接说明。

三个环节可独立调用，也可服务同一完整委托。大纲阶段提供所需参考搜索关键词；独立收到风格图而没有制作委托时只做第11条拆解。已经要求绘制或整套制作时，必要参考分析属于制作内部步骤，不强制先交一份拆解报告或再等一句“继续”。用户明确只拆解、等确认或暂停时，按该停点执行。

仅借鉴配色倾向、字体气质、插画笔触、材质和疏密节奏。根据本课内容独立构图，不照搬参考图的文字、人物、图案、具体布局和装饰组合，不以换字换图复刻整页。官方模板、批准的本项目页面及可画拆层修复仍按其保真要求执行。

## A 大纲阶段给搜索关键词

结合课题、学段和课堂任务，分别给出风格、排版两组简短且可直接搜索的关键词，通常每组3至5条，不堆砌空泛形容词。

- 风格参考可按“学段或题材＋视觉媒介＋具体表现”组合，如“小学语文 儿童绘本 平面插画 柔和配色”“科学课堂 科普杂志 线描插图”。
- 排版参考关注视觉层级、留白和阅读节奏，如“语文阅读 原文批注 页面设计”“课堂实验 步骤流程 留白排版”。寻找的是风格启发，不是待复制的构图。

实际关键词随课题变化，不能默认所有学段都适合儿童绘本。关键词放在大纲正文之外的独立复制区域，不占幻灯片页码，不插入逐页文字；用户明确只要纯大纲时不附。无需先收到参考图才能完成大纲，不在该阶段绘图。

已有足够参考、指定模板或批准风格时不重给关键词，不为走流程再索取图片。没有经过大纲阶段也可以直接进入有足够输入的任务，无需补做整份大纲。

可简短说明用户接下来需要提供喜欢的风格图或排版图，一张图兼具两种信息即可，不规定数量。只提供搜索建议时不声称已经检索或验证图片。

## B 收到图片只做风格拆解

实际查看用户提供的图片，不凭文件名、搜索词或一句风格标签推断。链接无法读取时指出缺口，请用户提供可读图片；不编造可见特征，不在拆解环节重新给搜索关键词。

用简短说明或紧凑表格输出“可借鉴的风格特征 → 本课的独立设计方式”，按实际相关性选择：

- 配色：冷暖、明暗、背景与强调色的关系，不复刻固定色块与面积比例。
- 字体气质：标题和正文的字形感受、层级、阅读舒适度；具体字体无法判断时只描述可见特征。
- 插画与材质：线条、平涂、纹理、写实程度及表现气质，不搬用具体人物和图案。
- 排版气质：层级、疏密与留白形成的阅读节奏，不复制对象位置、分栏或构图骨架。
- 独立设计方向：这些风格特征怎样服务本课学生的观察、比较、讨论或练习，哪些特征不适合沿用。

拆解结果要可被后续绘图任务直接复用，保留在当前上下文或已有设计记录中，不为此强建项目目录或写长报告。单独拆解任务交付到此结束，不调用图像生成、不附封面或样张。

以仍有效的项目委托判断是否继续：明确只要拆解时停止；已经要求按图绘制时，可在内部做必要分析后出图；整套制作中补交被索取的参考图时，接续原委托。不能仅因独立上传图片就推定有制作任务，也不能因最新一条只有图片就遗忘前面有效的制作委托。风格分析不等于可画图层拆分，后者按第10条执行。

## C 根据已有拆解绘制预览图

在用户要求绘制或当前有效委托包含制作时执行。读取页面文字、页码及可用的参考、拆解、模板或批准方向；有拆解直接复用，只有参考图时在制作内部提取必要风格，不要求另开一次拆解任务。既不重复给搜索词，也不新增风格确认，除非用户要求先审后画。

自有风格库及已经命名的S07童趣新国风水彩、S08国风文博半写实是可用设计依据。用户要求沿用时直接读对应摘要；未指定新方向且自有库适用时按主技能选用，不把“每次提供参考图”变成前置条件。仅当用户明确要求匹配一种新风格、现有依据不足且未授权自主设计时，才等待必要参考。

将拆解转为实际绘制指令：本页文字、信息主次、独立设计的图文位置、借鉴的配色和插画语言。参考图传给图像工具时标明“仅参考风格，依据本课内容独立构图，不复刻原版面”。页面组织由当前学生任务决定，不为了像参考而删减题干、变更结论或提前揭示答案。

按第04条交付独立高清图片，核对文字、图示、风格协调与课堂可读性。生成PPT图中的局部字形等可手工修正问题，按[单页验收规则](lesson-pack.md#单页绘图的两项优先验收)标注页码、位置与改法，留给用户修，不自动重绘；用户明确要求代修时才修正，不为主观风格反复重绘整套。仅要求预览图时不制作PPTX。

没有参考、模板或批准方向且未允许自主设计的新风格任务，仍按用户先收参考的偏好等待必要图片；简短指出缺少的输入，复用已给关键词，不重做大纲。缺的是正式拆解文档而不是视觉依据时，不应阻塞绘制。用户明确表示无需参考、直接自主设计时按其要求执行。导出审核图和按批准页面局部修复不重新收参考。
