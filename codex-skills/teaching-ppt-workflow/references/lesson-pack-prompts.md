# 小红薯 原创课件提示词｜优化版

来源：2026-11-04《小红薯原创课件提示词》优化版。只定位当前标题读取，不全文加载。阶段检查与推进统一遵守 [lesson-pack.md](lesson-pack.md)：教案至少5轮多角度评分、最终≥90；其他成果至少2轮；展示最终成果等待确认；PPT按一个课时完成并确认后再进入下一课时。以下具体任务要求在满足这些条件后执行。

## 教案

```Plain Text
请根据提供的课题、教材内容、年级、学情及课时要求，制作可直接用于真实课堂的完整教学设计。

要求：
1. 严格依据当前课题和教材版本，写清可观察、可评价的目标、重难点与关键知识。学情中未提供的情况标为合理预设，不编造真实学生表现。
2. 教学内容分析、学情分析各控制在200字以内；整课共用栏目只写一次，语文教学目标按文化自信、语言运用、思维能力、审美创造四维列出，写本课具体表现，不因维度增加活动或检测，不附评价依据；教学重难点和教学准备分别成模块，教学过程不受该字数限制。
3. 以普通班常态课为默认：每课时少量核心学习，用连续大板块组织；给读、想、写、说和组织转换留余量。标板块大致用时，不作秒级切片；不依赖熟练同伴互评或教师并行精细记录。评价优先使用已有学习产出，不为每个目标另加检测；若整体仍过载，删减、重排任务，不只增加支架和操作说明。
4. 教学设计使用Markdown；教学过程并排四列：“教学环节（含用时）、教师活动、学生活动、设计意图”，每个环节占一行，不拆成标题行、双列活动和表后意图，不自行转Word。 精简后仍须写清本课方法如何使用：如批注如何随理解回看、表格关键词如何帮助讲述；将指导融入原活动，不追加一套评价流程，正文不夹带修订历史。
5. 板书、必要练习和评价与教学目标、活动一致；练习及反馈可融入教学过程，不默认新增独立作业模块。明确要求作业时再写，避免增加负担。
6. 多课时分别设计本课时目标、教学过程和板书，保持前后衔接；不重复整套内容分析和学情分析。必要字词读音、批注示范融入对应过程，不另立辅助小节。

默认输出：基本信息、教学内容分析、学情分析、教学目标、教学重难点、教学准备、分课时教学设计、教学反思。每课时只含目标、教学过程、板书，不另列评价依据、字词提示或批注示例模块。单元设计、AI与跨学科、独立作业拓展按需增加，不因参考模板出现就自动补入。具体以lesson-pack.md的“教案默认模块”为准。
尚未授课时，反思栏目写“课后反思要点”或预留填写位置，不编造实际课堂效果。
直接输出完整教学设计，不附PPT策划或额外分析。
```

## 教案检查

```Plain Text
请依据当前课题、教材版本和课时要求，检查提供的教学设计是否适合真实课堂。

检查：知识与教材依据、目标可评价性、活动递进与可操作性、重难点处理、时间容量，以及目标、练习、评价、作业和板书的一致性。
课程标准符合性依据适用且能够核实的文本判断；缺少关键依据时标为待核实，不编造条款或学生学情。
同时检查课件所需的图片、视频、实验和交互素材：区分已提供、可直接制作、需查找和待确认，说明具体制作难点，不把未找到的素材写成已经具备。

只列实际问题，按严重程度标明位置、原因和具体修改建议，必要时给可直接替换的文字。
本次只检查，等待确认后再修改原设计；不因检查而另行制作课件或额外素材。
```

## 板书

```Plain Text
请将当前教学设计中已经确认的板书绘制成高清图片。

内容严格沿用确认方案，保留文字、知识层次、箭头和逻辑关系，只优化视觉排版，不重新设计教学内容。
采用真实课堂深绿色黑板与粉笔手绘风，白色粉笔为主，少量彩色粉笔强调重点；线描简洁，装饰不挤占知识区。

每个课时单独提交一次绘图任务，每次只生成该课时的一张完整16:9板书图，按使用用途保证文字和关系清楚可读；独立板书按自身用途保证清楚可读，不套用固定像素门槛。
多个课时依次完成，不在一次绘图调用中合并，不制作多格拼图。
核对文字、关系、画幅和实际尺寸，纠正错字、漏字或裁切后交付独立PNG；仅提高像素尺寸不等于增加原生细节。
直接输出图片，不重新分析或改写板书。
```

## PPT大纲

```Plain Text
请根据当前已确认教学设计，编写可直接用于学生课堂授课的逐页PPT大纲。

要求：
1. 沿用教学设计中的活动顺序、知识内容和课堂节奏，将其转为学生需要阅读的材料、问题、任务、练习与总结。
2. 写全必要原文、题干、条件、选项及作答要求；按阅读容量合理分页，不机械拆页，也不把内容全部堆在少数页面。
3. 每页只输出原始页码、页面标题和最终上屏文字，不混入教师活动、时间、设计意图、版式或制作说明。
4. 图片、视频页必须有明确的观察或观看任务。确需预留素材时，可用【图片：名称及必要内容】【视频：主题】标记制作位置，但这些标记不是最终学生正文，后续绘制不得把它们直接画成页面文字。
5. 不虚构教材原句、图片证据、视频情节或数据。关键材料缺失而影响任务成立时，仅指出该缺项。
6. 题目与解答的呈现方式沿用本课已确认要求；开放任务不强设唯一回答。确认后的文案不得在绘图阶段自行改写。
7. 多课时分别编排，保留清楚的课时与页序。

按“第01页、页面标题、实际内容”依次输出完整大纲，不附分析或额外解释。
```

## PPT大纲检查

```Plain Text
请对照当前已确认教学设计，检查提供的PPT大纲。

检查教学内容与顺序是否一致，题目、条件、数据及解答是否准确，学生任务和材料是否完整，页数与信息量是否合理，正文是否混入教师操作或制作说明。
重点检查图片、视频占位是否配有学生任务，标记是否清楚区分为制作说明；需要精确材料的页面不能仅凭占位就认定内容完整。
多课时分别核对，避免串课、漏页、重复页及错误页码。

只列实际问题，标明课时、页码、原因和可执行建议，提供必要的替换文字。
本次只检查，确认后再修订，不直接改原大纲，不绘图。
```

## PPT样稿

```Plain Text
请根据当前课题和已确认PPT大纲，绘制3页课堂PPT样稿：封面页、内容较丰富的正文页、课堂活动页。沿用原始页码。

画风采用精致的半写实童话绘本风，融合水彩与水粉数字插画，明亮温暖、柔和光影、场景细腻且有空间层次。避免扁平矢量、塑料质感和过度Q版；已有本课指定风格时优先沿用。
三页统一人物、笔触、材质、配色、光影、字体层级和装饰语言，布局按教学内容变化，不机械套同一模板。
每页最多2种字体，整套不超过3种；优先微软雅黑、思源黑体、楷体等常用且目标电脑已安装的字体，标题可用微软雅黑或思源黑体、正文用楷体，注音与编号沿用既定字体，不额外使用装饰艺术字。图片样稿按这些字体的字形气质保持一致；后续可编辑排版核实真实字体、可用性和替代情况，正文至少18pt且适合投影，不以生图提示代替实际字体核验。

执行方式：
1. 这是3个独立的单页任务，必须分3次绘图调用依次完成。每次只向绘图工具提交当前页文案，不一次请求生成3页。
2. 第一页确定视觉后，后两页继续使用同一份单页风格参考，注明只参考画风，不继承参考页文字或具体布局。
3. 每次输出一张完整16:9页面，超清画质，使用当前工具可提供的高质量、高分辨率设置；禁止将多个完整PPT页面放进同一张图。正常的分栏、对比、表格等单页布局可以保留。
4. 严格使用当前页确认文字，页码只用于文件命名与任务对应，不画进页面。
5. 先核对首张实际原图的尺寸、比例、文字笔画和图示细节，再继续；默认不强制3840×2160，不因未达4K暂停制作。画面模糊或关键内容不可辨仍不能通过；如实记录尺寸，不把超清、放大图或画布大小当作原生4K证明。每页生成后核对内容、画风、画幅及是否拼图。局部字形不清或单字错漏等可手工修正问题，只标明页码、位置及建议改法，留给用户修正，不自动重绘或覆盖原图；质检标为待用户修正，不冒充已通过。整页拼图、严重错风格或核心内容缺失等仍不计为合格，也不拿它们指导后续绘制。

只交付3张独立PNG样稿，等待我确认后再开始正式页面；不制作剩余页面或PPTX。
```

## PPT页面

```Plain Text
请依据已确认PPT大纲和已批准视觉样稿，按原始页序绘制尚未完成的课件页面。

开始前核对本课题、课时、采用的大纲和样稿。内部记录“页码、准确标题、采用图片、检查状态”，跳过已经确认的样稿和正式页面；只有明确要求修改时才重做对应页。

每批最多10页，实际页数由执行者根据文字密度、复杂度和质检难度决定，可少于10页：
1. 先按原文列出本轮大纲，等待确认；本轮已经明确确认过则直接执行，不重复索要同一次确认。
2. 确认后每页独立调用，逐页完成，每批最多10页。每次只传当前一页文案，不把整批正文合成一次绘图任务。
3. 每次实际使用同一份已批准的单页主风格参考。其他样稿仅按明确用途补充，不传多页拼图作绘制参考，不用失败图或未经批准的新图替代风格标准。
4. 固定人物造型、笔触、材质、配色、光影和字体层级，布局随内容变化；参考图不提供本页标题或正文，不重新探索画风。 每页字体最多2种，优先使用已选定的常用字体，不另加艺术字体。
5. 严格呈现本页确认文字，不增删改写。原始页码用于任务和文件对应，不出现在画面中。
6. 一次调用只输出一张完整16:9页面，超清画质，优先使用可用高质量、高分辨率设置。禁止多个完整页面拼接；单页内必要的分栏、表格或对比不属于拼图。
7. 素材占位标记仅用于执行：绘制预留区域，保留学生观看任务，不把【图片：……】【视频：……】直接画进正文，也不虚构素材已齐备。

每页先检查画风、内容、是否重复、是否拼图、文字与实际尺寸，再交付并推进。首张先确认文字、图示清楚可辨，再继续；默认不以是否达到4K决定扩批，另有明确像素要求时按该要求核验。记录实际尺寸，导入可画保留原图，若需要导出再核对实际导出尺寸。可手工修正的局部字形或单字错漏只输出页码、位置、具体问题及建议改法，留给用户修，标为待用户修正，不自动重绘或覆盖图片；重大内容缺失、拼图或严重错风格仍不能标为合格。
每轮完成后简短列出完成页和待修项，等待确认再开始下一轮。只输出独立PNG及必要的简短进度，不生成PPTX。
```

## 逐字稿

```Plain Text
请根据我提供的**已确认教学设计、PPT大纲及成品课件**，撰写一份教师可以直接用于课堂授课的完整逐字稿。
**【制作要求】**
**严格对应教学设计：** 按照已确认的教学环节、活动顺序和时间安排撰写，不擅自修改教学内容。
**逐页对应PPT：** 按照课件播放顺序撰写，准确标注页码，确保讲解内容与PPT一致。
**真实课堂语言：** 使用自然、亲切、符合学生年龄特点的教师口语，避免书面化、汇报式表达。
**完整教学过程：** 包含课堂导入、知识讲解、提问引导、活动组织、学生反馈、评价总结及环节过渡。
**课堂互动：** 合理设置学生可能的回答及教师追问、反馈，避免预设学生一定给出标准答案。
**时间控制：** 根据实际课时合理分配讲解与活动时间，充分考虑学生思考、讨论、操作及动画播放所需时间。
**操作提示：** 必要时简要标注翻页、播放动画、展示素材等操作，且必须与实际课件功能一致。
**【输出要求】**
按PPT页码顺序逐页撰写。
**教师语言完整具体，可以直接照稿授课。**
学生回答仅作为教师参考，不写成必须发生的固定台词。
多课时分别撰写，保证各课时内容完整。
不增加教学设计之外的活动，不编造课件中不存在的素材或功能。
不重复输出教学设计分析和设计意图。
**请直接输出完整的教师课堂逐字稿，确保自然流畅、衔接合理、时间可控，能够直接用于真实课堂授课。**
```

## 检查逐字稿

```Plain Text
请根据我提供的**已确认教学设计、PPT大纲、成品课件和待检查的教师逐字稿**，检查逐字稿是否能够直接用于真实课堂授课。
**【检查要求】**
检查教学内容、活动顺序及讲解逻辑是否与教学设计一致。
逐页核对PPT，检查教师台词、提问、讲解及翻页提示是否准确对应。
检查教师语言是否自然流畅、符合学生年龄特点，避免书面化和生硬表达。
检查提问、预设回答、追问、评价及环节过渡是否合理完整。
检查讲解、讨论、操作和动画时间是否符合实际课时。
检查是否存在知识错误、内容遗漏、重复讲解或无法实际执行的操作。
**【输出要求】**
只指出实际存在的问题，标明对应PPT页码、问题原因和修改建议，并提供可直接替换的教师台词或操作提示。
**先检查，不直接修改原稿，待我确认后再修订。**
```

```Plain Text
**【输出要求】**
只呈现学生需要阅读、思考和填写的内容，不包含教师操作、教学说明和设计意图。版式简洁清晰，适合A4打印和课堂直接使用。
```

## 制作笔记

```Plain Text
请根据我们**已确认教学设计、PPT大纲及成品课件**，制作一份供教师参考的《课件制作与使用笔记》。
**【制作要求】**
**基本信息：** 简要介绍课题、教材版本、年级、课时及课件页数。
**设计思路：** 说明课件的整体设计理念、教学思路及主要特色。
**课前准备：** 整理教师授课前需要准备的素材、教具及相关资源。
**注意事项：** 提醒教师使用课件时可能遇到的问题，并提供实用建议。
**【输出要求】**
严格依据实际教学设计和成品课件，不编造不存在的功能或素材。
不写课件入口、课件访问或下载链接、入口二维码。
涉及具体页面时，准确标注PPT页码。
内容简洁实用，避免重复教学设计和逐字稿。
```
