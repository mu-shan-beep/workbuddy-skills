# 教学课件工作流｜人工调用提示词

按环节复制对应代码块，随任务提供当前课的教材、已确认成果或待检查文件。制作到已确认进度后接续。板书绘图、宣传预览和录制脚本按单项调用。

## 整套制作与接续

```Plain Text
请按当前课题、教材、年级、课时和已有成果制作或接续完整教案包。先核对本课当前采用的材料、已确认成果和当前步骤。已经确认的内容直接沿用。仅在缺失会影响教学正确性或继续制作时指出具体缺项。

按 教案 → 本课时PPT大纲 → PPT样稿 → PPT页面 → 可画课件组装 → 制作笔记、逐字稿、学习清单 → 最终交付 推进。以普通班常态课为默认，给核心学习和组织转换留出真实时间。教案至少五轮六维评分，满分100分，终稿至少90分且关键问题关闭。其余成果至少两轮实际检查。每阶段展示实际成果，等我确认再继续。一个课时的课件成品确认后才做下一课时PPT。

最终交付教学设计、PPT课件、制作笔记、逐字稿和学习清单，各保留一份当前采用版本及选定格式。教学设计默认Markdown四列表格，板书方案并入教案。PPT按大纲顺序把已确认单页图原样放入可画，一页一张，交设计链接。大纲、样稿和源文件在制作中使用。独立板书图、宣传图、视频和ZIP仅在单项委托时制作。

交付内容统一用课文段落、材料名称或关键语句定位，省略教材页码。课号、课时和课件自身页序照常使用。

收到反馈后，先核实原问题与证据，按已授权范围修订并定点复查。记录触发场景、实际证据、改进动作和验证状态。本课特例留在项目中。可复用的教训合并到对应制作或检查条款，用本次问题复查是否能更早发现，并保留原有确认点。已确认要求按实际采用版本接续。
```

## 教案

```Plain Text
请根据提供的课题、教材内容、年级、学情及课时要求，制作可直接用于真实课堂的完整教学设计。

要求：
1. 严格依据当前课题和教材版本，写清可观察、可评价的目标、重难点与关键知识。学情中未提供的情况标为合理预设，不编造真实学生表现。
2. 教学内容分析、学情分析各控制在200字以内；整课共用栏目只写一次，语文教学目标按文化自信、语言运用、思维能力、审美创造四维列出，写本课具体表现，不因维度增加活动或检测，不附评价依据；教学重难点和教学准备分别成模块，教学过程不受该字数限制。
3. 以普通班常态课为默认：每课时少量核心学习，用连续大板块组织；给读、想、写、说和组织转换留余量。标板块大致用时，不作秒级切片；不依赖熟练同伴互评或教师并行精细记录。评价优先使用已有学习产出，不为每个目标另加检测；若整体仍过载，删减、重排任务，不只增加支架和操作说明。
4. 教学设计使用Markdown；教学过程并排四列：“教学环节（含用时）、教师活动、学生活动、设计意图”，不拆成标题行、双列活动和表后意图，不自行转Word。
   - 扁平化活动环节贯穿：取消“板块一、板块二”等大词打包，直接以全课 4~6 个递进式具体活动环节展开（如“环节一：情境导入，解题生疑（3分钟）”），每个具体活动环节独立占一行，师生动作严格水平对齐。
   - 控制单元格字数软上限（防 Word 排版挤压）：教师活动≤120字（抓关键指导）、学生活动≤80字（明确实操动作）、设计意图≤40字（紧扣素养目标）。
   - 下游映射标注：学生活动中需上屏的核心问题、例句或任务句，直接标注 `【上屏：xxx】`，供无缝映射 PPT 大纲。
   - 随堂产出即评价：学生的圈画、朗读、书写即评价证据，教师活动末尾以简短巡视点拨闭环，不设多余评价表。正文不夹带修订历史。
5. 板书、必要练习和评价与教学目标、活动一致；练习及反馈可融入教学过程，不默认新增独立作业模块。明确要求作业时再写，避免增加负担。
6. 多课时分别设计本课时目标、教学过程和板书，保持前后衔接；不重复整套内容分析和学情分析。必要字词读音、批注示范融入对应过程，不另立辅助小节。

默认输出：基本信息、教学内容分析、学情分析、教学目标、教学重难点、教学准备、分课时教学设计、教学反思。每课时只含目标、教学过程、板书，不另列评价依据、字词提示或批注示例模块。单元设计、AI与跨学科、独立作业拓展按需增加，不因参考模板出现就自动补入。具体以lesson-pack.md的“教案默认模块”为准。
尚未授课时，反思栏目写“课后反思要点”或预留填写位置，不编造实际课堂效果。
直接输出完整教学设计，不附PPT策划或额外分析。

交付内容统一用课文段落、材料名称或关键语句定位，省略教材页码。课号、课时和课件自身页序照常使用。

借鉴参考案例时，先根据本课学生的困难、学习顺序和证据重新推导设计，只有适用的思路才借用。AI 活动仅在有实际学习价值且课堂条件允许时采用。

交付前执行三道阻断闸门核验（教材事实无硬伤、常态课容量无超时虚构、下游映射与四列规范齐备），日常制作展示闸门结论与问题清零摘要；独立审查或需要完整报告时进行五轮六维评分（满分100，终稿≥90且关键问题清零）。记录证据和问题处理，分数依据真实检查，纸面自评不用99或100分。教案正文保持纯净，另在聊天附质检记录，展示整课教案待我确认。
```

## 教案检查

```Plain Text
你是具有一线经验的教研员，也是独立教学设计审查员。请对提供的教学设计做普通班常态课审查。只读检查，不重写教案；问题必须有证据，区分已证实问题、实施风险和优化建议；未提供教材、课标依据时不得假装已核对；不编造学情、试教和课堂反思。

核心标准：普通教师能否直接按教案上课；普通班学生能否完成核心任务；规定课时内能否完成教学、练习和反馈；是否落实教材要求、突破真实难点；是否有为形式完整而设的无效活动。

一、检查五项
1. 教材事实：课题、年级、版本、课时是否正确；原文、人物、事件、生字词、字音字形、背景资料是否准确；教学内容有无遗漏或拔高；重难点是否来自本课学习困难。区分“必须落实内容”和“可选资源”。
2. 目标评一致：目标是否具体、可观察；每项目标是否有对应活动和可观察表现；是否有即时反馈；是否空泛情感目标；不额外增加复杂评价表。
3. 逻辑与支架：环节是否围绕核心任务，递进是否清楚，是否重复；问题是否清楚；支架是否适量；是否依赖复杂设备；拆开环节内部动作，判断能否在时间内完成。
4. 容量与时间：按动作估算学生阅读、圈画、思考、讨论、书写、订正时间，以及教师讲解、追问、组织、转换时间；标出核心任务、可后移任务、弹性任务。禁止只改分钟不删动作、压缩必要学习时间、假设学生立即会答。核心任务明显完不成，不放行。
5. 综合适用：能否直接使用；主要任务是否明确；重点是否突出；学生是否有真实练习；是否有过度设计；正式教案是否使用确定、可执行表达；反思是否编造。

二、评分
六维百分制：教材与知识准确性25；目标与评价一致性20；教学逻辑与难点突破20；学习任务与可操作性15；课时容量与节奏10；完整性与规范性10。未达90分原则上不放行；即使达90分，有教材事实错误、主要资源不可用、核心活动无法实施或明显超时，也不放行。

问题分三级：A类阻断，必须修复；B类实质，建议修复；C类优化，默认不触发修改。无证据的审美偏好不得升级为必修问题。

三、固定输出
1. 总体结论：是否符合常态课；能否直接上课；突出优势；有无阻断问题；属于可定稿、局部修改后定稿，还是需较大调整。
2. 五项检查与六维评分：列分项分、总分、主要发现和依据。
3. 逐课时容量审计表：教学环节、原定用时、主要动作及估算、超时风险、调整建议；说明核心任务能否完成、有无机动、最可能超时环节、可删并后移活动及承接。
4. 问题清单：等级、位置、问题与依据、对课堂影响、最小修改建议，按A/B/C排列，不罗列无价值小问题。
5. 值得保留的设计及理由。
6. 放行结论：综合评分、有无A类问题、有无明显过载、是否达到放行标准、必须修复事项、可不改事项。若后续授权修改，只做最小必要修订并定点复核。

最终只看一条：这份教案能否帮助普通教师在正常条件下扎实完成本课，让学生真正学有所得。
```

```Plain Text
请依据当前课题、教材版本和课时要求，检查提供的教学设计是否适合真实课堂。

检查：知识与教材依据、目标可评价性、活动递进与可操作性、重难点处理、时间容量，以及目标、练习、评价、作业和板书的一致性。
课程标准符合性依据适用且能够核实的文本判断；缺少关键依据时标为待核实，不编造条款或学生学情。
同时检查课件所需的图片、视频、实验和交互素材：区分已提供、可直接制作、需查找和待确认，说明具体制作难点，不把未找到的素材写成已经具备。

只列实际问题，按严重程度标明位置、原因和具体修改建议，必要时给可直接替换的文字。
本次只检查，等待确认后再修改原设计；不因检查而另行制作课件或额外素材。

交付内容统一用课文段落、材料名称或关键语句定位，省略教材页码。课号、课时和课件自身页序照常使用。

整篇教案检查时至少做五轮，分别侧重事实、目标、任务、课堂演练和综合复核。每轮均按教材与知识25、目标与评价20、逻辑与难点20、任务与实施15、容量10、完整性10评分，并给出证据与问题。最终至少90分且无关键错误才可放行。只读任务原稿未改时据实保留相同分数，纸面自评不用99或100分。核对主要学习时间、组织转换、反馈和课堂负担，无法核实时标明。
```

仅在我单独委托板书图时执行此提示词。完整教案包的板书方案写入教学设计。做两轮实际检查，先对照依据和内容，再检查实际成果的呈现、可用性和问题处理。检查摘要另在聊天列出范围、发现、处理和未核实事项。展示当前阶段的实际成果，待我明确确认后再推进。

## PPT大纲

```Plain Text
请根据当前已确认教学设计，编写可直接用于学生课堂授课的逐页PPT大纲。

要求：
1. 沿用教学设计中的活动顺序、知识内容和课堂节奏，将其转为学生需要阅读的材料、问题、任务、练习与总结。
2. 写全必要原文、题干、条件、选项及作答要求；按阅读容量合理分页，不机械拆页，也不把内容全部堆在少数页面。
3. 每页只输出原始页码、页面标题和最终上屏文字，不混入教师活动、时间、设计意图、版式或制作说明。
4. 图片、视频页必须有明确的观察或观看任务。确需预留素材时，可用【图片：名称及必要内容】【视频：主题】标记制作位置，但这些标记不是最终学生正文，后续绘制不得把它们直接画成页面文字。
5. 不虚构教材原句、图片证据、视频情节或数据。关键材料缺失而影响任务成立时，仅指出该缺项。
6. 题目与解答的呈现方式沿用本课已确认要求；开放任务不强设唯一回答。确认后的文案不得在绘图阶段自行改写。
7. 多课时分别编排，保留清楚的课时与页序。

按“第01页、页面标题、实际内容”依次输出完整大纲，不附分析或额外解释。

交付内容统一用课文段落、材料名称或关键语句定位，省略教材页码。课号、课时和课件自身页序照常使用。

如需收集风格与排版参考，在大纲正文外另给简短可复制的搜索关键词。已有批准风格、参考充分或我只要纯大纲时省略关键词。做两轮实际检查，先对照依据和内容，再检查实际成果的呈现、可用性和问题处理。检查摘要另在聊天列出范围、发现、处理和未核实事项。展示当前阶段的实际成果，待我明确确认后再推进。
```

## PPT大纲检查

```Plain Text
角色
你是一名经验丰富的小学语文教研员和一线教师，同时担任独立的PPT课件质量审查员。
请根据我提供的教材原文、已确认教学设计及PPT大纲，对大纲进行严格、客观的交叉检查。
我们的课件用于40分钟普通班常态课堂，不是公开课或精品课，必须真正服务于教师教学和学生学习。
检查要求
教材准确性：核对课文原句、生字词、知识点、问题和答案是否准确。所有内容必须有依据，不得凭空增加或编造。
教案一致性：逐环节对照教学设计，检查教学顺序、教师活动和学生活动是否完整落实，有无遗漏、重复、偏离或擅自增加教学任务。
课堂实用性：站在真实上课的角度逐页检查，学生是否清楚要读什么、看什么、想什么、做什么；是否有必要的学习材料、观察对象、表达支架和反馈内容。不能只有标题和简单问题。
页数与课堂节奏：40分钟常态课通常按15—20页规划。检查页数是否合理，是否因页面过少导致教学支持不足，或因页面过多造成频繁切换。不得机械凑页，也不得增加课堂负担。
页面内容质量：检查页面之间是否重复、内容是否完整、文字是否过多、任务是否清晰，是否适合16:9课堂投影。问题、思考和答案的呈现顺序必须符合实际教学过程，避免提前泄露答案。
素材与视觉支持：检查需要图片、图示、田字格、表格或其他素材的页面是否明确标注，素材是否真正服务学习任务。不得虚构素材或未经核实的内容。
课堂完整推演：模拟普通教师按照大纲上课的过程，判断是否存在需要临时补充大量内容、教学衔接不顺、学生无法独立完成任务或实际课时过载的问题。
输出要求
先给出整体质量判断，说明是否可以直接进入PPT绘制阶段。
逐项列出发现的问题，注明具体页码、问题原因、对课堂的影响和修改建议。
区分必须修复的问题与一般优化建议。
明确指出值得保留的优秀设计，避免不必要的修改。
最后给出合理的页数调整建议和最终审查结论。
本次只进行独立检查，不直接修改大纲。
不要为了体现检查严格而强行寻找问题，也不要因为大纲看起来完整就轻易判定合格。
最终标准：这份PPT大纲能否完整落实教学设计，真正支持40分钟常态课堂，让教师拿来就能上课、学生能够顺利完成学习任务。
```
