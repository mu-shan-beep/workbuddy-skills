# 自有课件风格

## 共同语言

清楚的教学任务、一个视觉重心、充足留白、有意义的图形、可编辑的知识内容。风格可以温暖、理性或有文化感，但避免装饰压过教学。以下尺寸与颜色为我们自行制定的起点，不是参考图测量值。

16:9 基准 960×540pt：安全边距 48–60pt，模块间距 20–32pt；标题 36–44pt，正文 24–28pt，图注 18–20pt。投影条件差时增大字号；超量内容优先拆页、分段或逐步揭示，不默认缩字。中文先确认本机字体，Mac 可用苹方，文化类标题可用已安装的宋体/楷体；不要仅凭字体名判断实际替换结果。

同一份课件固定标题基线、正文层级、强调色含义及图注规则。默认左对齐长文本；图形内短标签可居中。原生形状可能默认居中，创建文字时应显式指定对齐。避免用连续空格定位页脚。底板、图像和说明文字作为完整模块编排动画。

S09–S12为新增原创候选规范，尚待实际样张确认；目录存在不代表已经生成素材、建立PPT模板或获得用户视觉批准。它们按媒介区分，不是S07换色版本。S01–S08沿用原有方向，当前项目的批准页面优先于目录默认值。

快速选择：低年级温暖叙事可比较S07水彩与S09蜡笔；强调分层、顺序或民俗可选S10；精读和较多文字优先比较S02与S11；需要直观操作情境可选S04平面与S12立体。科学实物证据优先S03，准确推导优先S05，不因可爱而牺牲对象准确性。每次只推荐与本课相关的2–3种，不要求用户遍历整个目录。

S07、S08依据《长城》《颐和园》《秦兵马俑》相关对话中的命名、风格沿用需求与修订经验整理，属于可复用设计起点。本次未重新逐图采样；配色、字号和布局建议是自主设计参数，不声称测量自原图，也不把历史文字分析当作本次看图验证。具体页面保真仍以当前批准预览为准。

## 原有八种风格

### S01 清晰青绿 / clear-teal
- 适用：科技、道法、方法说明、通用课堂；需要逻辑清楚且无强题材气质时的起点。
- 色彩：背景 #F7F8FA，正文 #172B4D，强调 #168579，辅助底 #E6F0EE。强调色正文需保持足够明暗差。
- 字体与图像：无衬线中文；平面示意图、真实案例照片、少量线性图标。
- 布局语法：短观点配主图、真正有方向的流程、同维度对比、证据与结论。避免每页三个等宽卡片。
- 密度：中；一个主关系带二至四个证据，可按内容调整。
- 预览摘要：暖白底、深蓝文字、克制青绿强调、整洁边距、一个明显阅读入口，依据页面内容独立构图。
- 原生制作：矩形/细线/短标签即可，少阴影；图标无必要时不为装饰额外搜索。

### S02 书页人文 / editorial-ink
- 适用：语文、阅读、人物故事、历史材料。
- 色彩：背景 #F5F1E8，正文 #292722，强调 #8C4938，辅助底 #E8DFD0。
- 字体与图像：正文清晰宋体或黑体，标题可用有书卷感的字形；史料、人物照片、书页或低纹理插画。
- 布局语法：材料正文与边注、人物与经历、关键引文与上下文、图像与证据；长文不居中。
- 密度：中至高，保留行距与批注区；长篇阅读分屏，不做小字海报。
- 预览摘要：温暖纸色、墨色文字、少量赭红批注，安静而清晰，文字区域干净。
- 原生制作：引文、解释、批注分别可编辑；背景纹理不影响正文对比。大字错落只可用于极短封面，不能破坏正常语序。

### S03 自然观察 / field-notes
- 适用：科学、地理、生态、研学与观察记录。
- 色彩：背景 #F4F6EF，正文 #243E34，强调 #47704E，辅助 #DDE6D3；少量暖黄用于观察提示。
- 字体与图像：清晰黑体；真实样本、环境照片、局部放大图及准确标注。
- 布局语法：一张主观察图加问题、同尺度样本比较、局部放大、观察记录表。
- 密度：低至中，图像承担证据作用；装饰树叶不占观察区。
- 预览摘要：柔和自然底色、深绿文字、真实观察主体、少量手记式标记、清晰可留空的回答区。
- 原生制作：图片裁切保持辨认要素；标注用原生引线，不把科学标签写进生成插画。

### S04 温暖探索 / playful-discovery
- 适用：小学、启蒙、活动任务；不因“教学”二字就默认幼儿化。
- 色彩：背景 #FFF8ED，正文 #303E4C，强调 #356C62，辅助 #F4C86A，点缀 #C56348。
- 字体与图像：圆润但易读的中文；统一笔触的扁平插画，一个情境主角即可。
- 布局语法：情境图与任务、操作步骤、分类配对、选择判断、答案揭示。
- 密度：低，一页一个主要动作；不强制写固定字数。
- 预览摘要：温暖奶油底、活泼克制的色块、少量原创手绘插画、清楚的任务和操作区域。
- 原生制作：文本和活动对象可独立移动；不把重要文字嵌入插画，不在每页重复堆人物、文具和贴纸。

### S05 理性实验 / scientific-grid
- 适用：数学、物理、实验、数据分析。
- 色彩：背景 #F8FAFC，正文 #18324B，强调 #285CA0，辅助 #E5EDF6；需要标记第二变量时用 #A55B21。
- 字体与图像：易辨数字与符号；准确矢量图形、坐标图、公式和步骤关系。
- 布局语法：图形与推导、现象与条件、假设—实验—证据、同轴比较。
- 密度：中；推导逐步展开，图形与当前步骤就近关联。
- 预览摘要：明亮干净底色、精确线条、克制蓝色、清晰图示区与推导区，避免虚构公式和实验结论。
- 原生制作：公式用可靠公式对象或已验证的图形；坐标、单位、比例和数据可核对，不靠生成图保证科学准确。

### S06 当代文化 / quiet-culture
- 适用：传统文化、地方文化、艺术与历史主题。
- 色彩：背景 #F2EBDD，正文 #37332D，强调 #814637，辅助 #DCD0BD；允许低饱和墨绿作局部配色。
- 字体与图像：标题可用宋/楷，正文高可读；文物、建筑、器物或淡雅原创插画。
- 布局语法：一个文化主体配解释、时间线、细节放大与出处、同类器物比较。
- 密度：低至中；“中式”不等于竖排全文或堆印章。
- 预览摘要：温润米色、墨色与少量朱色、清楚文化主体、现代阅读秩序、克制纹理。
- 原生制作：保持真实文物比例、材料出处和文字完整；装饰印章不能伪装成真实权威标识。

### S07 童趣新国风水彩 / playful-guofeng-watercolor
- 常用别称：新中式水彩、国风水彩＋儿童绘本；“国风叙事绘本”可作为S07与S08的共同风格方向，具体媒介按本课选择。
- 适用：小学语文中的山水、园林、古建筑、文化游览；《长城》《颐和园》式主题可用。沿用已命名方向无需再次上传相同参考。
- 色彩起点：暖纸白 #F8F3E8，墨青正文 #263F43，青绿 #5E8A83，淡赭 #C89468，少量朱红 #B95A48。水彩晕染留在景物与边缘，正文区保持浅净。
- 图像语言：国风山水的空间层次、水彩绘本的柔软边缘，建筑与景物有可辨细节，人物适龄且比例协调；不是把所有知识对象画成幼儿卡通。
- 布局语法：情境页可以完整山水叙事；阅读页用干净文字区与局部景物；构造观察用准确主图加引线；游览线索、观察顺序按课文证据组织，不让装饰路径虚构地理路线。
- 密度：低至中。正文不压在浓重山水上，避免每页都摆卷轴、印章、祥云和大人物。叙事插画与原文精读有不同图文比例。
- 预览摘要：童趣新国风水彩绘本，温暖纸白与青绿远景，柔和光影，清晰可辨的文化景物，正文留净；按本页任务独立构图。
- 分层制作：标题和正文原生可编辑；文字底板、引线与箭头独立；建筑、人物、花枝等主要插图各自可移动替换，保留图片中的水彩笔触，不追求笔触级矢量化。标签不画死在插图中。

### S08 国风文博半写实 / museum-narrative
- 常用别称：秦韵文博写实（相关秦代课题）、国风电影级半写实插画；这里的写实指插画材质与空间细节，不默认改成摄影风。
- 适用：文物、考古、历史、工艺和博物馆解说；《秦兵马俑》式主题可用。“秦韵”只用于相关课题，不推广为所有时代的装饰。
- 色彩起点：浅陶纸 #F3E8D7，深褐正文 #342D29，陶土 #9B6A4F，暗朱 #8E3F35，克制金色 #B69761；大型情境图可局部深色，阅读区保持足够对比。
- 图像语言：国风叙事绘本与文博半写实，文物、建筑、材料纹理清楚，柔和电影光影和空间纵深；学生角色可有绘本感，但文物形制、装备与年代必须有据。生成插画是示意，不冒充出土实物照片。
- 布局语法：军阵等全景页呈现宏观气势，观察页放大真实细节，对比页按同维度并列，数据页用准确单位和基准支撑感受；不是全套都套红金卷轴与展陈卡片。
- 密度：中。金边、纹样和情境UI退居辅助，原文、数据和任务占据清楚阅读区。只在教学需要时使用解说团等叙事，完成宣言必须有实际学习产出。
- 预览摘要：国风文博半写实教育插画，温暖陶土与克制朱金，文物材质和空间关系可信，任务与原文阅读区干净，主体按本页内容选择。
- 分层制作：保留重要文物和场景比例，人物、器物、标签及文字主要对象独立；不为了拆层破坏完整军阵透视。播放器、计时器和按钮若只是画面，不能作为功能宣传。

## 按内容选版式

| 内容关系 | 可选组织 | 关键检查 | 避免 |
|---|---|---|---|
| 单一观点 | 观点＋主图、关键引文＋解释 | 一眼找到核心 | 三个虚构要点凑版 |
| 并列 | 同等级区域、等宽图文、分组标签 | 各项真实同级 | 用箭头制造先后 |
| 对比 | 同维度双栏、对照表、同尺度双图 | 项目逐行对应 | 两边各讲各的 |
| 顺序 | 横向步骤、纵向过程、时间线 | 方向、编号和因果准确 | 把时间线当通用装饰 |
| 总分 | 主概念与分支、分层解释 | 层级明确 | 无意义圆环 |
| 原文阅读 | 连续文本＋旁批、分段阅读 | 原文、出处和阅读顺序 | 切碎成卡片破坏语义 |
| 图像观察 | 主图＋问题、放大细节、样本对照 | 主体与差异清晰 | 强透视和任意裁切 |
| 数据 | 结论＋相关图表、解释＋对比图 | 单位、轴、基准与来源 | 仅因美观改变图形比例 |
| 问答活动 | 任务＋材料＋回答区 | 提问先于答案 | 在初始画面泄露答案 |

相邻页不为变化而变化：同一连续练习可维持布局。章节切换、认知任务改变或材料类型改变时再调整构图。全套保持一种主风格，必要时使用同色系的低密度过渡页或高密度证据页。

## 可直接复用的制作记录

`style_id / palette / fonts / page_role / content_relation / visual_focus / layout_intent / density / reveal_order`

新课增加一次性风格锁：`medium / character_sheet / material_or_stroke / approved_reference`。它与逐页内容分开存放，后续只传摘要与批准的单页参考；按内容改变布局，不能逐页更换媒介或角色设定。尚无批准样张时明确标注候选，不用上一课的画面代替本课批准。

已有批准页面需要复现时，再补充实际需要的 `canvas_ratio / text_roles / key_object_bounds / reference_page`。`text_roles`记录标题、正文、标签的相对字级、行数与对齐；位置按画布比例换算。原生重建复用这些决定，不凭一张缩略图统一猜字号。

预览绘图提示只传选定风格摘要、当前页文字与上述页面字段；不重复附全部研究。PPT 原生制作复用同一记录和设计参数，不能只凭一张预览重新猜布局。要修改样式，优先批量调整相关字段，不重新生成整套。
