# S11 线描淡彩 / line-and-wash

状态：原创候选规范，待本课单页样张确认；以下为设计起点。

- 适用：小学中高年级精读、观察描写、人物分析、写作与知识梳理；也适合需较多留白的学习单配套视觉。
- 区别：图像以单色轮廓线为主体，少量局部淡彩强调；与S07依靠大面积水彩场景叙事不同，也不等同于S02史料书页排版。
- 色彩：暖白 #FAF8F1，主线与正文 #303B3B，青绿 #507A73，浅蓝灰 #DCE8E8，浅杏 #F1DFC1；只用一至两种淡彩标记教学重点。
- 图像语言：均匀细线、清楚轮廓、有限排线，淡彩位于局部对象内部，背景少纹理；远景、植物等装饰可省略。线条在投影尺寸下可辨，不用发丝线。
- 人物锁定：固定五官、体态比例、服装轮廓、配饰、排线疏密和线色；同一角色不可一页写实素描、一页Q版漫画。
- 字体：原文可用清晰宋体，任务与标注用黑体；固定角色分工，批注符号独立，不能伪造学生真实批注。
- 布局：原文与边注、局部观察与引线、人物证据与推断、前后对照、板书式关系图。精读页保留连续文本，不强拆为装饰卡片。
- 密度：中；必要时分屏阅读，避免为塞下长段原文而缩字。图像少而有用，不能把所有页面做成空白文字页。
- 绘图摘要：清爽教育线描淡彩，深灰绿色稳定轮廓、有限排线和局部浅色，暖白留白，观察对象清楚，阅读与批注空间充足，依据本页内容构图。
- 避免漂移：不切到彩色满版水彩、铅笔写实大面积阴影或黑色粗线漫画；保持轮廓线尺度与淡彩面积关系。
- 分层制作：正文、旁批、箭头和关系图原生可编辑；适合时线稿用SVG/原生线条，复杂插画作为独立素材，不宣称自动矢量化。
- 样张验收：原文易读，旁批不遮正文，淡彩只强调有意义对象；情境与精读页线条统一，线稿放大后仍清晰。
