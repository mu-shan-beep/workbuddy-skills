# 三类检查怎么跑、怎么判

> 配套 `scripts/scan.py`。脚本只筛候选，判读靠人。

## 一、同义并列（查同一个承诺的不同说法）

### 怎么跑

```bash
python3 scripts/scan.py <技能目录> --fact 交付形态 --same 可画,可编辑,PPTX
```

为同一事实列出别名、旧称和常用表述。`--fact` 把别名的命中并成一组，同一段只显示一次。单用 `--same` 时仍按关键词分组。

| 好的关键词 | 差的关键词 |
|---|---|
| `可编辑`（交付承诺） | `规则`（什么都是规则） |
| `复用`／`现生成`（履约动作） | `使用`（太泛） |
| `课堂真实场景`（真实性） | `教学`（满篇都是） |
| `8—10`／`10 个`（数字） | `要求` |
| `已废止`／`原创注`（旧口径残留） | `内容` |

### 怎么判

脚本会给每句标 `[必]`（含必须类词）或 `[禁]`（含禁止类词），并在同一关键词下**两类并存**时给出 ⚠ 提示。

- 有提示时按同一对象与适用条件并排读。单句也可能同时有两类词。无提示的组照样检查已登记位置和语义相反的候选。
- 遇到具体值、默认值和按实填并存，先确认它们分别约束哪类输入。历史反例、有效例外和已核实案例按其实际用途判定。

### 已知的判读陷阱

| 陷阱 | 说明 |
|---|---|
| 把"解释为什么废除旧写法"当成残留 | 变更记录、避坑表里引用旧写法是正当的，看它是在**规定**还是在**回顾** |
| 只改主规则就以为改完 | 模板、示例、自检清单、避坑表都是投影，漏一处就等于没改 |
| 把工具形态当作编辑权限 | 将 `可编辑PPT`、`可画设计链接` 和实际买家权限并排读，分别核交付格式与可编辑范围 |

## 二、对立检测（查"必须A"与"禁止A"）

### 怎么跑

```bash
python3 scripts/scan.py <技能目录> --opposites
```

输出两张清单：`必须／一律／固定／必写／只能` 类，与 `禁止／不得／不写／严禁／不设` 类。

### 怎么判

单看 500 多句没有意义。**要按对象配对**：

1. 先列出文档里的「动作对象」：写标题、写标签、写声明、取链接、选形态、承诺交付……
2. 每个对象去两张清单里各找句子
3. 两边都有 → 并排读

**典型矛盾形态**：

- `fulfillment` 说「能复用就不新建」 vs `compliance` 说「每条链接必须现生成」
- 主规则说「不写声明」 vs 示例正文留着「注：全部为本人原创」
- 「课时总数」和「第几课时」要分开核对，前者是数量，后者是次序。

## 三、可行性验算（查规则有没有把所有出口堵死）

### 怎么跑

不用脚本，逐条代入。**凡带前置条件的规则都要验。**

### 验算模板

```
规则：______
前置条件：______
最坏输入：把可选范围里"能满足前置条件"的选项逐个划掉，剩几个？
结论：剩 0 个 → 规则无解，必须改
```

### 实例（来自真实失误）

```
规则：近 4 篇不得重复形态；每 5 篇至少 1 篇短形态
可选：M1 M2 M3 M4 M5 M6
已用：M1 M2 M3 M6
剩余：M4 M5
前置条件：M4／M5 都以「封面能独立说明教学内容」为前提
最坏输入：封面不满足（用户只有 PPT 截图，首图是课题页）
结论：剩余 0 个 → 无解。
```

**这条规则写的时候没人觉得有问题，因为它看起来只是"别重复"。** 验算三十秒就能发现它把所有出口堵死。

### 常见无解形态

| 形态 | 例子 |
|---|---|
| 排除法凑不齐 | 六选一，四个已用，剩两个有前提 |
| 前置条件互相排斥 | A 要求有封面图，B 要求正文极简，而封面图需要正文说明 |
| 硬下限高于上限 | 配比合计最低 7，总数下限 10 |
| 必选项依赖可选项 | "必须写页数"但页数只在可选的详情页字段里 |

## 四、承诺回上游

### 查什么

凡涉及**交付物、格式、数量、金额、领取方式、平台机制**的表述。

### 回哪查

| 承诺 | 权威源 | 常见错误 |
|---|---|---|
| 交什么、什么格式 | 产出方技能的交付规程 | 继承旧模板的"可编辑 PPT"，实际交的是可画链接 |
| 几页几份 | 该课实际成品 | 抄对标帖的页数 |
| 平台怎么判 | 平台明文规则／官方文档 | 把 AI 预判当实测 |
| 样本结论 | 原始样本数据 | 从二手转述里推因果 |

### 判据

**问自己一句：这个承诺，我是从哪儿知道的？**

- 「模板里就这么写的」→ 不算知道，去核
- 「上次是这样」→ 不算知道，去核
- 「产出方技能的交付规程写着」→ 算

## 五、跑完之后的动作

1. **先出报告，不动文件**
2. 每条标证据类型（已证实／需验算／待核）与把握度
3. 审查委托停在报告。已获授权的修改按范围继续，留存可对照的改前证据。
4. 改完再跑一遍同样的检查，确认没有新增矛盾
