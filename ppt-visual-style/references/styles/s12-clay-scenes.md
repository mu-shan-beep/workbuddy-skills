# S12 黏土立体 / clay-scenes

状态：原创候选规范，待本课单页样张确认；以下为设计起点。这里的立体是静态视觉风格，不自动提供3D模型或可旋转交互。

- 适用：小学低年级情境导入、数量操作、分类、空间想象、活动任务；需精确形态、比例或真实材料证据的科学页面优先准确图示或实物图。
- 区别：有体积的柔软哑光造型、轻微手塑质感、柔和漫反射；不是S04平面插画加阴影，也不是S08文博半写实。
- 色彩：浅灰白 #F5F7F6，正文 #293C45，鼠尾草绿 #77988B，浅杏 #EBC9A3，雾蓝 #9EBBCC；浅色立体对象搭配深色标签，不用低对比的小字。
- 图像语言：简洁体块、柔和转折、少量手塑痕迹、固定左上柔光、适度环境阴影；不用反光塑料、高亮金属或强景深模糊。
- 人物锁定：固定年龄、头身比、脸型、眼睛样式、发型、服装和材质粗糙感；同一物体不随页变大小或数量。可观察性优先于可爱夸张。
- 字体：标题与正文用清晰黑体，任务短而明确；文字放平面区域，不贴到透视中的物体表面。
- 布局：一个操作主场景配任务；分类用真实可分对象与区域；数量对比同尺度；精读用局部人物退到边缘与干净正文区。不要每页都布置玩具展台。
- 密度：低至中；只出现本次需要数、比或操作的对象，避免装饰物让数量题答案发生歧义。
- 绘图摘要：清新哑光黏土教育场景，简洁可信体块、轻微手塑质感、固定左上柔光，浅灰白底与低饱和鼠尾草绿杏色雾蓝，独立主体清楚，文字区平面浅净。
- 避免漂移：不混用毛绒、塑料、纸雕、真实人物照片或水彩；锁定镜头倾角、阴影柔度与角色比例，同一连续操作保持观察视角。
- 分层制作：对象、底板、标签、箭头独立；复杂立体对象可用透明图片，文字与操作区域原生可编辑。静态图不能宣称可拖拽、可旋转或按钮可用；真实交互需对应实现。
- 样张验收：数量、空间、形态准确；对象间遮挡不影响判断；连续操作页视角稳定，正文清楚，光向与材质一致。
