# 教学PPT交付检查表

只检查本次交付涉及的项目；不适用项标为“不适用”，无法实际验证的标为“未验证”。独立的内容检查不因本表扩展为文件技术质检。

## 内容

- [ ] 页数和顺序与通过的大纲一致
- [ ] 环节名称、标题、知识点和作业一致
- [ ] 客户要求已经逐项关闭
- [ ] 不含占位符、批注或待确认文字

## 同步

- [ ] 课件默认核对可画设计链接与页序；仅当用户要求交付 pptx 时才核对 PPTX 文件本身
- [ ] PPT与教学设计一致（差异改下游以匹配上游权威）
- [ ] PPT与逐字稿一致
- [ ] 视频、音频和动画提示一致
- [ ] 总时长适合课堂

## 视觉与播放

- [ ] 官方模板和锁定元素保留
- [ ] 页面任务清楚、阅读顺序自然，版式与内容关系相符
- [ ] 未用机械卡片、空泛口号或无功能装饰替代教学内容
- [ ] 全套渲染正常
- [ ] 重点页面放映正常
- [ ] 图片、字体、视频和音频正常
- [ ] 动画点击顺序正常

## 可画拆层路线

- [ ] 拆层文字与确认文案一致，无残留重复字和错误识别
- [ ] 图层无遗漏、错位或无意义碎片，必要对象可独立编辑
- [ ] 图片边缘、背景补洞和局部重绘自然，教学图示准确
- [ ] 修复结果已保存，最终设计或所要求的导出文件已核对

## 文件

- [ ] PPTX无修复提示（仅当本次交付 pptx 文件时核对）
- [ ] 文件名清晰
- [ ] 交付目录只含客户需要的文件
- [ ] 本地源稿直接就地修改，无多余版本副本、回退文件或临时命名文件
- [ ] 没有本轮测试副本、临时预览或多余的生成版本
