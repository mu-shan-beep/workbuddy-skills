# 课堂逐字稿：编写与审核（lesson-transcript）

一句话：**逐字稿是课件的口播版——课件放什么，稿就讲什么，一页对一页，一问对一问。**

> **唯一依据（2026-11-07 用户裁定，最高）**
> 逐字稿**只针对课件**，**服务于课件**，必须与课件**完全匹配**：页数、页序、页标题、页面问句、
> 词表条数、图片内容、操作方式，一律以课件实物为准。
> **教学设计不参与判断**——它既不是页的切分依据，也不是检查项，不必读它才能动笔，
> 更不能拿它来质疑稿子或课件。稿子唯一要回答的问题是：**这一页课件，老师该说什么、学生该做什么。**
> 教材只用于核对引文与字词原样（课件引课文时，字句以教材为准）。

| 文件 | 作用 |
|---|---|
| `references/script-spec.md` | 唯一编写与审核标准（二十四章）。判断“该不该这样写”只看它 |
| `references/lessons-learned.md` | **复盘台账（只存案例）**：用户原话 ＋ 当时的想法 ＋ 漏检原因 ＋ 加固动作 ＋ 防复发检查项 |
| `references/audit-playbook.md` | 对读与时间核算的操作规程：抽课件文字、建页—时间对应、跑校验、报问题口径 |
| `scripts/pptx_text.py` | 逐页抽取课件文字（可选备注），作为对读底稿 |
| `scripts/audit_script.py` | 校验课件逐页对齐（页数／页标题／问句落地）、时间轴、页内时间预算、动画与切页区分、虚构课堂回指（含〔学生可能说〕预设）、含对话页缺〔操作〕的结构提醒、指代错位、指令数字、标记格式、板书列名、配图张数；结果分 ERROR／WARN／未验证三态，语速可 `--rate` 指定；并入 `[复盘]` 硬校验与提醒（V6，2026-11-08） |

排版不归本技能：写好的源稿交给 `lesson-typeset`，它会自动按 `pNN.jpg` 配课件截图。

> 台账条目的「正确口径／防复发检查项」效力等同 `script-spec.md` 条款，日期新的用户裁定优先；
> 改 spec 正文仍须用户确认，口径先落台账即可立即生效。**同一件事只在一处写**：流程在 §7、效力在 spec 二十四、硬校验在脚本、案例在台账。

## 执行纪律（与教案包主流程同一套，不得另立）

写稿与审稿一律按全任务口径执行（不论任务大小，不因「只是改一段」豁免），按 `teaching-ppt-workflow/SKILL.md`「全任务执行状态机与硬门禁」执行，禁止跳级（状态定义只有一个归属，此处不复制全文）：
`LOCK → AUDIT → EXECUTE → VERIFY → DONE`

写稿侧的硬含义，缺一项即不算交付：

| 状态 | 写稿侧的必做动作 |
| :-- | :-- |
| LOCK | 锁定课件实物（页数／页序／版本）与本次不改范围 |
| AUDIT | 先跑 §0「不读教学设计」的取材核对与 `scripts/pptx_text.py` 逐页抽文，报页数与来源 |
| EXECUTE | 按审过的页序写，不跳页、不改课件、不夹带教材页码 |
| VERIFY | 跑 `scripts/audit_script.py`（或按 §9 说明报「未验证」），贴出 ERROR／WARN 计数 |
| DONE | 只有 VERIFY 有输出才可报「稿已写完」；**不得用「已核对」代替机检输出** |

规则改动前后必跑体检：`python3 ~/.workbuddy/skills/teaching-ppt-workflow/scripts/rule_audit.py`（FAIL 先修）；治理细则、单点定义表与权限边界见 `teaching-ppt-workflow/references/self-maintenance.md`，本技能不另立治理流程。

## 0. 一条铁律，五条不许，一条必须

**铁律：课件是唯一依据。** 稿里的每一页、每一问、每一个清单条数、每一句板书，都能在课件对应页上指认出来；
课件上没有的内容，一句都不写。

1. **不读教学设计来定稿**——不用它页码、不用它环节分钟、不用它 S 栏动作当检查项。手上只有课件就去写。
2. **不改课件**——页序、问句、词表、图都不动；发现错字只报告。
3. **不跳页不添页**——课件多少页，稿就多少页，顺序一致；页标题、页面问句要对得上。
4. **不带教材页码**——台词与操作提示严禁出现教材页码数字（如“翻到第85页”），统一用“课文开头”“第2自然段”“课后第一题”或关键语句定位，违者机检报 ERROR。
5. **不留备份副本**——重写就地在课题根目录 `<课文>-<课时段>-逐字稿-源.md` 上改，不另存 `-旧版`、不建 `备份-<日期>/`、不打 zip。要回退靠系统废纸篓与 git（用户 2026-11-06 裁定；逐字稿源稿是唯一真身）。**拿不准时先问用户：拉一份副本再改，还是直接在源文件上改？**
6. **必须把课件本身的缺陷列出来**：位置 ＋ 现象 ＋ 建议，三样齐全，不替课件补页、不替它改字。
   **缺页、错字、错误引文、素材缺失这类影响授课的严重缺陷未处理前，不得宣称“验收完成”**，
   只能报“稿已写完，待课件修订”。课件解析不了同理，按「未验证」上报，不按「通过」上报。
   （依据 `script-spec.md` 2.3、二十、二十三）

允许的补充只有：课堂常规语言、自然过渡、即时反馈、组织秩序的提示（4.2）。

**与旧技能冲突时以本技能为准（2026-11-07 用户裁定）**：`codex-skills/teaching-ppt-workflow` 的
`lesson-pack-prompts` 仍写“根据已确认教学设计、PPT 大纲及成品课件”写稿与审稿，与本文件 0.1 冲突时
按本技能执行，不掺教学设计；同一页出现两种切分方式时也不表决，直接按课件页走。

## 1. 开工前要拿到三样东西

| 要拿到的 | 怎么拿 | 用途 |
|---|---|---|
| 每页屏幕内容（**唯一骨架**） | `python3 ~/.workbuddy/skills/lesson-transcript/scripts/pptx_text.py <课件.pptx> [--notes]`；**图片页、图表页、组合形状页必须把页面渲染成图逐页看** | 页数、页序、页标题、问句清单、词表／写字表／作业项、图上有什么 |
| 课文原句 | 教材 PDF 或用户给的原文 | 引文、多音字、动词串只能照教材 |
| **历史复盘台账（开工必读）** | 直接读 `references/lessons-learned.md` 的「生效条目」 | 把过去被指出的问题变成本课防复发清单，不靠记忆 |

按触发条件挑出本课适用的条目，交付前逐条答「是／不适用」；冲突时按日期更新的条目执行。

教学设计不是开工材料。用户主动给了就读，但**只用来理解课件为什么这么排**，
读完仍按课件写、按课件查（2.1、2.4）。

**文字抽取不等于看过页面**：`pptx_text.py` 只读 `<a:t>`，图内文字、图表数值、SmartArt、
组合形状里的字一律抽不到；只看抽取结果就写稿，必然漏掉页面上真实存在的提示与任务。

### 先锁定来源（2026-11-08 增补）

动笔前把这六项抄进交付说明顶部，缺哪项就向用户要，**不靠推算补齐**：

| 必须锁定 | 防的是什么 |
|---|---|
| 课题 ＋ 课时 | 第一、第二课时混用 |
| 课件文件名 | 教师真正要上的不是这一份 |
| 页面总数 | 拿制作笔记里的页数当依据，写出来对不上 |
| 文件修改时间或校验值 | 课件被换过，稿子还按旧版写 |
| 有效页序 | 隐藏页、重复页造成整册错位 |
| 逐字稿源稿路径 | 改错文件、覆盖别的课 |

课件换过就先复核受影响页，只重写这几页，不必整份重来。

**没有课件文件就别写稿**：按 ①用户导出的 `pNN.jpg` 逐页图 → ②可画／PPT 链接截图 → ③向用户索取，
三条都走不通就停在这里说明原因，**绝不按页数推算页面内容**（那是编造，不是写作）。

## 2. 四段工作流（对应 spec 第 23 章九步；复盘闭环见 §7）

### 开工前置：读台账

读 `references/lessons-learned.md` 的「生效条目」，按触发条件挑出本课适用的；
复发条目置顶，须先按 §7 加固已有规则。没读就动笔，等于把上次被指出的错再犯一次。

### 第一段 对读与动笔前推演（第一步～第三步）

1. 抽课件文字，逐页记：**页标题 / 问句（含编号）/ 固定清单条数 / 图上内容**。
2. 动笔前沙盘推演：
   - **推演支架时钟**：支架是引导还是结论？引导任务先出，结论范例必须在同桌或独立思考后点击出示，严禁提前亮屏剥夺学生思考；
   - **推演因果逻辑**：概念分类是否严密，严禁把“感受/影响”与“成因/依据”混为一谈；
   - **推演扣除时间**：大任务扣除学生纯动笔或默读后，剩余交流汇报时间是否真实充裕，拒绝在 1 分钟内塞入 5 项操作的虚假繁荣。
3. 把课件页摊成一列，先定“哪几页是一件事”，再给每页分时间（第 4 节）。
4. 建对应表：`课件页 → 页主题 → 稿页起止 → 该页做什么`，一行一页（见 playbook 第 2 节）。
5. 页数与页序对上、推演闭环之后才算可以动笔；对不上先报告，不写。

### 第二段 写稿（第四步～第五步）

按页写，每页五项：〔操作〕→ 师（任务与提问）→ 生／〔学生可能说〕→ 师（反馈、追问、点拨）→〔板书〕。
其中**〔板书〕按需**：这页没有板书任务就不写，不硬凑一栏；板书内容只能来自课件板书区或用户给的板书图。
要点：

- 页标题取课件该页的标题原话，不另起文雅名字；课件页没有标题就用其内容主题，别造。
- 页面问句就是稿子的问句，编号也要对得上；课件四问就写四问，不合并、不换问。
- 页面上的任务提示（画出／补记／选一句读／与同桌说说）必须在〔操作〕里落地，不能只在屏幕上躺着。
- 不念屏幕全文（5.5）；图片页先让学生看画面再说话（5.3）。
- 学生预设一律 `〔学生可能说〕`，写成可能而非事实（8.1）；四年级的回答要说四年级的话（8.2）。
- 评价落到具体表现：“你找到了关键句子”“你不仅说想法，还找了依据”（9.1）。
- 一次一问，不把“找句子＋解词＋说感受＋讲道理”堆在一句里（7.2）。
- 过渡从上一个答案里长出来，不喊“进入下一个环节”（12.1）。
- 涉及动物、器材、实验，按课件页面提示写安全提醒（13.5）。
- **【正文纯净｜引用唯一归属】**：模块白名单与源稿纯净要求按 `teaching-ppt-workflow/references/lesson-pack.md`「全包源稿纯净化与去 AI 味铁律」执行；逐字稿只承载当堂师生对话与课件操作，此处不另立口径。

### 第三段 自检（第六步～第七步）

**三轮，各查各的，不能互相替代**：

| 轮次 | 时机 | 只查这几件 |
|---|---|---|
| 逐页 | 写完一页立刻 | 本页问句、任务、台词、学生实践、页时长；发现错就改这一页，不留到后面 |
| 整课 | 全稿写完 | 跨页衔接、重复讲解、语气是否一致、40 分钟分配、对应表是否回填 |
| 口语通读 | 交付前 | 站在上课教师的位置念一遍：说得出口吗、学生听得懂吗、有没有长段独白与自问自答 |

跑机器校验，再人工过 `script-spec.md` 十九 A–G 六类清单（45 条）：

```bash
python3 ~/.workbuddy/skills/lesson-transcript/scripts/audit_script.py \
  <源稿.md> --pptx <课件.pptx> --total 40 --images <assets/ppt-第N课时> \
  --board-keys <列名1,列名2>
```

`<…>` 是占位符，**没换成本课的实际值就是错**——直接抄上一条命令的路径，等于检查了别的课。

`--pptx` 一次校验四件事：页数是否与课件相等、页标题是否对得上、课件问句是否被漏讲、
稿里写的“依次出现／飞入／淡入”是否真有动画（5.4）。
`--board-keys` 可选，核对〔板书〕有没有漏掉板书设计图的列名（板书图是独立素材，不是教学设计）。

**脚本没有 `--acts`，也不要为了“看起来严谨”去找教学设计补一个**——逐字稿不按教学设计判定。

**结果分三态，不许混用**：

| 状态 | 含义 | 怎么处理 |
|---|---|---|
| ERROR | 必须修 | 漏页、页序错、改课件问句、编内容、知识错、时间矛盾、虚构动画 |
| WARN | 必须逐条判断 | 台词冗长、评价重复、活动偏紧、过渡生硬、疑似念屏——每条写下结论 |
| **未验证** | 缺依据，不得冒充通过 | 没课件、课件解析失败、图片没看、脚本没跑、源稿版本不明 |

`--rate` 默认 4.0 字/秒，可用 `--rate 3.5` 按实际语速复核；报表会同时给 4.0 与 3.5 两档台词占用，
按哪一档都装不下，就是真的超了，不要靠调快语速糊过去。

**这几条规则是从实际审稿事故里长出来的，
动画虚构、回指虚构、页首“翻页前”、问句换说法都是当时漏掉的，不要图省事省参数。**
`[复盘]` 在同一次校验里检查台账条目是否写全、是否超量，并在末尾打印仍生效的防复发检查项；
读不到台账记「未验证」，不得记作已复核。`--no-lessons` 仅供脚本调试。

### 第四段 交付（第八步～第九步）

- 只交正式稿，不附教学理念、不附设计复述、不附 PPT 建议（十七 输出限制）。
- 课件本身的缺陷单列一段：哪一页、缺什么、建议怎么补（不代它补）。
- 交付话术：固定五列——页数｜总时长｜每页时间｜课件缺陷｜本次改动；末尾再加两行留痕：
  ①机检结论（ERROR n／WARN n／未验证 n，贴脚本输出原行，含 `[复盘]` 区）；
  ②人检结论六项——语言自然度、学生回答真实度、活动能否真做、引文准确、缺陷处理、是否已口语通读
    ＋ 防复发清单逐条结论 ＋ 本次加固了哪条已有规则。
  没做的项写“未做”，不写“已检查”。

用户指出问题时按 §7 在同一轮内归档；有未归档条目不得宣称交付完成。

## 3. 源稿契约（必须长成这样，排版引擎才认）

路径与命名：课题根目录 `<课文>-<课时段>-逐字稿-源.md`（如 `牛和鹅-第二课时-逐字稿-源.md`）。
排版成品名由 `lesson-typeset` 自动推导为 `<课文>-<课时段>-逐字稿.docx`，不带课文编号数字。

```
# 20 牛和鹅 · 第二课时 逐字稿          ← 主标题
小学语文 · 四年级上册 · 第二课时（40 分钟）  ← 副标题行
## 使用说明                            ← 固定四段：按课件顺序／行首标记／时间依据／页数对应
### 第二课时　理解认识变化…              ← 课时主题
## 第 1 页 · 封面：理解认识变化｜0:00—0:20   ← 页标题：页码 · 课件页标题｜起—止
〔操作〕出示第 1 页…
师：…
生（齐）：…
〔学生可能说〕…
〔板书〕…
```

| 行首标记 | 渲染 |
|---|---|
| `师：` / `师（指名）：` | 教师台词（最重）；括号里可写任意短标注 |
| `生（齐）：` | 全班齐答／齐读 |
| `生（部分）：` / `生（全体）：` | 部分或全体学生；渲染同学生台词，**括号后必须有冒号** |
| `生：` | 个别学生 |
| `〔操作〕` | 课堂操作／翻页／巡视 |
| `〔学生可能说〕` | 预设回答，弱化显示；**严禁简写为〔学生说〕** |
| `〔板书〕` | 板书记录 |
| `〔停顿〕` | 等待、思考提示 |

**标记格式硬铁律**：必须使用标准六角括号 `〔〕`，禁止使用方括号 `【】` 或英文括号 `[]`；标记与学生台词之间必须是半角或全角冒号；写成 `生（部分）不能。` 会被排版引擎当成正文，
字号与缩进随即塌陷（2026-11-07 在《一只窝囊的大老虎》一课时 p7 上出现过）。`audit_script.py` 会对畸变标记直接报警拦截。

时间写法固定 `0:00—0:20`（半角冒号、全角破折号），不写“约 1 分钟”充当区间。

---

## 4. 时间怎么算（唯一算法）

1. 总长 ＝ 课时长（小学常规 40 分钟）；**按课件页分，不按教学设计的环节分**。
2. 先看课件哪几页是同一件事，把 40 分钟按“内容分量”分块，块内再分到页。
3. 单页时长 ≈ 台词字数 ÷ 4.5 字/秒 ＋ 学生活动时间（默读、圈画、书写、同桌交流都要真给时间）。
4. 页区间首尾相接：上页止 ＝ 下页起；首页 `0:00`，末页止 ＝ 课时长。
5. **正文里自述的“约 N 分钟”必须与页区间一致**——这是最常出现的自相矛盾
   （例：页给 3.5 分钟，正文却写“不要求大家在这五分钟里”）。
6. 一页只对课件一页，装不下就砍话，不并页、不拆页。
7. 时间不够时先砍重复的教师语言和空评价，不砍学生实践，不虚构成“极快节奏”（11.5）。

## 5. 只审不改（用户拿已有稿来查时）

1. 先出对读表与问题表，不改文件。
2. 每条问题带位置、现象、依据、建议（playbook 第 6 节）；依据只能是课件页与教材，不能是教学设计。
3. 用户说“改”再动手；改动只限语言与页内结构，不改变页序、页数与目标。
4. 改完重跑校验，报出页数、总时长、图数三项前后对比。

- [ ] 页数 ＝ 课件页数，页标题逐页一致，页序无误；使用说明里“共 N 页”与实际页数一致
- [ ] 课件该页的每句问话都在稿里落地，问法与课件一致（不是换成自己的说法就完事）

- [ ] 页面任务提示（画出／补记／选一句读／与同桌说说）都在〔操作〕里有对应，不只在页面上躺着
- [ ] 凡是师生有对话的页都有〔操作〕，页面任务落到了操作上（脚本〔结构〕检查）

- [ ] 写“刚才有人说”的，前文真有学生说过那句话
- [ ] 页首没有“翻页前／上一页”这类刚翻页却指向上一页的话

## 7. 自我进化：先加固，后新增（2026-11-08 用户裁定）

**核心口径**：用户指出问题，不是「再写一条规则」的信号，而是「已有哪条规则没拦住」的信号。
优先把已有规则改硬（表述、触发条件、机检强度），**让技能变准而不是变长**。

### 7.1 归档动作（同一轮内完成）

用户任何纠错、质疑、撤回，以及事后发现的同类复发，都触发本节；自己复核发现的错也补记。

1. 复述问题、就地改源稿（不建副本，§0.4）。
2. **定位失效的已有规则**：在 §0／§6／spec 与 `audit_script.py` 标签里找本该拦住它的一条。
   找到 → **改硬它，不新增条目**，只在台账对应条下追加一行「事故佐证：课题＋页＋原话」；
   确属规则空白 → 才按台账模板新增一条，且须同时合并或归档一条旧条目。
3. 台账条目必写「当时的想法／漏检原因／正确口径／加固动作／防复发检查项」，用户原话照录；
   缺任一项，`audit_script.py` 报 `[复盘]` ERROR，不许交付。
4. 重跑 `audit_script.py`（带本课真实参数）；新增机检项的，拿本课出错原句做回归，确认能报出来。
5. 回报：改硬了哪条规则、台账编号、下次怎么防。只回「已修改」不算完成。

### 7.2 三道硬化点（不另立工具、不复制规则）

| 约束 | 落在哪 | 怎么触发 |
|---|---|---|
| 必填思考、总量上限 | `audit_script.py` `[复盘]` | 缺字段 → ERROR；生效条目 > 8 → WARN 要求合并 |
| 开工必读、交付必答 | 本文 §1／§2／§6 | 读台账 → 防复发清单 → 交付逐条答「是／不适用」 |
| 口径效力与验收 | `script-spec.md` 二十四 | 台账口径等同 spec；有未归档反馈不得验收 |

**复发**：同类问题第二次出现，说明上次只是「加了规则」没「改硬规则」——把对应机检标签升为 ERROR
或把口径写进 §0，在台账该条标「复发」，**不再另立新条**。

**收敛硬指标**：生效条目 ≤ 8；同一件事只在一个文件写一次；归档一条前先问能否并入已有条款，
确需新增文本时必须同时删掉等量的冗余描述，不让技能靠复盘越变越长。
判断依据始终是课件与教材——复盘优化的是「怎么把课件讲准」，不是给稿子加内容，也不是给技能加章节。
