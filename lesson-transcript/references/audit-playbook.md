# 对读与时间核算操作规程

> 本文件是 `script-spec.md` 的执行版：把「**逐字稿完全匹配课件**、设计只作背景、时间真实」三条
> 落成可重复的检查动作。规范说“要对应”，这里说“怎么查出来”。
> 2026-11-07 用户裁定：**课件为主**，教学设计降为背景参考（`script-spec.md` 2.4）。
> 2026-11-06 在《牛和鹅》两课时（各 18 页课件、40 分钟）上实测通过。

---

## 0. 三方事实来源（按权威度排序）

| 事实 | 取自 | 不可替代的原因 |
|---|---|---|
| 屏幕上有什么 | 成品课件 pptx（逐页 `<a:t>` 文字＋图片） | **第一权威**：页码、页序、页标题、问句、词表、作业项都以课件为准 |
| 课文原句 | 教材 PDF／课文原文 | 引文、多音字、动词串只能照教材 |
| 教什么、几分钟 | 教学设计源稿（环节／活动的括号分钟数） | 只决定时间分配与组织方式，不决定页面内容 |
| 稿子怎么讲 | 逐字稿源稿 | 只允许是上面三者的口语实现，且必须逐页咬住课件 |

冲突时按 `script-spec.md` 2.4 裁定：**课件与设计不一致，照课件写，把冲突列出来**；
不改已确认材料，也不为迁就设计写出课件上没有的内容。

## 1. 抽课件文字（先拿到“画面事实”）

```bash
python3 ~/.workbuddy/skills/lesson-transcript/scripts/pptx_text.py 牛和鹅-第一课时-课件.pptx
```

- 输出「第 N 页：文字…」，页码即播放顺序，可直接当稿页标题的来源。
- 加 `--notes` 一并输出备注页，加 `--json` 供后续比对。
- 只读 pptx 包内 XML，不改文件；97MB 的课件也是一秒出结果。

拿到后逐页记三样东西：**页标题、页面上的问句（含编号）、页面上的固定清单**（词表／
写字表／作业项／板书条数）。这三样是后面查漏的依据。

---

## 2. 抄活动分钟表（时间核算的基准）

从教学设计里把所有带括号分钟数的活动抄成两列表：`环节 → 活动（分钟）`。
环节分钟数之和必须等于课时总长（如 3+12+5+6+11+3=40）。抄完先自查一遍加法，
再看每个环节内部活动之和是否等于该环节分钟数——设计本身对不上时，先报告，不改稿。

---

## 3. 建对应表（本技能的核心动作）

一行一页，六列：

| 页 | 稿页标题 | 起—止 | 时长 | 归属活动 | 该页课件上的问句／清单 |
|---|---|---|---|---|---|
| 4 | 走进童年故事 | 3:00—8:00 | 5.0 | 二·自主阅读(5) | 自主阅读四条要求 |

规则：

1. 课件页数 ＝ 稿页数，一页不跳、不加、不调序（`script-spec.md` 4.0）。**页标题直接取课件该页的标题原话**，
   课件页无标题时取内容主题，不另起文雅名字。
2. 一页可以装一个环节里的多个小步骤，但不许跨两个环节。课件页与设计环节本来就错位时（某环节在课件无承载页），
   按课件排，把错位列进交付说明，不拆页不增页。
3. 页时长必须能装下：教师台词字数 ÷ 约 4.5 字/秒 ＋ 学生活动时间。
4. 页区间首尾相接：第 N 页的止 ＝ 第 N+1 页的起；首页 0:00，末页止 ＝ 课时长。
5. 建表时先只填「课件页」两列（页标题、问句／清单），再往右填设计与时间——**左边填不出来，右边不许动笔**。

## 4. 机器校验

先把活动表写成 JSON（起止用 `分:秒` 或 `时:分:秒` 都认）。`must` 写该活动设计 S 栏里
学生必须真做的动作词——这是唯一能把“设计里写了、稿子里没做”查出来的钩子：

```json
[
  {"name": "二·自主阅读", "start": "0:03:00", "end": "0:08:00", "must": ["字表", "批注"]},
  {"name": "五·填写前三项心情", "start": "0:23:00", "end": "0:32:00",
   "must": ["同桌", "核对", "我从"]}
]
```

`must` 的选词口径：选**设计 S 栏里能一眼判定的动作词**（同桌、核对、默读、动笔、作记号、
听写、自查、退出票），不选泛词（“参与”“思考”）。词要能在稿里原样出现；稿子改写了就换词，
不要为了过检查去改稿子。**`must` 只反映设计的组织方式，缺了报 WARN 不报 ERROR**——
因为第一权威是课件，设计里的动作若在课件没有承载页，是可以不做的。

```bash
python3 ~/.workbuddy/skills/lesson-transcript/scripts/audit_script.py \
  .workbuddy/牛和鹅-第一课时-逐字稿-源.md \
  --acts acts-1.json --total 40 --images assets/ppt-第一课时 \
  --pptx 牛和鹅-第一课时-课件.pptx --board-keys 事情,心情,原因
```

报什么：

| 标签 | 查什么 | 级别 |
|---|---|---|
| `[课件]` | 稿页数 ≠ 课件页数 | ERROR |
| `[课件]` | 稿页标题与课件该页标题对不上（无 2 字以上公共片段） | WARN |
| `[课件]` | 课件该页的问句在稿该页找不到（漏问／换了问法） | ERROR |
| `[页数]` | 使用说明“共 N 页”＝ 实际稿页数 | ERROR |
| `[时间轴]` | 页号 1…N 连续、首尾相接、首页 0:00、末页＝课时长 | ERROR |
| `[活动]` | 每页落在某活动内；跨相邻活动 WARN，跨 3 个以上 ERROR | ERROR／WARN |
| `[时间]` | 页内〔操作〕时长 ＋ 教师台词朗读时长（4.5 字/秒） ≤ 页时长（＋0.8 分钟容差） | WARN |
| `[时间]` | 纯操作时长 > 页时长 ＋0.3 分钟（学生活动本身就塞不进这一页） | WARN |
| `[时间]` | 学生活动合计占课时 < 40%（规范 10.3 不用讲解替代实践） | WARN |
| `[时间]` | 正文自述“约 N 分钟”超过页区间 | WARN |
| `[PPT]` | 稿写“依次出现／逐个出现／飞入／淡入／自动出现”，课件该页无 `<p:timing>` | ERROR |
| `[回指]` | 稿写“刚才有人说‘X’”，前文学生台词里没有 X 的任何 4 字片段 | ERROR |
| `[指代]` | 页首两行出现“翻页前／上一页／前一页” | WARN |
| `[数字]` | “找出 N 处”与“M 处都找到了”不一致；“听写 N 个字”与词表字数不一致 | WARN |
| `[标记]` | 行首 `师`／`生` 后缺冒号或括号未闭合（排版会当正文） | WARN |
| `[背景]` | 活动的 `must` 词在覆盖该活动的稿页里找不到（设计动作未落地，课件无承载页时可接受） | WARN |
| `[板书]` | 〔板书〕各行合起来没覆盖 `--board-keys` 给的列名 | WARN |
| `[配图]` | 截图张数 ≠ 稿页数 | ERROR |

**有 ERROR 就不算完成**；WARN 要逐条判断后再交付。判断口径：
- `[活动] 跨相邻活动`：设计里两个活动在课件上没有独立页、只能并行，属材料结构问题，交付时说明；
- `[时间]`：要么砍重复的教师语言，要么把操作时长写成真实值，不许两头都留。

### 这些规则是怎么来的（2026-11-07 两批事故记录）

**第二批（口径变更后：课件为主）**——用户裁定「逐字稿服务于课件，必须完全匹配」，

|---|---|
| 课件问“'我'为什么怕老师改变主意”，稿问“在担心什么”（换说法） | `[课件]` 问句覆盖 |

## 5. 内容对读（机器查不出的五类，必须人工过一遍）

按页对读「课件问句 ↔ 稿页问答」，重点抓这五类，它们最常漏：

| 类型 | 表现 | 判据 |
|---|---|---|
| **多写** | 稿里说“屏幕上／页面上有……”，课件该页根本没有 | 逐句指认：指认不出的删，或改写为教师口头补充 |
| 漏项 | 页面上有 4 条，稿子只讲 3 条（课后作业、写字表、自查条数最常漏） | 页面清单条数 ＝ 稿中讲到的条数 |
| 换问 | 稿子把课件第 3 问换成了别的问题，或与前面页重复 | 课件每一问都要在本页得到正面回答 |
| 错字 | 课件与课文／设计不一致（如“被捉起来”应为“提起来”） | 以教材原句为准，课件错就报，不迁就 |
| 板书 | 稿中〔板书〕条数少于板书设计图／课件收束页 | 板书图与课件阅读感悟几条，稿就几条 |

**「多写」是 2026-11-07 新增的首要一类**：稿子为了贴合教学设计而虚构屏幕内容（写“四个阶段依次出现”、
写页面上没有的栏目），是最隐蔽也最伤课堂的一类错——教师上课会照着找，找不到就打乱节奏。

另外三处固定核对：**封面页课题与课时号**、**使用说明里的页数与实际页数**、
**跨课时衔接**（上一课时课后任务是否指向下一课时第一页要复习的内容）。

## 6. 排版后复查（图文同页）

稿子交给 `lesson-typeset` 落地后，再查一次：

```bash
soffice --headless --convert-to pdf --outdir /tmp/chk 牛和鹅-第一课时-逐字稿.docx
python3 -c "import pymupdf,re;d=pymupdf.open('/tmp/chk/牛和鹅-第一课时-逐字稿.pdf');print(d.page_count);[print(i+1,len([x for x in p.get_image_info() if x['width']>600])) for i,p in enumerate(d)]"
```

- 内嵌大图数 ＝ 稿页数（18 页稿 → 18 张图）；
- 每张图与它的「第 N 页」标题同页；
- 无空白页、无孤图。

## 7. 报问题的口径

一条一行，四要素：**位置 → 现象 → 依据 → 建议**。

> 例：第二课时 p12 ｜ 稿子第 3 问是“后来态度有什么变化”，课件第 12 页第 3 问是
> “金奎叔改变了‘我’原来怎样的看法” ｜ 依据：课件页原题 ｜ 建议：按课件四问补齐，
> 态度变化另作第 4 问。

- 不擅自改稿、不改课件、不改设计；先把表贴出来，用户确认后再动手。
- 属于材料本身冲突（设计写 5 分钟、稿子按 3.5 分钟算）时，明确说是“哪一份材料的问题”。
